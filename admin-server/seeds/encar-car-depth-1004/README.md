# 엔카 승용 뎁스 · 다나와 매핑 데이터 (2026-10-04 수집)

모든 CSV는 UTF-8(BOM) 쉼표 구분, 1행은 헤더.

## 1. encar_car_depth_all_1004.csv — 엔카 승용 전체 뎁스 (7,504행)
엔카 승용 제조사 63개(국산 7 · 수입 56), 매물 198,212대 기준.

| 컬럼 | 뜻 |
|---|---|
| 순번 | 행 번호 |
| 국산/수입 | 국산 / 수입 |
| 제조사 | 엔카 Manufacturer 값 (예: BMW) |
| 1뎁스 모델그룹 | 엔카 ModelGroup (예: 5시리즈) |
| 2뎁스 모델(세대) | 엔카 Model (예: 5시리즈 (G60)) — 괄호 안이 세대코드 |
| 3뎁스 연료·구동 | 엔카 BadgeGroup (예: 가솔린 2WD) |
| 4뎁스 등급 | 엔카 Badge (예: 520i M 스포츠) |
| 5뎁스 세부등급 | 엔카 BadgeDetail (일부 제조사만, 없으면 빈칸) |
| *_매물 | 각 뎁스의 매물 수 (수집 시점 값, 매일 바뀜) |

- 한 행 = 가장 아래 뎁스 1개. 상위 뎁스 값은 행마다 반복 기재.
- 키: (제조사, 1뎁스, 2뎁스, 3뎁스, 4뎁스, 5뎁스) 조합이 유일.

## 3. bmw_encar_danawa_trim_map_1004.csv — BMW 엔카 등급 ↔ 다나와 트림 (709행)
| 컬럼 | 뜻 |
