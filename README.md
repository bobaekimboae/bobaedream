# CARVID AI Studio

보배드림 딜러가 중고차 사진과 차량 정보를 이용해 세로형 매물 광고 영상을 제작하는 숏폼 스튜디오입니다.

## 주요 기능

- 내 매물·판매 URL·직접 입력 방식의 차량 정보 등록
- 사진 순서 변경과 9:16 숏폼 장면 구성
- 15초·30초·60초·90초 영상 길이 선택
- 한국어 차량명·가격·주행거리 발음 전처리
- 캐릭터별 음성 선택과 겹침 없는 미리듣기
- 직접 등록한 음원, 배경음악, 자막을 포함한 영상 구성
- 프로젝트 임시 저장 및 재편집
- 모바일·PC 반응형 편집 화면

## 실행 환경

- Node.js 22.13 이상
- npm
- Linux 권장

## 로컬 실행

```bash
npm ci
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인합니다.

```bash
npm run build
```

## 환경 변수

필요한 값은 `.env.example`을 복사해 `.env.local`에 입력합니다. 인증값과 API 키는 Git에 커밋하지 않습니다.

## 기술 구성

- Next.js / React / TypeScript
- Vinext / Vite
- Cloudflare Workers
- Cloudflare D1 / Drizzle ORM
- Cloudflare R2

## 현재 음성 운영 방식

현재 공개본은 API 키 없이 사용할 수 있도록 기기 내장 한국어 음성을 미리듣기에 사용합니다. 사용자가 직접 등록한 MP3·WAV와 기본 샘플 음원은 영상 구성에 사용할 수 있습니다. 서버 TTS는 추후 한국어 모델 또는 상용 API를 연결하는 구조로 분리되어 있습니다.

## 라이선스와 운영 주의

차량 이미지·샘플 영상·브랜드 자산은 서비스 검증용입니다. 외부 배포나 상업 운영 전 각 자산의 사용 권한을 확인해야 합니다.
