# 게시물 등록폼 보완 보고서

작성일: 2026-10-15

## 완료 내용

- 모바일에서 사진 아래에 생기던 분홍색 전폭 선을 제거했다.
  - 원인: 편집기 전체 `contenteditable`에 공통 `focus-visible` 외곽선이 적용됨.
  - 처리: 본문 편집기만 공통 외곽선 대상에서 제외하고 버튼·입력·사진 캡션 포커스 표시는 유지.
- 게시판 선택 목록을 보배드림 커뮤니티 체계로 교체했다.
  - 자유게시판, 국산차 오너톡, 수입차 라운지, 전기차, 정비 · DIY, 튜닝, 중고차, 보험 · 사고, 블랙박스 제보, 바이크.
- 게시판별 말머리 선택을 추가했다.
  - 게시판을 먼저 선택해야 활성화됨.
  - 말머리 없음을 포함하며 선택값은 임시저장·등록 데이터에 보존됨.
- 투표 만들기 기능을 추가했다.
  - 질문, 선택지 2~10개, 단일/복수 선택, 익명 여부, 1일·3일·7일·제한 없음 마감.
  - 본문 카드 삽입, 수정, 삭제, 임시저장·등록 데이터 보존.
- 게시판·말머리는 기존 49px 한 줄 안에 배치해 제목·도구막대·본문 위치가 밀리지 않도록 했다.
