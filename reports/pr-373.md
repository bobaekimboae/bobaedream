# PR #373 바이크 딜러·매매단지 제거, 가상 바이크샵 이름

① 바이크에는 딜러와 매매단지가 없어서, 업체 매물은 가상 바이크샵 이름으로 바꾸고 위치는 시도 구군까지만 쓰게 했다.

② 과제 ID 미지정 · 브랜치 `feat/qf-bike-shop-names-1010` · PR(번호는 채팅 보고에 적음) · 상태 병합·배포 · 함께 들어간 과제 없음

③ 한 일
- 바이크 업체 매물의 판매자 이름을 `김민준 딜러` 같은 사람 이름 대신 가상 바이크샵 이름 40곳(`라이드온 바이크샵`, `모토파크`, `신호등 바이크샵` 등)으로 바꿨다. 매물 번호로 정해서 같은 샵이 여러 매물을 올린다. 실존 상호와 무관하게 만든 이름이다.
- 바이크 위치에서 매매단지를 뺐다(`경기 김포시 · 국민차(공항점)` → `경기 김포시`). 개인은 그대로 `개인판매자` · 시도 구군이다.
- 다른 카테고리(트럭·건설기계·캠핑카·자재운반장비·부품)의 딜러·단지 표시는 그대로다.
