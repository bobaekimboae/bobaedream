# 모바일 하단 푸터 잘림 점검

## 화면과 흐름

1. 첫 화면 기존 상태 — 주의 필요
   - 384×832px에서 `매물등록` 라벨 아래 여백이 4px뿐이라 글자와 pill이 화면 끝에 붙어 잘려 보였다.
   - 증거: `01-before.jpg`.
2. 첫 화면 수정 상태 — 정상
   - 74px 콘텐츠 구조는 유지하고 하단 기본 여백 6px을 추가했다.
   - `매물등록` 라벨 아래 실측 여백은 10px이며 아이콘·라벨·중앙 정렬은 유지된다.
   - 증거: `02-after.jpg`, `03-before-after.jpg`.
3. 목록 끝 실제 푸터 — 정상
   - 페이지 푸터의 마지막 테마 전환 영역이 고정 GNB 뒤에 가려지지 않는다.
   - 스크롤 푸터에도 동일한 총 높이를 예약했다.
   - 증거: `04-footer-end.png`.

## 수정 내용

- 고정 GNB: `74px 콘텐츠 + 6px 기본 하단 여백 + device safe area`.
- 스크롤 푸터: `80px + mobile safe area`만큼 하단 공간 확보.
- 흰색 하단 연장면을 추가해 노치형 배경 SVG와 안전영역 사이가 끊기지 않게 처리.

## 접근성·제약

- 버튼의 접근성 이름과 터치 구조는 변경하지 않았다.
- 스크린샷으로 색 대비나 실제 iOS 홈 인디케이터 충돌까지 완전 판정할 수는 없지만, CSS 안전영역 변수를 포함해 구조적으로 대응했다.

## 결과

- 푸터 잘림: 해결.
- 하단 GNB 시각 균형: 유지.
- 콘솔 오류·경고: 없음.
