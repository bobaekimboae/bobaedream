# 게시물 등록폼 이미지 첨부 기능 보강 보고

## 결론

기존의 “10장·10MB·미리보기·삭제” 수준을 등록폼에서 실제로 사용할 수 있는 이미지 작업 흐름으로 교체했다. PC와 모바일에서 같은 데이터와 기능을 사용하되, 모바일 속성 툴바는 좁은 폭에서 가로 스크롤된다.

## 변경 내용

- 사진 최대 100장, 장당 20MB, JPG/JPEG/PNG/GIF/BMP/HEIC/HEIF/WEBP 지원
- 여러 장 선택, 본문 드래그앤드롭, 클립보드 이미지 붙여넣기
- 정상/오류 파일 혼합 선택 시 부분 성공과 오류 요약
- 대표 사진 한 장 지정
- 작게/문서 너비/옆트임, 왼쪽/가운데/오른쪽 정렬
- 사진 설명 200자, 외부 링크, 교체
- 회전, 좌우 반전, 비율, 필터 편집
- 사진 블록 순서 변경, 삭제 버튼, Delete/Backspace 삭제
- 임시저장 이미지 Blob을 IndexedDB에 보관해 새로고침 후 복원
- 일반 파일 한도를 10개·장당 50MB로 정정
- 사진 기능 자동검사 22개 시나리오 추가

## 남은 서버 연동

현재 페이지는 정적 GitHub Pages 테스트 시안이다. 운영 적용 시에는 객체 스토리지 업로드, 업로드 취소/재시도, 서버 바이러스 검사, 게시물 API 저장을 별도 연결해야 한다. 동영상 파일 업로드도 서버 업로더가 준비된 뒤 같은 진행 상태 컴포넌트로 붙이는 것이 안전하다.
