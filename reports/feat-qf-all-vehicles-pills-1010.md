# 카테고리 시트 전체차량 아래에 모든 카테고리 알약

① `전체차량`을 고르면 그 아래에 `중고차 · 트럭/특장차 · 바이크 …` 카테고리 알약이 보이게 했다.

② 과제 ID 미지정 · 브랜치 `feat/qf-all-vehicles-pills-1010` · 상태 병합·배포(v 값은 채팅 보고)

③ 한 일: `전체차량` 그룹의 하위 알약에 모든 카테고리를 넣고, 시트를 열 때 현재 카테고리와 값이 같은 그룹을 먼저 펼치도록 순서를 고쳤다(중고차에서 열면 중고차, 바이크에서 열면 바이크).

⑤ 검증: `npm run verify:qf` 통과 · 전체차량 아래 알약 8개 표시 · 중고차/바이크에서 열면 각 그룹 표시 · 전체중고차 동작 유지

⑧ 확인 링크: 모바일 `?qf=guazi` → 카테고리 칩(배포본은 `&v=<커밋>`)
