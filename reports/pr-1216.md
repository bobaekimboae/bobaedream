# PR #1216 — 사진 쇼츠 차량 정보 카드 · CLE 아이콘 비교 샘플

① 한 줄 요약: 장금용 딜러 벤츠 CLE 200 카브리올레 사진 쇼츠에 아이콘 6칸 차량 정보 카드를 넣고, 아이콘 2종(오토스카우트24 · 영국 오토트레이더)으로 4편을 만들어 비교 페이지로 배포함.

② 과제 ID 없음 · 브랜치 `shootkit/nuxt-4.6.4` · 커밋 `7818dd1` · PR https://github.com/bobaekimboae/bobaedream/pull/1216 · 상태: main 병합(`047145f`) · 같이 들어간 것: 같은 브랜치의 사진 쇼츠 렌더러 커밋 3개(`b227bae` `6f87e82` `84103b6`)

③ 한 일
- 차량 정보 카드: 최초등록 · 주행거리 · 연료 · 변속기 · 차종/배기량 · 외관/시트 6칸(아이콘 + 라벨 + 노란 밑줄 값). 칸마다 차례로 켜지고 내레이션·자막이 같이 나옴.
- 섹션 칩: 제원 🚘 → 성능점검 🔍 → 보험 이력 💥 순서를 카드 위에 붙임. 카드 머리 제목은 그대로 둠.
- 딜러·상사 칩은 화면 아래에 두고, 카드가 나오는 컷에서는 숨겼다가 마지막 컷에서 크게 다시 보임.
- 아이콘: 노션 「영국_오토트레이더_중고차 기본정보」의 연식 · 주행거리 · 연료 · 변속기 · 바디 타입 원본 SVG와 필터의 「10. 색상」 SVG를 받아 색만 #1A1A1A로 맞춤.
- 고친 것: 문장 사이에 쉼 없이 다음 말이 이어지면 페이드가 시작될 때 자막이 먼저 내려가 0.4초 동안 비던 문제(51.4~51.8초). 쉼이 없을 때는 자막이 페이드가 끝날 때까지 남음.

④ 원본과 비교: 벨기에 오토스카우트24 쇼츠 칩 실측(기울기 약 −2°, 노랑 (244,240,1))을 그대로 유지했고, 이번 작업은 정보 카드 아이콘만 바뀜.

⑤ 검증: check_render 4편 모두 통과(말하는데 자막 없음 0) · 길이 74.7초 · −14.2 LUFS / 피크 −1.3 dBFS. verify:qf는 대상 아님(시안 화면 코드를 바꾸지 않음).

⑥ 원본과 다르게 남긴 것: 오토트레이더 기본정보에는 색상 아이콘이 없어 같은 사이트 필터 아이콘을 씀. 배기량 1,999cc는 같은 모델의 서울오토갤러리 매물 값이라 이 차 매물에서 직접 확인한 값이 아님.

⑦ 못 한 것 · 다음: 이어 붙인 음성은 사람이 직접 들어 보는 검수를 하지 않음. 제원 숫자(EU 기준)는 국내 공식 제원과 대조하지 않음. 카이엔 · MC20에도 같은 설정 적용 예정.
