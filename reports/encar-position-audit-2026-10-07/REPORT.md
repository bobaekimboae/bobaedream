## 결론

- 매물이 있는 7개 모델의 상대 순서는 엔카와 일치한다.
- 엔카 전체 목록에서의 절대 위치는 일치하지 않는다. 우리 DB에는 매물 0대 모델 4개가 없어서 목록이 압축된다.
- 세대의 계층 위치도 다르다. 엔카는 선택한 모델 행 바로 아래에 세대를 들여쓰기하여 인라인 노출하지만, 우리는 별도 `세부모델` 화면으로 이동한다.

| 단계 | 엔카 | 우리 시안 | 판정 |

| 제조사 선택 후 | 모델 목록 | 모델 목록 | 일치 |

| 세대 선택 후 | 검색조건 화면으로 복귀 | `연료·구동` 화면으로 이동 | 설계 차이 |

## 판단

- 데이터 정합성은 통과다. 현재 7개 모델과 세대 key 연결은 맞다.
- 엔카와 위치까지 완전히 맞추려면 `0대 모델 유지`와 `세대 인라인 펼침` 두 변경이 필요하다.
- 다만 우리 시안은 이미지로 세대를 비교하고 연료·등급까지 단계적으로 고르는 목적이므로, 별도 세대 화면을 유지하는 편이 가독성은 낫다.
- 권장안은 현재 뎁스를 유지하되, 매물 0대 모델을 회색 비활성 행으로 원래 위치에 복원하는 것이다. 그러면 엔카의 전체 모델 위치는 보존하면서 0건 화면 진입은 막을 수 있다.

## 현재 데이터 시점 차이

- 엔카 실시간: 전체 209대, 우루스 143대.
- 우리 스냅숏: 전체 208대, 우루스 142대.
- 매물 수는 실시간으로 변하므로 위치 검수와 별도로 스냅숏 갱신일을 표시해야 한다.
