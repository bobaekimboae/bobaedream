# PR #348 모바일 피드 사진 레딧식 스와이프

① 피드 카드 사진을 레딧처럼 옆으로 밀어 넘기게 하고, 아래 가운데 점 알약으로 현재 위치를 보여 준다.

② 과제 ID 미지정 · 브랜치 `feat/qf-m-feed-carousel-1010` · 커밋 e5e5593 · PR https://github.com/bobaekimboae/bobaedream/pull/348 · 상태 푸시(병합·배포 전) · 함께 들어간 과제 없음

③ 한 일
- 사진 칸 안에서 사진이 가로로 한 장씩 넘어간다(한 번에 두 장 넘어가지 않음). 사진을 탭하면 상세로 들어가는 동작은 그대로다.
- 아래 가운데 10px 위에 어두운 반투명 알약(높이 24)을 두고 점을 표시한다. 현재 점은 흰색, 나머지는 흐리게, 현재에서 멀리 떨어진 가장자리 점은 작게 줄인다. 점은 최대 7개이고 현재 점 둘레로 창이 옮겨 간다(레딧 방식).
- 사진 1장짜리 카드는 점을 그리지 않는다. `3분전` 시간 글자는 왼쪽 아래 그대로다.
- **임시 데이터**: 매물마다 사진이 1장뿐이라, 같은 제조사 → 같은 목록 다른 매물 사진을 3~6장 임시 슬라이드로 붙였다. 그래서 슬라이드에 다른 차 사진이 나올 수 있다. `&feedphotos=single`을 붙이면 1장 그대로 보인다.
