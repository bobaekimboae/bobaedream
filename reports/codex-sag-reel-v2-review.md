# 서울오토갤러리 릴스 v2 — 일레븐랩스 음성 · 신차 리뷰 대본

① 한 줄 요약: AI 티 나던 edge-tts 음성을 일레븐랩스 한국어 크리에이터 목소리로 바꾸고, 대본을 신차 리뷰 말투로 다시 썼다.

② 브랜치 `codex/sag-reel-v2-review` · 상태: PR 올림, 병합·배포 전(「배포해라」 대기)

③ 한 일
- 대본을 「오늘 리뷰할 차는… → 사양 → 디자인부터 보시죠 → 실내 → 정리하면」 신차 리뷰 순서로 바꿈(매물 정보·영상에 보이는 사실만).
- 음성: 일레븐랩스 eleven_v4, Mr.J - Korean Creator, 2테이크 생성(테이크당 428크레딧 ≈ $0.086) 중 1번 사용.
- 일레븐랩스 받아쓰기(scribe)로 낱말 96개 시각을 받아, 대본 글자와 맞춰(`align_external`) 자막·컷을 말에 맞춤. `SAG_VOICE_FILE` · `SAG_VOICE_WORDS`로 외부 음성을 넣는 방식이라 구글 TTS도 같은 자리에 넣을 수 있음.
- 샘플 페이지 영상·포스터·대본 줄·만드는 방식 갱신.
