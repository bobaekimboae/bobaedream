# 보배드림 커뮤니티 글쓰기 — 네이버 기능 전수조사·보완 보고

- 조사일: 2026-10-15
- 비교 기준: 로그인된 네이버 카페 모바일 웹 글쓰기 화면
- 대상: `public/community/naver-write-parity.html`
- 원칙: 네이버 상표·전용 스티커·비공개 API는 복제하지 않고, 동일 목적의 자체 UI와 라이선스가 확인되는 오픈소스만 사용

## 1. 결론

기존 시안의 핵심 약점은 텍스트 편집기였다. 네이버 실제 화면은 글꼴 9종, 글자 크기 10종, 정렬, 글자색, 배경색, 본문/인용구를 제공하지만 기존 시안은 임시 글꼴 3종과 크기 4종만 있었다. 이를 실제 선택 영역에 적용되는 기능으로 교체했다.

게시물 설정도 네이버 실제 구조처럼 `게시물 검색 허용`을 먼저 보여주고, `카페 · 블로그 스크랩 허용`과 `복사 · 저장 허용`은 `상세설정`을 펼쳤을 때 나타나도록 수정했다. 주요 등록·추가·완료 버튼은 에어비앤비 계열의 검정 `#222`로 통일했고, 삭제·오류처럼 위험을 알리는 색만 빨강으로 유지했다.

## 7. 남은 제품 결정

정적 시안에서 구현 가능한 작성 기능은 모두 넣었다. 다음 단계는 기능 누락이 아니라 서버 제품 결정이다.

1. 실제 게시물 업로드 API와 권한 정책
2. 실제 동영상 미리보기 제공자 허용 목록
3. 장소 검색 API 공급자와 지도 약관
4. 바이러스 검사·첨부파일 영구 저장소
5. 게시물 공개 범위별 실제 열람 권한

이 다섯 항목은 API·백엔드 정책 확정 후 별도 작업해야 한다.
