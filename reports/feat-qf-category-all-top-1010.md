# 카테고리 시트 전체 카테고리를 위로

① 시트에서 `전체 카테고리` 알약을 펼친 그룹의 하위 알약보다 위로 올렸다.

② 과제 ID 미지정 · 브랜치 `feat/qf-category-all-top-1010` · 상태 병합·배포(v 값은 채팅 보고)

③ 한 일: 순서를 `전체 카테고리` → 펼친 그룹(예: 중고차의 전체중고차·국산차…)로 바꾸고 두 구역 사이 간격을 20px로 했다.

⑤ 검증: `npm run verify:qf` 통과 · 중고차를 펼쳤을 때 구역 순서 `전체 카테고리`, `중고차`

⑧ 확인 링크: 모바일 `?qf=guazi&category=중고차` → 카테고리 칩(배포본은 `&v=<커밋>`)
