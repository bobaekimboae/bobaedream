# PR #104 QF-120 보완 — 배포본 글꼴 주소 404 수정

## 1. 한 줄 요약
QF-120 병합 뒤 배포본을 점검하다가 글꼴 주소가 저장소 경로(`/bobaedream/`) 없이 만들어져 404(콘솔 오류 15개)가 나는 것을 찾았습니다. 글꼴 폴더를 `public/assets/fonts/pretendard/`로 옮겨 고쳤습니다.

## 3. 한 일
- **원인**: 빌드 기준 경로가 `/`이고, 배포(`deploy-pages.yml`)는 결과물 안의 `/assets/` 글자만 `/bobaedream/assets/`로 바꿉니다. 글꼴 주소는 `/fonts/…`라 바뀌지 않아 `github.io/fonts/…`로 요청됐습니다. 로컬 미리보기는 `/`에서도 파일이 있어 통과했습니다.
- **수정**: 폴더를 `public/assets/fonts/pretendard/`로 옮겼습니다. 주소도 `${import.meta.env.BASE_URL}assets/fonts/pretendard`로 한 줄에 적어, 번들에 `/assets/fonts/pretendard` 글자로 남게 했습니다(→ 배포 때 바뀜).
- **확인**: 배포와 같은 경로 변환(sed)을 로컬 사본에 적용해 `/bobaedream/`로 띄웠습니다. 콘솔 오류 0, 글꼴 PC 17조각 · 모바일 14조각 로드(미리 불러오기 조각이 먼저), 초톳·동처띠 글꼴 파일 요청 0을 확인했습니다.
