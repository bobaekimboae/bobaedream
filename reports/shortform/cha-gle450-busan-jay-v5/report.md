# 벤츠 GLE450 '제이' v5 — 벨기에식 칠 칩 정리판

- 포인터(점·선) 모두 뺌. 부위 이름은 벨기에 원본처럼 노랑 붓칠 칩만, 화면 고정 자리에 띄움
  - 부위가 화면 아래쪽이면 칩은 위(42%대 높이 420px), 위쪽이면(선루프·메모리 시트) 아래(1480px)
  - 칩 6개: 뒷좌석 송풍구 · 센터 터치패드 · 파노라마 선루프 · 메모리 시트 · 헤드업 디스플레이 · 360° 카메라 (말하는 구절 시작 +0.05초, 장면 안에서만)
- 정보칩 3개는 그대로(첫 장면 차명·연식, 끝 장면 보배드림)
- 모든 칩 같은 기울기(반시계 약 2.7°, 벨기에 원본 실측)로 통일 — 들쭉날쭉 없음
- 글꼴: 벨기에 원본 자막·칩이 중간 굵기 산세리프라 한글도 Pretendard ExtraBold → SemiBold로 맞춤(자막·칩 모두)
- 자막 싱크는 v3 그대로
- 렌더러: `render_auto.py` 사양 `be_clean: true`(포인터 없음 + SemiBold + 고정 기울기), 칩마다 `size` 지정 가능
