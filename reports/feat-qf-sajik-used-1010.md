# 사직오토랜드 4대를 중고차에 넣기

① 부산 사직오토랜드 실데이터 4대(볼보 XC40 · XC90 2대 · 벤츠 E클래스)를 중고차 목록에 넣었다.

② 과제 ID 미지정 · 브랜치 `feat/qf-sajik-used-1010` · 상태 병합·배포(v 값은 채팅 보고)

③ 한 일: 도이치오토월드 폴더에 같이 있던 사직 4대의 사진 20장을 흐림 처리해 저장하고, 실제 상사명·딜러명·판매중 대수와 함께 중고차(와 전체차량) 목록에 추가. 위치 `부산 연제구 · 사직오토랜드`, 순서는 지시 매물 3001~3004 다음.

⑤ 검증: `npm run verify:qf` 통과, 중고차 목록에서 4대 표시 확인

⑧ 확인 링크: 모바일 `?qf=guazi&category=중고차`(배포본은 `&v=<커밋>`)
