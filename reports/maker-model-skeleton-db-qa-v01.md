## 화면 반영

- 화면 0~4: 필터 개요 → 제조사 → 모델 → 세부모델 → 연료·구동/등급/세부등급.
- 제조사·모델 검색은 한글명, 영문명, 세대코드를 포함한다. `Mercedes`→벤츠, `W213`→E-클래스 확인.
- 현대 바디타입은 `modelGroups.bodyType`을 사용한다. 9개 이미지 슬롯을 유지하고 DB가 없는 유형은 비활성 표시한다.
- 현대 `REVIEW_REQUIRED` 8개 모델은 행에 `🟡`를 표시한다.
- 세대 연식은 `releaseYm~endYm`, `salesStatus=판매중`이면 `~현재`로 표시한다.
- 이미지 필드가 없으므로 회색 실루엣과 `data-image-key="gen_*.png"` 자리만 만들었다. 존재하지 않는 파일을 요청하지 않아 404가 없다.
- 연료·구동과 등급 묶음 체크는 하위 세부등급을 한 번에 선택하며, 결과 버튼은 선택된 leaf 매물 수의 합계를 즉시 표시한다.
- 선택 칩은 `×`로 해당 단계 또는 등급만 제거한다.
