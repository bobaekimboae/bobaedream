# PR #779 바이크 사이트 로그인 아이콘 주황 제외

① 한 줄 요약: `/bike/` PC 헤더의 로그인 전 계정 아이콘에서 주황을 빼 흰 바탕·회색 아이콘으로 되돌렸고, 우리 파랑이 초톳 파랑과 같은 값인지 확인해 기록했다.

② 브랜치 `claude-consult/bike-login-neutral` · PR https://github.com/bobaekimboae/bobaedream/pull/779 · 상태: 병합·배포(v 값은 채팅 보고 참고) · 함께 들어간 과제: 없음

③ 한 일
- 바이크 테마의 `.bbm-account-avatar` 주황 칠을 `:not(.is-guest)`로 좁혀, 로그인 전 아이콘은 메인 사이트와 같은 흰 바탕 · `#333` 아이콘이 되게 했다.
- `로그인/가입` 알약은 원래부터 흰 바탕 · `#222`라 그대로 두었다.
- 주황은 로고 글자 · 검색 버튼 · `바이크 판매` 버튼에만 남는다.
- 파랑 대조: vieclamtot 주 파랑 `#306BD9` = 우리 `#306BD9`(같음). 마우스 올림만 다르다(vieclamtot는 밝게 `#548AF0`, 우리는 진하게 `#1952BA`). 바꾸지 않고 기록만 했다.
