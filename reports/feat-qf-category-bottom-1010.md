# 카테고리 시트 하단에 전체 카테고리 알약

① 어느 그룹을 펼쳐도(중고차 포함) 시트 맨 아래에 `전체 카테고리` 알약(전체차량 · 중고차 · 트럭/특장차 · …)이 보이게 했다.

② 과제 ID 미지정 · 브랜치 `feat/qf-category-bottom-1010` · 상태 병합·배포(v 값은 채팅 보고)

③ 한 일: 시트의 그룹별 알약(예: 중고차의 전체중고차·국산차…) 아래에 `전체 카테고리` 구역을 추가. 전체차량 그룹은 위 알약이 같은 목록이라 생략. 지금 보고 있는 카테고리가 선택(검정)으로 표시된다.

⑤ 검증: `npm run verify:qf` 통과 · 중고차를 펼쳤을 때 `중고차`, `전체 카테고리` 두 구역 표시

⑧ 확인 링크: 모바일 `?qf=guazi&category=중고차` → 카테고리 칩(배포본은 `&v=<커밋>`)
