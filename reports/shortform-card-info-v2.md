# 숏폼 카드 정보 2차 — 카드 순서 고정 · 차량 이력 타임라인 · 차량 편집에 1~N장 끼우기

① 한 줄 요약: 카드 순서를 엔카 기본 순서(차량 정보 → 성능 점검 → 보험 이력 → 차량 이력 타임라인) + 우리 카드(옵션 → 추가 옵션 → 특징 → 판매자 설명)로 고정하고, 타임라인 카드를 새로 만들고, 매물 데이터에 따라 카드를 1장~여러 장 골라 차량 편집 안에 끼우는 도구(card_edit.py)를 만들었다.

② 과제: 노션 「숏폼 카드정보 샘플 제작 및 숏폼 콘텐츠 아이디어 내기」 2차 제안 · 브랜치 `shortform/card-info-v2`(기준 `shortform/card-info-v1` 0892dfea) · 작성 클로드 시안 마스터(Claude Opus 5.5) · 상태: 푸시, 병합·배포 안 함

③ 한 일
- `card_spec.json` v2: `card_order`(8종 고정 순서) · `selection`(데이터 조건 · 우선순위 · 길이별 한도) · `edit`(사진 투어 + 카드 묶음 위치)
- 새 카드 유형 `timeline`(세로 날짜 타임라인, 날짜 확인된 사건만) · 편집용 사진 컷 `photo` · 보험 카드에 날짜·금액 줄(`note`)
- `card_edit.py`: 카드 고르기(빠진 카드와 이유 출력) → 첫 화면·바깥 사진·카드 묶음·실내 사진·끝 로고 한 편 렌더 → plan.json
- G400d 데이터 보정(다른 에이전트 의견): 보험 「수리(견적)비 839,280원」·자료일/확인일 분리, 점검자 의견 「운전석 앞문·쿼터 도장수리」, 리콜 시점 표시, 시세 카드 보류, 판매자 설명 생략
- 매뉴얼 10장 추가, 구글 시트 「2차_카드순서·고르기」 탭
