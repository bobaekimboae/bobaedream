# PR #370 모바일 스크롤 매끄럽게

① 모바일에서 매물을 아래로 내릴 때 끊기는 느낌을 줄이려고, 화면 밖 카드를 그리지 않게 하고 사진을 나눠 불러오게 했다.

② 과제 ID 미지정 · 브랜치 `feat/qf-scroll-smooth-1010` · PR https://github.com/bobaekimboae/bobaedream/pull/370 · 상태 병합·배포(커밋·v 값은 채팅 보고에 적음) · 함께 들어간 과제 없음

③ 한 일
- 화면 밖 카드는 그리기·배치를 건너뛴다(`content-visibility: auto`). 카드 크기는 실측(목록 151·171, 피드 373)으로 미리 알려줘서 스크롤 길이가 흔들리지 않게 했다.
- 목록 사진은 처음 4장만 바로, 나머지는 지연 로딩 · 비동기 해독으로 불러 한꺼번에 해독하지 않게 했다.
- 화면 모양은 그대로다.

④ 비교(헤드리스 크롬, CPU 4배 느리게, 트럭 목록 끝까지 스크롤)
| 화면 | 프레임 95번째 값 작업 전 → 후 |
|---|---|
| 목록형 | 16.8ms → 16.8ms(최대 16.8 → 33.4) |
| 피드형 | 33.3ms → 16.8ms(최대 50 → 49.9) |

⑤ 검증: `npm run verify:qf` 통과 · 콘솔 오류 0건 · 목록·피드 화면 모양 변화 없음 확인

⑥ 원본과 다르게 남긴 것: 실제 폰에서 느끼는 끊김은 헤드리스 크롬으로 재현되지 않아(전에도 같음) 실기기 개선 정도는 측정하지 못했다.
