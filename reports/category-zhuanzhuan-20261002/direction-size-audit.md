# 차량 카테고리 방향·사이즈 검수

- 검수 화면: `05-direction-left-no-subtitle.png`
- 기준 화면: 좐좐 차량 카테고리 원본
- 대상: 보배드림 실제 메인 차량 카테고리

| 항목 | 적용값 | 상태 |
|---|---:|---|
| 카테고리 시작 방향 | 왼쪽, 16px 여백 | 정상 |
| 차량 진행 방향 | 모두 왼쪽 | 정상 |
| 차량 이미지 슬롯 | 52×38px | 정상 |
| 항목 폭 | 70px | 정상 |

| 차량명 | 14px/20px/600 | 정상 |

| 카테고리 설명문구 | 제거 | 정상 |

## 방향 처리

- 반전 적용: 국산차, 수입차, 바이크, 캠핑카.
- 원본 방향 유지: 트럭, 전기차.
- 이미지 파일 자체는 수정하지 않고 해당 카테고리에서만 수평 반전했다.

## 검수 메모

- 모든 차량은 왼쪽을 향하고 있으며 이미지 슬롯과 행 기준선은 그대로 유지된다.
- 실루엣 차이 때문에 차량별 실제 가시 폭은 조금 다르지만, 슬롯 크기와 중심 정렬은 동일하다.
- 장식 이미지는 빈 대체 텍스트를 사용하고 각 버튼의 텍스트명이 접근 가능한 이름이 된다.
