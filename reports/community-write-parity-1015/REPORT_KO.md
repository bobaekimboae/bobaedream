## [1/8 · 약 12%] 기준 화면 확인

- 로그인된 Chrome에서 네이버 카페 실제 글쓰기 화면을 읽기 전용으로 확인했다.
- 빈 편집기, 게시판 선택 모달, 텍스트 도구막대, 공개 설정, 임시글 0건 화면을 확인했다.
- 네이버에 제목·본문·파일을 입력하거나 실제 등록하지 않았다.
- 원본 실측: 헤더 52px, 게시판 행 49px, 제목 47px, 기본 도구막대 48px, 본문 300px, 태그 행 45px, 게시판 모달 300×417px.

## [2/8 · 약 25%] 아이콘 원천 연결

- 사용자 지정 노션 아이콘 DB에서 SVG 21개를 내려받아 저장소에 추가했다.
- 아이콘별 원본 이름·카테고리·선택 이유를 `icon-manifest.json`에 기록했다.
- 외부 아이콘 패키지, 이모지, 임의 래스터 아이콘은 사용하지 않았다.
- 글감·구분선·파일은 노션 DB 안에서 기능이 가장 가까운 태그·취소선·표 아이콘을 사용했다. 네이버 편집기 스프라이트 자체는 저장소에 복제하지 않았다.

## [3/8 · 약 38%] 실행 화면 구현

- 빈 글쓰기 화면과 PC/모바일 반응형 레이아웃을 구현했다.
- 게시판 모달: 검색, 라디오 단일 선택, 선택값 반영, 바깥 영역·ESC 닫기.
- 제목/본문/태그: 입력, placeholder, 태그 최대 10개 제한.
- 편집 도구: 기본 도구막대, 확장 텍스트 도구막대, 굵게·기울임·밑줄·취소선, 인용구·구분선.
- 임시글: 저장, 0/1 건수, 목록, 복원, 삭제.
- 공개 설정: 공개 범위 버튼과 3개 스위치.
- 등록: 게시판·제목·본문이 모두 있을 때만 활성화하며, 테스트 화면에서는 실제 전송 없이 확인창만 표시한다.

- 원본과 구현을 같은 도구 입력에서 나란히 확인해 상단 헤더·게시판·제목·편집기·태그·공개설정의 흐름을 대조했다.
