# 카테고리 시트 행 방식

① 한 줄 요약: 카테고리를 한 줄씩 보여주고, 오른쪽 화살표를 누르면 하위 알약이 펼쳐지게 했습니다.

② 과제 ID 미지정 · 브랜치 `feat/category-sheet-rows-1011` · 상태: 병합·배포

③ 한 일
- 행: 전체차량 → 중고차 → 트럭/특장차 → 바이크 → 캠핑카 → 건설기계 → 자재운반장비 → 부품/용품
- 이름을 누르면 선택, 하위가 있는 줄(중고차·트럭/특장차·캠핑카)은 오른쪽 화살표로 하위 알약 펼침·접기
- 이전 알약 한 줄 화면은 `?catsheet=flat`

⑤ 검증: verify:qf 통과, 384px 캡처에서 중고차·트럭 동시 펼침 확인, 콘솔 오류 없음

⑥ 다르게 남긴 것: 하위 없는 줄에는 화살표를 두지 않음

⑦ 다음: 하위 없는 줄에 초톳처럼 `>` 화살표를 둘지 결정
