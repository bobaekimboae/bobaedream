# 판매점 리뷰 작성 기능 검수

## 기준

- Chợ Tốt 판매점 리뷰 공개 화면의 평점·키워드·거래 매물 연결 구조를 확인했다.
- Chợ Tốt 공식 도움말의 실제 작성 흐름을 기준으로 거래 완료 건에서만 한 번 작성하도록 구성했다.
- 한국 사용자에게 익숙한 용어인 `차량 구매`, `내차 판매`, `판매점 리뷰`로 번역했다.

## 구현 흐름

1. 판매점 리뷰에서 `리뷰 쓰기`를 누른다.
2. 차량 구매 또는 내차 판매를 선택한다.
3. 거래 완료 차량을 선택한다.
4. 1~5점 별점을 선택한다.
5. 별점과 거래 유형에 따라 달라지는 평가 키워드를 최대 3개 선택한다.
6. 선택적으로 상세 후기를 입력한다.
7. 실제 거래 확인에 동의한다.
8. 수정·삭제 불가 안내를 확인한 뒤 최종 등록한다.
9. 새 리뷰가 목록 맨 위에 표시되고 전체/구매/판매 개수, 평균 평점, 키워드 개수가 즉시 갱신된다.

## 가변 요소

- 거래 역할: 구매자 / 판매자
- 거래 차량: 현재 딜러의 판매 차량 또는 판매 완료 차량
- 별점: 1~5점, 점수별 한국어 안내 문구
- 평가 키워드: 역할과 별점 구간(1~2 / 3 / 4~5)에 따라 변경
- 상세 후기: 선택 입력, 최대 300자
- 중복 방지: 동일 거래 건의 재작성 차단
- 저장: 브라우저 로컬 저장소에 보존해 새로고침 후에도 유지

## 검수 결과

- TypeScript + Vite 프로덕션 빌드 통과
- PC 작성 폼 확인
- 390×844 모바일 작성 폼 확인
- 최종 확인 단계 확인
- 등록 후 리뷰 17→18, 차량 구매 16→17, 키워드 개수 갱신 확인
- 새로고침 후 `전체 (18)` 유지 확인
- 브라우저 콘솔 오류 0건

## 운영 전환 시 필요한 서버 기능

현재 시안은 실제 사용 가능한 프런트엔드 프로토타입이다. 운영 서비스에서는 로그인 사용자, 실제 거래 ID, 1회 작성 제약, 신고·블라인드·검수 상태를 서버에서 검증하고 저장해야 한다.
