# 커뮤니티 화면 정렬 정리

① 한 줄 요약: 제각각이던 시작선·간격을 바이두 기준으로 맞췄다(시작선 16, 간격 4의 배수, 배너 그림자 제거, ☰ 80%).

② 브랜치 `community-layout-align` · PR https://github.com/bobaekimboae/bobaedream/pull/1133 · 이번 병합에 ☰ 80%(PR #1132 커밋) 함께 포함

③ 한 일
- 좌우 시작선을 16으로 통일: ☰, 배너, 필터 버튼, 프로필 오른쪽 끝.
- 세로 간격을 4의 배수로: 배너→게시판 이름 16, 통계→칩 16, 칩→목록 12.
- 배너 그림자를 없애 바이두처럼 평평하게(모서리 6 유지).
- 배너 설명 글자 10→12px. ☰ 크기 80%(앞 작업) 포함.
