# 초톳 모바일 목록형·앨범형 일치 작업 보고

## 적용 범위

- 브랜치: `test/chotot-list-match`
- 대상: 트럭 · 특장 모바일 목록형·앨범형
- 활성 조건: URL에 `ref=chotot`이 있을 때만
- 머지·배포: 하지 않음

## 결과

- 노션 베트남 초톳 DB에서 기준 SVG 16개를 받아 `public/assets/chotot-test/`에 영문 파일명으로 저장했다.
- 상단 검색·지역·칩, 퀵필터 슬롯, 정렬행, 목록 카드, 앨범 카드를 기준 워크북 값으로 맞췄다.
- 보기 전환 버튼이 시트만 열던 흐름을 시험 모드에서 목록↔앨범 직접 전환으로 수정했다.
- 카드 채팅 아이콘은 시험 모드에서 숨겼으며 하단 GNB는 변경하지 않았다.
- 기존 URL은 테스트 클래스·아이콘·임시 사진이 적용되지 않는 것을 확인했다.

## 예외

- 실제 트럭 매물 사진 파일이 저장소에 없어서, 저장소 내부의 실사형 트럭 카테고리 이미지 4장을 임시 목록 사진으로 사용했다. 적용 범위는 `ref=chotot`뿐이다.
