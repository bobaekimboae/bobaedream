# 초톳 크로스체크: 전체차량이 중고차로 읽히던 꼬임 정리

① 초톳 카테고리 시트를 직접 눌러 보고, 우리 쪽에서 전체차량이 중고차로 읽히던 제목 · 검색창 · 빵부스러기와 시트의 겹친 선택 표시를 바로잡았다.

② 과제 ID 미지정 · 브랜치 `fix/qf-category-crosscheck-1010` · 상태 병합·배포(v 값은 채팅 보고)

③ 초톳에서 확인한 것(`xe.chotot.com`, 모바일): 시트 = `Xem tất cả danh mục` 알약 + 그룹 `Xe cộ`의 알약 7개(마지막이 「Tất cả xe cộ」=전체 차량). 전체 차량을 고르면 칩 `Xe cộ`, 하위를 고르면 `Ô tô`·`Xe máy`. 빵부스러기는 `Chợ Tốt Xe / Xe cộ`·`/ Ô tô` 한 칸. 한 번에 하나만 선택 표시.

④ 우리 쪽 꼬임과 고친 것
| 위치 | 전 | 후 |
|---|---|---|
| 전체차량 제목 | `중고차` | `전체차량` |
| 전체차량 검색창 안내 | `중고차` | `전체차량` |
| 전체차량 빵부스러기 | `보배드림 / 중고차` | `보배드림 / 전체차량` |
| 바이크 등 빵부스러기 | `보배드림 / 중고차 / 바이크` | `보배드림 / 바이크` |
| 시트 선택 표시 | 같은 값이 두 곳에서 선택, 중고차 하위(국산차)는 위쪽에 선택 없음 | 위쪽은 그룹(중고차), 아래쪽은 정확한 하위(국산차) |

⑤ 검증: `npm run verify:qf` 통과 · PC(1440) 제목 · 빵부스러기 4개 상태 확인 · 모바일 검색창 안내 · 시트 선택 표시 4개 상태 확인

⑥ 초톳과 다르게 남긴 것: 시트에 원형 아이콘 줄과 하위 알약(국산차 · 수입차 …)을 둔다(우리 구조). 초톳은 `전체 차량`이 그룹의 마지막 알약이고 `전체 카테고리 보기`가 맨 위인데, 우리는 사용자 지시로 `전체차량`이 아이콘 줄 맨 앞이고 `전체 카테고리`가 위에 있다.

⑦ 확인할 것: 시트의 아이콘 줄과 `전체 카테고리` 알약이 같은 8개 목록이다(초톳에는 아이콘 줄이 없음). 하나로 줄일지 결정이 필요하다.

⑧ 확인 링크: `?qf=guazi&category=전체` · `?qf=guazi&pc=1&category=중고차`(배포본은 `&v=<커밋>`)
