## ⑤ 검증
- `npm run verify:qf` 통과.
- 콘솔 오류: 모바일 A·B·기존 모두 0건.
- 브랜드 선택: 페라리 4대 · 테슬라 2대로, 테마 헤더가 있을 때와 없을 때 같다.
- 검색창 열기와 추천 검색어 표시 정상.
- 구독 버튼: 누르면 1,284 → 1,285명, 「✓ 구독중」으로 바뀐다.
- `luxhead`가 없으면 기존 화면 그대로다.

## ⑥ 원본과 다르게 남긴 것
- 테마 헤더에서는 지역 줄(`전국 ▾`)을 숨겼다. 좐좐·피그마에도 없다. 필요하면 시트 안에 다시 넣을 수 있다.
- B안에는 「딜러 매물 등록하기」 띠를 넣지 않았다. 차량 라인업을 가리기 때문이다.
- 구독자 수(1,284)는 가상 값이다.

## ⑦ 못 한 것 · 다음에 할 것
- PC(`&pc=1`)에는 적용하지 않았다(모바일 시안만).
- 좐좐처럼 브랜드·모델을 누르면 헤더가 그 브랜드·모델 헤더로 바뀌는 2단계는 다음 단계다.
- 실제 배경 사진(브랜드 공식 이미지 등)은 출처를 정하면 교체한다.
- 검색 추천어가 일반 중고차 기준이다. 럭셔리 전용 추천어는 아직 없다.
