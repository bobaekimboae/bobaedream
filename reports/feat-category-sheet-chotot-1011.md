# 카테고리 시트 초톳 방식 정리

① 한 줄 요약: 카테고리 시트를 초톳처럼 알약 한 줄(전체차량 맨 앞)로 바꿨습니다.

② 과제 ID 미지정 · 브랜치 `feat/category-sheet-chotot-1011` · 상태: 병합·배포

③ 한 일
- 아이콘 줄·「전체 카테고리」 중복 알약 제거, 「차량」 아래 알약 한 줄
- 순서: 전체차량 → 중고차 → 트럭/특장차 → 바이크 → 캠핑카 → 건설기계 → 자재운반장비 → 부품/용품
- 중고차를 고르면 하위 알약(국산차·수입차·서울오토갤러리 등) 한 줄이 아래에 나옴
- 예전 화면 `?catsheet=old`

⑤ 검증: verify:qf 통과, 384px 캡처 확인, 콘솔 오류 없음

⑥ 다르게 남긴 것: 초톳 웹 카테고리 창은 헤드리스에서 열리지 않아 사용자 앱 캡처를 기준으로 함

⑦ 다음: 중고차 하위 알약을 없앨지 확인 필요

⑧ 확인 링크: `?qf=guazi` 에서 카테고리 칩
