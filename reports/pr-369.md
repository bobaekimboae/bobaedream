# PR #369 개인판매자 지역 시도 구군까지

① 개인 판매자의 위치가 `충북`처럼 시도만 나오던 것을 `충북 진천군`처럼 시도 구군까지 나오게 했다.

② 과제 ID 미지정 · 브랜치 `feat/qf-private-gugun-1010` · PR https://github.com/bobaekimboae/bobaedream/pull/369 · 상태 병합·배포(커밋·v 값은 채팅 보고에 적음) · 함께 들어간 과제 없음

③ 한 일
- 개인 직거래는 단지 없이 `시도 구군`까지 쓴다. 시트에 구군이 없으면 `regions-kr.json`에서 그 시도의 구·군을 돌려 쓴다.
- 트럭·바이크·건설기계·캠핑카·자재운반장비·부품의 개인 매물에 모두 적용했다. 세종은 구·군이 없어 시도만 나온다.

| 매물 | 작업 전 | 작업 후 |
|---|---|---|
| 트럭 개인(충북) | `충북` | `충북 진천군` |
| 트럭 개인(인천) | `인천` | `인천 남동구` |
