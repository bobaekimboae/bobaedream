# PR #985 딜러 명함 카카오톡 미리보기

## ③ 한 일
- 카톡은 링크 페이지의 og 태그(제목·설명·그림)만 읽고 화면 코드는 실행하지 않는다. 그래서 딜러 4,096명마다 og 태그가 든 작은 정적 페이지(`c/<shop>-<emp>`)를 만들고, 열면 바로 실제 명함 화면으로 넘긴다.
- 공유 주소를 긴 `?profile=dealer&…#theme=…` 대신 짧은 `…/bobaedream/c/da100022-28`로 바꿨다. 꾸민 명함만 꾸밈 값이 `#` 뒤에, 차량을 붙이면 `?car=`가 붙는다.
- 미리보기 그림 800×400(보배드림 파랑): 실사진이 있는 딜러 732명은 딜러별, 나머지는 단지별 공용 그림(단지명 + 건물 사진).
- 공유 글: `○○ 딜러 명함 · 상사명`.
- 첫 배포에서 배포 빌드가 `/assets/` 글자를 바꿔 그림 주소가 404였다 → 그림을 `c/og/`로 옮겨 해결(PR #987).

## ⑥ 원본과 다르게 남긴 것과 이유
- 실사진이 없는 딜러(약 3,364명)는 이름 대신 단지 공용 그림이다. 이름은 미리보기 제목에 나온다. 4천 장을 다 만들면 저장소가 너무 커진다.
- 기존 외부 명함 서비스(숫자 상사 번호 전용) 주소는 그대로 둔다.
