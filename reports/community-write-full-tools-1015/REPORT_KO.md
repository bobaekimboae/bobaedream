# 보배드림 게시물 작성 전체 기능 구현 보고

## 적용 내용

- 네이버 전용 문구를 `게시물 허용 설정`으로 변경
- 주 액션 색을 Airbnb 계열 `#FF385C`로 통일
- 사진 첨부: PNG/JPEG/WebP/GIF, 최대 10개·개당 10MB, 본문 미리보기와 삭제
- 파일 첨부: 최대 10개·개당 20MB, 목록·용량·다운로드·삭제
- 동영상 주소 카드, 링크, 스티커, 글감, 인용구, 구분선, 장소 카드
- 문단·서체·크기·굵게·기울임·밑줄·글자색·배경색·취소선
- 공개 범위(전체/멤버/나만 보기), 검색·공유·복사 허용 토글
- 임시글과 테스트 등록 결과를 브라우저 localStorage에 보관

## 범위 안내

현재 GitHub Pages 시안은 정적 사이트이므로 사진·파일과 게시물은 외부 서버로 전송하지 않는다. 사진은 본문 미리보기 및 브라우저 임시저장에 포함되고, 일반 파일은 현재 탭에서만 다운로드할 수 있다. 운영 적용 시 업로드 API, 사용자 인증, 게시물 DB 연결이 추가로 필요하다.
