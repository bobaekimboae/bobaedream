# 숏폼 제작기: 샘플 템플릿 5종 + 샘플 채우기

① 스타일·길이·음악·문구를 한 번에 바꾸는 템플릿 5종과, 예시 사진·정보를 채워 주는 「샘플 채우기」를 넣었다.

② 과제 ID 미지정 · 브랜치 `feat/shortform-templates-1011` · 상태 병합·배포는 채팅 보고 · 대상 `public/shortform/index.html`

③ 한 일
- 템플릿: 기본 판매형(파랑·15초) · 프리미엄 블랙(골드·20초·Full Fit·차분한 음악) · 특가 이벤트(빨강 「특가」 배지) · 신차급 컨디션(초록 「신차급」 배지·TikTok) · 패밀리 SUV(실버·30초). 색 포인트·배지·길이·변환 방식·음악·CTA가 같이 바뀐다. 사용자가 입력한 문구는 덮어쓰지 않는다.
- 샘플 채우기: 저장소의 예시 차량 사진 5장 + 예시 차량명·가격·연식·주행·판매 포인트를 한 번에 채운다(실제 판매 정보 아님이라고 화면에 표시).
- 템플릿 색은 미리보기·브라우저 MP4/WebM·서버 렌더링 영상에 모두 같게 반영된다(같은 Canvas 그림을 쓰기 때문).

④ 실제 동작 확인 (`npm run check:shortform`, 35항목 중 33 통과, 2건은 헤드리스 환경 한계: 음성 소리·서버 MP4 브라우저 재생)

|---|---|
