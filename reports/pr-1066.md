# 매물 등록 SNS 동시 홍보 시안

① 한 줄 요약: 매물 등록 화면(`?register`)에 등록과 동시에 블로그·카페·인스타·숏폼 등에 올리는 「SNS 동시 홍보」 카드를 시안으로 추가했다.

② 과제 ID 없음 · 브랜치 `feat/register-sns-crosspost` · 상태: 로컬 커밋(푸시·배포 전)

③ 한 일
- `상세 정보` 카드 아래에 `SNS 동시 홍보` 카드 추가(켜기/끄기 스위치, 접기)
- 채널 6개: 네이버 블로그 · 네이버 카페 · 인스타그램 피드 · 릴스·쇼츠 · 카카오톡 채널 · 페이스북 페이지. 미연결 채널은 `계정 연결`(목업)
- 올리는 시점: 등록 즉시 / 예약 발행(저녁 시간 추천)
- 게시 문구: 매물 정보(제목·가격·연식·주행·지역)로 자동 작성 + 해시태그, 직접 수정·`다른 문구` 가능
- 미리보기: 피드형 / 블로그형
- 자동 관리: 가격 인하 시 자동 재게시 · 판매완료 표시 · 7일 끌어올림
- `등록하기`를 누르면 선택한 채널 수를 안내(목업)

④ 벤치마킹 근거: 오토포스트허브·아임리얼(국내 블로그·카페·인스타 자동 발행), AutoLister Pro·CARVID(해외 SNS·마켓플레이스 자동 게시, 판매 시 자동 삭제), Push Property·Lofty(등록·가격 인하·판매완료 트리거)

⑤ 검증: `npm run verify:qf` 통과, 모바일 390 · PC 1280 콘솔 오류 없음

⑥ 원본과 다르게 남긴 것: 채널 표시는 실제 SNS 로고 대신 글자 배지(로고 파일 미확보, 상표 재현 회피)

⑦ 다음에 할 것: 실제 SNS 로고 에셋, 딜러 이용권 요금제와 연결, 메타 정책(페북 마켓플레이스는 인벤토리 파트너만 자동 게시) 반영 여부 결정

⑧ 확인 링크(배포 후): 모바일 `?register&qf=guazi`, PC `?register&qf=guazi&pc=1`
