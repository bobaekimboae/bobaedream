# 숏폼 카드 정보 기법 v1 — 유형별 카드 샘플 12종 + 몽타주

① 한 줄 요약: 엔카에서 하나씩 눌러 보는 매물 정보를 숏폼 카드 컷으로 요약하는 렌더러(card-info-v1)와 샘플 영상 12종·47초 몽타주를 만들었다.

② 과제: 노션 「숏폼 카드정보 샘플 제작 및 숏폼 콘텐츠 아이디어 내기」 · 브랜치 `shortform/card-info-v1`(기준 `shortform/sam31-integrate` e9178584) · 작성 클로드 시안 마스터(Claude Opus 5.5) · 상태: 푸시, 병합·배포 안 함

③ 한 일
- 차란차 샘플 매물(벤츠 G400d)의 공개 데이터(기본정보·옵션·보험 요약·JATO 제원·시세)와 카모두 성능·상태점검기록부를 읽어 카드 데이터로 정리
- 오토스카우트24 상세 카드 문법(흰 카드·아이콘 타일·회색 라벨+굵은 값)에 벨기에판 잠금 규칙(노랑 하나·칩·자막 y1283·-14 LUFS)을 얹은 템플릿
- 데이터(JSON) → 프레임 캡처 → FFmpeg 렌더러, 효과음·배경음 믹스, 2단계 음량 맞춤, 검사 보고서(report.json)
- 카드 12종: 차량 정보·앞옆뒤 사진·성능점검·보험이력·옵션·추가 옵션(G80)·차량 특징·연비·보증/리콜·시세 위치·판매자 설명·한눈에 요약
- 규격은 `card_spec.json` 하나, 매뉴얼 `docs/shortform/card-info-manual-v1.md`, 구글 시트 「숏폼 카드정보 규격 v1」
