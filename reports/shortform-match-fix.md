# 숏폼 자동편집 칩·말 ↔ 화면 맞춤 수정

① 한 줄 요약: 칩·말과 화면이 어긋나던 원인 3가지를 찾아, 고정값 수정이 아니라 자동화 가변 규칙(`shot_fit`)으로 규정했다.

② 브랜치 shortform/match-fix · PR(아래) · 상태: 병합·배포

③ 한 일
- 근본 원인: 렌더러가 원본을 30fps로 계산(차란차 원본 25fps) → `source_fps: auto`
- 장면이 부위 구간을 넘침 → 같은 부위 합치기·구간 안 고정·최저 0.4배·시작 당기기(모두 규칙 값)
- 원본에 없는 부위 → `missing_part`(구간별 처리)·`required_shots`(촬영 필요 목록)
- 검사 도구 `check_match.py --render`: 칩이 뜬 순간 실제 화면 부위·넘침·촬영 필요, 허용치 넘으면 실패
- 마스터 파일(편집 매뉴얼 v4 §9-8)에 어긋남 기록

④ 비교: GLE 넘침 → 0곳. 남은 어긋남 3곳(가격 칩 2·4륜 칩 1, §9-8)

⑤ 검증: GLE NL·BE 프레임 1초 간격 확인(옵션 칩 = 그 부위, 칩 모두 원본 노랑, 끝 검은 화면 없음), check_match 넘침 0

⑥ 다르게 남긴 것: 엔진룸 없는 원본은 뒷모습 등으로 대신(촬영 필요로 표시)
