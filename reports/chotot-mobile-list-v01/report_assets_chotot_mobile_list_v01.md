# [assets] 보배드림 모바일 매물리스트 초톳 목록형 정합화 v01 — 작업 완료(검토 요청)

## 요약

- 모바일 공통 목록 컴포넌트의 타이포그래피, 카드 구조, 정렬 행, 하단 탭을 초톳 목록형 실측 규격에 맞췄다.
- 초톳 원본 Notion 페이지에서 내려받은 SVG 3개는 패스를 수정하지 않고 그대로 저장했다.
- 트럭·특장과 중고차에서 같은 공통 컴포넌트가 적용되는 것을 Pixel 7 조건으로 확인했다.
- 저장소 변경만 수행했으며 병합·배포는 하지 않았다.

## 방법

1. 초톳 트럭 목록과 보배 빌드 화면을 동일 Pixel 7 브라우저 컨텍스트에서 직접 열었다.
2. `getComputedStyle`과 `getBoundingClientRect`로 글자, 색, 줄간격, 박스, 간격을 수집했다.
3. 변경 후 값을 다시 수집해 `measurements.json`으로 저장했다.
4. 상단, 카드 2개, 하단 탭을 같은 폭으로 나란히 캡처했다.
5. 중고차 카테고리를 별도로 캡처해 공통 컴포넌트 영향을 확인했다.

## 구현 요약

- 목록 관련 값을 `--list-title`, `--list-meta`, `--list-price`, `--list-secondary`, `--list-divider` 토큰으로 정리했다.
- 모바일 카드의 썸네일을 120×120으로 통일하고, 판매자·채팅·찜을 카드 하단 전체 폭 행으로 옮겼다.
- 정렬 행을 초톳 순서로 재배치하고 보기 아이콘을 원본 SVG 자산으로 교체했다.
- 트럭 유형 레일의 선행 `유형` 라벨을 제거했고, 레일 이미지 64px와 데이터는 변경하지 않았다.
- 채팅 버튼 동작은 토스트 `채팅 연결 예정`으로 연결했다.

## 미측정·제안

- 초톳 라이브 표본에서 `1 chủ` 회색 배지가 실제 배지로 노출된 매물을 찾지 못했다. 이 항목은 지시대로 기존 보배 배지 스타일을 유지했다.
- `▼ n% 시세` 배지는 이번 라이브 표본에서 노출되지 않아 실측값을 확보하지 못했다. 추정값을 만들지 않았고 구현도 하지 않았다.
- 초톳 모바일 웹은 접속 시점에 브레드크럼·페이지 제목이 노출됐지만, 보배는 지시의 유지 차이에 따라 추가하지 않았다.
