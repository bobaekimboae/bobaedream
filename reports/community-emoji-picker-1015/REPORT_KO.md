# 커뮤니티 등록폼 전체 이모지 선택기 작업 보고

## 결과

- 기존 12개 스티커 목록을 Unicode Emoji 17 기반 전체 선택기로 교체했다.
- 기본 1,867개와 변형 2,077개, 총 3,944개 선택 항목을 제공한다.
- 분류는 최근 / 표정 / 사람 / 동물·자연 / 음식·음료 / 여행·장소 / 활동 / 사물 / 기호 / 국기 순서다.
- 검색, 피부색 6단계, 최근 사용 24개 저장, 본문 삽입을 구현했다.
- 데이터는 이모지 창을 처음 열 때만 245.5KB JSON을 지연 로딩한다.

## 데이터 원천

| 항목 | 값 |
|---|---|
| 오픈소스 | unicode-emoji 2.8.0 |
| 라이선스 | MIT |
| 유니코드 기준 | Emoji 17.0 |
| 기본 이모지 | 1,867 |
| 변형 | 2,077 |
| 총 선택 가능 문자 | 3,944 |
| 공식 카테고리 | 9 |

## 화면 규칙

- 모바일은 7열, PC는 8열로 배치한다.
- 카테고리 탭은 가로 스크롤이며 아이콘과 한글 이름을 같이 표시한다.
- 검색은 영문 이름·키워드와 한글 카테고리 키워드를 지원한다.
- 피부색을 바꾸면 변형을 지원하는 항목만 선택한 피부색으로 표시하고, 지원하지 않는 항목은 기본 문자를 유지한다.
- 선택한 이모지는 기존 본문 스티커 칩 형식으로 삽입해 저장·복원 구조를 바꾸지 않았다.
- 최근 사용은 브라우저 로컬 저장소에 최대 24개를 저장한다.
