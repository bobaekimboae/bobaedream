# 퀵필터 좌측 타이틀 전수 제거 결과

## 결론

- 모바일·PC 모든 카테고리와 뎁스에서 좌측 고정 타이틀을 제거한다.
- 별도 상단 문맥 제목도 추가하지 않는다.
- 이미지·로고·알약은 초톳식 단일 슬롯 레일로 배치한다.
- 접근성용 섹션 이름과 `aria-label`은 화면 표시 여부와 관계없이 유지한다.

## 2026-10-04 실측

- 초톳 모바일 384px 현재 화면: 제조사 로고 첫 중심 x=44px, 반복 피치 72px, 5개 로고가 한 화면에 표시된다.
- 초톳 모바일 현재 화면에는 제조사 로고 줄 왼쪽 고정 타이틀이 없다.
- 변경 후 보배 모바일: 좌측 제목 칸 0px, 첫 슬롯 x=16px.
- 변경 후 보배 PC: 좌측 제목 칸 0px, 콘텐츠 카드 안 첫 슬롯 x=20px.
- 트럭 유형→세부유형→제조사→모델 전 단계에서 같은 시작선을 유지한다.

## 뎁스별 권장 규칙

| 단계 | 모바일 표시 | PC 표시 | 슬롯 시작선 |
|---|---|---|---|
| 카테고리 | 없음 | 없음 | 16px / 20px |
| 유형 | 없음 | 없음 | 16px / 20px |
| 세부유형 | 없음 | 없음 | 16px / 20px |
| 제조사 | 없음 | 없음 | 16px / 20px |
| 모델 | 없음 | 없음 | 16px / 20px |
| 세부모델 | 없음 | 없음 | 16px / 20px |
| 트림·톤수·적재량·연식 | 없음 | 없음 | 16px / 20px |

## UX·접근성 주의

- 필터 칩이 가로 스크롤 밖으로 밀릴 수 있으므로 깊은 단계에서는 칩만 문맥 표시 수단으로 의존하지 않는다.
- 시각 타이틀을 제거해도 각 레일의 `aria-label`과 의미 있는 섹션 제목은 유지한다.
- 뎁스가 바뀔 때 스크린리더에 현재 단계가 전달되는지는 별도 키보드·스크린리더 검증이 필요하다.

## 전수 확인 결과

1. 중고차·트럭/특장·바이크·캠핑카·건설기계·자재운반장비·부품/용품: 좌측 제목 노드 0건.
2. 트럭 유형·세부유형·제조사·모델: 모바일 첫 슬롯 x=16px.
3. PC 트럭 유형: 콘텐츠 시작점+20px.
4. 모바일·PC 문서 가로 오버플로 0건.
5. 브라우저 콘솔 오류 0건.

## 최종 권장안

`모든 화면에서 좌측 타이틀 제거 + 모바일 16px·PC 20px 단일 슬롯 시작선`을 표준으로 채택한다.
