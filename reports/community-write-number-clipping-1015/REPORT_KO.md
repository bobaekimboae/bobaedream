## 1. 수정 결과

모바일 글자 크기 선택창에서 브라우저 기본 화살표가 숫자 영역을 침범하던 문제를 수정했다.

- 네이티브 화살표를 제거하고 저장소의 `chevron-down.svg`를 사용했다.
- 글자 크기 칸을 64px에서 68px로 늘렸다.
- 오른쪽 화살표 여백 26px, 왼쪽 문자 여백 9px을 고정했다.
- 숫자 폭이 흔들리지 않도록 `font-variant-numeric: tabular-nums`를 적용했다.
- 모바일 도구막대의 가로 스크롤은 유지하되 스크롤바만 숨겼다.

## 3. 시각 확인

- 수정 전: 사용자 캡처에서 `15`의 마지막 숫자 일부가 네이티브 화살표 영역에 가려졌다.
- 수정 후: 360px에서 `15`와 최대값 `38` 모두 전체 획이 보인다.
- 투표 `7일`, 안내 `2개 이상 10개`, 이모지 `226개`, `Unicode 17`도 같은 기준으로 잘림이 없다.
- 모바일 텍스트 도구막대는 기능 수가 많아 가로 스크롤을 사용한다. 이는 의도한 동작이며, 현재 선택한 글자 크기 칸은 첫 화면 안에서 전부 보인다.
