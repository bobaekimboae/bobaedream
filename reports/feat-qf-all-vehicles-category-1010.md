# 카테고리 시트에 전체차량 추가, 전체중고차는 중고차에 한함

① 카테고리 시트 맨 앞에 `전체차량` 칩(노션 원본 아이콘)을 넣고, 중고차의 `전체차량` 알약을 `전체중고차`로 바꿔 중고차 목록만 보이게 했다.

② 과제 ID 미지정 · 브랜치 `feat/qf-all-vehicles-category-1010` · 상태 병합·배포(v 값은 채팅 보고)

③ 한 일
- 시트의 원형 칩 줄 맨 앞에 `전체차량`: 아이콘은 노션 「여러 차종·바디타입」 SVG 그대로, 누르면 모든 카테고리가 섞인 목록(값 `전체`).
- `중고차` 아래 첫 알약 `전체차량` → `전체중고차`(값 `중고차`, 중고차 목록만).
- 첫 화면 유형 줄에는 `전체차량` 칩을 넣지 않았다(이미 전체차량 상태).

⑤ 검증: `npm run verify:qf` 통과 · 시트 칩 순서 `전체차량 · 중고차 · 트럭/특장차 · …` · 전체차량 목록에 트럭·바이크 포함 · `전체중고차` 선택 후 트럭·바이크 없음(URL `category=중고차`) · 콘솔 오류는 기존 404 1건뿐

⑧ 확인 링크: 모바일 `?qf=guazi` → 카테고리 칩(배포본은 `&v=<커밋>`)
