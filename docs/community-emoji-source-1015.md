# 커뮤니티 이모지 데이터 출처

- 원천 패키지: `unicode-emoji` 2.8.0
- 라이선스: MIT
- 기준: Unicode Emoji 17.0
- 생성 명령: `npm run community:build:emoji`
- 공개 데이터: `public/community/data/emoji-v17.json`

패키지에서 제공하는 이모지 문자, 영문 설명, 검색 키워드, 카테고리, 변형 문자만 정적 JSON으로 변환한다. 외부 이미지·스프라이트·상표 자산은 포함하지 않는다.

생성 결과는 기본 이모지 1,867개, 변형 2,077개이며 총 3,944개 문자를 선택할 수 있다. 화면에는 한 카테고리만 렌더링하고 검색을 시작할 때 전체 색인을 조회한다.
