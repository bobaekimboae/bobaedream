# 바이크 매물 v04 연동 검수 v01

## 적용 기준

- 시나리오: `bike_listing_scenario_v04.csv`
- 이미지 매니페스트: `bike_listing_manifest_v01.csv`
- 연결 키: `scenario_id` + `image_file`
- v02 시나리오: 참고 기록으로만 취급하며 구현에는 사용하지 않음

## 데이터 검수 결과

- 시나리오 행: 30
- 고유 `scenario_id`: 30
- 고유 `image_file`: 30
- 매니페스트와 일치한 이미지: 30
- 파일 크기 일치: 30
- SHA-256 일치: 30
- 누락 이미지: 0
- 중복 연결: 0
- 판매자 정보: 30건 모두 테스트용 가상 정보

## 구현 내용

- 목록 이미지 경로: `public/assets/bike/listings/{image_file}`
- 목록/상세 데이터: 제조사, 모델, 연식, 주행거리, 배기량, 장르, 면허, 가격, 지역, 판매자 유형·이름·주소·소개·영업시간·연락 방식
- 필터 실제 연동: 제조사·모델·연식·가격·장르·배기량·면허·주행거리·지역·매물출처
- 필터 선택지는 v04 값과 맞추기 위해 면허를 `원동기 이상`·`2종 소형`, 매물출처를 `전문 판매업체`·`인증 판매업체`·`개인 판매`로 구성함
- 실제 전화번호와 상세 번지는 추가하지 않음

## 검증

- `node scripts/generate-bike-scenario-v04.mjs`: 30개 연결·파일 크기·SHA-256 검증 통과
- `npm run verify:qf`: 런타임 무결성, TypeScript, Vite 프로덕션 빌드 통과
- `node scripts/verify-bike-v04-ui.mjs`: 모바일 전체 필터에서 `장르 → 스포츠` 선택 후 시트와 전체 필터의 `10대 보기` 버튼 클릭 성공
- 클릭 결과: 전체 30대, 첫 페이지 20대, 스포츠 10대
- 상세 결과: `bike-030`과 `bike_listing_030_v01.webp`, 배기량 1,340cc, 가상 판매자 정보의 1:1 연결 확인
