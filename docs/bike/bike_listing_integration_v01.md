# 바이크 가상 매물 v07 시안 연동 검수 v01

## 적용 기준

- 시나리오: `bike_listing_scenario_v07.csv`
- 교체 기록: `bike_listing_image_replacement_manifest_v01.csv`
- 목록 이미지: `public/assets/bike/listings/`
- 연결 키: `scenario_id` + `image_file`
- 최종 사용 버전: `v07`

## 데이터 검수 결과

- 시나리오 행: 30
- 고유 `scenario_id`: 30
- 고유 `image_file`: 30
- 누락 이미지: 0
- 중복 연결: 0
- 가상 판매자 정보: 30건
- 이미지 등급: A 13장, B 15장, C 2장
- v02 교체 이미지: `bike-001`, `bike-009`, `bike-019`

## 구현 내용

- `category=바이크`에서만 바이크 가상 매물 30대를 사용한다.
- 목록과 상세에 제조사, 모델, 연식, 주행거리, 배기량, 장르, 면허, 가격, 지역, 판매자 유형·이름·주소·소개·영업시간·연락 방식을 연결했다.
- 제조사 선택 뒤 v07에 실제 존재하는 모델만 모델 이미지 레일에 노출한다.
- 제조사·모델·연식·가격·장르·배기량·면허·주행거리·지역·매물출처 필터가 v07 값으로 목록과 결과 수를 거른다.
- 실제 연락처나 실제 상세 주소는 사용하지 않는다.

## 검증

- `node scripts/generate-bike-scenario-v07.mjs`: 30행·30 ID·30 이미지 연결과 파일 존재 검증 통과.
- `npm run verify:qf`: 런타임 무결성, TypeScript, Vite 프로덕션 빌드 통과.
- `node scripts/verify-bike-v07-ui.mjs`: 모바일 첫 페이지 20장 이미지 로드, 깨진 이미지 0, 스포츠 10대 필터, `bike-030` 상세 연결 통과.
- PC 1440×900·모바일 393×852 캡처에서 바이크 전용 목록과 실제 이미지 노출 확인.

## 남은 사항

- `bike-008`, `bike-027`은 동일 매물의 전체 차량 대체 사진을 확보하지 못해 C등급 원본을 유지한다.
- 이미지 상업 이용 및 재배포 권리는 미확인이다.
