# 바이크 가상 매물 시나리오 v07

## 결과

- v05의 데이터 교정을 유지하고 동일 매물 갤러리에서 전체 차량 사진 3장을 교체했습니다.
- 교체: bike-001, bike-009, bike-019
- 교체 대기: bike-008, bike-027
- 이미지 등급: A 13장 / B 15장 / C 2장

## 교체 원칙

- 다른 매물이나 다른 연식 차량 이미지는 섞지 않았습니다.
- 동일 매물에서 전체 차량이 확인되는 사진만 새 v02 파일로 저장했습니다.
- 원본 v01 이미지는 삭제하거나 덮어쓰지 않았습니다.

## 파일

- 데이터: bike_listing_scenario_v07.csv
