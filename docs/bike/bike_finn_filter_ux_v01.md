# 바이크 FINN형 필터 UX v01

## 적용 범위

- 바이크 장르 1뎁스 이미지 선택
- 제조사 선택 뒤 모델 2뎁스 텍스트 선택
- 혼다 전체 모델 카탈로그와 테스트 매물 연결

## 참고 기준

- FINN 바이크 검색: `https://www.finn.no/mobility/search/mc`
- 확인일: 2026-10-04
- FINN의 현재 구조에서 확인한 원칙: 현재 조건의 매물 수를 항목 옆에 표시하고, 자주 쓰는 항목을 먼저 보여준 뒤 전체 목록으로 확장한다.

## 확정 규칙

### 1뎁스 장르 이미지 카드

| 환경 | 카드 | 이미지 표면 | 배경 | 선택 상태 | 명칭 |
|---|---:|---:|---|---|---|
| 모바일 | 72×80px | 64×36px | `#F1F1F3` | 흰색, 안쪽 2px `#222`, 약한 그림자 | 11px/15px, 최대 2줄 |
| PC | 88×90px | 80×43px | `#F1F1F3` | 흰색, 안쪽 2px `#222`, 약한 그림자 | 11px/15px, 최대 2줄 |

- 가로 스크롤이며 다음 카드가 일부 보여 더 선택할 수 있음을 알린다.
- 복수 선택을 허용한다.
- 현재 결과 0대는 흐리게 표시하고 선택할 수 없다.
- 이미지 비율은 유지하고 바닥 기준으로 정렬한다.
- 현재 v02 이미지가 있는 네이키드·스쿠터·스포츠·멀티퍼포즈만 실이미지를 표시한다.
- 나머지 9종 이미지 상태는 `미확인`이며 임시 빈 슬롯으로 표시한다.

### 2뎁스 모델 텍스트

- 모델 이미지는 이번 버전에서 사용하지 않는다.
- 제조사 선택 직후 빠른 선택 줄에는 현재 매물이 있는 모델만 텍스트 칩으로 표시한다.
- 마지막에 `전체 N개`를 표시하고 전체 모델 시트를 연다.
- 전체 모델 시트에는 검색 입력, 전체 모델 수, 현재 매물이 연결된 모델 수를 표시한다.
- 전체 모델을 빠짐없이 노출하되 현재 결과가 0대인 모델은 흐리게 표시하고 선택할 수 없다.
- 모델명 비교는 공백·하이픈·대소문자를 제거한 정규화 값으로 연결한다.
