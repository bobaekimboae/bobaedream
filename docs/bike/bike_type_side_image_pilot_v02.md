# 바이크 유형 완전 정측면 이미지 시안 v02

## 변경 목적

- v01의 유형별 색상·명암 편차를 제거한다.
- AutoTrader Canada의 바이크 유형 이미지보다 낮지 않은 축소 가독성과 재질 표현을 배포 기준으로 삼는다.

## AutoTrader 교차검수

- 확인 위치: `https://www.autotrader.ca/motorcycles-atvs`의 `Browse by type`
- 비교 항목: Street, Touring, Cruiser, SuperSport
- 확인 결과: 정측면, 앞머리 왼쪽, 흰색·은색 저채도 차체, 검은 기계부, 투명 배경, 선명한 유형 실루엣을 공통 규칙으로 사용한다.
- 외부 원본 이미지는 제품에 포함하지 않고 품질 비교에만 사용한다.

## v02 제작 규칙

- 90도 완전 정측면, 앞바퀴 왼쪽, 뒷바퀴 오른쪽.
- 펄 화이트·라이트 실버 차체와 다크 그래파이트 기계부로 색조 통일.
- 두 바퀴는 원형이며 접지선은 하나의 수평선에 맞춘다.
- 투명 배경, 중립 스튜디오 조명, 타이어 바로 아래의 약한 접지 그림자.
- 로고·문자·번호판·워터마크·라이더·배경 소품 금지.
- 1536×1024 마스터를 보존하고 180×120 투명 PNG 배포본으로 정규화한다.
- UI는 56×40px 표면에서 `contain`, `center bottom`으로 표시한다.
