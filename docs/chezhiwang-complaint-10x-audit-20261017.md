## 4. 10배 강화 검수 규칙

1. 캡처 출처·시간·기기·해상도를 기록한다.
2. 화면만 보지 않고 Android UI hierarchy의 실제 텍스트와 checked 상태를 확인한다.
3. 원본의 정상·빈 제출·가변 선택·오류 상태를 각각 촬영한다.
4. 웹은 목록·상세·등록을 독립 URL로 검수한다.
5. 모든 가변 분기를 프로그램으로 계수한다.
6. 360px 이하와 393px 모바일 레이아웃을 함께 점검한다.
7. 이미지 `naturalWidth`, 콘솔 오류·경고, 비활성 컨트롤을 확인한다.
8. 민감정보가 상세 DOM·로컬 공개 데이터에 포함되는지 검사한다.
9. 키보드·스크린리더를 위해 레이블·버튼명·오류 `role=alert`를 검사한다.
10. 수동 캡처 판정과 정적 게이트를 모두 통과해야 완료로 판단한다.

## 5. 이번 수정

- 필수 안내와 공개 후 수정 제한 안내 추가
- 작성자·차량·업체·첨부·불만 섹션에 기존 초톳/레딧/보배드림 계열 아이콘 적용
- 나이 직접 입력 및 남·녀 두 선택지만 유지
- 자동차등록증 업로드와 개인정보 안내 추가
- 바이크 선택 시 `이륜자동차 사용신고필증`으로 문구 전환
- 사진과 영상 업로드를 별도 타일과 별도 제한으로 분리
- 원본의 증상·업체 소통·평소 정비 이력 작성 안내를 한국어로 현지화
- 입력 행을 얇은 구분선 기반의 원본형 플랫 레이아웃으로 변경
- 활성 선택은 보배드림 에어비앤비 블랙 스타일로 통일

## 6. 설계 권고

### 즉시 유지해야 할 것

- 중국의 공식 통지·처리 상태를 흉내 내지 말고 `공개·추가 제보·해결 후기` 상태만 운영한다.
- 차대번호와 엔진번호는 사용자가 입력하더라도 공개 게시물에는 절대 저장하지 않는다.
- 수입차는 수입사와 판매 딜러사를 분리해 이해관계자를 특정할 수 있게 한다.
- 사고·인명피해가 `있음`이면 안전 경고와 운행 중지 안내를 우선 노출한다.

### 다음 강화 단계

- 작성 중 자동 저장과 이탈 경고
- 차량번호·VIN 마스킹 미리보기
- 동일 모델·동일 증상 중복 사례 추천
- 제조사·수입사·딜러사별 통계와 해결 후기 필터

## 7. 증거 한계

- 원본 앱에는 실제 제출을 하지 않았다. 제출 이후의 중국 서버 심사·통지·수정 제한 상태는 캡처 근거가 없으므로 구현 판정에서 제외했다.
- 웹 파일 첨부는 현재 선택 화면 프로토타입이다. 실제 업로드·서버 저장·악성 파일 검사는 다음 백엔드 단계가 필요하다.
- 외부 기관 공식 접수 기능은 한국 운영 범위에서 제외했다.
