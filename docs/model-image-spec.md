# 모델·세부모델 이미지 코드 정렬 규칙 (QF-109)

과쯔 모드 모델 줄·세부모델 줄 이미지는 출처(당근 · 보배드림 · 나중의 AI 생성)와 관계없이 **코드 정렬 부품 하나**(`scripts/image-normalize.mjs`)로 만든다. 새로 그리거나 색을 바꾸지 않는다(크기·위치만).

> 이 문서는 현재 QF-109 구현 규격이다. 초톳 앱·모바일웹 실측과 보배드림 차기 공용 슬롯 규칙은 `docs/quick-filter-image-slot-rules_v02.md`를 우선한다.

## 1. 정렬 부품
| 단계 | 규칙 |
|---|---|
| 흰 배경 | 가장자리 픽셀의 40% 이상이 불투명한 흰색(RGB 모두 235 이상)이면, 가장자리에서 이어진 흰색만 투명으로(차 안의 흰색은 남김) |
| 여백 자르기 | 알파 16 이하 여백을 자른다 |
| 출력 | 228×120 투명 PNG |
| 차 폭 | 224 고정, 가로 가운데 |
| 차 높이 | 폭 224일 때 높이가 100을 넘으면 높이 100으로 줄인다(폭은 그만큼 좁아짐) |
| 바닥선 | 차 아래 끝 y = 111 고정 |
| 확대 | 원본보다 크게 키워야 하면 키우지 않고 원본 크기 그대로(바닥선만 맞춤), manifest `upscaleSkipped` |
| 그림자 | 코드로 그림: 타원 가로 220 · 세로 12, 중심 (114, 113), 검정 14% → 가장자리 0%, 차 뒤에 |
| 반전 | 좌우 반전 금지 |

## 2. 출처 순서
1. 당근 중고차 subseries 이미지(`node scripts/daangn-fetch.mjs` — 1초에 1번, 실패하면 30초 쉬고 3번까지, 원본은 `tmp/daangn-cache/`에만) — 세대 맞춤표로 연결된 것만
2. 연결이 없으면 보배드림 `model_{번호}.png`(카탈로그 image_url)
3. 둘 다 없으면 빈 칸(점선)

## 3. 세대 맞춤표(`scripts/model-images-dg.mjs`)
확실하지 않으면 연결하지 않는다. 결과: `src/prototype/data/model-image-match.json`, `reports/qf-109/match.csv`.
| 규칙 | 확신도 | 예 |
|---|---|---|
| 코드 일치: 당근 이름에 보배 코드가 있고 코드·"N세대"를 뺀 이름이 같음 | 높음 | "더 뉴 그랜저"·IG ↔ "더 뉴그랜저IG" |
| 이름 일치: 띄어쓰기·괄호만 다름(모델 안에서 그 이름이 하나뿐일 때만) | 높음 | "디 올 뉴 그랜저" ↔ "디 올뉴그랜저" |
| 세대 번호 일치: 보배 세대 번호가 당근에 모두 있으면 같은 번호끼리 | 높음(당근에 더 새 세대가 있으면 중간) | C클래스 W206(5) ↔ "C클래스(5세대)" |
| 세대 밀어 맞춤: 보배 번호가 당근에 없을 때 최신 세대끼리 맞춰 차이만큼 옮김 | 중간 | E클래스 W214(11) ↔ "E클래스(6세대)" |
| 세대 없는 이름 = 1세대: 당근이 "(2세대)"부터 있고 이름만 있는 칸이 하나 | 중간 | X1 E84 ↔ "X1" |
| 파생형 세대 일치 | 높음 | "2시리즈 액티브 투어러" U06(2) ↔ "액티브투어러(2세대)" |
| 단일 일치: 양쪽 하나뿐 | 높음 | 벤츠 190 ↔ "190-클래스" |
- 세대 번호 규칙은 이름이 모델 이름과 같은 세부모델에만(파생형은 파생형 규칙으로)
- 이름이 다른 보배 세부모델 여럿이 같은 당근 칸을 가져가면 보배 이름이 당근 이름과 정확히 같은 쪽만 남긴다(예 "더 뉴 아반떼"(13~15, 보배 코드 AD) ✕ "더 뉴아반떼AD")
- 당근 목록(최신 → 과거) 순서와 보배 연식 순서가 뒤집히면 "중간"
- 보배 한 칸에 당근 여러 개 → 당근 목록에서 가장 최신 것 하나 / 당근 한 칸을 보배 여러 칸이 쓰면 manifest `shared`
- 모델 대표 이미지 = 최신 세부모델부터 당근 이미지가 있는 첫 칸(없으면 최신부터 이미지가 있는 첫 칸)

모바일 값은 2026-10-03 초톳 실사 슬롯 1080×2340 캡처를 384 CSS px로 환산해 갱신했다. 세단·SUV·바이크처럼 차체 비율이 달라도 이미지 높이를 억지로 맞추지 않고, 투명 캔버스와 하단 기준선만 통일한다.

## 5. 점검
`npm run check:model-images` — 모든 파일 228×120 · 차 바닥선 111±1 · 차 폭 224±1(높이 제한이면 높이 100±1) · 가운데 ±1 · 그림자 표본 ±3, 화면 칸 규격과 로고 바닥 = 차 영역 바닥.

## 6. 다시 만들기
`node scripts/daangn-fetch.mjs` → `node scripts/model-images-dg.mjs`(끝에 `scripts/model-catalog-data.mjs`) → `npm run check:model-images`
