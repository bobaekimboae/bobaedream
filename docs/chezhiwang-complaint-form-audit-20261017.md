# 처즈왕(车质网) 불만 등록 전수조사 및 보배드림 이식 명세

- 조사일: 2026-10-17
- 원본 앱: 车质网 / `我要投诉`
- 조사 방식: USB 연결 Android 실제 앱 화면을 단계별 캡처하고 UI 계층 XML을 함께 보관
- 안전 범위: 빈 필수값 상태에서 클라이언트 검증만 확인. 중국 서비스에 불만을 제출하지 않음
- 캡처 폴더: `artifacts/chezhiwang-complaint-form-audit-20261017/`
- 구현 URL: `community/naver-cafe-list.html?board=chezhiwang-complaint`

## 1. 전체 흐름

1. 작성자 정보 입력
2. 자동차/바이크 선택
3. 제조사 → 모델 → 세부 모델 선택
4. 차대번호·엔진/모터 번호·차량번호 입력
5. 구매일·문제 발생일 선택
6. 사고 여부·인명 피해 여부·발생 주행거리 입력
7. 지역(성/도 → 도시) → 판매/정비 업체 선택
8. 사진/영상 첨부
9. 불만 유형 선택
10. 유형별 세부 항목 선택
11. 짧은 설명·상세 설명 입력
12. 필수값 누락 검증 후 제출

보배드림 이식본은 위 흐름을 유지하되 공식 접수·제조사 통지 기능을 가장하지 않고, 이용자 공개 공론화와 동일 사례 수집까지만 제공한다.

## 2. 원문과 한국형 문구

| 중국어 원문 | 한국형 문구 | 동작 |
|---|---|---|
| 我要投诉 | 불만 등록 | 등록 화면 제목 |
| 提交 | 등록 | 상단/하단 제출 |
| 汽车 / 摩托车 | 자동차 / 바이크 | 제조사 카탈로그 분리 |
| 品牌 / 车系 / 车型 | 제조사 / 모델 / 세부 모델 | 순차 선택 |
| 车架号 | 차대번호 | 비공개 확인 필드 |
| 发动机号 | 엔진·모터 번호 | 비공개 확인 필드 |
| 车牌号 | 차량번호 | 비공개 확인 필드 |
| 购车日期 | 구매일 | 날짜 선택 |
| 问题日期 | 문제 발생일 | 날짜 선택 |
| 是否发生事故 | 사고 여부 | 있음/없음 |
| 是否造成人员伤亡 | 인명 피해 | 있음/없음 |
| 行驶里程 | 발생 주행거리 | km 숫자 입력 |
| 经销商所在区域 | 지역 | 시·도/시·군·구 |
| 经销商 | 판매·정비 업체 | 계약서상 사업자명 |
| 投诉类型 | 불만 유형 | 품질/서비스/기타/종합 |
| 问题简述 | 짧은 설명 | 원본과 동일하게 24자 제한 |
| 问题描述 | 상세 내용 | 사실 중심 서술 |

보배드림 요구에 따라 `제목(60자)`을 별도로 처음부터 추가했다.

## 3. 유형별 가변 항목

### 品质问题 → 품질

1. 发动机/电动机 → 엔진·모터
2. 变速器 → 변속기
3. 离合器 → 클러치
4. 转向系统 → 조향 시스템
5. 制动系统 → 제동 시스템
6. 轮胎 → 타이어
7. 前后桥及悬挂系统 → 전후 차축·서스펜션
8. 车身附件及电器 → 차체 부속·전기장치

### 服务问题 → 서비스

1. 服务态度 → 서비스 태도
2. 人员技术 → 정비 기술
3. 服务收费 → 서비스 비용
4. 承诺不兑现 → 약속 불이행
5. 销售问题 → 판매 과정
6. 配件争议 → 부품 분쟁
7. 服务流程不完善 → 서비스 절차 미흡

### 其他问题 → 기타

1. 召回问题 → 리콜 문제
2. 产品问题 → 제품 문제
3. 配套问题 → 공급·협력 문제
4. 其他问题 → 기타 문제

### 综合问题 → 종합

- 품질·서비스·기타의 세 선택 그룹을 모두 노출한다.
- 서로 다른 세부 항목을 합계 2개 이상 선택해야 등록 가능하다.

## 4. 차량 유형과 이해관계자 가변 요소

- 자동차: 기존 보배드림 중고차 제조사/모델/세대 카탈로그를 사용한다.
- 바이크: 별도 제조사/모델 목록을 사용한다.
- 국내 신차: 제조사 + 신차 판매점/정비 지점
- 공식 수입차: 제조사 + 공식 수입사 + 수입차 딜러사 + 판매/정비 지점
- 병행수입차: 제조사 + 병행수입 업체 + 판매 업체
- 중고차: 제조사/모델 + 판매 상사/담당자

공개 상세에는 이해관계자 식별 정보만 표시하고 차대번호, 엔진 번호, 전체 차량번호, 연락처는 표시하지 않는다.

## 5. 미디어·검증 규칙

- 사진: 최대 6장, 장당 최대 5MB
- 영상: MP4, 최대 50MB
- 제출 시 누락 필드 아래에 주황색 오류 문구 표시
- 첫 번째 누락 항목으로 자동 스크롤
- 자동차/바이크를 바꾸면 제조사·모델·세부 모델 선택을 초기화
- 품질/서비스/기타는 세부 항목 1개 이상, 종합은 2개 이상 필수
- 짧은 설명은 24자, 제목은 60자, 상세 내용은 3,000자 제한
- 실제 중국 서버 전송 없이 로컬 저장소 `bobae-chezhiwang-complaints-v1`에만 저장
- 댓글 저장소 `bobae-chezhiwang-complaint-comments-v1`는 다른 게시판과 완전히 분리

## 7. 보배드림 구현 화면

- 목록: 브랜드 로고 프사, 실차주 표시, 모델, 공개 상태, 유형·세부 항목, 제목, 내용, 실제 차량 이미지, 댓글·공감
- 상세: 차량/발생 정보, 업체, 불만 내용, 이미지, 댓글, 저장·공감
- 등록: 원본 순서, 차량 유형별 카탈로그, 유형별 가변 항목, 인라인 오류, 민감 정보 비공개 안내
- 공개 상태: `공개`, `추가 제보`, `작성자 업데이트`, `해결 후기`

공식 접수, 제조사 통지, 행정 처리 상태는 한국형 범위에서 제외했다.
