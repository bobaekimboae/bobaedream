## 보존 규칙

- V1 파일을 덮어쓰지 않는다. 변경본은 새 파일과 V2, V3 기록으로 추가한다.
- 각 버전은 입력 자료, 변경 내용, 제작 설정, 재생 URL, 배포 커밋, 파일 해시, 검수 결과를 기록한다.
- 아이디어·제작 예정과 실제 제작·배포 완료를 구분한다. 제작 완료 버전도 사용자 최종 디자인 승인과 구분한다.
- 기술 검수 통과는 사용자 디자인 승인, 음성 청취 승인, 저작권 확보 또는 운영 서비스 완성을 의미하지 않는다.

- [차란차 원본 매물](https://charancha.com/cars/01a1570c-df73-700d-a3be-38c580900138)의 사진 4종 사용. 전면·후면·시트·열선/통풍 버튼을 구성하고 번호판 부위는 블러 처리했다.
- 등록 정보에 있는 앞좌석 열선·운전석 통풍을 소개했다. 실제 장비 실사 검증은 하지 않았다.
- Pretendard Variable, 블루 `#2F65D9`, 배경 `#F5F6F8`, 본문 `#15191F`. 사진의 완만한 확대와 텍스트 등장 효과.
- Edge 한국어 남성 `ko-KR-InJoonNeural` 내레이션. 음성 복제·BGM·합성 엔진음 없음.
- HyperFrames 0.8.221로 제작 후 FFmpeg로 오디오 음량과 웹 재생 호환성을 정리했다.

## V1 확인 결과와 제한

- 1080×1920, 30fps, 31초. H.264/yuv420p + AAC 48kHz, faststart.
- 파일 11,932,445 bytes. SHA256: `F512AD65E2B7D03730274AB36000C01F65C0AC2F75F067FDE15503CBAB2A1D44`.
- 측정 음량 -14.2 LUFS, true peak -1.9 dBTP. 검출된 검은 구간 0, 3초 초과 정지 구간 0.
- HyperFrames lint 오류·경고 0, 브라우저 검사 오류 0. 프레임과 장면 연결부 육안 확인.
- 음성을 직접 청취한 자연스러움·발음 승인은 미완료다.
- HTTP 200, byte-range 206, 원격 미디어 규격 확인 완료. [배포 실행](https://github.com/bobaekimboae/bobaedream/actions/runs/41368635008) 성공.
- 외부 매물 사진의 상업적 재배포 권리는 확인되지 않았다. 출처 표기와 제작 샘플 고지를 유지하며 실제 판매 광고나 SNS 자동 배포에 재사용하지 않는다.
- 실제 차량을 생성형 AI로 바꾸지 않았다. 딜러 제휴·차량 인증·음악 권리 확보를 주장하지 않는다.
- 장면별 흰 여백, 전면 사진 반복, 마지막 장면 길이는 후속 개선 검토 대상이다.
- Nuxt/Laravel 자동 제작 서비스나 SNS 게시 API를 구현한 결과가 아니라 렌더링된 샘플이다.
