## 동작 규칙 (QF-085·086·089·090, 원본 2026-09-24 실측)
| 위치 | 언제 조건이 걸리나 | 목록·총 대수·최근검색기록 |
|---|---|---|
| PC 사이드바 체크박스·구간 칩 | 누르는 즉시 | 즉시 |
| PC 사이드바 모달(연료 등) | [확인 N대]를 눌러야(모달 안은 초안, X는 버림) | 확인 뒤 |
| PC 상단 칩 모달(연식·가격·연료·판매자) | 누르는 즉시(적용 칩·배지) | 창을 닫을 때 |
| 모바일 칩 바텀시트 | 누르는 즉시(적용 칩·배지) | 시트를 닫을 때 |
| 모바일 전체 필터 → 항목 시트 | 시트의 [N대 보기](전체 화면은 열린 채) | 즉시 |
| PC 사이드바 "초기화" | 확인 창 "필터 초기화 / 선택한 필터를 초기화하시겠습니까? / [취소][초기화]" | 초기화 뒤 |

- 버튼 숫자("확인 N대"·"N대 보기")는 누르기 전 목록 수
- 적용 칩: 진한 채움 + ×. 값이 걸린 필터 칩(연식·가격·연료·판매자)은 줄에서 빠지고 그 자리에 적용 칩. 제조사를 고르면 [현대 ×][모델]
- 적용 칩 문구: 체크는 선택지 이름("SUV", "디젤", "7인승"), 가격 "3,000만원부터 3,999만원까지", 연식 "2023년 9월 ~ 2026년 9월", 주행거리 "5천부터 1만까지 km"
- 적용 칩 순서: 거는 순서와 무관. 바디타입 → 연료 → 가격 / 연식 → 인승 → 판매자 구분 → 주행거리(두 번 실측, 나머지는 추정)
- 구간 칩은 입력칸을 채운다: 3천만원 → 3,000 · 3999, ~3년 → 2023년 9월 ~ 2026년 9월, 5천~1만km → 5,000 · 10,000
- "필터" 칩: 아이콘 + 개수(진한 채움, 안쪽 4/14/4/8). PC 칩은 누를 수 없음
- 사이드바: 머리 배지 26 원형 #222, 값이 걸린 항목 제목 #1B4C8C + 왼쪽 3px 막대
- 최근검색기록: 첫 조건에서 1이 되고 그 뒤로 늘지 않음
- 모바일 칩 줄: 새 적용 칩의 왼쪽이 스크롤 영역 왼쪽에서 약 47px 에 오도록 스크롤
