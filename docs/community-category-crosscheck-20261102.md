# 게시판 바로가기 분류 변경·교차검증 v1.1

- 작성: Codex, 2026-11-02 KST
- 기준: origin/main `afa36b7` / 브랜치 `codex/community-category-labels-20261102`
- 대상: 기존 정적 커뮤니티 비교 시안의 카테고리 데이터와 관련 스크롤 보정. 신규 React/Nuxt 화면·백엔드 구현이나 전체 이관 작업이 아님.
- 사용자 프론트 신규 개발 기준은 Nuxt 4 + Vue 3 + TypeScript, 업무 API는 Laravel 12 + PHP 8.4 유지. 이번에는 해당 manifest/lockfile/의존성을 교체하지 않음.

## 확정 적용

분류 순서: **일반 → 자동차 → 차량/운송 → 사건제보 → 결함/불만**.

- 차량/운송: 트럭/버스/중기, 항공/해운/철도, 오토바이/자전거.
- 사건제보: 기존 교통사고/블박, 직찍/특종발견 유지.
- 결함/불만: 기존 차량 결함·불만, 처즈왕 결함·불만 유지.
- 항공/해운/철도만 일반에서 차량/운송으로 재분류. 게시판 ID, 정식 게시판명, 주제 키, 주소, 기본 홈/즐겨찾기 저장 키는 유지.
- 퀵 바로가기 분류와 햄버거 분류는 같은 `sections()` 원본을 사용하므로 함께 변경.

## 시각·브라우저 검수 한계

검수는 Chrome 데스크톱의 뷰포트 변경이며 실제 iOS/Android가 아니다. 추가·삭제·터치 드래그·실행취소의 전체 경로를 이번 검사에서 승인하지 않았다. 이번 화면 일부에는 ‘저장’ 검정 아이콘 오버레이가 나타났으나 해당 좌표의 앱 DOM에서 아이콘 출처를 확인하지 못했다. 브라우저/확장 레이어 가능성을 포함해 출처를 분리해야 하며, 이 증거만으로 앱 CSS 결함이라고 확정하지 않는다.

사진/영상, 게시물 원본, 회원 권한, 서버/DB/검색 색인 변경 없음. 바이두 원본 실측에 대한 이전 다른 에이전트의 보고를 이번 실측으로 재사용하지 않았으며 동일성 승인도 하지 않는다.
