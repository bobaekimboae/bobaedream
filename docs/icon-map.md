## 참고

- 요청 카테고리 중 `셰브론`·`하트(좋아요)`·`벨(알림)`·`중고차 필터`에는 SVG 파일이 달린 행이 없어, 같은 이름의 `UI 기본 아이콘`·`셰브론_화살표` 행을 썼다.
- `하트_그레이`(아이콘 배경)는 채워진 하트라 원본의 외곽선 하트와 달라 `즐겨찾기`로 대체했다.
- `저장된 검색` 아이콘은 채워진 북마크라 원본 검색저장 버튼(외곽선)과 맞는 `북마크`로 대체했다.
