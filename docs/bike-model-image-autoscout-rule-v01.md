# 바이크 모델 이미지 제작 규칙 v01

## 1. 기준 분리

- 모델 외형·부품 구성: 오토홈 바이크와 제조사 공식 이미지를 참고한다.
- 촬영 각도·배치·조명·그림자: 오토스카우트24식 카탈로그 규칙을 적용한다.
- 참고 이미지를 복사하거나 잘라 붙이지 않고 새 이미지로 제작한다.

## 2. 마스터 규격

- 제작 캔버스: 1920×1200 또는 동등한 고해상도, 가로세로비 16:10
- 서비스 슬롯: 84×56px(3:2), `object-fit: contain`, 중앙 정렬
- 배경: 불투명 순백색 `#FFFFFF`
- 출력: PNG, 텍스트·로고·번호판·워터마크 없음

## 3. 방향과 구도

- 차량은 반드시 화면 왼쪽을 본다.
- 기본 각도는 좌향 앞 3/4이다. 정면이나 완전 측면은 사용하지 않는다.
- 모델 식별을 위해 옆면을 충분히 보여준다.
- 카메라 높이는 바퀴 허브 높이로 고정한다.
- 양쪽 바퀴와 미러·핸들·머드가드를 모두 캔버스 안에 넣는다.

## 4. 슬롯 내 수치

- 긴 차체의 시각 폭: 캔버스의 88~90% 이내
- 미러가 높거나 차체가 세로로 긴 유형은 시각 높이 90~92%를 먼저 맞추고, 그 결과의 폭을 사용한다. 폭을 맞추려고 미러·윈드스크린을 자르거나 차체 비율을 찌그러뜨리지 않는다.
- 차량 중심 오차: 캔버스 중심 대비 ±2%
- 타이어 바닥선: 캔버스 높이의 92~94%
- 위쪽 여백: 미러 또는 윈드스크린을 기준으로 일관되게 유지
- 스쿠터·언더본·스포츠·네이키드·크루저는 실제 비율을 유지하되 중심과 바닥선은 동일 규칙을 따른다.

## 5. 조명과 그림자

- 중성 주광색의 부드러운 스튜디오 조명을 사용한다.
- 타이어 바로 아래에 짧고 연한 회색 접지 그림자만 둔다.
- 긴 투영 그림자, 검정 배경, 비네팅, 바닥 반사는 사용하지 않는다.
- 흰색·은색 차체는 흰 배경에서 사라지지 않도록 중간 명도의 출시 색상을 우선한다.

## 6. 색상

- 제조사 출시 색상 또는 모델을 잘 식별할 수 있는 대표 색상을 사용한다.
- 같은 제조사 목록에서는 색상을 반복하지 않아 빠르게 구분되게 한다.
- 예시: 스쿠터 딥 네이비, 언더본 레드·크림, 스포츠 레드, 네이키드 그래파이트, 투어링 티타늄 그레이, 크루저 버건디.
- 색상만 바꾸고 차체 형상·휠베이스·램프·엔진·배기 구조는 임의로 변경하지 않는다.

## 7. 검수

- 84×56px 실제 슬롯에서 모델이 즉시 식별되는지 확인한다.
- 좌향 여부, 바퀴 2개 노출, 미러·윈드스크린 잘림, 타이어 접지, 배경색을 확인한다.
- 동일 화면에 5장 이상 배치해 높이·크기·바닥선 편차를 비교한다.
- 규칙을 벗어난 이미지는 기존 파일을 덮어쓰지 않고 `-v02`, `-v03`으로 새로 저장한다.
