- 적용 대상: 중고차·바이크·트럭/특장·건설기계의 카테고리, 브랜드, 모델, 세부모델 퀵필터
- 측정 시트: [보배드림 퀵필터 이미지·로고 슬롯 규칙 v02](https://docs.google.com/spreadsheets/d/1vCy9bVCo6xcpkzeSOQ3iMH5lXGKV7zak8Bb88BtWaIg/edit?usp=drivesdk)
- 근거: 초톳 1080×2340 캡처 12장, `xe.chotot.com` 384px 직접 테스트, 코덱스-중고차·자료·특장 상호 검수

## 1. 측정 원칙

1. 1080px 원본은 384 CSS px 화면으로 보고 `2.8125`로 환산한다.
2. 원본 픽셀값, CSS 환산값, 보배드림 채택값을 별도 열로 기록한다.
3. 초톳 앱 캡처, 현재 모바일웹, PC웹을 같은 규격으로 단정하지 않는다.
4. 캡처만으로 확인할 수 없는 원본 형식·알파 채널·PC 슬롯은 `미확인`으로 둔다.
5. 같은 자산을 재사용하되 화면별 래퍼 크기와 맞춤 방식은 용도에 따라 분리한다.

## 3. 실사형 제작 규칙

- 투명 컷아웃은 같은 색온도, 같은 방향, 같은 하단 기준선을 사용한다.
- 승용·SUV·바이크의 높이를 억지로 같게 만들지 않는다.
- 차량은 바퀴·그림자, 사람은 발을 하단 기준선에 맞춘다.
- 카테고리 메인 래퍼는 64×48, 리스트 상단 퀵필터 래퍼는 64×40이다.
- 원본에 외부 투명 여백을 굽지 않는다. 화면별 래퍼가 여백을 담당한다.
- `object-fit: cover`, 좌우 반전, 차종별 임의 확대를 탐색용 컷아웃에 사용하지 않는다.
- 정규화 작업 영역은 8:5로 관리하되 최종 투명 파일은 외곽 여백을 제거한 tight crop으로 내보낸다. 64×48·64×40 래퍼가 화면별 상한과 여백을 담당한다.
- 권장 마스터는 투명 WebP/PNG, 최소 256×192이며 PC 확대 가능성이 있으면 4배 원본 또는 `srcset`을 제공한다.

### 트럭·버스·특장·모터홈

- 퀵필터 정규화 작업 영역은 8:5이며 차체 bbox 최대 84%를 사용한다. 최종 파일은 tight crop으로 내보낸다.
- 안전영역은 좌우 각 8%, 상하 각 6~8%다.
- 긴 트레일러는 폭 기준, 버스·고상차는 높이 기준으로 축소한다.
- 앞·뒤 끝, 적재함, 트레일러, 후축, 지붕, 오버캡, 바퀴가 잘리지 않아야 한다.
- 실제 매물 사진은 트럭·버스·트레일러 목록 템플릿 전체에 4:3을 필수 적용한다. 같은 목록 안에서 1:1과 4:3을 카드별로 섞지 않는다.
- 원본은 최소 800×600이며 모바일·PC가 같은 focal point와 `object-position` 메타데이터를 사용한다.
- 앞뒤 끝·후축·지붕이 잘리면 해당 소스의 재프레이밍을 요구하고 검수 불합격으로 처리한다.

### 캠핑카 유형

| 표시명 | 보조 설명 | 이미지 식별점 |
|---|---|---|
| 클래스 A | 버스형 | 평평한 버스형 전면과 일체 차체 |
| 클래스 B | 밴형 | 원형 밴 차체 유지, 독립 오버캡 없음 |
| 클래스 C | 캡오버형 | 운전석 위 돌출형 취침부 |

Class A/B/C는 텍스트 칩만 쓰지 않는다. 카드에는 위의 짧은 2줄만 표시하고 긴 설명은 `aria-label`과 상세 도움말에 보존한다. 같은 3/4 방향·바퀴 기준선·명암의 실루엣 비교용 실사 카드를 사용하며, 64×40 실크기에서 색상 없이도 세 유형이 구분되어야 한다.

## 4. 브랜드 로고 규칙

- 래퍼: 40×40.
- 원형·정사각 엠블럼: 긴 변 31~33px.
- 가로 심벌·워드마크: 폭 36~40px.
- 카드: 76px, 간격 8px, 중심 피치 84px.
- 브랜드는 긴 제조사명을 최대 2줄로 담기 위해 아이콘보다 넓은 76px 카드를 사용한다.
- SVG를 우선하고, 래스터는 투명 PNG/WebP 최소 160×160을 사용한다.
- 배경·테두리·그림자는 넣지 않는다.
- 로고마다 40px를 꽉 채우지 않고 형태군별 광학 크기를 맞춘다.
- 원본 내부 여백이 큰 로고는 여백을 제거한 뒤 정규화한다.

## 5. 아이콘 규칙

### 원형 칩

- 외곽 원 40×40, 내부 glyph 최대 28×28.
- 카드 64px, 간격 8px, 중심 피치 72px. 유형명은 브랜드명보다 짧아 64px 카드를 사용한다.
- 배경 기본 `#F4F4F4`, 선택 `#EAEAEA`를 기준으로 하되 선택 상태 토큰은 제품 테마가 관리한다.
- 원형 배경은 CSS 레이어이며 SVG/PNG 원본에 포함하지 않는다.
- 터치 영역은 시각 크기와 별도로 최소 44×44다.

### 아이콘 단독

- 투명 40×40 래퍼, glyph 긴 변 최대 36px.
- 배경 원과 그림자를 넣지 않는다.
- 선 굵기와 광학 중심을 한 세트 안에서 통일한다.

## 6. 긴 명칭 규칙

컴포넌트 용도에 따라 처리한다.

| 컴포넌트 | 규칙 |
|---|---|
| 이미지 퀵필터 카드 | 14/20, 최대 2줄, `line-clamp: 2`, 초과 시 말줄임 |
| 고정폭 선택창·목록 | 16/24, 1줄, `nowrap`, `ellipsis` |
| 자연폭 모델 알약 | 높이 32, 좌우 12, 14/20, `width:max-content; flex:none; white-space:nowrap`, 가로 스크롤 |

- 긴 이름 때문에 글자 크기를 줄이지 않는다.
- 짧은 `displayName`을 쓸 수 있지만 원문은 데이터와 `aria-label`·`title`에 보존한다.
- 자연폭 알약도 `max-inline-size: calc(100vw - 32px)` 안전 상한을 두고, 상한을 넘을 때만 말줄임한다. 모바일에서 `title`은 전체명 확인 수단으로 간주하지 않고 `aria-label`과 접근 가능한 상세 UI를 제공한다.
- 현재 초톳 모바일웹의 `Corolla Cross` 모델 알약은 약 108×32로 자연폭이며 말줄임이 없다.
- 현재 초톳 모델 선택창의 `CRF 1000L Africa Twin`은 고정폭 안에서 1줄 말줄임이다.

## 7. 모바일·PC 공용 정책

- 모바일과 PC는 같은 마스터 자산, 방향, 초점, 안전영역을 사용한다.
- PC는 화면이 넓다는 이유로 자산을 자동 확대하지 않고 레일에 더 많은 항목을 노출한다.
- 앱 캡처값과 현재 반응형 웹값은 별도 표면으로 기록한다.
- 초톳 PC의 실제 슬롯은 미확인이므로 보배드림 PC 값은 내부 제품 규칙으로 표기한다.
- DPR 1/2/3에서 업스케일과 흐림을 확인한다.

## 8. 검수 체크리스트

- [ ] 원본 픽셀값과 CSS 환산값을 구분했다.
- [ ] 1080→384, 배율 2.8125를 사용했다.
- [ ] 카테고리 메인 64×48과 리스트 퀵필터 64×40을 구분했다.
- [ ] 실제 매물 사진에 컷아웃 `contain` 규칙을 적용하지 않았다.
- [ ] 브랜드 카드 피치 84, 아이콘 카드 피치 72를 구분했다.
- [ ] 중심 피치 측정 오차가 ±1 CSS px 이내다.
- [ ] 로고·아이콘에 흰 배경이 구워져 있지 않다.
- [ ] 이미지 카드 라벨이 14/20, 최대 2줄이다.
- [ ] 선택창, 이미지 카드, 자연폭 알약의 긴 이름 규칙이 서로 다르다.
- [ ] 장축 차량의 앞뒤 끝·후축·지붕·오버캡·바퀴가 보인다.
- [ ] 같은 목록 안에서 1:1과 4:3 썸네일을 혼용하지 않는다.
- [ ] 같은 자산과 초점이 모바일·PC에 유지된다.
- [ ] 콘솔 404와 이미지 왜곡이 없다.
