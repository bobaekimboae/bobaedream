# 차량 숏폼 촬영 스튜디오

기준 소스: main `51e8c2d8`. 작업 브랜치: `codex/shoot-studio-parts`.

## 진입과 범위

- `?register=shoot&studio=1` 또는 `/shoot/?studio=1`로 바로 연다.
- 기존 등록 화면의 `영상 추가`와 `보배드림 숏폼 스튜디오`에서 연다.
- 사진·차량 인증·실제 매물 등록 기능은 변경하지 않는다.
- 완성 후 `이 영상을 등록 화면에 추가`는 세션 내 영상 칸에만 반영한다. 외부 등록 요청을 보내지 않는다.
- 공개 배포는 수행하지 않았다. 로컬 개발 서버는 4192 포트다.

## 구현

- 앞좌석 시트와 뒷좌석 시트 독립 클립.
- 일반/패밀리·SUV/전기차/오픈카별 규칙 기반 추천. 기존 촬영본·사용자 부위를 지우지 않고 추가한다.
- 직접 부위 생성: 이름, 촬영 안내, 확인한 자막, 1~60초 사용 길이, 현장음 설정.
- 부위별 촬영 또는 앨범 입력. 원본 시작 구간 설정. 클립 교체와 부위별 포함/제외.
- 전문 모드: 순서 이동, 삭제 확인. 간편 모드: 촬영·앨범 중심으로 조작을 줄인다.
- 카메라는 사용자가 촬영을 눌러 연다. 실제 스트림이 준비되기 전 녹화를 막으며, 실패/권한 미응답 시 앨범 경로를 제공한다. 시험 영상으로 대체하지 않는다.
- 촬영은 최대 60초이며 편집 사용 길이와 독립적이다.
- 15/30/45/60초 목표에 맞춰 실제 사용 가능한 클립을 프레임 단위로 비례 배분한다. 미촬영·제외 부위는 빠진다. 부족한 길이를 반복/정지 화면으로 채우지 않는다.
- 브라우저에서 H.264 MP4 720x1280 또는 1080x1920/30fps를 생성한다. 가로 원본은 contain으로 보존한다.
- 차량명·부위명 또는 사용자 자막, 보배드림 워드마크를 합성한다.
- 현장음을 보존하며 혼합 채널/샘플레이트는 OfflineAudioContext로 stereo 48kHz에 맞춰 AAC로 인코딩한다. 출력 지원이 없으면 오류 안내하며 몰래 무음으로 대체하지 않는다.
- MP4 저장/기기 공유, JPG 표지 저장, 게시 문구 복사.
- IndexedDB 초안: 설정과 Blob 원본을 저장한다. 직접 저장/불러오기를 제공하며 불러오기는 현재 편집 교체임을 명시한다. 서버 업로드 및 계정 동기화 없음.
- 프로젝트·화질 변경 시 이전 완성본을 무효화한다. 생성 취소는 원본을 유지한다.

## 검증

- `npm run verify:qf`: 런타임 28개 보호 파일 무변경, TypeScript와 Vite 통과.
- `node --test tests/shoot-studio-model.test.mjs`: 8개 통과.
- 생성 부위 7초 설정과 순서 이동 확인.
- 새 탭에서 초안 불러오기: Blob 원본, 1초 시작/2초 사용 설정 확인.
- 세로 음성 테스트 파일 + 가로 무음 테스트 파일: 실제 출력 H.264 720x1280, 영상 5초, AAC 음성 존재 및 신호 확인.
- 사용 가능 19초 이상 클립의 15초 비례 배분: 실제 H.264 1080x1920 영상 15.000초 확인.
- mono 48kHz와 stereo 44.1kHz 혼합: 실제 출력 AAC stereo 48kHz, 음성 신호 확인. AAC 패딩으로 컨테이너 길이는 약 15.019초.
- 기존 등록 화면에 결과 추가, 재생 화면 진입 확인. 불러온 완성 영상에 원래 4단계 칩을 잘못 표시하던 부분과 빈 길이 NaN 표시를 수정했다.
- 테스트에 쓴 컬러 패턴 영상은 기능 검사용 합성 파일이며 실제 차량 촬영본으로 제시하지 않는다.

## 한계

- 실제 휴대전화 카메라·마이크 녹화 및 iOS 공유 동작은 실기 검증하지 않았다.
- WebCodecs AVC/AAC 지원 브라우저 필요. 서버 렌더링 대체 경로 없음.
- AI 옵션 인식, 흔들림/초점 자동 판정, 내레이션, 배경음악, SNS 계정 연결/자동 게시 미구현. 규칙 기반 편집임을 화면에 명시했다.
- 원본은 기기에만 저장되며 브라우저 데이터 삭제·용량 제한에 영향을 받는다.
- 빌드 경고: 기존 대형 번들 경고와 sparse 작업본의 일부 비촬영 자산 경로 경고. Storybook 출력 없음.
