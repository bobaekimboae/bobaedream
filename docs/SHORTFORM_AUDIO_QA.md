# 숏폼 음성 겹침 재발 방지

2026-11-04 BMW X5 60초 영상의 좌우 음성 시간차 오류를 수정했다.

## 원인과 실측

음성을 250ms 늦추려던 `adelay=250`는 나머지 채널에 같은 지연을 적용하지 않는다(`all=false` 기본값). 스테레오 배경음악과 믹스하는 동안 FFmpeg가 채널 형식을 협상하면서 왼쪽 음성만 250ms 지연되고 오른쪽 음성은 0ms에 남았다.

| 비교 | 왼쪽 원본 대비 지연 | 오른쪽 원본 대비 지연 | 좌우 차이 |
|---|---:|---:|---:|
| 문제 배포본 | 250ms | 0ms | 250ms |
| 수정본, 6개 발화 구간 | 250ms | 250ms | 0ms |

문제 배포본과 로컬 파일의 디코딩 오디오가 일치했다. 따라서 CDN에서 새로 생긴 문제가 아니었다. 수정 과정에서 영상 스트림 SHA-256은 동일함을 확인했다.

## 생성과 완료 기준

- 공용 `makeDialogueMix`로 음성을 명시적 모노로 정규화한 뒤 `adelay=...:all=1`을 적용하고, 그 다음 두 채널에 복제한다. 음성에 딜레이·리버브·코러스 효과를 사용하지 않는다.
- 각 채널을 **독립적으로** 음성 원본과 비교한다. 최종 파일에 음악이 있으므로 단순 L/R 상관도만으로 판정하지 않는다.
- 최소 3개 이상의 발화 구간, 좌우 지연차 1ms 이하, 약속한 시작 시각 오차 2ms 이하, 원본과의 파형 상관도 0.97 이상을 기술 통과 조건으로 삼는다.
- 음량·길이·코덱이 정상이어도 위 검사가 실패하면 완료 처리하거나 게시하지 않는다.
- 기술 검증과 청취 평가를 분리한다. `technicalPassed`는 음색의 자연스러움·모든 잔향 제거·독립된 사람의 청취 통과를 의미하지 않는다. 청취 미실시 상태를 숨기지 않는다.

## 회귀와 배포

`npm run test:shortform-audio`는 정상 지연, 이번 250/0ms 오류, 양 채널의 잘못된 지연, 지연된 두 번째 음성, 정상 스테레오 BGM을 검사한다. 전체 `npm run verify`에도 포함했다.

Pages 워크플로는 `media-contracts/shortform-audio.json`의 실제 MP4 두 경로를 비교한다. 관리 폴더의 새 MP4가 계약이나 명시된 기존 예외에 등록되지 않으면 실패한다. 오류를 무시하는 옵션은 두지 않는다.

```sh
node scripts/check-shortform-audio.mjs --manifest media-contracts/shortform-audio.json
```

`FFMPEG_PATH`·`FFPROBE_PATH`로 실행 파일을 지정할 수 있다. 웹 UI나 Laravel의 인증·권한 로직을 새로 구현한 것은 아니며, 이 코드는 미디어 작업용 도구다.

기존 V1 링크의 영상도 고친 파일로 교체하고, 캐시 혼동을 줄이기 위해 V2 파일명도 제공한다. 배포 후 공개 파일을 다시 디코딩해 같은 검사를 실행한다.
