## 화면 흐름

1. 독립 게시판 목록: 동력원 필터, 브랜드 로고 프로필, 인증 오너, 5점 표기, 제목·본문·2열 미디어, 공유·댓글·추천.
2. 상세: 프로필·구독, 이미지 카운터, 제목·본문, 만족도/동력원/실연비/실주행거리 요약, 평가 태그, 구매 정보, 댓글, 하단 댓글·추천·저장.
3. 등록: 진행 표시, 차량 선택, 구매 시기·가격, 동력원별 가변 입력, 5단계 만족도, 8개 항목 장단점, 제목·30자 본문·미디어.
4. 검증: 차량 정보·만족도·평가 태그 2개·제목·본문 30자가 모두 충족되어야 등록된다.
5. 이탈: 작성 내용이 있으면 임시 저장 여부를 묻는다.
6. 등록 완료: 별도 테이블의 로컬 행으로 저장하고 즉시 상세 화면으로 이동한다.
