# 선우혁 딜러 럭셔리 숏폼 자동 편집 파이프라인 v1

Google Sheets `SNS 레퍼런스`의 `선우혁_8289.superfast 릴스` 탭 상위 3개 영상에서 공통 편집 문법을 추출했다.

## 참조 릴스

- `DfGej3AuYgN`: 롤스로이스 스펙터. 전면 디테일에서 전체 차체로 확장하는 주간 워크어라운드.
- `DfEqeIHBddZ`: 벤틀리 벤테이가 V8. 야간 측면 실루엣과 브랜드·모델 글로우 타이틀.
- `De9Q_xaBLNR`: 벤틀리 플라잉스퍼 V8. 엠블럼·그릴 극근접과 핵심 단어 적색 강조.

## 기본 규격

- 1080×1920, 30fps, 30초, H.264/AAC
- 컷 길이 0.8~1.8초
- 자막 1~4어절, 흰색 굵은 글자와 검정 외곽선
- 한 자막 덩어리당 강조색은 한 단어만 허용
- 클래식 재즈·라운지 음악, 내레이션 중 약 8dB 감쇠

## 처리 순서

`매물 수집 → 미디어 정규화 → 차량 부위 분류 → 사실 검증 → 스토리보드 → 대본·음성 → 자막 정렬 → 편집 합성 → 렌더·자동 QC → 사람 승인 → SNS 게시`

Nuxt는 진행 상태와 검수·승인 UI만 담당한다. Laravel은 매물 사실, 권한, 음성 동의, 음악 라이선스, 작업 상태와 게시 이력을 소유한다. 미디어 워커가 분석·합성·렌더·기계 QC를 담당한다.

확인되지 않은 옵션을 광고 문구로 만들지 않으며, 필수 차량 부위가 없으면 생성형 장면으로 숨기지 않고 재촬영 요청을 만든다.
