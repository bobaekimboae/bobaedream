# 선우혁 딜러 럭셔리 숏폼 자동 편집 파이프라인 v1.1

Google Sheets `SNS 레퍼런스`의 `선우혁_8289.superfast 릴스` 탭 상위 3개 영상에서 공통 편집 문법을 추출했다.

## 참조 릴스

- `DfGej3AuYgN`: 롤스로이스 스펙터. 전면 디테일에서 전체 차체로 확장하는 주간 워크어라운드.
- `DfEqeIHBddZ`: 벤틀리 벤테이가 V8. 야간 측면 실루엣과 브랜드·모델 글로우 타이틀.
- `De9Q_xaBLNR`: 벤틀리 플라잉스퍼 V8. 엠블럼·그릴 극근접과 핵심 단어 적색 강조.

## 렌더·검수 계약

- 영상: 1080×1920, 30fps CFR, H.264 High@4.1, yuv420p, 10Mbps. 길이 30.0초 ±0.15초, 프레임 드롭 0.
- 음성: AAC-LC, 48kHz, 192kbps, stereo. 통합 -15 LUFS ±1, True Peak -1dBTP 이하.
- 컷: 일반 0.8~1.8초, 히어로 최대 2.2초, 하드컷 80% 이상, 음악 비트 오차 ±2프레임.
- 자막: Pretendard 56px/700, 행간 1.18, 최대 2줄, 1~4어절. 좌우 72px·상단 180px·하단 384px 안전 영역.
- 장면 점수: 차량 식별 30%, 선명도 20%, 부위 완결 20%, 움직임 15%, 노출 10%, 중복 감점 5%. 대표 컷 0.75, 일반 컷 0.62 미만은 재촬영 요청.
- 사실: `listing_id + option_id + stable shot_id`가 연결된 `confirmed` 항목만 판매 문구에 사용한다.
- 개인정보: 얼굴·번호판 마스크 신뢰도 0.90 이상. 단 한 프레임이라도 누락되면 게시를 차단한다.

## 3D 옵션 말풍선

- 앵커: 24×24px 링, 중심점 8px, 흰색 1px, 청색 글로우 12px.
- 연결선: 2px, 48~280px, 꺾임 1회 이하.
- 패널: 300~420px, 패딩 24px, 반경 18px, perspective 800px, rotateY ±6도.
- 추적: 신뢰도 0.72 이상, EMA α 0.25, 1080px 캔버스 기준 흔들림 8px 이하.
- 모션: 180ms 등장, 1.6~3.2초 유지, 140ms 퇴장.
- 밀도: 한 화면 최대 2개, 차량 bbox 중첩 10% 이하, 자막과 24px 이상 이격.
- 실패 처리: 4프레임 연속 미검출 시 말풍선을 페이드아웃하고 중립 하단 정보바로 전환한다.
- `confirmed option_id`와 화면에서 식별되는 차량 부위가 모두 존재할 때만 3D 말풍선을 쓴다.

## 처리 순서

`매물 수집 → 미디어 정규화 → 차량 부위 분류 → 사실 검증 → 스토리보드 → 대본·음성 → 자막 정렬 → 편집 합성 → 3D 옵션 말풍선 → 렌더·자동 QC → 사람 승인 → SNS 게시`

Nuxt는 진행 상태와 검수·승인 UI만 담당한다. Laravel은 매물 사실, 권한, 음성 동의, 음악 라이선스, 작업 상태와 게시 이력을 소유한다. 미디어 워커가 분석·합성·렌더·기계 QC를 담당한다.

확인되지 않은 옵션을 광고 문구로 만들지 않으며, 필수 차량 부위가 없으면 생성형 장면으로 숨기지 않고 재촬영 요청을 만든다.
