# 건설기계 인수인계 v04

## 1) 담당 범위

건설기계 시안의 빅레몬 형식·세부형식·제조사·모델 체계와 v04 가상 매물 30대 연동.

## 2) 현재 진행 상태

- 완료: 빅레몬 전체 형식 52종과 순서 복원
- 완료: v04 매물 30대를 빅레몬 형식으로 재매핑
- 완료: 이미지 30장과 매물 30대 연결 유지
- 진행 중: 자동 검증·배포
- 미착수: 매물별 동적 상세 화면

## 3) 결정된 사항과 그 이유

v04의 원천 유형은 데이터 보존용으로만 사용하고 화면의 형식은 빅레몬 원본을 사용한다. 원천 유형을 화면값으로 덮어쓰면 빅레몬 체계가 깨지기 때문이다.

## 4) 미결 사항·막힌 점

heavy-010과 heavy-016의 빅레몬 세부형식은 확인 근거가 부족해 `미확인`으로 유지한다. 브라우저 직접 클릭 검수는 현재 미확인이다.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

코덱스-자료의 v04 시나리오와 이미지 연결은 변경하지 않았다. 추가 자료 대기 없음.

## 7) 검수 상태

형식·세부형식 데이터 검수완료. 자동 빌드·배포와 브라우저 직접 클릭은 별도 확인.

## 8) 다음에 할 일

1. 자동 빌드·배포 확인
2. 형식 → 세부형식 → 제조사 → 모델 직접 클릭 확인
3. heavy-010·016 세부형식 근거가 확보되면 새 버전으로 보정
