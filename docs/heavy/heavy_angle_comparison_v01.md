# 건설기계 5종 측면·각도 비교 v01

## 목적

건설기계 법정 유형 전체를 제작하기 전에 작은 퀵필터 슬롯에서 `좌향 90° 정측면`과 `좌향 3/4 각도` 중 어느 구도가 유형 인지와 시각 품질에 유리한지 비교한다.

## 비교 대상

- 불도저
- 굴착기
- 로더
- 지게차
- 스크레이퍼

## 공통 조건

- 원본 캔버스 비율: 8:5
- 실제 모바일 슬롯: 64×40px
- 카드: 76px, 카드 간격 8px
- 이미지와 명칭 간격: 14px
- 명칭: 14px / 20px, 최대 2줄
- 투명 배경, 노랑·차콜 계열, 동일 바닥선
- A와 B는 쌍별 동일 배율로 정규화

## AutoTrader.ca 실측 참고

2026-10-04 모바일 `486 CSS px` 화면에서 `Browse by type` 레일을 직접 측정했다.

- 첫 카드 시작: 왼쪽 16px
- 카드 및 이미지: 84×51px
- 카드 피치: 100px → 카드 사이 16px
- 카드 전체 높이: 79px
- 이미지 비율: 약 1.65:1
- 배치 특징: 흰 배경, 장비 전체 외곽 노출, 높은 피사체 점유율, 일관된 바닥선

보배드림은 초톳 계열의 기존 레일 규격 `카드 76px / 이미지 64×40px / 간격 8px / 왼쪽 16px`을 유지한다. 이미지 비율은 AutoTrader의 약 1.65:1과 가까운 8:5(1.6:1)를 사용하고, 배경 제거·해상도·색온도·바닥선 일관성은 AutoTrader 이상을 품질 하한으로 둔다.

## 비교 변수

- A: 차량 전면이 왼쪽인 90° 완전 정측면, 정투영, 앞·뒤·상판 면 미노출
- B: 차량 전면이 왼쪽인 3/4 각도, 전면과 측면이 함께 보이는 구도

## 판단 보류

5종 실기기 비교가 끝날 때까지 건설기계 27종 전체 구도는 확정하지 않는다.
