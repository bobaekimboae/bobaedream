# 건설기계 형식 매핑 수정 v02

## 수정 이유

v01 구현에서 v04의 `equipment_type` 5종을 화면 형식으로 직접 사용해 빅레몬 형식 체계가 틀어졌다. 빅레몬 시트의 전체 형식 52종과 순서를 복원하고, v04 매물은 별도 매핑했다.

## 적용 원칙

- 형식 목록: 빅레몬 원본 52종
- 세부형식: 빅레몬 원본에서 해당 형식의 첫 세부 분류 사용
- 제조사명: 확인 가능한 표기만 변환(`코벨코 → 고베루코건기`, `구보다 → 구보타`)
- 불확실한 세부형식: `미확인`
- 이미지 연결: 기존 `scenario_id ↔ image_file` 30건 유지
