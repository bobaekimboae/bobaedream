# 건설기계 매물 v04 연동 검수 v01

## 적용 기준

- 시나리오: `heavy_listing_scenario_v04.csv`
- 이미지 매니페스트: `heavy_listing_manifest_v01.csv`
- 연결 키: `scenario_id` + `image_file`
- v02 시나리오: 참고 기록으로만 보존하며 구현에는 사용하지 않음

## 검수 결과

- 시나리오 행: 30
- 고유 `scenario_id`: 30
- 고유 `image_file`: 30
- 매니페스트와 일치한 이미지: 30
- 누락 이미지: 0
- 중복 연결: 0
- 제조사 `미확인`: 11건, 원문 그대로 유지
- 판매자 정보: 30건 모두 가상 정보임을 확인

## 구현 메모

- 목록 이미지 경로는 `public/assets/heavy/listings/{image_file}` 규칙을 사용함.
- 가격은 시나리오의 `price_10k_krw`를 만원 단위로 표시함.
- 형식·세부형식·제조사·모델 선택값은 v04의 실제 값으로 연결해 결과 0건이 생기는 임의 매핑을 하지 않음.
- 빅레몬 형식·세부형식 기준표는 코드에 별도 기준 데이터로 보존함.
- `heavy_listing_018_v01.png`는 파일명 확장자가 PNG이나 원본 MIME은 JPEG임. 원본 `image_file` 연결 규칙을 우선해 이름은 그대로 유지하며, 브라우저 표시 여부는 배포 후 확인 대상임.

## 상태

- 데이터 정합성: 검수완료
- 빌드 검수: 배포 워크플로 실행 후 기록
- 브라우저 직접 클릭 검수: 미확인
