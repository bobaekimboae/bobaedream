# 건설기계 법정 유형 이미지 적용 v03

## 1. 기준의 우선순위

1. **초톳**: 슬롯 크기, 반복 피치, 좌우 여백, 가로 레일, 라벨 간격, 모바일·PC 공용 자산 운용의 최상위 UX 기준
2. 대한민국 법령: 건설기계 유형 명칭과 순서의 원천
3. 한국·일본 제조사 공식 자료: 실제 구조와 비례 참고
4. AutoTrader Canada·AutoScout24·Carsales: 원본 이미지 해상도와 카탈로그 품질의 보조 기준

다른 사이트의 큰 사진이나 3/4 구도를 초톳 슬롯 규칙보다 우선하지 않는다. 모바일과 PC는 같은 승인 마스터를 사용하고 CSS 슬롯만 64×40과 76×40으로 바꾼다.

## 2. 유형 원천

`건설기계관리법 시행령 별표 1`의 27종을 1뎁스 유형으로 사용한다.

공식 원문: https://www.law.go.kr/flDownload.do?bylClsCd=110201&flSeq=156920701&gubun=

불도저, 굴착기, 로더, 지게차, 스크레이퍼, 덤프트럭, 기중기, 모터그레이더, 롤러, 노상안정기, 콘크리트뱃칭플랜트, 콘크리트피니셔, 콘크리트살포기, 콘크리트믹서트럭, 콘크리트펌프, 아스팔트믹싱플랜트, 아스팔트피니셔, 아스팔트살포기, 골재살포기, 쇄석기, 공기압축기, 천공기, 항타 및 항발기, 자갈채취기, 준설선, 특수건설기계, 타워크레인.

기존 빅레몬 52개 형식은 폐기하지 않는다. 법정 27종은 빠른 탐색용 1뎁스이며 52개 형식과 세부형식은 검색용 하위 분류로 유지한다.

## 3. 이미지 생산 규격

- 방향: 앞 또는 작업부가 왼쪽인 정확한 90° 정측면
- 팔레트: 안전 노랑 + 차콜
- 마스터: RGBA PNG, 긴 변 1024px 이상 권장
- 웹 파생본: 512×320 RGBA
- 안전 상자: 448×224
- 중심: x=256
- 기준선: y=262
- 화면 슬롯: 모바일 64×40, PC 76×40
- 배경: 실제 알파 투명
- 그림자: 접점 아래 중성 회색 8~12%
- 라벨: 14px/20px, 최대 2줄

모든 수치는 `docs/image/quickfilter_image_production_manual_v01.md`와 `docs/heavy/heavy_type_production_manifest_v03.csv`에 고정한다.
