# 제조사·모델·세대 이미지 각도 테스트 v01

## 목적

제조사 → 모델 → 세대 선택 흐름에서 측면과 전면 좌측 3/4 이미지를 같은 슬롯 규격으로 비교한다. 오토스카우트 자료는 각도와 실루엣 참고에만 사용하며 서비스 자산으로 직접 게시하지 않는다.

## 비교안

| 안 | 모델 단계 | 세대 단계 | 확인 포인트 |
|---|---|---|---|
| 혼합안 | 90° 측면 | 전면 좌측 3/4 | 모델 실루엣과 세대 전면부 식별을 각각 우선 |
| 측면 통일 | 90° 측면 | 90° 측면 | 슬롯 균형과 차체 비율 비교를 우선 |
| 각도 통일 | 전면 좌측 3/4 | 전면 좌측 3/4 | 그릴·램프·인상 차이 식별을 우선 |

## 테스트 규격

| 단계 | 이미지 슬롯 | 행 높이 | 이미지·텍스트 간격 |
|---|---:|---:|---:|
| 제조사 | 40×40px | 56px | 12px |
| 모델 | 80×48px | 72px | 16px |
| 세대 | 88×52px | 84px | 16px |

## 임시 판단

혼합안을 우선 검토한다. 모델 단계는 측면이 차체 비율과 차급을 빠르게 비교하기 좋고, 세대 단계는 3/4 각도가 그릴·램프·범퍼 등 세대 차이를 더 잘 보여준다. 최종 규칙은 세 시안을 모바일과 PC에서 비교한 뒤 확정한다.

## 테스트 자산

- 대상: 메르세데스-벤츠 E-클래스 W214, W213, W212
- 배경: 투명
- 차체색: 실버 계열 통일
- 그림자: 중성 회색의 약한 접지 그림자
- 측면안: 차량이 좌측을 바라보는 정확한 90° 측면
- 각도안: 차량이 좌측을 바라보는 전면 좌측 3/4
