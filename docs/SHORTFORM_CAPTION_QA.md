# BMW X5 자막 수정 · V3

사용자 확인 시안: 큰 자막 박스 제거, 작은 흰색 자막, 핵심어 블루, 말의 의미에 맞는 묶음.

## 변경

- 40개 짧은 조각을 15개 문장/의미 단위로 묶었다. 원래 발화 문구와 시작 시각은 보존하고 두 줄을 동시에 표시한다.
- Pretendard Variable 46px / 650, 행간 1.42. 1080×1920 영상에서 좌측 110px, 우측 150px의 안전 여백을 유지한다.
- 큰 남색 배경 박스를 제거하고 얇은 어두운 외곽선·그림자로 읽기 쉽게 했다. 핵심 기능명은 #90bcff / 750으로 강조한다.
- 자막만 수정하는 작업이므로 V2에서 수정 완료한 AAC 트랙을 그대로 복사한다. 재생성·재믹싱하지 않는다.
- 기존 링크 V1·V2도 새 파일로 갱신하고 캐시 혼동을 줄이는 V3 주소를 함께 제공한다.

## 참고 범위

- [AutoScout24.be 시트로엥 릴스](https://www.instagram.com/autoscout24.be/reel/DfFR7Y6jQ04/): 흰색 자막과 단어별 노란색 강조를 실제 화면에서 확인했다.
- [DubiCars VIP Design 릴스](https://www.instagram.com/dubicars/reel/DfRqhmeswhN/): 차량·발표자 화면 하단의 작은 흰색 아랍어 자막을 확인했다.

참고 영상의 정확한 폰트 파일·원본 글자 크기를 확보한 것은 아니다. 위 구현 수치는 보배드림 시안의 선택값이다.

## 검증과 기록

- 자막 원문 전체를 공백 정규화해 이전 자막과 대조하고, 누락·중복이 있으면 중단한다.
- 의미 단위와 실제 화면 줄바꿈은 구분한다. 원문이 두 줄이어도 렌더 화면에서 더 많은 줄이 되거나 잘리면 통과로 보지 않는다.
- HyperFrames 전체 검사와 스냅샷으로 배치·대비·넘침을 확인하고, 최종 MP4를 디코딩한 프레임에서도 다시 확인한다.
- V2/V3의 인코딩된 AAC 오디오 해시를 비교하고 최종 파일을 원본 내레이션과 독립 채널별로 비교한다. 좌우 시간차 1ms 초과, 약속된 발화 지연 오차, 낮은 파형 상관도는 배포를 차단한다.
- `media-contracts/bmw-x5-captions-v3.json`에 자막 시각·문구·스타일을, 같은 이름의 SRT에 자막 원문을 남긴다. 기술 검사는 독립된 사람의 청취 평가와 구분한다.

이 작업은 미디어 샘플 수정이다. Nuxt 사용자 화면이나 Laravel API를 신규 구현하거나 운영 연결한 작업으로 보고하지 않는다.
