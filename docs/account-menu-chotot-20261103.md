# PC · 모바일 계정 메뉴 — 작동 샘플 v2

2026-11-03 후속 요청: 「실제 동작되게 해라 초톳 샘플로」. 초톳 로그인 상태의 프로필·팔로잉·지갑·저장 목록·설정 화면을 읽기 전용으로 대조했다. 초톳 사용자의 실제 정보는 복사하지 않았다.

## v2 구현 및 운영 경계

- 샘플 닉네임/회원 유형 로그인·로그아웃, 프로필 수정, 팔로잉 추가/해제.
- 기존 매물 리스트의 찜 → 관심 목록, 차량 열기 → 최근 본 매물. 삭제 및 최근 기록 전체 지우기. 공개 DOM 스냅샷만 읽으며 앱 내부 상태·인증 쿠키를 읽지 않는다.
- 저장 검색 10개, 중복 방지, 조건 재실행, 샘플 알림 설정. 초톳의 저장 콘텐츠 매물/영상/게시글 탭 및 각 100개 표시는 참고했으며 영상·게시글 저장 연동은 미구현 빈 상태다.
- 차량/매매단지 후기 작성·수정·삭제. 판매 중/판매 완료/재판매 상태 변경.
- 체험 포인트, 쿠폰 받기, 샘플 프리미엄 신청·차감·중복 방지·취소·환급. 상품 가격과 포인트는 모두 테스트 값이다.
- 파트너 신청·의견은 브라우저 내 샘플 저장만 수행한다. 고객센터 전화 링크와 기존 매물 등록·건의 게시판으로의 이동을 제공한다.
- PC는 400px 메뉴에서 상세 기능 선택 시 최대 900px 모달로 전환한다. 모바일은 전체 화면을 유지한다.
- 상태는 `bbm.account.demo.v2`, 공개 매물 활동은 `bbm.account.listing-activity.v1`에 저장한다. 같은 브라우저의 PC/모바일 화면에서 공유되며 다른 기기·브라우저·도메인에는 동기화되지 않는다.
- 매물 DOM에는 안정 매물 ID가 없으므로 제목·이미지·공통 제원으로 샘플 키를 만든다. PC 전용 마력 표기는 제외한다. 목록에서 해당 키를 찾으면 원래 상세 화면을 열고, 없으면 당시 검색으로 돌아간다. 운영에서는 Laravel의 안정 ID/상세 URL 계약으로 대체해야 한다.
- 모든 상세 화면에 작동 샘플/브라우저 저장/실제 결제 없음 표시. 비밀번호·OTP·카드 정보 수집 없음. 실제 인증·결제·광고 노출·푸시 발송·운영팀 전송은 연결되지 않았다.
- 업무 규칙의 운영 정본은 Laravel 12/PHP 8.4 API다. 이번 브라우저 샘플 코드는 운영 인증/과금 로직으로 사용하지 않는다.

검증: Nuxt 테스트 15개, 타입 검사, 정적 생성 및 루트 `npm run verify` 통과. 브라우저에서 로그인→프로필 변경→검색 저장→후기 저장/수정→쿠폰 받기→4,900 P 신청→취소→30,000 P 복구→새로고침 유지 확인. PC와 모바일 찜 상태·최근 본 매물 공유 확인. 샘플 딜러 매물 판매 완료/재판매 확인.

## 진입 · 디자인

기존 매물 리스트 PC 프로필 버튼과 모바일 하단 마이를 연결한다. PC 로그인/회원가입 버튼도 같은 계정 화면을 연다. Nuxt 화면은 `/bobaedream/nuxt-community/#/account`에서 독립적으로 열 수 있다.

- PC: 버튼 아래 폭 400px, 최대 높이 616px의 스크롤 팝오버. 작은 창에서는 가용 높이·폭 이내.
- 모바일: 마이 전체 화면. 상단 뒤로·닫기, safe-area와 세로 스크롤 지원.
- 공통: 48px 항목 행, 24px 원본 SVG, 16px 항목 텍스트, Pretendard, 카드 radius 12px, 블루 `#2f6fe4`.
- 순서: 계정 → 편의 기능 5 → 유료 서비스 5 → 혜택 2 → 설정·지원 3. 하나의 타입 있는 데이터 정의를 PC와 모바일에서 공유한다.

## 기존 앱과의 접점

`public/assets/account-menu-bridge.js`는 기존 React 쉘에 UI를 추가하지 않는 호환 어댑터다. `index.html`의 외부 스크립트 한 줄로 진입 버튼 클릭을 Nuxt iframe으로 전달한다. 기존 React 화면·필터·보호 런타임은 수정하지 않는다.

- 관심 매물 → 기존 저장 매물 화면.
- 프리미엄 등록 → 설명 후 기존 매물등록 시안으로 이동. 결제를 실행하지 않음.
- 의견 보내기 → 제안·건의 게시판.
- 고객센터 → 연락처·운영시간·전화 링크. 자동 통화하지 않음.
- 그 밖의 개인 계정 데이터 → 계정 API 연결 전임을 표시. 가짜 보유 포인트·결제 내역·쿠폰 등을 만들지 않음.
- `pcauth=member`는 기존 회원 **미리보기**이며 실제 로그인으로 취급하지 않음.

## 상호작용 · 접근성

팝오버 바깥 클릭, Esc, 닫기 버튼, 브라우저 뒤로 가기, 포커스 복귀를 지원한다. 배경 root를 inert 처리하고 이전 상태로 복원한다. iframe 내부 Tab 순환을 제한하며 `role=dialog`, `aria-modal`, `aria-expanded`, `aria-controls`를 사용한다. 로딩 지연 시 메시지와 닫기 버튼을 제공한다.

메시지는 같은 origin과 현재 iframe의 contentWindow를 함께 확인하고 `favorites/register/feedback/logout-preview` 네 동작만 허용한다. 메뉴 닫기 history 복구 후 기존 화면을 열어 뒤로가기 경합을 피한다.

## 범위 · 잔여 작업

Laravel 인증·회원·결제·쿠폰 API, PostgreSQL·검색·캐시 스키마 변경은 이번 작업에 없다. 프리미엄 결제와 실제 계정 데이터 연동을 완료했다고 간주하지 않는다. 초톳 모바일 네이티브 앱과의 1:1 동등성은 별도 실기기 대조 대상이다.

배포는 기존 Nuxt community 빌드 단계에 계정 route가 포함되므로 새 프레임워크·빌드 단계·의존성을 추가하지 않는다.
