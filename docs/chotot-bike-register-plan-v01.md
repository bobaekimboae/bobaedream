# 초톳 기준 바이크 매물등록 작업 계획 v01

## 목표

- 초톳 모바일 앱의 정보 구조와 화면 밀도를 기준으로 보배드림 바이크 매물등록 화면을 구현한다.
- 기존 자동차 매물등록 화면은 그대로 보존한다.
- 실제 등록 API·사진 업로드는 호출하지 않는 안전한 인터랙션 시안으로 만든다.

## 화면 구조

1. 뒤로가기 / 중앙 타이틀 / 임시저장
2. 사진·영상 업로드
3. 매물 설명 / 제목 / 가격 / 거래지역
4. 판매자 유형
5. 카테고리 / 서류 / 상태 / 제조사 / 모델 / 연식 / 유형 / 주행거리 / 배기량 / 원산지 / 보증
6. 검색 가능한 전체 화면 선택기
7. 미리보기 / 매물 등록 고정 버튼

## 검수 기준

- 360px 가로 넘침 0
- 제조사 선택 후 해당 모델만 노출
- 360·390·430px에서 하단 액션이 가려지지 않음
- 실제 등록·저장 네트워크 요청 0건
