# 바이크 매물등록 작업 계획 (2026-10-09)

근거: 노션 「매물 등록 문서」(보배드림 시안 문서들), 초톳 앱 캡처 2장(드라이브 `초톳 앱 화면 캡쳐` 폴더: 카테고리 선택 · Xe cộ 등록 폼), 노션 초톳 아이콘 DB, 보배드림 dev 매물등록(`/car/register` → `/car/register/form`, 우리 `?register`).

## 1. 정한 방향

- 차량 유형 6종(중고차 · 바이크 · 트럭/특장 · 건설기계 · 캠핑카 · 부품/용품) 중 **바이크부터** 만든다.
- 뼈대는 초톳 매물등록 화면. 버튼 · 화살표 · 아이콘은 노션 초톳 아이콘 원본을 그대로 쓴다(`public/assets/register/chotot-v01/`, `manifest.json`).
- 초톳과 다른 점은 하나: 사진을 올려 AI가 카테고리를 정하는 단계를 두지 않고 **바로 등록 폼으로 들어간다**.
- 모바일 웹 · 앱은 초톳 앱 화면 그대로, PC 웹은 초톳 모바일 웹 화면(가운데 고정 폭)으로 만든다.
- 중고차 등록(dev `?register`)은 지금 화면을 기준으로 유지하고, 바이크는 별도 화면(`?register=bike`)으로 시작한다.

## 3. 클로드 코드가 할 일(순서)

1. `src/prototype/register/bike/`에 바이크 등록 화면을 새로 만든다. `?register=bike`로 연다. 중고차 등록 코드는 건드리지 않는다.
2. 위 표 순서대로 입력칸 · 선택 행 · 알약 · 체크박스를 초톳 크기로 만든다(384 CSS 기준, 1080 캡처 ÷ 2.8125 실측).
3. 제조사 · 모델 · 연식 · 장르 · 주소 선택은 바텀시트(모바일) / 같은 시트를 가운데 고정 폭으로(PC). 제조사 · 모델 목록은 기존 바이크 기준표(`public/data/vehicle-catalog/bikes-*.json`)를 **읽기만** 한다.
4. 필수 항목 검사: 비면 빨간 테두리 + 안내 문구(초톳 「Vui lòng điền」 위치·색 그대로).
5. 사진: 시안에서만 미리보기로 붙이고 업로드 요청은 보내지 않는다. 미리보기 · 등록 버튼도 요청 없이 안내만.
6. 가상 매물 채워보기: 바이크 v08 시나리오 1건으로 「예시 채우기」를 넣어 화면 확인을 쉽게 한다.
7. 초톳 캡처와 나란히 비교해 영역별 차이 비율을 보고한다.
8. 바이크가 확정되면 같은 틀로 트럭/특장 · 건설기계 · 캠핑카 · 부품/용품 순서로 항목만 바꿔 넓힌다.
