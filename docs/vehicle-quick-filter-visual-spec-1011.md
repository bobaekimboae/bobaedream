## 구현 규칙

1. 승용은 `grayscale(1)`로 잔색을 제거한다.
2. 공통 대비는 `contrast(.92)`로 고정한다.
3. 밝기는 바디타입과 국내·수입 원본별로 보정해 AutoScout24의 차종별 중앙 명도에 맞춘다.
4. SUV·픽업처럼 유리와 타이어 면적이 큰 차종은 세단과 같은 밝기 값을 강제로 쓰지 않는다.
5. 선택 상태에서도 이미지 색·크기를 바꾸지 않고 라벨 굵기만 바꾼다.
6. 바이크·트럭은 이번 승용 대조 범위 밖이므로 기존 값을 유지하며, 별도 원본 대조 뒤 같은 방식으로 교정한다.
