## 시험 방법
- T1: `python3 scripts/shortform/oss_tests/t1_aligner_ab.py --work /tmp/osst` — 입력 `<work>/in/<차>/voice_a.mp3 + tts.txt`, 사람 정답 `<work>/labels/<차>.json`. `--labels-todo`로 경계 후보 CSV(rs3 26 · e450 28 · x6m 24곳)를 만들어 사람이 고친다. 자동 기준(−40dB)은 쉼 맞춤과 같은 기준이라 Qwen에 유리 → 결론은 사람 정답으로만.
  - 사전 측정(자동 기준, rs3 38.8초, 경계 26곳): Qwen + 쉼 맞춤 중앙값 0.025초 · 최대 0.20초 · 100ms 안 92% · 처리 77.5초(2코어).
- T2: `bash scripts/shortform/oss_tests/t2_ffmpeg_ab.sh <이름> "<렌더 명령>" <결과 mp4>` — PATH만 바꿔 같은 렌더를 두 번 돌리고 SSIM · check_be · 시간을 남긴다. 6.1.1은 지우지 않는다.

## T3 결과 (2026-11-25) — 통과
- 대상: 이미 받은 SAM 3.1 결과 37개(글자 30 + 상자 7). 새 요금 0원.
- 풀기: 37개 파일 모두 성공, 마스크 3,885장(287MB 원본 바이트).
- 마스크 크기 = 상자 크기: 3,885 / 3,885. 마스크는 상자 안쪽만 담는 형식이라 「상자 밖 마스크」는 생길 수 없음.
- 마스크가 상자 네 변에 모두 닿음: 3,875 / 3,885(99.7%) → 상자가 마스크 외곽선.
- 채움 비율: 최소 0.157 · 하위 5% 0.258 · 중간값 0.723 → 빈 마스크 없음.
- 눈 확인: 30컷 접촉 시트에서 마스크가 부위 모양을 따라감(바퀴·엔진 커버·사이드미러·계기판·문턱).
- 글자 뒤 지나가기 시험: w2_wheel_pan에서 노랑 글자가 타이어 아래쪽 뒤로 가려짐 확인.
- 확정: 부위 강조(칠·외곽선)와 「글자가 부위 뒤로」 효과에 SAM 마스크를 그대로 쓴다. 도구 `scripts/shortform/oss_tests/decode_masks.mjs` + `t3_mask_check.py`.
- 주의: 글자 프롬프트가 빈 컷(o2_climate, z4_hud)은 상자 결과로 채운다(글자 우선·빈 장면만 상자 규칙 그대로).
