# 보배드림 숏폼 편집 두 판 — 네덜란드판 · 벨기에판 v1 (2026-11-09)

- 사용자 결정(2026-11-09): 네덜란드식·벨기에식 두 판을 만들어 필요에 따라 고른다. 음악·효과음은 원본대로 나누고, 벨기에판 말 자막은 노랑 따라가기.
- 근거 문서: `as24-caption-rules-v2.md`(자막), `as24-sfx-rules-v1.md`(효과음), `as24-4country-compare-v1.md`(컷·음악), `as24-edit-skeleton-v3.md`(칩).
- 바꾸지 않는 확정 기준: 칩 파랑 `#306BD9` + 흰 글자, 노랑 `#EEEF05`는 말 따라가기 전용. 효과음은 자체 팩만.

## 1. 두 판 비교

| 항목 | 네덜란드판 `bobae_nl` | 벨기에판 `bobae_be` | 원본 근거 |
|---|---|---|---|
| 언제 쓰나 | 정보를 또박또박 보여 줄 때(사양·가격 중심) | 분위기·속도감을 살릴 때(외관·감성 중심) | NL = 효과음 채널, BE = 음악 채널 |
| 말 자막 | 흰 굵은 글자 + 검정 외곽선, 말하는 어절만 노랑 | 흰 굵은 글자 + 진한 그림자(외곽선 없음), 말하는 어절만 노랑 | NL 43/43, BE 34/39 |
| 자막 높이 | 65% | 67% 고정 | NL 55~75%(최빈 65), BE 66~67% |
| 자막 등장 | 톡 튀어나옴 | 바로 등장 | — |
| 컷 경계 | 자막 그대로 | 컷 뒤 0.3초 자막 비움 | BE 측정 |
| 칩 모양 | 반듯한 파랑 상자, 기울기 0 | 기울인 파랑 붓띠(±2~3°) | NL 검정 상자, BE 노랑 붓띠 |
| 큰 숫자 | 숫자 사양·가격을 크게, 그동안 말 자막 숨김 | 숫자도 칩 안에(크게 띄우지 않음) | NL 39/50 |
| 장면 길이 | 약 2.5초. 블록 길이에 맞춰 장면 수를 줄이되 칩이 뜨는 구절의 장면을 먼저 남김(칩 글자와 화면 부위가 맞게) | 약 1.9초(설정 그대로) | 중간값 NL 2.5 · BE 1.9 |
| 음악 | 없음 | 배경음악(spy, 0.34) | NL 거의 없음, BE 자주 |
| 효과음 | 딩, 칩·숫자의 약 40%, 최대 6번 | 팝, 칩의 20%, 최대 3번 | NL 칩 39% · 큰 숫자 58%, BE 띠 22% |
| 효과음 크기 | 목소리보다 −6dB | 같음 | — |
| 첫 2초 · 끝 | 차명 제목 / 로고 커짐 | 같음 | 두 나라 공통 |

## 2. 고르는 법
- 영상 설정 파일에 `STYLE.update(edit_style='bobae_nl')` 또는 `'bobae_be'`. 또는 실행할 때 `SAG_EDIT=bobae_be`.
- 예시 설정: `scripts/shortform/reels/vantage_edit_nl.py` · `vantage_edit_be.py`.
- 칩 배치 계획 프로그램도 같은 이름을 쓴다: `as24_edit_planner.py --style bobae_nl|bobae_be`.
- 예전 이름 `bobae`는 네덜란드판과 같은 칩 규칙이다. 예전 시안 `nl2`(파랑 강조어 칩)·`be2`(흰 자막 + 따로 칩)는 측정 다수 방식과 달라 비교용으로만 남긴다.

## 3. 아직 못 본 것
- 밴티지 샘플 결과: 네덜란드판 장면 10개·평균 2.48초, 딩 3번(4.4·15.3·17.1초). 벨기에판 장면 13개·평균 1.91초, 팝 1번(17.1초, 가격). 둘 다 효과음 목소리보다 −6dB.
- 벨기에판 효과음 1번은 그대로 둔다(2026-11-09 사용자가 Claude 판단에 맡김): 원본 벨기에도 띠의 22%에만 넣고 박자는 음악이 맡는다. 우선순위상 그 1번은 가격에 간다. 40초 안팎·칩 10개 이상 영상이면 자연히 2~3번이 된다. 억지 하한은 두지 않는다.
- 첫 시도에서 장면을 고르게 줄였더니 「브라운 톤 실내」 칩이 바퀴 화면 위에 떴다 → 칩 구절 장면 우선으로 고침.
- 벨기에판 배경음악은 지금 자체 제작 곡 1개(spy)뿐이다.
