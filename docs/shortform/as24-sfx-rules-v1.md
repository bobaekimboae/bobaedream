# AS24 4개 채널 효과음 규칙 v1.1 (2026-11-09, 전수조사 반영)

- 근거: 네덜란드(NL)·벨기에(BE)·독일(DE)·리싱마크트(LM) 쇼츠 598편. 소리를 스펙트로그램 그림(−0.5~+1.0초, 60Hz~11kHz)으로 바꿔 눈으로 판정했다.
  - 1차 440곳: 칩·컷·끝·첫 화면을 나라별로 무작위로 골랐다.
  - 2차 181곳(전수조사): 사람이 편집물이라고 확인한 칩·큰 숫자·끝 로고가 **실제로 나타난 순간**을 판정했다.
- 분석용으로만 들었다. 원본 소리와 음악은 쓰지 않는다. 보배드림은 자체 효과음 팩(`public/assets/shortform/sfx`, ElevenLabs 생성, 브랜치 `codex/sag-reel-sfx-pack`)만 쓴다.

## 0. v1에서 바로잡은 것
- **끝 로고 효과음.** v1(1차)은 「영상 끝 2.2초 전」 고정 시각을 봤다. 실제 로고는 그보다 −1.8~+1.3초 어긋나 대부분 판정 범위(−0.25~+0.3초) 밖이었다. 로고가 실제로 뜬 순간을 다시 보니 NL 2/30, BE 1/21이었다. **끝 로고에는 효과음을 거의 넣지 않는다.** 교본 v3의 「끝 로고 효과음 강함(23/30, +14dB)」은 소리 크기만 잰 자동 측정의 착오다.
- **「칩」 순간의 범위.** 1차의 칩 순간 40곳에는 말 따라가기 노랑 낱말이 4~6곳 섞여 있었다. 독일·리싱마크트의 칩 순간은 대부분 번호판·노란 차 같은 노랑 물체였다. 그래서 칩 효과음 비율은 2차 값을 쓴다.
- **소리 종류.** 교본 v3는 「뿅/툭 또는 휙」이라고 적었지만, 판정해 보니 NL은 거의 딩 하나다. 칩 27건 중 딩 24건, 큰 숫자 11건 중 딩 11건이었다.

## 1. 측정 결과 (효과음 있음 / 판정한 순간, 괄호 = 애매)

| 채널 · 순간 | 효과음 | 종류 | 시작(나타난 순간 기준, 중간값) |
|---|---|---|---|
| NL 이름표 칩 | **27/70 = 39%** (14) | 딩 24 · 휙+쿵 2 · 휙 1 | −20ms |
| NL 큰 숫자 | **11/19 = 58%** (3) | 딩 11 | −30ms |
| NL 끝 로고 | 2/30 = 7% (4) | 찰칵 2 | — |
| NL 컷 | 3/40 = 8% | 딩 | — |
| BE 노랑 띠 | 9/41 = 22% (13) | 딩 8 · 팝 1 | +70ms |
| BE 끝 로고 | 1/21 = 5% (1) | 딩 | — |
| BE 컷 | 4/40 = 10% | 딩 2 · 팝 1 · 쿵 1 | — |
| DE · LM 칩 · 컷 | 0/40 · 0/40 | — | 컷의 킥 드럼은 **배경 음악 박자** |

배경 음악(판정한 순간 기준): NL 칩 4/70, BE 띠 13/41, BE 끝 로고 15/21. DE는 컷 15/40, LM은 컷 6/40에서 음악이 깔려 있었다.

- 딩: 위쪽(1.5kHz~3kHz 이상)에 가늘고 곧은 줄이 생기는 소리다. 길이는 0.15~1초, 흔히 약 0.5초다.
- 효과음은 말소리보다 작다. 말이 쉬는 틈에서 뚜렷하게 들린다.
- 한 영상 안에서는 한 가지 소리만 쓴다.

## 2. 나라별 성격
- **NL = 효과음 채널.** 큰 숫자는 10개 중 6개, 칩은 10개 중 4개에 딩을 넣는다. 칩이 뜨기 0.02~0.03초 전에 시작한다. 음악은 거의 없다.
- **BE = 음악 채널.** 띠의 약 5분의 1에만 딩을 넣고, 끝은 음악으로 맺는다.
- **DE · LM = 효과음 없음.** 컷은 음악 박자에 맞춘다.

## 3. 보배드림 규칙

| 항목 | 규칙 |
|---|---|
| 기본 | **NL형.** 파랑 칩·큰 숫자가 뜨기 **0.02초 전**에 딩 |
| 넣는 곳 | 큰 숫자와 핵심 칩. **끝 로고·컷에는 넣지 않음** |
| 빈도 | 칩·숫자의 약 40%. 가격 → 주행거리 → 연식 → 마력 → 옵션 순으로 고름. 영상당 최대 6번 |
| 간격 | 효과음끼리 최소 0.6초 |
| 종류 | 영상 하나에 한 종류. 딩이 기본, 팝은 벨기에형(기울인 띠) 시안에만 |
| 크기 | 목소리(말하는 구간 평균)보다 **−6dB**, 말과 겹쳐도 같음. 렌더러가 목소리 파일을 재서 맞춘다(밴티지 샘플 실측 −6.2dB). 더 낮추면 2026-11-08 샘플처럼 안 들린다 |
| 음악을 깔 때 | 칩의 20%, 최대 3번(BE형) |
| 딜러가 말하는 영상(DE형) | 효과음 없음 |
| 금지 | 다른 앱(캡컷 등)의 소리, 원본 영상 소리, 저작권 음악 |

코드: `scripts/shortform/as24_edit_rules.json`의 `sfx`, `scripts/shortform/as24_edit_planner.py --style … [--music]`. 점검: `python3 scripts/shortform/test_as24_edit_planner.py`.

## 4. 아직 못 본 것
- 원본의 효과음 세기(dB)는 그림 밝기로만 봤다. 우리 −6dB는 「안 들린다」를 고친 2026-11-08 샘플 수준에 맞춘 값이다.
- 애매 판정(NL 칩 14, BE 띠 13)은 「없음」으로 셌다. 모두 「있음」이라면 NL 칩은 59%, BE 띠는 54%가 된다.
- 독일·리싱마크트에는 칩이 거의 없어서 칩 효과음은 판정할 거리가 적다(0건으로 봄).
