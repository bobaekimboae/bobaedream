# 카드 정보 기법 매뉴얼 v0.2 (2026-11-26, 작성: 클로드 시안)

사용자 지시(노션 「숏폼 카드정보 샘플 제작 및 숏폼 콘텐츠 아이디어 내기」)
- 1차: 독립 컷에서 카드가 순서대로 나오며 자막과 함께 정보를 요약한다. 엔카처럼 하나씩 열어 보지 않아도 숏폼 한 번에 끝나게 한다.
- **2차(이 판의 기준)**: 엔카 매물정보에 있는 카드는 엔카 항목 기본 순서(차량 기본정보 → 성능 점검 → 보험 이력 → 차량 이력 타임라인)로 잡고 우리 유형을 잇는다. 신규 추가는 국토부 차량이력 타임라인. **카드는 필수가 아니다** — 매물에 따라 1개부터 여러 개까지 차량 편집에 들어간다.

어떤 에이전트도 같은 결과를 내도록 아래 순서·파일만 쓴다.

## 1. 파일

| 파일 | 하는 일 |
|---|---|
| `scripts/shortform/card_info/card_info_rules.json` | 카드 순서·종류·배치·움직임·효과음·금지어·고르기 규칙의 단일 기준(v0.2) |
| `scripts/shortform/be_locked_rules.json` | 노랑·칩 글자 크기·자막 크기·음량(읽기만) |
| `cards_from_charancha.py <차 폴더>` | 차란차 공개 데이터 → `facts.json`. 판매자 설명이 고유 글인지 틀 글인지만 판정(글은 저장 안 함). 다른 스크립트가 넣은 항목은 지우지 않음 |
| `cards_from_carmodoo.py <차 폴더> <기록부 번호>` | 성능·상태점검기록부(카모두 출력본)를 헤드리스로 열어 **체크된 칸만** 읽어 `facts.inspection`에 넣음(점검일·주행·최초등록·검사 유효기간·사고/단순수리·특별이력·리콜·부위 부호·점검자 의견). 차량번호·차대번호·계좌·연락처 저장 안 함 |
| `card_select.py <차 폴더>` | 카드마다 넣음/뺌과 이유, 차량 이력 타임라인 사건 출력(빈 카드 금지) |
| `render_card_info.py <차 폴더> out/이름.mp4 --clips` | 전체 영상 + 카드별 조각(편집 삽입용) + `.plan.json`(검수 기록) |
| `compose_cards.py <조각 앞이름> <종류,…> <출력>` | 조각 1개~여러 개를 순서 규칙대로 이어 차량 편집에 넣을 한 조각을 만듦 |
| `examples/g400d_plan_v2.json` · `g400d_facts_v2.json` | 2차 샘플(벤츠 G400d) 대본·카드 내용·사실 원장 |

## 2. 카드 순서 (2차 제안, 고정)

| 순서 | 종류 | 칩 | 말 첫 문장 | 데이터 | 이 매물(G400d) |
|---|---|---|---|---|---|
| 1 | overview | 차량 정보 | 차량 정보부터 보겠습니다. | 등록연월·주행·연료·변속기·배기량·색상 | 넣음 |
| 2 | report | 성능 점검 | 성능점검기록부 요약합니다. | 기록부 체크 칸. 좋은 줄 먼저 → 단순수리 부위·도장 의견·리콜 미이행은 「다만 …」. 점검일 함께 | 넣음 |
| 3 | insurance | 보험 이력 | 보험 이력입니다. | 없는 것 먼저 → 내 차 피해(날짜·수리비)·소유자 변경 | 넣음 |
| 4 | timeline | 차량 이력 | 차량 이력을 시간 순서로 보면, | 날짜 있는 사건만 세로 선 위에(아래 3장) | 넣음 (신규) |
| 5 | options | 옵션 정보 | 옵션은 모두 N개. | 묶음별 개수 + 주요 옵션 중 없는 것 안내 | 넣음 |
| 6 | addopt | 추가 옵션 | 선택 옵션 유무부터 | 판매자 등록 선택옵션 + 눈에 띄는 장착 옵션 ✓ | 넣음 |
| 7 | features | 차량 특징 | 제원은 … | JATO 공식 제원(마력·제로백·복합 연비) | 넣음 |
| 8 | seller | 판매자 설명 | 판매자는 … | 판매자 고유 설명이 있을 때만 | **뺌** — 기본 정보만 되풀이한 틀 글 |

- 보류(코드만 남김): 신차가 비교(price), 시세 위치(market) — 2차 목록 밖. 시세는 비교 기준(모집단·트림·기준일)이 없으면 쓰지 않는다.

## 3. 차량 이력 타임라인 (신규)

- 사건 = **날짜가 있는 사실만**: 최초 등록(기록부) · 보험 처리(보험이력 상세: 날짜·수리비) · 검사 유효기간 갱신(기록부의 검사 유효기간 시작일) · 성능점검(점검일·주행) · 지금 판매 중(매물 주행). 사건 3개 미만이면 카드를 뺀다.
- 날짜 없는 사실(소유자 변경 시기)은 사건으로 만들지 않고 아래 안내 줄로 돌린다.
- 출처를 카드 아래에 적는다: 「성능점검기록부(국토부 등록 정보) · 보험이력 · 매물 — 원부 직접 조회 아님」. 국토부 원부(자동차365)를 직접 받게 되면 소유자 변경·정비·검사 날짜를 사건으로 더한다.
- 그림: 왼쪽 날짜(오른쪽 맞춤) · 세로 선 · 점(켜지면 먹색, 마지막 「지금」은 노랑 큰 점) · 오른쪽 사건 + 값. 마지막 값만 노랑 밑줄. 말이 그 사건을 시작할 때 선이 이어지며 켜진다.

## 4. 화면 규칙 (v0.1과 같음)

- 1080×1920·30fps. 칩(노랑 원본 칠, 70px) 가운데 y 300 → 종이색 카드(좌우 60, 위 400, 아래 1540 이하, 모서리 32) → 자막 가운데 y 1660(60px, 2줄, 말하는 낱말만 노랑).
- 배경 매물 사진 흐림 28·어둡게 0.42, 카드 바뀔 때 0.3초 겹침. 카드 0.28초 동안 40px 올라옴, 줄은 말 0.04초 전 0.18초 겹쳐 켬.
- 강조는 노랑 한 색. 확인 필요는 먹색 테두리 「!」, 정보는 「i」. 빨강·초록·주황 금지.

## 5. 소리

- 내레이션은 대본 전체를 **한 번만** 생성(목소리 고정 아님). 0.4초 넘는 쉼은 0.32초로, 1.08배속. 받아쓰기로 낱말 시각을 잰다.
- 받아쓰기에서 낱말이 이상하게 나오면 두 모델(large-v3·turbo)로 그 구간만 다시 받아 적어 본다. 둘 다 같은 이상 낱말이면 발음 문제 → 같은 녹음 안의 같은 낱말을 잘라 붙인다(재생성 금지). 2차 샘플: 「보험 처리」의 「보험」을 「보험 이력」에서 잘라 붙임. 「10월 30일」이 「31일」로 적힌 것은 「삼십일」의 받아쓰기 숫자 바꿈이라 고치지 않음(청취 확인 권장).
- 효과음: 차량 정보 카드는 card-sfx 규칙, 다른 카드는 들어올 때 휙 한 번. 배경음 bobae_luxury_v1(덕킹).
- 음량 −14 LUFS(±1)·꼭짓값 −1.5dBTP 이하: 전체 영상과 **조각마다** 두 번째 패스로 맞춘다.

## 6. 만드는 순서

1. 매물 페이지 공개 데이터·사진 받기(`raw/net.json`, `raw/rsc.txt`, `raw/page.txt`, `src/`).
2. `cards_from_charancha.py` → `cards_from_carmodoo.py`(기록부 번호가 있으면) → 보험이력 상세가 있으면 `facts.insurance_detail`(날짜·수리비·자료일·출처) 입력.
3. `card_select.py`로 넣을 카드 확인. 뺀 카드는 대본에서도 뺀다.
4. `plan.json`: 말 덩어리마다 자막(`t`)·받아쓰기 기준 낱말(`a`)·카드 시작(`card`)·켤 줄 수(`reveal`)·효과음. 타임라인 사건은 `card_select.timeline_events()` 결과를 그대로 넣는다.
5. 음성 1회 생성 → 쉼 줄이기·배속 → 받아쓰기(`whisper_words.json`) → 이상 낱말 점검.
6. `render_card_info.py 차폴더 out/이름.mp4 --clips`.
7. 편집에 넣기: `compose_cards.py out/이름 report,insurance,timeline out/edit_insert.mp4` (1개~여러 개, 순서는 규칙대로).
8. 검수: `.plan.json` 카드 시각·줄 공개, 음량(ebur128), 화면에서 줄이 말보다 늦지 않은지.

## 7. 지키는 것

- 값은 원장(매물·기록부·보험이력·JATO)에만 있는 것. 없는 값은 카드에서 빼거나 「원본에서 확인」.
- 보험 금액은 「수리(견적)비」 이름 그대로, 「보험금」으로 바꾸지 않는다. 판매가·보험가액·신차가는 서로 다른 값.
- 리콜은 점검일 기준임을 적는다(지금 이행 여부는 단정하지 않음).
- 금지어: 무사고 · 완벽 · 문제없음 · 걱정 없습니다 · 최저가.
- 노션·시트·코드 어디에도 차량번호·차대번호·전화번호를 적지 않는다.
