# 카드 정보 기법 매뉴얼 v0.1 (2026-11-26, 작성: 클로드 시안)

사용자 지시(노션 「숏폼 카드정보 샘플 제작 및 숏폼 콘텐츠 아이디어 내기」): 독립 컷에서 카드가 순서대로 나오며 자막과 함께 정보를 요약한다. 엔카처럼 웹·앱에서 하나씩 열어 보지 않아도 숏폼 한 번 시청으로 끝나게 한다. 어떤 에이전트도 같은 결과를 내도록 아래 순서·파일만 쓴다.

## 1. 파일

| 파일 | 하는 일 |
|---|---|
| `scripts/shortform/card_info/card_info_rules.json` | 카드 종류·순서·배치·움직임·효과음·금지어의 단일 기준 |
| `scripts/shortform/be_locked_rules.json` | 노랑·칩 글자 크기·자막 크기·음량(읽기만) |
| `scripts/shortform/card_info/cards_from_charancha.py` | 차란차 매물 공개 데이터 → `facts.json`(사실 원장). 차량번호·연락처는 저장하지 않음 |
| `scripts/shortform/card_info/render_card_info.py` | `facts.json` + `plan.json` + 내레이션 → 전체 영상 + 카드별 영상 + `.plan.json`(검수 기록) |
| `scripts/shortform/card_info/examples/g400d_plan.json` | 샘플 대본·카드 내용(벤츠 G400d) |

## 2. 카드 종류 (순서 고정)

| 순서 | 종류 | 칩 | 말 첫 문장 | 데이터 |
|---|---|---|---|---|
| 1 | overview | 차량 정보 | 차량 정보부터 보겠습니다. | 등록연월·주행·연료·변속기·배기량·색상 |
| 2 | report | 성능 점검 | 성능점검기록부 요약합니다. | 기록부 요약. 확인 필요는 맨 뒤 「다만 …표시가 있습니다」 |
| 3 | insurance | 보험 이력 | 보험 이력입니다. | 없는 것 먼저 → 내 차 피해·소유자 변경 |
| 4 | options | 옵션 정보 | 옵션은 모두 N개. | 묶음별(안전·외관/내장·시트·편의) 개수 |
| 5 | addopt | 추가 옵션 | 선택 옵션 유무부터 | 판매자 등록 선택옵션(없으면 「없음」) + 눈에 띄는 장착 옵션 ✓ |
| 6 | features | 차량 특징 | 제원은 … | JATO 공식 제원(마력·제로백·복합 연비) |
| 7 | seller | 판매자 설명 | 판매자는 … | 딜러·상사·단지·판매중/완료·소개 한 줄 |
| 8 | price | 신차가 비교 | 신차가 … | JATO 기준가 → 판매가, 절약 비율 (추가 유형) |
| 9 | market | 시세 위치 | 같은 연식 시세는 … | 시세 범위 막대 + 이 차 위치 (추가 유형) |

## 3. 화면 규칙

- 1080×1920·30fps. 위 칩(노랑 원본 칠, 칩 글자 70px) 가운데 y 300 → 종이색 카드(좌우 60, 위 400, 아래 1540 이하) → 자막 가운데 y 1660.
- 배경은 매물 사진을 흐리게(28px)·어둡게(0.42). 카드가 바뀔 때 배경 0.3초 겹침, 카드는 0.28초 동안 40px 올라오며 나타남.
- 칸 공개: 말이 그 줄을 시작하기 0.04초 전에 0.18초 겹쳐 켬. 꺼진 칸은 옅은 회색.
- 강조는 노랑 한 색: 값 아래 노랑 밑줄, 노랑 원 ✓. 확인 필요·정보 줄은 먹색 테두리 원 「!」 「i」. 빨강·초록·주황 금지.
- 자막: 문장 단위(최대 2줄), 프리텐다드 Bold 60px, 지금 말하는 낱말만 노랑. 자막에 칠 없음.
- 끝: 먹색 바탕 보배드림 로고 0.5초 커짐, 1.6초.

## 4. 소리

- 내레이션: 목소리는 고정하지 않는다(2026-11-25). 샘플은 일레븐랩스 1회 생성 + 1.1배속.
- 차량 정보 카드: `card-sfx-rules-v1.md` 그대로(시동 → 달력 → 계기판 → 주유 → 기어 → 엔진 → 스프레이).
- 다른 카드: 카드가 들어올 때 휙 한 번, 판매가 공개 때 동전. 0.3초 안에 겹치면 카드 효과음만 남김.
- 배경음 `bobae_luxury_v1.mp3`(목소리 나올 때 자동으로 줄임). 음량 −14 LUFS(±1), 꼭짓값 −1.5dBTP 이하 — 렌더러가 두 번째 패스로 맞춘다.

## 5. 만드는 순서

1. 매물 페이지를 한 번 열어 공개 데이터(`raw/net.json`, `raw/rsc.txt`)와 사진(`src/`)을 받는다.
2. `python3 cards_from_charancha.py <차 폴더>` → `facts.json`.
3. `plan.json`을 쓴다: 말 덩어리마다 자막 글자(`t`)·받아쓰기 기준 낱말(`a`, 두 낱말이면 띄어 씀)·카드 시작(`card`)·켤 칸 수(`reveal`)·효과음(`sfx`). 값은 `facts.json`에서만.
4. 대본 전체를 한 번만 음성 생성 → `voice/voice_fast.wav`, faster-whisper로 낱말 시각 → `voice/whisper_words.json`.
5. `python3 render_card_info.py <차 폴더> out/이름.mp4 --clips`.
6. 검수: `out/이름.mp4.plan.json`의 카드 시각·효과음, 음량(ebur128), 카드별 영상 길이, 칸 공개가 말보다 늦지 않은지 화면 확인.

## 6. 지키는 것

- 말·카드에 쓰는 값은 원장(매물 데이터·JATO·시세)에만 있는 것. 성능점검 부위별 내용처럼 원장에 없으면 「원본에서 확인」으로 돌림.
- 금지어: 무사고 · 완벽 · 문제없음 · 걱정 없습니다 · 최저가.
- 자막은 말한 낱말 그대로(예: 배기량을 「2,900cc」로 말했으면 자막도 2,900cc, 카드는 원장 값 2,925cc).

## 7. 남은 일

- `edition_lock.json`에 판(CARD-INFO) 등록과 `check_be.py`식 자동 검사는 사용자 확정 뒤.
- 대본(`plan.json`)을 facts에서 자동으로 만드는 단계(card_routine 문장 틀 확장).
- 아이디어 유형(전비 그래프·사진 스크롤·영화 등장 컷·카탈로그 확대)은 노션 의견 참고.
