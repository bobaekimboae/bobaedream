# 오토스카우트24 네덜란드·벨기에 쇼츠 자막 규정 v2 (2026-11-09)

> 100+100편 재조사(`as24-nl-be-edit-manual-v4.md` §3·§7)에서 바로잡음: 벨기에 말 자막은 「보통 글씨 + 그림자」와 「대문자 + 테두리」(새 50편 중 21편) 두 가지가 섞여 있다. 자막 높이 중간값은 NL 약 60~65%, BE 약 62~67%.

- 근거: 유튜브 쇼츠 **네덜란드 50편 + 벨기에 50편**(벨기에 2편은 같은 영상 → 49편). 원본은 구글 드라이브 `SNS레퍼런스_원본영상/오토_네덜란드`·`/오토_벨기에`, 링크는 「SNS 레퍼런스」 시트 O열.
- 방법: 영상마다 12장 화면 묶음 + 자막이 바뀌는 2초 구간을 초당 8장으로 잘라 직접 확인. 영상별 기록은 작업 폴더 `notes/*.jsonl`(100줄).
- 분석용으로만 본다. 원본 영상·음악·목소리는 다시 쓰지 않는다.
- v1(`as24-edit-manual-v1.md`, 제미나이 자동 분석)과 다른 점: **벨기에도 대부분 말하는 낱말을 노랑이 따라간다**(v1은 "흰 글자 + 별도 스티커"로 기록). 다만 벨기에 5편은 v1 기록처럼 흰 자막 + 따로 키워드 스티커다(2026-11-09 전수조사에서 바로잡음). 벨기에 말 자막 위치는 70%가 아니라 **66~67% 고정**.

## 1. 공통 (두 나라 모두)

| 항목 | 규칙 | 확인 수 |
|---|---|---|
| 말 자막 색 | 흰 글자, **지금 말하는 낱말만 노랑**. 노랑이 목소리를 따라 낱말마다 옮겨 감 | NL 43/43(말 자막 있는 영상 전부), BE 34/39(나머지 5편은 흰 자막만 + 따로 키워드 스티커) |
| 바뀌는 방식 | 덩어리째 바로 바뀜(튀어나옴·흐려짐 없음). 노랑만 낱말마다 이동 | 전부 |
| 덩어리 크기 | 한 줄 1~3낱말. 긴 낱말만 두 줄 | 전부 |
| 바뀌는 간격 | 0.5~1.0초 (말 빠르기 초당 약 3낱말) | 받아쓰기 16편 기준 |
| 컷 경계 | 컷이 바뀔 때 0.25~0.4초 자막 비움 | BE 확인, NL 일부 |
| 숫자 | 숫자 + 단위 붙여 씀 (`43.000 km`, `€31.900`, `320 pk`) | 전부 |
| 첫 2초 | 화면에 글자가 있다(차명 제목·가격·「맞혀 봐」 질문) | NL 49/50, BE 대부분(글자 없이 시작하는 영상 최소 4편) |
| 끝 | 오토스카우트24 로고가 **영상 위에서** 작게→크게 커짐, 마지막 1.5~3초. 따로 된 끝 화면 아님 | NL 36/50(나머지 확인 못 함), BE 46/49(3편 확인 못 함) |
| 말 없는 맛보기 | 8~10초 「RAAD HET MERK(브랜드 맞혀 봐)」는 말 자막 없이 고정 제목만 | NL 7, BE 8 |

## 2. 네덜란드형

- 글자: **전부 대문자**, 굵고 둥근 고딕, 흰색 + **얇은 검정 테두리** + 부드러운 그림자, 바탕 상자 없음.
- 위치: 화면 위에서 55~75%(가장 흔한 값 65%). 컷마다 조금씩 옮겨 다님. **아래 20%는 늘 비움.**
- 숫자 크게: 가격·km·마력·연식을 **말 자막의 2~3배 노랑 숫자(검정 테두리)**로 1~2장 만에 작게→크게. 숫자가 떠 있는 동안 말 자막은 숨김. (NL 39/50)
- 이름표: **검정 상자 + 노랑 글자**, 화면 위 15~30%. 차명, 기능 이름(+✓), 마력(+🏁). 해당 장면에서 약 2초. (NL 약 43/50)
- 시작 질문: 「RAAD HET MERK」, 「HEB JIJ EEN BUDGET VAN €25.000」, 「IN 30 SECONDEN」처럼 검정 상자 질문·약속.
- 끝 직전: 「LAAT HET WETEN IN DE REACTIES(댓글로 알려 줘)」 같은 댓글 유도.

## 3. 벨기에형

- 글자: **보통 대·소문자**(문장부호도 그대로), 작은 굵은 고딕(화면 높이 약 3~3.5%), 흰색 + **오른쪽 아래로 진한 그림자만**. 테두리·상자 없음.
- 위치: **66~67%에 고정**. 장면·앱 화면 녹화 위에서도 그대로. (인터뷰는 약 49%, 팟캐스트는 약 60%)
- 키워드 스티커: **살짝 기울어진 손글씨 느낌 노랑 띠 + 검정 글자**, 가리키는 부품 옆에. 「Carbon」, 「DSG-automaat」, 숫자 「320 pk」·「€31.900」. 1~2장 만에 커지며 1~2.5초.
- 제목 스티커: 브랜드는 노랑 띠 위 검정, 모델은 흰 글자, 아래 작게 가격. 화면 위 26~37%. (BE 약 25/49)
- 가격 인하: 옛 가격은 노랑 띠 + 빨간 줄, 새 가격은 아래 크게 흰 글자. (3편)
- 길거리 인터뷰: 매물 카드(사진 + 가격)를 노랑 테이프로 붙인 듯 띄움, 대답 숫자는 스티커.

## 4. 보배드림에 쓰는 법 (제안 — 확정 기준을 바꾸는 것이므로 사용자 결정 필요)

| 항목 | 제안 | 이유 |
|---|---|---|
| 말 자막 바탕 | 네덜란드형: 굵은 흰 글자 + 검정 테두리 + 그림자 | 한글은 획이 많아 작은 그림자만(벨기에형)으로는 밝은 차 위에서 잘 안 읽힘 |
| 낱말 따라가기 | 유지. 한국어는 **어절(띄어쓰기 단위)**마다 노랑 `#EEEF05` | NL 전부, BE 87%가 이 방식 |
| 위치 | **65% 고정**(벨기에처럼 움직이지 않음) | 눈이 같은 자리만 보면 됨. 아래 20% 비움은 네덜란드 규칙 따름 |
| 덩어리 | 한 줄 2~3어절, 0.6~1.0초 | 두 나라 측정값 |
| 숫자 | 네덜란드형 큰 숫자 튀어나옴, 그동안 말 자막 숨김. 표기 `4.3만km`·`2,890만원` | 가격·주행거리가 매물 정보의 핵심 |
| 키워드·옵션 | 이름표 1종만: 현재 결정인 **파랑 `#306BD9` 칩** 유지 | 2026-11-08 사용자 결정. 노랑은 낱말 따라가기 전용으로 나눔 |
| 첫 2초 | 차명 제목 + 볼 이유 한 줄 | 두 나라 공통 |
| 끝 | 보배드림 로고가 영상 위에서 커짐 1.5~2.5초 | 두 나라 공통 |
| 컷 경계 | 0.3초 자막 비움 | 벨기에 측정값 |

## 5. 노랑과 목소리 시간차 (측정)
- 방법: 100편 음성을 받아써 낱말마다 말 시작 시각을 얻고, 화면을 초당 10장으로 보며 노랑이 다른 낱말로 옮겨 가는 순간을 찾아 가장 가까운 낱말 시작과 비교.
- 네덜란드 43편(노랑 이동 3,623번): 영상별 중간값의 중간값 **+0.01초**, 가운데 절반이 0.00~+0.02초.
- 벨기에 34편(1,849번): **+0.04초**, 가운데 절반이 +0.02~+0.05초.
- 결론: 노랑은 **낱말을 말하기 시작하는 바로 그 순간**(화면 한 장 0.1초 안)에 옮겨 간다. 미리 켜지거나 늦게 켜지지 않는다.
- 보배드림 규칙: 어절 시작 시각에 맞춰 노랑으로 바꾼다(앞당기거나 늦추지 않음). 받아쓰기 시각 오차(약 ±0.05초)는 그대로 둔다.

## 6. 아직 못 본 것
- 일부 영상(NL 약 10편)의 끝 로고는 12장 묶음에 안 잡혀 "확인 못 함"으로 둠.
- 글꼴 이름은 확인하지 못했다(모양만 기록).
