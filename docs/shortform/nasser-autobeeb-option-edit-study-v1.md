# 나세르 · 오토비브 옵션 편집 학습 v1 (2026-11-22)

사용자 지시: 「나세르와 오토비브 10대만 / 옵션 기능 편집 어떻게 하는지 학습해서 / 우리 적용할거 찾아라」.
대상: 나세르(Nasser Hessien) 틱톡 10편, 오토비브(AutoBeeb) 유튜브 쇼츠 10편. 사용자 PC에 받아 둔 영상(내부 분석용)을 1초 간격 장면 시트와 받아쓰기(faster-whisper large-v3-turbo, 아랍어)로 봤다.
vidIQ는 크레딧이 0이라 쓰지 못했다.

## 1. 한눈에

### 1-1. 말과 그림의 시각 (받아쓰기 20편 대조)

| | 나세르 | 오토비브 |
|---|---|---|
| 말 속도(전체 길이 기준) | 초당 2.88낱말, 말 없는 구간 거의 0 | 초당 2.34낱말, 말 없는 구간 3% |
| 말 덩어리 길이(중간값) | 1.6초 | 1.9초 |
| 옵션 낱말을 말한 구간(10편 합) | 52번 | 119번(센서·카메라·화면·열선·통풍이 많음) |
| 그림으로 띄운 수 | 말한 옵션 대부분 | 한 편 4~8개 — **말은 많이, 그림은 적게** |
| 그림이 뜨는 때 | 낱말 순간 | 낱말 시작 뒤 약 0.5~1.0초(손이 그 부위에 닿을 때), 약 1.5초 유지 뒤 사라짐 |
| 시트 표시 | 3D 글자 + 불꽃 | **시트 면을 색으로 칠함**: 통풍 = 파랑 칠 + 눈송이 + 「تبريد」, 열선 = 빨강 칠 + 불꽃 + 「تسخين」, 마사지 = 초록 아이콘. 말한 순서대로 쌓이고 한꺼번에 사라짐 |
| 휠 | 노랑 3D 인치 | 손이 휠에 닿고 컷이 휠로 바뀐 뒤 「18"」 |
| 센서 · 카메라 | 일부 아이콘 | 말해도 대부분 그림 없음 |

확인 방법: 오토비브 8편에서 옵션 낱말이 처음 나온 구간마다 시작 1초 전부터 0.5초 간격 8장을 뽑아 대조했다(`tm/all.jpg`, 장면 시트 1초 간격이라 ±0.5초 오차).
