# AS24 네덜란드·벨기에 vs 독일·리싱마크트 편집 대조 v1.1 (2026-11-09, 전수조사 반영)

- 근거: NL 200 · BE 198 · DE 100 · LM(리싱마크트) 100편. 컷·노란 글자 자동 측정 598편 + 영상마다 16장 화면 묶음을 눈으로 확인(DE·LM 200편) + 효과음 스펙트로그램 440곳.
- 숫자 중 「약」이 붙은 것은 화면 묶음을 사람이 읽은 근사치다.
- v1에서 바로잡은 것: 컷·노랑 숫자를 같은 기준으로 다시 계산했고(아래 표 아래 설명), 독일의 「핵심어 노란 상자 약 20편」(실제 1편), 리싱마크트의 「스펙 칩은 광고형에만」(실제로는 말 없는 광고·사진형 10편 + 진행자 설명형 7편), 끝 로고 효과음을 고쳤다.
- 함께 보는 문서: `as24-edit-skeleton-v3.md`(NL·BE 칩), `as24-caption-rules-v2.md`(자막), `as24-sfx-rules-v1.md`(효과음).

## 3. 한 줄 요약

- **NL·BE = 「편집자가 그래픽으로 설명」**: 컷이 빠르고(분당 17~21), 칩·큰 숫자·효과음으로 정보를 화면에 박는다.
- **DE = 「사람이 말로 설명」**: 컷이 거의 없고(분당 3.5), 그래픽 대신 진행자 + 문장 자막 + 법적 문구.
- **LM = 「놀이 형식」**: 퀴즈·3가지 사실 같은 틀이 먼저, 노랑 따라가기 자막, 스펙 칩은 말 없는 광고·사진형과 일부 설명형에만.

## 4. 보배드림에 주는 뜻

| 상황 | 따를 채널 | 이유 |
|---|---|---|
| 매물 사진·영상만 있음(사람 없음) | **NL** | 정보를 그래픽(칩·숫자)으로 전달해야 함. 현재 뼈대 v3 그대로 |
| 딜러가 직접 말하는 영상 | **DE** | 컷을 줄이고 문장 자막 + 칩 최소(가격·주행거리 정도). 효과음 없음 |
| 퀴즈·맞히기 기획 영상 | **LM** | 「이 차 뭘까?」 제목 + 단계 표시 + 낱말 따라가기. 효과음 없음이 원본이지만 우리는 NL형 딩을 그대로 씀(bobae_quiz) |
| 음악을 까는 영상 | **BE** | 효과음은 칩의 20%, 최대 3번 |
| 법적 문구 | DE·LM | 우리는 연비 표기 의무 대상이 아니라 넣지 않음(확인 필요) |

- 확정 기준(파랑 `#306BD9` 칩, 노랑 `#EEEF05`는 따라가기 전용)은 네 형식 모두 그대로 쓴다. DE형은 칩을 줄일 뿐 색은 같다.
- 코드: `scripts/shortform/as24_edit_rules.json`에 `de`·`lm` 프리셋과 보배드림용 `bobae_talk`(DE형)·`bobae_quiz`(LM형)을 넣었다. `as24_edit_planner.py --style …`로 고른다.
