## 공통 시험 규칙

- 같은 입력·같은 설정으로 바꾸기 전/후를 나란히 만든다. 바꾸는 도구 하나 말고는 고정한다.
- 판정 숫자(시간·오차·SSIM·검사 결과)는 시트에, 결정은 노션에, 코드·잠금 파일은 깃허브에.
- 크레딧·요금이 드는 생성은 한 번만. 사람 청취·눈 확인이 필요한 항목(1·2·3·7)은 비교 파일을 드리고 판정을 받는다.
- 확정되면 `scripts/shortform/requirements-lock.txt`(또는 해당 잠금 파일)에 판을 고정한다.
