# 옵션 붓칠 칩 자리 규격(슬롯 규격) v1 — 제안 · 2026-11-24

차란차 10번 GLE450 v2 샘플에서 시험한 안이다. 잠금 규칙 파일(`be_locked_rules.json`)은 바꾸지 않았고, 다른 차 입력(car.json)에 `"chip_layout": "slots"`를 넣었을 때만 켜진다. G350 기준 영상 동작은 그대로다.

## 왜
v1까지 「부위 이름표」 칩은 부위를 따라다녀 컷마다 자리가 달랐다(가운데·오른쪽·아래 제각각). 벨기에 오토스카우트 캡처(시트 「오토스카우트24 쇼츠 편집사례」 28·29·31·33·35·37번)를 보면 칩은 부위를 따라다니지 않고 **정해진 띠 두 곳(위쪽 / 아래 1/3)** 에만 놓이고 화살표가 없다.

## 규격
| 항목 | 값 | 근거 |
|---|---|---|
| 가로 | 모든 칩 같은 왼쪽 선(칠 시작 x = 50px 근처, 안전영역 40px 안) | 기준 영상 위쪽 칩 자리와 같음 |
| 세로 T줄 | 위 300px (잠금 규칙 값 그대로) | `chip.y_top_px_feature_video` |
| 세로 B줄 | 위 1030px (말 자막 1283px 바로 위) | 벨기에 「아래 1/3」 띠. 자막·아래 20% 비움과 안 겹침 |
| 줄 고르기 | 기본 T줄. 부위가 T줄 칩 + 화살표 자리와 겹치거나, 돋보기 원(T06)이 있는 컷만 B줄. 컷 안에서는 안 바뀜 | 부위를 가리지 않기 |
| 화살표 | 칩에서 떼어 부위 옆에 둠(칩 쪽에서 부위를 가리킴, 길이 70~170px). 칩은 고정, 화살표만 부위를 따라감 | 「부위 이름표」 기법 유지 |
| 정보 알약 | 칩 왼쪽 선에 맞춰 칩 아래(B줄은 위)에 쌓음. 칩이 없는 컷은 큰 숫자 묶음 아래 가운데 | ✓ 목록(T02) 자리 규칙과 같음 |
| 큰 숫자 | 위 12% 가운데(그대로) + 양옆 위 강조 선(노션 원본 두들, 노랑) | 꾸밈 |

## 결과(GLE450 v2, 칩 14개)
T줄 10개 · B줄 4개(내비게이션 · 터치패드 컨트롤러 · 전동 시트 조절 · 메모리 시트 3개). 검사 `check_be.py` · `edit_gate.py post --plates` 통과.

## 정해야 할 것
- 이 규격을 기준으로 삼을지(삼으면 `feature_edit_rules.json` mapping에 적고 G350에도 적용).
- B줄 높이 1030px, 화살표를 아예 없앨지(벨기에 원본은 화살표 없음).
