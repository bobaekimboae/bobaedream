# 사진 매물 숏폼 제작 플레이북 v1 (2026-11-22)

사진만 있는 딜러 매물(서울오토갤러리 등)을 30~40초 세로 숏폼으로 만드는 순서와 규칙을 한곳에 모았다.
숫자 값은 규칙 파일이 단일 기준이다(이 문서는 「어디에 무엇이 있고 왜 그렇게 정했나」만 적는다).

| 찾는 것 | 단일 기준 |
|---|---|
| 색 · 칩 · 자막 · 효과음 숫자 | `scripts/shortform/be_locked_rules.json` |
| 옵션 그림(시트 묶음 · 휠 · 숫자 표기) | `scripts/shortform/photo_listing/option_visual_rules.json` |
| 카드 컷 말하기 순서 | `scripts/shortform/photo_listing/card_routine_rules.json` |
| 부위 당기기 | `scripts/shortform/photo_listing/part_zoom_rules.json` |
| 버전 기록 | `shortform-kit/CHANGELOG.md` |

## 1. 순서

1. **매물 받기**: `sag_prep.py <상세.html> <성능기록부.html> <사진폴더> <차폴더>` → `listing.json`(차명·연식·주행·연료·색·**등록 옵션**·상사·딜러) · `cards.json`(성능점검 카드 줄) · `src2/pNN.jpg` + `photos.json`(부위 이름표).
2. **대본**: 판매글 문체(아래 3장). 사실은 `listing.json` · `cards.json`에 있는 것만.
3. **목소리**: 일레븐랩스 한 번 생성(지금 기본 Taehyung, 젊은 목소리 · eleven_v3 `[confident]` 태그). 다시 녹음은 틀린 문장만 `revoice_splice.py`.
4. **받아쓰기**: `tr.py` → `voice_a_words.json`. 잘못 들은 낱말은 json 글자만 고치고, 받아쓰기가 계속 같은 말로 들으면 실제 발음 문제로 보고 그 문장만 다시 녹음.
5. **cfg 작성 → `check_cfg.py`**: 말한 낱말 전부 자막, 합니다체, 카드 루틴(⑦), 금지 표현.
6. **렌더**: 기본판(동적) + `BBM_FADE=1` 페이드판. `PYTHONPATH=$PWD python3 common.py <차폴더>`.
7. **검수**: `check_render.py <차폴더> <mp4>`, 음량 −14±1 LUFS(`ffmpeg -af ebur128`), 정지 화면(칩·자막·스티커 겹침, 끝 2초). 통과 전에는 전달하지 않는다.

## 2. 화면 규칙(오늘 정한 것)

| 항목 | 규칙 | 근거 |
|---|---|---|
| 기본판 | 동적판 = 켄번스 100→110~114% · 키 2개 · 부드러운 가속, 전환은 **구간 경계 3곳만**(외관→실내 당김 · 실내→카드 번쩍 · 카드→딜러 휙), 나머지는 바로 컷 | 캡컷 가이드 조사 v1 |
| 박자 맞춤 | `BEAT_SNAP = True`: 컷 경계를 「앞 낱말 끝 ~ 첫 낱말 소리 0.04초 전(최대 0.45초 전)」 안의 배경음 박자에, 구간 경계는 강박 먼저. 말 싱크가 우선 | 캡컷 박자 편집 가이드 |
| 페이드판 | 선택안(모든 넘김 0.5초 페이드, 휙 소리 없음) | 사용자 비교용 |
| 칩 자리 | 붓칠 칩은 **사진 헤더**: 가로 사진이면 사진 위 띠, 꽉 찬 사진이면 위 470px(`CAPS_UNDER_PHOTO` · `CHIP_Y=470`). 자막은 사진 아래 | 사용자 「붓칠이 사진 헤더에」 |
| 시트 묶음 | 시트 사진 컷 + 그 컷 대본에 기능 낱말이 있을 때만: 가죽(재질 글자) · ⚡ 전동 · 🔥 열선 · ❄️ 통풍 · 💆 마사지 · 💾 메모리. **말한 순서대로** 배치 | 사용자 「시트 사진 있을 때 이모지 표시가 규칙」 |
| 카드 컷 | 성능점검 카드: 「성능점검기록부 요약합니다.」→ 문제없는 줄 「…없습니다!」→ 확인 필요 줄은 맨 뒤 「다만 …표시가 있습니다.」(주황 느낌표). 무사고 · 완벽 · 문제없음 금지 | `card_routine_rules.json` |
| 쓰지 않는 것 | 3D 줌 · AI 이미지→영상 · 배경 바꾸기 · 번호판 흐림(번호판은 가리지 않음) · 글리치 | 반사기 원칙 |

## 3. 대본 문체 — 판매글

- 판매자 1인칭 군말(「제가 직접」 「정말 좋습니다」) 없이 **차량 판매글처럼 사실 한 문장씩**.
- 순서: 차명·단지 → 등록·주행 → 외장·실내 색 → 눈에 띄는 부위(휠·캘리퍼 등) → 시트 옵션 → 실내 → 편의(어라운드뷰 등) → 성능점검 카드 → 딜러 → CTA.
- 문장 끝은 합니다체. 숫자는 매물 정보 그대로(주행 57,913km 같은 정확값이 있으면 그 값).

## 4. 크로스체크 절차

1. 받아쓰기 다시 돌려 의심 구간 확인(발음이 뭉개진 낱말 = 다시 녹음 후보).
2. 성능 카드 줄을 **기록부 원본 체크값**과 한 줄씩 대조(`inspect_parse.py`로 체크된 값만 뽑음).
3. **옵션은 사이트 「차량옵션」 아이콘 중 켜진 것(class="on")만**. 아이콘 목록 전체는 모든 매물에 똑같은 틀이라 옵션이 아니다(아래 6장).
4. 정지 화면: 첫 화면 · 칩 뜨는 순간 · 시트 컷 · 카드 컷 · 끝 2초.

## 5. 서울오토갤러리 사진 순서(10대 대조)

서울오토갤러리 스튜디오는 20장을 같은 순서로 찍는다. K10 · K15~K17만 차마다 다르다.

| K | 부위 | K | 부위 |
|---|---|---|---|
| 01 | 측전면 | 11 | 앞좌석 |
| 02 | 정면 | 12 | 뒷좌석 |
| 03 | 측후면 | 13 | 대시보드(조수석 쪽) |
| 04 | 후면 | 14 | 뒷좌석 전체 |
| 05 | 엔진룸(전기차는 앞 트렁크) | 15~17 | 디테일(화면 · 어라운드뷰 · 도어 · 썬루프 · 시계 등) |
| 06 | 휠 | 18 | 정면 3/4 낮게 |
| 07 | 대시보드 | 19 | 후면 3/4 |
| 08 | 운전석 계기·핸들 | 20 | 트렁크 |
| 09 | 계기판 | | |
| 10 | 디테일(변속 레버가 많음) | | |

## 6. 바로잡을 것 — 콰트로포르테 옵션

- 콰트로포르테 v3~v5의 「전동, 열선, 통풍 시트까지 됩니다」는 **사이트에 등록된 옵션이 아니었다.** 상세 페이지의 차량옵션 아이콘 21개는 모든 매물에 똑같이 들어 있는 틀이고, 실제 등록 옵션은 그중 `class="on"`이 붙은 것뿐인데 이 매물은 0개다. 틀을 옵션으로 읽은 오판.
- 사진으로 보이는 「가죽 시트」만 남기고 전동 · 열선 · 통풍 낱말과 ⚡🔥❄️ 아이콘을 뺐다. v6(2026-11-22): 시트 문장만 「앞좌석은 브라운 가죽 시트입니다.」로 다시 녹음(같은 목소리, `revoice_splice.py`), 뒤 낱말 번호 −4. 딜러 확인을 받으면 되살린다.
- 재발 방지: `sag_prep.py`가 `class="on"`만 옵션으로 읽는다.
