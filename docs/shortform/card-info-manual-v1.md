# 숏폼 카드 정보 기법 매뉴얼 v1 (클로드 시안 2)

2026-11-26 · 노션 「숏폼 카드정보 샘플 제작 및 숏폼 콘텐츠 아이디어 내기」 지시로 만듦.
목적: 엔카는 웹·앱에서 항목을 하나씩 눌러 봐야 하는 정보를, 숏폼 한 번 시청으로 요약해 준다. 어떤 에이전트가 만들어도 같은 결과가 나오게 규칙·코드·데이터를 나눈다.

## 1. 파일

| 무엇 | 위치 |
|---|---|
| 규칙(색·크기·시간·문장 틀·효과음) 단일 기준 | `scripts/shortform/card_info/card_info_rules.json` |
| 렌더러 | `scripts/shortform/card_info/card_info.py` |
| 차량 데이터(카드 값) | `scripts/shortform/card_info/samples/<차>.json` |
| 샘플 결과 | `public/shortform-samples/card-info-v1-s2/` (카드별 mp4 + `card_info_all.mp4` + 카드별 `.plan.json`) |
| 기존 성능지 사진 카드(사진 매물 숏폼 안의 컷) | `scripts/shortform/photo_listing/report_cut.py` · `card_routine_rules.json` — 말하기 순서는 같은 규칙을 따른다 |

## 2. 만드는 법

```
cd scripts/shortform/card_info
python3 card_info.py samples/g400d.json out/ --stills      # 확인용 정지컷(카드마다 PNG)
python3 card_info.py samples/g400d.json out/               # 카드별 mp4 + 전체 mp4
python3 card_info.py samples/g400d.json out/ --only vehicle,price
```

출력은 1080×1920 · 30fps · H.264 · AAC, 음량 −14 LUFS(2단계 loudnorm, TP −1.5).

|---|---|---|---|---|

| seller | 판매자 설명 | 판매자 설명 요약합니다. | {요약}. | 판매자 글 핵심 2~3줄 |

## 4. 화면 규칙 (AS24 참고)

- 틀: AS24 웹 상세 「기본 정보」 사실표처럼 흰 판에 라벨 왼쪽·값 오른쪽, 줄 사이 가는 선. 위에는 AS24 BE 릴스식 노랑(#F5F200) 테이프 제목(판만 −1.6° 기울이고 글자는 수평).
- 바탕: 어두운 무채색 그라데이션. 카드는 테이프와 자막 사이 가운데(중심 y 930).
- 머리: 유형 아이콘(노랑 원) + 제조사·모델 + 코드네임·등급 + 오른쪽에 카탈로그 차 그림.
- 줄: 아이콘 44px(원본 SVG 색만 입힘) · 라벨 34px · 값 40px ExtraBold. 성능점검은 초록 체크 / 주황 「!」.
- 자막: 화면 아래(중심 y 1665), 흰 글자 + 그림자, 값 낱말만 노랑.
- 진행 점: 카드 아래, 지금 카드만 밝게.
- 「샘플 값」: 데이터에 `"sample": true`이면 카드 오른쪽 위에 회색 테두리 표시를 반드시 넣는다.

## 5. 움직임·소리

- 카드 등장 0.4초(아래 90px에서 올라옴) → 머리말 1.3초 → 줄 하나씩 켜짐(0.22초, 18px 올라옴), 줄마다 1.15초(긴 문장은 더) → 1초 멈춤 → 0.25초 퇴장.
- 줄 하나 = 자막 문장 하나 = 효과음 하나(check.wav, 확인 필요 줄은 beep_on.wav). 카드 등장은 card_page_flip.wav. 배경음 bobae_showroom_v1 −20dB.

## 6. 지킬 것

- 값은 차량 데이터 파일에만 쓴다. 매물에 없는 값을 채우지 않는다. 열람하지 못한 값은 `sample: true`로 표시하고 화면에도 「샘플 값」.
- 금지어: 무사고 · 완벽 · 문제없음 · 걱정 없습니다 · 최고(판단을 붙이지 않는다).
- 차량번호·차대번호·제시번호·개인 연락처는 넣지 않는다.
- 코드네임은 BMW·벤츠·포르쉐만.

## 7. 검사 (전달 전)

1. `--stills` 정지컷으로 겹침·잘림 확인.

3. `.plan.json`의 문장과 데이터 값이 같은지, 금지어가 없는지.

## v2 (2026-11-26 · 음성 · 대사 · 크기 통일 · AS24 노션 원본)

사용자 지시: 「음성 넣자」 → 「대사 만들고 카드 크기 밸런스 맞추고, 붓칠 및 아이콘은 오토스카우트 노션 원본」 → 「추가 옵션 카드에 옵션 합계와 신차가 + 옵션 총액」 → 「연식과 연형 둘 다, 수입차는 정식 출고인지도」 → 「색상은 외장과 시트 색상」.

### 만드는 법
```
cd scripts/shortform/card_info
python3 card_info.py samples/g400d.json out/ --script                       # out/tts.txt(읽는 글) · out/script.json(자막·읽는 글 짝)
# tts.txt 전체를 ElevenLabs Hwan(GFsKFsadyjMQ7MPv89Tw) · eleven_v4 · generations_count 1로 한 번 생성 → out/voice.mp3
python3 card_info.py samples/g400d.json out/ --voice out/voice.mp3 --stills  # 정지컷
python3 card_info.py samples/g400d.json out/ --voice out/voice.mp3           # out/card_info_voice.mp4 + .plan.json
```

### 대사(= 자막 문장)
- 자막은 원래 표기, 읽는 글은 `speak.py`가 숫자·단위·영문을 소리 나는 대로 바꾼다(33,475km → 삼만 삼천사백칠십오 킬로미터, 1회 → 한 번, LED → 엘이디).
- 문장 틀은 규칙 파일 `types.*`의 intro · row · row_none · row_warn · row_sum · row_total. 조사(은/는)는 라벨 받침으로 자동.
- 차량 정보: 최초등록(연식)과 연형을 둘 다 말한다. 색상은 「외장 ○ · 시트 ○」 한 줄. 수입차는 「수입 구분」(정식 출고/병행 등) 줄을 넣는다. 매물 원문에서 확인 못 한 값은 줄 4번째 칸 `"check"` → 값 왼쪽 「확인 전」 표시.
- 추가 옵션: 옵션 값(+ N만원)을 더해 「옵션 합계」, price 카드 신차가에 더해 「신차가 + 옵션 총액」 줄을 자동 계산(총액은 노랑 판).

### 음성 맞추기
- 전체 대사를 한 번만 생성(다시 시도 금지). 바뀐 문장만 있으면 그 문장만 따로 만들어 무음 구간에서 잘라 붙인다.
- faster-whisper(large-v3-turbo) 낱말 시각을 읽는 글과 글자 단위로 맞춰(difflib) 문장마다 소리 시작 시각을 얻는다. 줄은 그 시각에 켜지고 효과음도 같은 시각.
- 목소리는 0.45초 늦춰 붙여 카드가 먼저 올라온다. 카드는 다음 카드 머리말 0.45초 전에 바뀐다. 배경음 −24dB, 2단계 loudnorm −14 LUFS.

### 크기 · 원본 에셋
- 카드 높이는 모든 유형 같음: 머리 210 + 9줄 × 92 + 40. 줄이 적으면 줄 높이를 130까지 늘리고 줄 묶음을 가운데에.
- 붓칠 제목: 노션 원본 103_33(`g350_v5_lib.chip`, `be_locked_rules.json` chip.fill_fit — 칠 높이 = 글자 × 2.0, 좌우 = 글자 × 1.25, 기울기 0).
- 아이콘: 노션 「독일 오토 24」 원본 `public/assets/shortform/card-info/as24-icons/`(체크 원 checkmark-sale만 원본 색, 나머지는 색만 입힘). 유형: 차량 Info · 성능 service_security_check · 보험 Insurance · 소유 person · 옵션 Equipment · 추가 car-sale · 특징 black-star · 가격 price_history · 판매자 speech_bubble_text.

### 샘플
`public/shortform-samples/card-info-v2-s2/card_info_voice.mp4`(116초, −14.7 LUFS). 차량 정보의 최초등록·주행·연료·변속기·외장색·지역·판매가만 실값(Grok 차란차 기록), 연형·시트색·수입 구분은 「확인 전」, 나머지 카드는 「샘플 값」.

## v2.1 (2026-11-26 · 2차 제안 반영)

- 기본 순서(`card_info_rules.json` default_order): 엔카 매물정보에 있는 항목은 엔카 기본 순서 — **차량 기본정보 → 성능 점검 → 보험 이력 → 차량 이력 타임라인(국토부, 신규)**, 그 뒤 우리 카드 — **옵션 정보 → 추가 옵션 → 차량 특징 → 판매자 설명**.
- 카드는 필수가 아니다. 매물 데이터 `order`에 값이 있는 카드만 넣으면 1장부터 여러 장까지 기본 순서대로 정렬된다. 렌더러는 전체 이어 붙인 영상과 함께 **카드 한 장씩 따로**(`card_NN_<유형>.mp4`) 만들어, 차량 편집 영상에 필요한 카드만 끼워 넣는다.
- 신규 `timeline` 카드: 줄 = [아이콘 없음, 날짜, 사건]. 세로선 + 노랑 점, 줄이 켜질 때 선이 다음 점까지 내려간다. 문장 「{날짜}, {사건}.」. 소유 이력 카드 내용(소유자 변경 등)은 여기로 합친다.
- price·owners 카드는 기본 순서에서 뺐다(price의 신차가는 추가 옵션 「신차가 + 옵션 총액」 계산에만 씀).
- 음성: 순서가 바뀌면 카드 구간(plan.json start~end)대로 기존 목소리를 잘라 새 순서로 이어 붙이고, 새 카드 문단만 새로 생성한다.
- 샘플: `public/shortform-samples/card-info-v3-s2/`(전체 111초 · −14.6 LUFS + 카드별 8개). 타임라인 값은 국토부 열람 전이라 「샘플 값」.

## v3 (2026-11-26 · 3차 지시 + 실제 매물값)

- 실제 값으로 교체: 노션 페이지에 다른 에이전트가 원문 확인한 값(차란차 기본정보 · 카모두 성능점검기록부 · 차란차 보험 상세 · 주요 옵션). 성능 점검은 사고 이력 없음 + 단순수리(트렁크리드 판금·용접) · 점검자 의견(운전석 앞문·쿼터 도장) · 리콜 해당·미이행을 숨기지 않고 끝에 말한다(첫 줄 「다만 … 기록이 있습니다.」, 다음 줄은 「{라벨}, {값}.」). 판매자 설명은 매물에 고유 설명이 없어 카드 생략. 추가 옵션(선택 옵션 0개)·차량 특징은 형식 시연용 「샘플 값」.

- 진행 점 제거(영상은 좌우 넘기기가 아님), 카드 폭 1000 · 글자 키움(제목 56 · 라벨 38 · 값 44 · 아이콘 50).
- 속도감: 목소리 atempo 1.15, 카드 등장 0.28초 · 줄 0.16초 · 마지막 멈춤 0.35초 · 앞당김 0.3초.
- 보험 이력 + 소유 이력 합침(테이프 「보험·소유 이력」, 소유자 변경 · 번호판 변경 줄 추가).
- 타임라인 머리말: 데이터 source가 molit(국토부 원장)일 때만 「국토부 차량 이력」, 아니면 「차량 이력」.
- 샘플: `public/shortform-samples/card-info-v3b-s2/`(102초 · −14.8 LUFS + 카드별 7개).

## v4 (2026-11-26 · 4차 지시)

## v5.1 (2026-11-26) — 차량 기본정보 그리드 확정
- 차량 기본정보는 2열 그리드(grid2) 확정, 나머지 카드는 세로 목록(list), 판매자 설명은 말풍선(quote).
- 그리드 칸 값은 12자 이내(`grid_value_max_chars`). 넘으면 렌더 전에 멈춘다 → 값을 줄이고 자막 문장은 줄의 5번째 칸으로 따로 쓴다.
- 줄 5번째 칸 = 자막·대사 문장(값이 줄어도 말은 그대로). 예: `3년·10만km 만료` / 「제조사 보증은 3년 · 10만km 만료입니다.」
- 세로 목록은 `--layout vehicle=list`로 비교용만.

## v5.2 (2026-11-26) — 전체 나열 · 바로 칠하기
- 모든 카드(목록·그리드·판매자)는 카드와 함께 줄 전체가 한꺼번에 나온다(`motion.rows_mode: all`, 0.18초 뒤 줄당 0.05초 계단). 말할 때마다 한 줄씩 나오던 방식은 `rows_mode: speech`로 비교용.
- 밑줄 칠은 줄이 다 나온 직후 0.15초 뒤 바로 시작(항목당 0.18초). 차량 정보 카드는 약 2.2초 안에 핵심 3항목 칠 완료.
- 자막은 그대로 말하는 문장·낱말을 따라간다.

## v5.3 (2026-11-26) — 칠이 말을 따라감(싱크 칠)
- 밑줄 칠은 고정이 아니다(`underline.mode: sync`). 말이 그 줄의 값에 닿는 순간(자막 낱말 시각) 값 길이만큼 왼쪽→오른쪽으로 칠하고, 다음 줄이 칠해지면 0.2초에 사라진다 → 화면에는 지금 읽는 줄 하나만 노랑 밑줄.
- 칠 길이 = 값 첫 낱말 소리 시작 ~ 값 다음 낱말 시작(0.25~0.7초). 낱말 시각을 못 찾으면 그 문장 시작 0.25초 뒤.
- 모든 카드(그리드·목록·타임라인)에 같은 규칙. 합계·총액 줄은 칠하지 않는다(노랑 상자가 있음).
- 줄 전체는 v5.2처럼 처음부터 한꺼번에 보인다. 이전 고정 칠은 `mode: keys`로 비교용.

## v5.4 (2026-11-26) — 타임라인 사건이 많을 때 · 크로스체크 수정
- 타임라인 최대 5줄(`types.timeline.max_events`). ① 같은 사건이 되풀이되면 한 줄로 합침(정기 검사 2017~23 ×4) ② 그래도 넘치면 처음 등록·마지막 사건은 남기고 중요도(사고·보험 > 소유·번호·리콜 > 등록 > 검사·정비) 높은 것부터 ③ 나머지는 맨 아래 회색 「그 밖에 소유·번호 2건 · 정비 3건 · 검사 4건」 한 줄, 대사도 한 문장. 사고·보험 사건은 「그 밖에」로 빼지 않는다.

- 칠 남기기(`underline.keep: true`): 설명한 항목은 칠이 남음. 대사를 핵심 항목만 남겨야 강조가 살아남(다음 판).
