# 보배드림 자동 편집기 v1 — 사람 없이 네덜란드판·벨기에판 편집 (2026-11-09)

> 사용자 지시(2026-11-09): 「모든 규칙을 자동화해서 네덜란드·벨기에 편집자가 직접 편집한 듯한 자동 편집 시스템」 · 「음성은 일레븐랩스」 · 「가장 중요한 건 옵션 기능 칩 노출」 · 「영상 분석하면서 재교정하면서 고도화」.
> 근거: `as24-nl-be-edit-manual-v4.md`(100+100편 실측), `as24-edit-skeleton-v3.md`(부위별 칩 자리).

## 1. 흐름

| 단계 | 하는 일 | 파일 |
|---|---|---|
| ① 대본 | 매물 정보(facts.json)에서 사실만으로 대본을 만든다. 숫자는 TTS 한글 읽기 + 화면 숫자 짝 | `auto/auto_edit.py script` → `tts.txt` |
| ② 음성 | 일레븐랩스로 읽힌다(지금은 Klamon, eleven_v4) | `voice.mp3` |
| ③ 낱말 시각 | 일레븐랩스 받아쓰기 또는 내 컴퓨터 faster-whisper. 받아쓰기 글자(오인식)는 쓰지 않고 대본 어절에 시각만 붙인다 | `words.json` → `words_flat.json` |
| ④ 장면 고르기 | 구절마다 그 말에 맞는 부위 장면을 원본 장면 목록(shots.json)에서 고른다 | `auto_edit.py build` → `config.py` |
| ⑤ 렌더 | 기존 렌더러에 네덜란드판·벨기에판 프리셋으로 | `sag_reel_v1.py` |

규칙은 전부 `auto/auto_edit_rules.json` 한 곳에 있다(부위 26개, 부위별 칩 높이, 옵션 사전 58개, 옵션 노출 규칙, 대본 순서, 재교정 목표). 코드는 규칙을 읽기만 한다.

## 2. 옵션 칩 노출 (가장 중요)

- 옵션 사전 58개 = 우리 필터의 공식 옵션 목록(`bbm-filter-options.ts` `bbmOptionGroups`). 옵션마다 칩 글자 · 읽는 말 · 보이는 부위 · 우선순위(1~3) · 화면에 보이는지.
- 고르기: 우선순위 순, 같은 순위는 보이는 옵션 먼저. **그 부위 장면이 원본에 있을 때만** 칩을 띄운다(없으면 다음 옵션). 한 영상 최대 NL 4 · BE 3(재교정 대상).
- 매물 옵션표 밖이지만 영상에 보이는 특징(노란 캘리퍼 등)은 `features`로 넣는다. 옵션표에 없는 옵션은 지어내지 않는다.
- 옵션 하나 = 자막 구절 하나 = 장면 하나. 칩은 그 구절 시작 +0.1초에 뜬다. 네덜란드판이 장면을 2.5초로 줄일 때도 옵션 장면은 줄이지 않는다(렌더러 `plan_shots`).
- 네덜란드판: 옵션이 2개 이상이면 ✓ 목록 — 말할 때마다 한 줄씩 늘고(왼쪽 정렬, 최대 3줄) 블록 끝에 한꺼번에 사라진다. 벨기에판: 한 개씩, 최소 1.8초.
- 칩 높이는 부위별(`part_band`): 위 480 · 가운데 820 · 아래 1420(1920 기준). 아래 칩이 떠 있는 동안은 말 자막을 숨긴다.

## 2-1. 일레븐랩스 AI 티 벗기기 (2026-11-09 사용자 지시)

규칙 `voice`(auto_edit_rules.json). 근거: 일레븐랩스 v4 공식 안내 + 원본 NL·BE 말투.

| 항목 | 이전 | 지금 | 이유 |
|---|---|---|---|
| 숫자 | 한글로 풀어 씀(천사백팔십, 사점영 브이에잇) | 글로 쓴 그대로(1,480킬로, 4.0 V8, 510마력) | v4는 숫자를 그대로 줘야 사람처럼 읽는다. 풀어 쓰면 또박또박 낭독 |
| 끝말 | -예요 · -어요 반복 | 문장마다 다르게(-예요 / -거든요 / -고요 / -어요 / -이에요 / -보세요) | 같은 끝말 반복이 합성 티의 큰 원인 |
| 나열 | 「23년 6월 등록, 1억 7,390만 원.」 | 「23년 6월에 등록됐고, 가격은 1억 7,390만 원이에요.」 | 표 읽듯 끊기지 않게 |
| 감정 태그 | 없음 | 분위기가 바뀌는 곳만: 첫 화면·끝 [warmly], 옵션 [excited]. 웃음·감탄 태그는 안 씀 | 과장하면 오히려 AI 티 |
| 안정도 | 0.5(기본) | 0.35 · 유사도 0.85 | 문장마다 억양이 같으면 낭독처럼 들림 |
| 후처리 | 없음 | 70Hz 아래 자르기 · 치찰음 살짝 · 부드러운 압축 · −16 LUFS · 아주 작은 방 소리(약 −55dB) | 말 사이 완전 무음 = 합성 티. 속도·높이는 안 바꿈 |

- 키로 자동 생성: `auto/eleven_tts.py`(서버 환경 변수 `ELEVENLABS_API_KEY`, 글자별 시각을 함께 받아 받아쓰기가 필요 없음).
- 칩 예산: 칩 수는 원본 위 끝(NL 14 · BE 10개/분) 안으로. 지우는 순서 앱 → 기타 → 등록연월 → 마력 → km → 가격, 옵션 칩은 맨 마지막(`chip_priority`).
- 장면 최소 길이: 원본 중간값 아래(NL 2.2 · BE 1.6초)로는 자르지 않고 앞 장면을 이어 쓴다. 옵션 구절은 예외.

## 2-3. 2차 조사 (2026-11-09, 새 100편 → 합계 200편)

- 새 100편(NL 50 · BE 50, 말하는 영상 NL 44 · BE 38)을 노트북에서 받아 받아쓰기·측정. 1차 100편도 고친 칩 해석으로 다시 재서 합쳤다(말하는 영상 159편). 두 조사 방향은 일치(`auto/learned_200_summary.json`의 l1·l2·all).
- 화면 대조로 찾은 것: NL 칩은 위쪽 굵은 노랑 차명·숫자 32% + **말 자막 자리 큰 노랑 글자(✓ 기능 칩·숫자, 그동안 자막 없음) 66%**(위·가운데·아래 칩 높이 32·37·32%). NL 자막 높이는 영상마다 46~61%.

## 3. 밴티지 시험 결과 (2026-11-09)

- 음성 2개(NL 21초 · BE 16초) 일레븐랩스로 생성, 낱말 시각은 faster-whisper(small).
- 첫 렌더에서 고친 것: ① ✓ 목록이 말 자막(62%)에 붙음 → 가운데 높이 1000 → 820. ② 네덜란드판 장면 줄이기 때문에 「브라운 톤 실내」 칩이 바퀴 화면에 뜸 → 옵션 장면은 줄이지 않게. ③ 「노란 캘리퍼」가 휠 근접(캘리퍼 안 보임) 구간에 뜸 → 장면 목록을 캘리퍼가 보이는 구간으로 나눔. ④ 다 쓴 장면을 같은 구간으로 두 번 쓰는 문제 → 다 쓴 장면은 거의 마지막 수단.
- 재교정 표: `calib.json`(아래 4장 수치 참고).

## 4. 아직 남은 것

- 장면 부위 자동 표시(shot_tagger): 지금 시험 장면 목록은 사람이 사진을 보고 붙였다. 노트북에서 CLIP으로 자동 표시를 만들 차례.
- 일레븐랩스 자동 호출: 서버 환경 변수 `ELEVENLABS_API_KEY`를 사용자가 직접 넣어야 한다(키는 채팅으로 받지 않는다). 지금은 연결 도구로 만든 음성을 내려받아 쓴다.
- 벨기에판 나눔 화면 전환 · 네덜란드판 타자 효과는 아직 없다.
- 옵션 칩 수(최대 NL 4 · BE 3)와 hold 시간은 초기값. 원본 옵션 칩 전수(칩 자리 · 말한 시각 대비)를 더 재서 고친다.
