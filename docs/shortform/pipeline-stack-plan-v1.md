# 숏폼 자동 제작 파이프라인 — 오픈소스 스택 최종 정리와 작업 계획 v1

- 작성: 시안 마스터(Claude Opus 5.5) · 2026-11-25
- 근거: 노션 「새로 도입하는 최신 스킬 도구들」 전체(벨기에 세션 · 코덱스 마스터 v1.0 · 코덱스 교차검증 · bobae_auto · 클로드코드 · 시안 마스터 · 총괄 v1.0 · 최종 지시 v2 · Gemini 9장 · 13-1/13-2 · 빈 곳 해결 방안 · 클로드코드 1·2·3 시험 · 총괄 최종 지시 컨설팅), 「최종 컨설팅 전달문서」, 30건 부하 시험 실측
- 목표 세 가지: ① 사람 손이 가장 덜 가는 자동화 ② 나세르식 편집(부위 추적 그래픽 · 3D 글자 · 차 뒤 제목) ③ 대량 제작(하루 수백~천 편)

## 0. 결론

1. 새 도구 조사는 멈춘다. 본체는 **Python + FFmpeg**, 그래픽만 **HyperFrames**, 서버는 **Laravel 12 큐 + Python 워커**로 확정한다.
2. 사람 손을 빼는 가장 큰 지렛대는 모델이 아니라 **입력**이다: 촬영키트가 컷마다 부위(shot_id)를 붙여 보내면 부위 판정 · 구간 고르기 · 위치 찾기가 거의 필요 없어진다.
3. 새로 들어갈 유일한 큰 부품은 **SAM 3.1(Meta Model API)** 이다. 글자로 엠블럼 · 부위를 찾고 영상 추적까지 한 번에 해서, 지금 사람이 찍는 엠블럼 좌표와 OWLv2+SigLIP 재확인 · VitTrack/CSRT 추적 · TAPNext++ 대기를 한꺼번에 대신할 수 있다. 가중치 3.5GB·GPU·허깅페이스 승인 문제도 API라서 사라진다(프레임 과금).
4. 지금 가장 급한 것은 도구가 아니라 **점검의 구멍**이다. 30건 부하 시험은 속도·실패율은 통과했지만, 30편 모두 「말하는데 자막 없음」 2곳이 있었다(점검이 경고만 해서 통과로 셈). 총괄 기준 「품질 검사 통과 97%」로 보면 0%다.

## C. 3D 이미지 간소화

원칙: 3D는 미리 만든 재사용 자산만. 매물마다 만들지 않는다.

| 자산 | 만드는 법 | 쓰는 곳 |
|---|---|---|
| 옵션 아이콘 | Fluent 3D(MIT) → 3dicons(CC0) → 없으면 Blender | 옵션 칩 |
| 숫자·단위 3D 글자 | 0~9·쉼표·점·단위 스프라이트 한 번 렌더 → 이어 붙이기 | 큰 숫자(T04) |
| 카테고리·칩 아이콘 | Blender 템플릿 1개 + `blender --background --python` 일괄 렌더(SVG → 돌출 투명 PNG 3각도) | 앱·영상 공용 |
| 브랜드 엠블럼 | 만들지 않음 — 실제 장면 + SAM 3.1 추적 | 첫 화면·휠 |

자산 창고 `asset_registry.json`(id·출처·라이선스·해시·판), 같은 해시는 다시 렌더 안 함. 통과: 30종 일괄 30분 이내, 영상당 3D 추가 시간 2초 이하.
