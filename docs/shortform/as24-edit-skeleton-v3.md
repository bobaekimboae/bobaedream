# 오토스카우트24 네덜란드·벨기에 편집 뼈대 교본 v3 (2026-11-09)

칩·칠·큰 숫자·효과음을 어디에, 언제, 어떤 모양으로 넣는지 정리한 교본이다. 편집자가 하는 판단을 그대로 다시 할 수 있게 경우를 나눠 적었다. 자막(말 자막·노랑 따라가기) 규칙은 `as24-caption-rules-v2.md`를 따른다.

## 0. 근거와 한계
- 원본: 유튜브 쇼츠 네덜란드 200편, 벨기에 198편(2편 다운로드 실패). 드라이브 `SNS레퍼런스_원본영상/오토_네덜란드`·`/오토_벨기에`에 있고, 링크는 「SNS 레퍼런스」 시트 O열에 있다. 분석용으로만 보고, 원본 영상·음악·목소리는 다시 쓰지 않는다.
- 방법:
  1. 컴퓨터로 영상을 초당 10장씩 보며 노랑 덩어리(칩·띠·숫자·로고)를 따라갔다. 네덜란드 4,274개, 벨기에 2,613개를 기록했다.
  2. 덩어리마다 나타난 시각, 위치, 크기, 기울기, 그 순간 소리의 고음역이 무작위 시점보다 얼마나 튀는지(dB)를 쟀다.
  3. 그중 440개(나라당 220개, 종류별 고르게)를 사람 눈으로 판정했다. 판정 내용은 종류, 글자, 그 순간 보이는 차 부위, 부위와의 관계, 모양, 등장 방식이다.
- 오탐: 판정한 440개 중 약 27%는 편집물이 아니었다. 네덜란드는 노랑 번호판, 벨기에는 노랑 차·의자·간판이 주된 원인이다. 아래 숫자는 오탐을 뺀 것이다(네덜란드 158개, 벨기에 159개).
- 말과의 시간차는 받아쓰기가 있는 영상만 쟀다(153편). 벨기에 띠 스티커는 5건뿐이라 참고값이다.
- 효과음은 2026-11-09 전수조사에서 스펙트로그램을 눈으로 다시 판정했다(`as24-sfx-rules-v1.md`). 처음의 「소리 크기가 튀었다」 자동 측정은 끝 로고에서 크게 틀렸으므로 쓰지 않는다.

## 3. 어느 부위에서 어디에 놓나 (판정 표본에서 실제 나온 짝)

| 화면에 보이는 부위 | 칩 내용 예 | 놓는 자리 |
|---|---|---|
| 시트 | NL `✓ LUXE STOELEN`, `✓ STUURVERWARMING / ✓ STOELVERWARMING` · BE `Elektrisch verstelbare zetels`, `✓ koperen accenten` | 시트 옆 빈 곳, 화면 아래쪽(53~72%) |
| 스피커 | BE `Bose surround soundsystem`, `Burmester soundsystem` | 스피커 옆, 아래 띠(72~74%) |

| 핸들 | NL `✓ BLUETOOTH` · BE `HEAD UP DISPLAY`, `RIJDMODUSSEN / ECO / NORMAAL` | 핸들 위나 아래 빈 곳 |
| 기어 | BE `automaat`, `zesversnellingsbak`, `DSG AUTOMAAT`, `REVERSE NEUTRAL DRIVE`(계단식) | 기어 옆, 위쪽(21~23%) 또는 가운데 아래 |
| 트렁크 | NL `ELEKTRISCH UITKLAPBARE TREKHAAK` · BE `✅ 500L koffer`, `VLAKKE LAADVLOER` | 트렁크 위 빈 곳 또는 아래(70~76%) |

| 헤드램프 | BE `Vierkante lampjes` | 램프 아래(61%) |
| 그릴 | BE `Carbon` | 그릴 옆(42%) |
| 뒷모습 | NL `DAKSPOILER`, `DIE KOPERKLEURIGE ACCENTEN` | 이름은 위쪽(24~38%), ✓ 옵션·숫자는 가운데(50~59%) |
| 사이드미러 | BE `dodehoekdetectie` | 미러 위 빈 하늘·벽(23%) |
| 앞모습·3/4 전체 | 차 이름·가격·연식·km·마력 | 위 가운데(17~36%), 차 위 빈 곳. ✓ 옵션은 가운데(45~59%, 9개 중 7개) |
| 사람이 말하는 장면 | 변속기·연료·마력 | 가운데(50~59%) 또는 위(18~32%) |

자리 정하는 법(두 나라 공통):
1. **부위를 가리지 않는다.** 칩이 부위 위에 겹친 경우는 NL 11/70, BE 3/41뿐이고, 모두 넓은 면(보닛·시트 등받이) 위였다.
2. 부위가 화면 아래쪽에 있으면 칩은 위쪽 띠, 부위가 위쪽이면 아래쪽 띠에 둔다. 가운데 정렬이다.
3. 전체 차가 보이는 장면의 숫자는 차 지붕 위 빈 하늘·벽(위 가운데)에 둔다.
4. 아래 20%는 비운다(앱 버튼 자리).
5. "칠"(부위 위를 노랑으로 칠하거나 화살표·동그라미로 가리키기)은 거의 쓰지 않는다. 440개 중 1건(BE, 시트를 가리키는 노랑 화살표)뿐이다. 벨기에의 "칠"은 부위가 아니라 **띠 바탕을 칠하는 동작**이다(빈 띠가 먼저 칠해지고 글자가 나중에 뜸).

자리 규칙을 원본에 되돌려 맞혀 보니(2026-11-09) NL 이름표 70개 중 52개(74%), BE 띠 41개 중 23개(56%)가 맞았다. BE는 아래 띠를 더 많이 쓴다.

## 4. 시간 규칙
- 칩은 그 정보를 말하는 낱말과 **거의 같은 순간(±0.2초 안)**에 뜬다. 처음 측정은 NL 이름표 0.06초 먼저(가운데 절반 −0.40~+0.16초), NL 큰 숫자 0.22초 먼저, BE 띠 0.16초 먼저였다. 2026-11-09 전수조사에서 낱말 맞추는 방법을 바꿔 다시 재니 NL 이름표 +0.10초(25건, 가운데 절반 −0.06~+0.24), NL 큰 숫자 +0.13초(6건), BE 띠 +0.41초(4건)로 앞뒤가 바뀌었다. 표본이 작고 방법에 따라 흔들리므로 「먼저/나중」은 정하지 않는다. 우리 렌더러는 말 구절 시작 +0.1초에 칩을 띄운다(이 범위 안).
- 머무는 시간: NL 이름표 1.3초, NL 큰 숫자 1.3초, BE 띠 1.8초, BE 제목 1.6초, 끝 로고 1.3~1.6초.
- 큰 숫자가 떠 있는 동안 말 자막은 숨긴다. 이름표가 말 자막 자리에 대신 뜨기도 한다(NL).
- 같은 자리에 칩이 이어질 때는 장면이 바뀌어도 띠는 그대로 두고 글자만 바꾼다(BE `zetelverwarming → automaat`).
- 장점 목록은 말할 때마다 한 줄씩 늘어나고, 그 장면이 끝나면 한꺼번에 사라진다.
- 컷이 바뀌면 칩은 다음 장면으로 넘어가지 않는다. 예외는 같은 자리 글자 바꾸기다.

## 7. 보배드림에 옮기는 법
고정 기준(2026-11-08 결정)은 바꾸지 않는다.
- 키워드 칩은 파랑 `#306BD9` + 흰 글자이고, 노랑 `#EEEF05`는 말 자막 낱말 따라가기 전용이다.

나머지는 위 규칙을 그대로 쓴다.
- 자리·시간·목록 쌓기·부위 옆 배치·효과음 맞춤은 네덜란드형을 따른다. 효과음은 핵심 칩·큰 숫자의 약 40%에만 넣는다.
- 띠 모양(약 3° 기울임, 빈 띠가 먼저 칠해지고 글자가 나중에 뜨는 등장)은 벨기에형을 파랑 띠로 옮긴 「BE형 변형」으로 둔다. 기본으로 쓸지는 사용자가 정한다.
- 표기: `4.3만km`, `2,890만원`, `250마력`, 연식은 숫자 4자리 `2021`(월을 알면 `21년03월`, 목록 카드 표기와 같게). 체크는 `✓`.
- 기계로 읽는 규칙은 `scripts/shortform/as24_edit_rules.json`, 편집 계획을 만드는 코드는 `scripts/shortform/as24_edit_planner.py`에 있다.
