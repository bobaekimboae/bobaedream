# AS24 네덜란드·벨기에 편집 완전 구현 매뉴얼 v4 (2026-11-09, 100+100편 재조사)

- 범위: 오토스카우트24 네덜란드(NL) 100편 + 벨기에(BE) 100편. 이전에 사람이 본 50+50편(`as24-caption-rules-v2.md`)에 새로 고른 50+50편(무작위, seed 1109)을 더했다.
- 분석 전용이다. 원본 영상·음악·목소리·효과음은 쓰지 않는다. 보배드림은 자체 효과음 팩만 쓴다.
- 이 문서가 NL·BE 편집의 최신 기준이다. 앞선 문서(`as24-sfx-rules-v1.md`, `as24-caption-rules-v2.md`, `as24-edit-skeleton-v3.md`)와 다른 곳은 이 문서를 따른다(§7 바로잡은 것).

## 2. 효과음 — 어디에 넣나 (순간별 비율, 오판정 보정값)
| 순간 | NL | BE |
|---|---|---|
| 칩·이름표가 뜰 때 | **약 43%** | 약 23% |
| 큰 숫자가 뜰 때 | **약 45%** | 약 15% |
| 첫 화면(0초 제목) | **약 46%** | 약 13% |
| 컷 | 약 12% | 약 6% |
| 끝 로고 | 약 11% | 약 9% |
| 말 따라가기 노랑 낱말 | 기준선 수준(따로 안 넣음) | 기준선 수준 |
| 아무 시각(대조) | 약 3% | 약 3% |

- 시작 시각: 효과음은 칩이 **처음 보이는 바로 그 순간** 시작한다(추적기 기준 중간값 +0.05초, 가운데 절반 −0.03~+0.13초. 추적기가 0.1초 단위라 「같은 순간 ±0.1초」로 본다).
- 영상마다 차이가 크다: NL 영상별 칩 효과음 비율은 10%(하위) ~ 65%(상위), 중간 35%(보정 전).
- 음악과의 관계: BE에서 음악 없는 29편은 영상당 3번, 음악 있는 71편은 1번. NL에서 음악 있는 6편도 1번. → **음악을 깔면 효과음을 줄인다**는 규칙이 두 나라 모두 맞다.
- 칩 추적기가 못 잡는 순간의 효과음: 소리만으로 영상 전체를 훑었을 때 칩·컷과 떨어진 곳의 후보는 사람 확인에서 NL 4/20, BE 2/20만 진짜였다. 효과음은 거의 다 **화면 편집물에 붙는다**.

## 7. 바로잡은 것 (앞선 문서와 다른 곳)
1. **벨기에 말 자막은 한 가지가 아니다.** v2는 「보통 글씨 + 그림자」만 적었지만, 새 50편 중 21편은 NL과 같은 「대문자 + 테두리」였다. 우리 벨기에판은 그림자형을 쓴다(벨기에다운 쪽).
2. **NL 첫 화면에도 효과음이 있다**(약 46%). 이전 규칙 「첫 화면에는 넣지 않는다」를 네덜란드판만 바꿨다.
3. **효과음 간격**은 실제로 짧아도 약 1초다. 최소 0.6초 → 1.0초.
4. **BE 칩 기울기는 늘 반시계**다. 이전 시안은 좌우를 번갈아 기울였다.
5. **BE도 숫자 칩이 떠 있으면 말 자막을 숨긴다**(9편).
6. **자막 높이**: NL 65% → 62%, BE 67% → 64%(100편 중간값 기준).
7. NL 칩 효과음 비율은 39%(소표본) → 약 43%(100편, 보정값). 「약 40%」 규칙은 그대로 맞다.
8. BE 띠 효과음 22% → 약 23%, 음악 없는 BE는 영상당 3번으로 NL에 가깝다.

## 8. 아직 못 본 것
- 넘김 효과(나눔 화면 등)와 등장 움직임은 정지 화면 16장으로 본 것이라 일부만 잡혔다. 보배드림 벨기에판에는 아직 나눔 화면을 넣지 않았다.
- 효과음 세기는 상대값(NL보다 BE가 약 5dB 작음)만 쟀다. 절대 크기는 우리 −6dB를 유지한다.
- 칩 종류 자동 분류(67%)가 약해 종류별 효과음 비율은 확률 가중 추정이다(±5%p 안팎으로 봄).
- 다시 돌리는 법(노트북): `sfxscore.py`(소리 수치) → 작업 폴더 `rs/run200.py`(순간별 판정) → `scan.py`(전체 훑기). 판정기 학습 자료는 `labels.json`(사람 판정 621곳).

### 9-2. 옵션·기능 ↔ 컷 맞추기
1. 옵션 칩은 **그 부위가 보이는 컷 위에서만** 뜬다(옵션표의 `parts`와 컷 라벨 `part`가 같아야 함).
2. 그 부위 컷이 영상에 없으면 칩도 대사도 넣지 않는다(화면에 안 보이는 옵션은 말하지 않음). 실내 화면 기능(내비·통풍 등)만 계기판·화면·핸들 컷으로 대신할 수 있다.
3. 한 부위 컷은 한 옵션에만 쓴다. 겹치면 다음 순위 부위로 넘기고, 남는 부위가 없으면 그 옵션은 뺀다.
4. 옵션은 매물 옵션표에 있는 것만 쓴다. 지어내지 않는다.
5. 코드: `scripts/shortform/auto/auto_edit.py`(옵션 고르기 · 부위 배정), `sag_reel_v1.py` `chip_kind`(칩 종류).
