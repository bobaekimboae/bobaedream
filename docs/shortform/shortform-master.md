# 보배드림 매물 숏폼 자동 제작 마스터 (편집 규격 · 플러그인 · 도구)

이 문서 하나가 숏폼 자동 제작의 기준이다. 편집 규격(자막 위치 · 칠 · 효과음 · 스티커 …)과 파이프라인 부품(플러그인), 쓰는 도구를 버전별로 기록한다.
값을 바꾸면 아래 「버전 기록」에 한 줄을 더하고, 근거 자료(분석 결과 · 측정)를 함께 적는다.

- 기준 편집: 오토스카우트24 네덜란드 · 벨기에 · 독일 쇼츠. **항상 같은 규격, 과하지 않음, 세련됨**을 우리 숏폼에 옮긴다.
- 대상: 서울오토갤러리 등 딜러 매물 → 자체 자동 제작 영상(인스타 릴스 · 유튜브 쇼츠 · 틱톡)
- 근거: `docs/shortform/as24-edit-manual-v1.md`(NL·BE 197편 분석) · `docs/shortform/as24-stats-v1.json`

## 2. 플러그인 구조

캡컷의 「편집 → 저장 → 업로드」를 우리 라이브러리로 나눠 가진다. 부품마다 입력 · 출력(JSON)이 정해져 있어 도구를 갈아 끼워도 나머지는 그대로 돈다.

```
매물 정보 + 딜러 영상/사진
  → P01 매물 사실 → P02 촬영 영상 분석(컷 시간표) → P03 대본 → P04 음성(TTS) → P05 낱말 시각
  → P06 컷 고르기 → P07 옵션 인식 → P08 자막 · 칠 → P09 스티커 · 3D 아이콘 → P10 중간 애니메이션
  → P11 효과음 → P12 배경음악 → P13 합치기 · 음량 · mp4 → P14 품질 검사 → P15 업로드
```

규격 파일(`spec.json`, 이 문서의 1장 값)을 모든 부품이 읽는다 → 같은 품질. 서비스에서는 Laravel 작업 대기열이 영상 서버(파이썬 · FFmpeg 컨테이너)를 여러 대 띄워 나눠 돌린다 → 하루 수천 대.
