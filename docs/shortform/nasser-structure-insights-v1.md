- 근거: 유튜브 @NasserHessien7 쇼츠 제미나이 분석 **181편**(analysis/refs `reports/shortform/as24-reviewer-nasser`) + 대사 SRT 181편(원문·한국어 각 1벌, 같은 폴더 `*.orig.srt` `*.ko.srt`)
- 300편: 채널 쇼츠 340편 목록은 받아 둠(`scripts/shortform/as24-jobs/reviewer-nasser300.txt`). 말투(speech_style)·대사 비트(script_beats)·SRT를 더한 재분석은 **제미나이 선불 크레딧 소진(HTTP 402)으로 멈춤** — 충전 뒤 액션을 다시 돌리면 300편으로 이 문서를 갱신한다(`python3 scripts/shortform/nasser_insights.py <폴더> <출력.md>`).

## 핵심 10가지 (우리 자동 편집에 옮길 것)

1. **길이·컷**: 길이 중앙값 64초(짧은 쪽 47초 · 긴 쪽 84초), 컷 20개 · 컷 길이 3.0초, 전환 97%가 바로 컷. → 60초 판 컷 길이 기준 3초, 전환 효과 없음.
2. **구성 뼈대**: 훅(6%) → 차 소개(14%) → 기능(23%) ⇄ 사양(17%) → 끝 화면(9%). 가격은 31%만, 나올 때는 영상 절반 지점(중앙 47%)에서 처음 말한다. → 우리 기본 틀 `훅 → 차 소개 → 기능·사양 번갈아 → 가격 → 끝`과 같다.
3. **훅 종류**: 행동 34% · 질문 22% · 가격 14% · 감탄 13% · 희귀차 10% · 숫자 6%. 첫 말 절반(52%)이 「저는 나사르입니다」로 자기 이름부터. → 매물 영상은 딜러 이름 훅(「○○모터스 김태규입니다」)을 기본 후보로, 「~를 원하신다면」 질문형을 두 번째로.
4. **첫 장면**: 외관 전면 62% · 사람 22%. 부위 출현은 외관 전면 91 → 실내 앞 78 → 뒷좌석 70 → 측면 61 → 센터 화면 56 → 휠 51 → 트렁크 47 → 후면 46 → 계기판 44 → 엔진룸 30%. → 촬영키트 순서 그대로 쓸 수 있음(엔진룸은 선택).
5. **옵션 보여주기**: 영상당 6개, 한 옵션 2.3초. 실제 작동 시연 49% · 글자 카드 18% · 2D 아이콘 15% · 3D 아이콘 11%. → 옵션은 「작동하는 장면 + 짧은 글자 칩」이 기본, 3D 아이콘은 1~2개만(마스터 v1.4와 같음).
6. **옵션 + 효과음**: 옵션 등장에 톡 29% · 딸깍 16% · 띵 13% · 휙 10%. 영상 전체 효과음 13개(톡 32 · 휙 16 · 쿵 15 · 띵 14 · 딸깍 11%), 실제 차 소리 7%.
7. **대사 리듬(SRT)**: 영상당 대사 12줄, 한 줄 4.2초, 줄 사이 쉼 0초(쉬지 않고 이어 말함), 한국어로 옮기면 초당 약 7.8자. 숫자가 든 줄 44%, 질문 줄 4%. → TTS 대본 한 줄 = 한 컷(약 4초), 숫자를 절반쯤 넣는다.
8. **말 끝**: 「~습니다/입니다/합니다」가 압도적, 사이사이 「~있죠」「~보세요」. → 이미 정한 합니다체 + 「~죠」 섞기(`make_script_nasser`)와 일치.
9. **자막**: 키워드 스티커 79% · 말 자막 9% · 가격 7%. 높이 6%, 세로 35% 지점(화면 위쪽). 외곽선 47% · 바탕 없음 29% · 상자 19%. → 말 자막을 다 깔지 않고 핵심어 스티커 위주. 우리는 AS24식 말 자막 + 칩을 유지하되 칩이 주인공.
10. **음악·끝**: 힙합 비트 BPM 115, 말 밑으로 줄임 96%. 마지막 말은 매장 위치·방문 37% · 감탄 10% · 구독 7% · 전화 4%. → 끝 화면 = 상사·단지 위치 + 안심번호.
