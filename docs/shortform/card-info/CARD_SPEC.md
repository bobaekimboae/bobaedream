## 결과와 적용 범위

차란차 G400d 매물 표시를 직접 확인하고 같은 입력 JSON으로 **스택형·가로 전환형** 두 가지를 제작했다. 각 시안은 7장, 1080×1920, 30fps다. 각 49.9초 음성 상세본과 21초 무음 요약본을 구분한다. 상세본은 각 카드의 음성 설명을 다 읽는 훈련용이며, 12~20초 홍보용 완성본으로 평가하지 않는다. 21초본은 카드당 3초의 가독성 비교용이다.

7장 순서: 판매가 → 차량 정보 → 특수 사고 보험기록 → 피해·소유 이력 → 성능점검 요약 → 표시 옵션 → 보증 상태. 카드마다 독립 MP4도 추출한다.

원문 요청 7종 가운데 차량·성능·보험·옵션은 구현했고, 추가 선택옵션은 근거가 없어 생략했다. 차량 특징은 제원 반복, 판매자 설명은 제원 반복 문구여서 독립 카드를 생략했다. 새 유형은 아래 규칙 JSON에 18종으로 기록했다. 가격·소유·보증은 별도 카드 또는 보험 카드로 추가했다.

이번 렌더러는 Python/FFmpeg로 만드는 미디어 제작용 도구다. 서비스 프런트엔드나 API를 추가하지 않았다. 타사 페이지 수집과 TTS 요청은 이번 회차에 직접 수행했으며, URL을 넣으면 끝까지 실행하는 운영 자동화는 아직 아니다. 자동화된 부분은 확인된 JSON → 카드 구성 → 영상·독립컷·검증 보고서다.

## 제작 규격

- 좌측 80px, 위 220px부터 내용. 우측 136px 여백, 하단 380px 이상은 핵심 내용에서 제외한다. 실제 SNS UI별 안전 영역은 게시 전에 추가 실기기 검수한다.
- 제목 42px, 핵심 수치 80~118px, 값 41px, 본문 자막 40px. 작은 출처 문구는 26px이며 핵심 판단 정보로 사용하지 않는다.
- 카드당 행 3개 이하, 자막은 문장·의미 단위 2줄 이하. 낱말을 조금씩 교체하는 자막은 사용하지 않는다.
- 스택형은 어두운 바탕 위 흰 카드와 뒷장 2개. 전환형은 밝은 바탕 위 카드가 가로로 이동한다. 판정 색은 확인 필요만 갈색으로 표시하며 ‘좋음/우수’ 점수를 만들지 않는다.
- 0.35초 진입, 0.12초 행 간격. 두 시안의 데이터·음성·자막 구간은 같다.
- KKC HQ, eleven_multilingual_v2, 단일 TTS 1회 생성. 같은 건조 음성 파일을 두 시안에서 재사용한다. 음성에 효과음·BGM은 섞지 않았다.
- 측정된 발화 시각에 250ms 믹스 지연을 더해 자막을 표시한다. 프레임 양자화 오차는 최대 1프레임(33.3ms); 단어 시각은 STT 추정값으로 청취 검수를 대신하지 않는다.

## 파일과 재현

`scripts/shortform/card_info/cards_input.json`: 확인된 값·출처 범위·제외 사유.

`card_rules.json`: 팔레트·화면·모션·누락 규칙·18개 카드 유형. `render_cards.py`: 결정적 렌더러. `timing.json`: 카드/문장 시각. `narration_words.json`: STT 발화 시각. `check_cards.py`: 데이터 오류 회귀 검사.

설치: Python 3, Pillow 13, FFmpeg/FFprobe, Node.js. Noto Sans CJK의 파일 경로는 `card_rules.json`에서 수정한다. 기존 저장소에는 오디오 라이브러리와 검사기가 이미 있다.

```bash
python -m pip install Pillow==13.0.0
python scripts/shortform/card_info/check_cards.py
# 21초 무음 시안 2개 + 독립컷
python scripts/shortform/card_info/render_cards.py
# 배포받은 output/narration_dry.mp3를 한 번만 사용
node scripts/shortform/card_info/prepare_narration.mjs
python scripts/shortform/card_info/render_cards.py --narrated
node scripts/check-shortform-audio.mjs --manifest media-contracts/card-info-samples-audio.json --report output/audio_review.json
```

다른 차량 입력은 `--input /absolute/path/verified.json`으로 지정한다. 확인된 기본 차량 필드가 없으면 중단하며, 보험·성능·옵션·보증 카드는 해당 필드가 없으면 생략한다. 차량 변경 시 음성·자막·출처를 다시 만들고 입력값과 발화 대조를 완료해야 한다. 이번 timing.json과 음성을 다른 차량에 그대로 재사용하지 않는다. 18종 전체의 렌더러를 구현한 것은 아니다.

## 검증과 평가

자동 데이터 검사 7건: 비활성 옵션 제외 / 무사고 추론 방지 / 미확인≠0 / 양수 보험 사고 횟수 보존 / 누락 카드 생략 / 0원 가격 거부 / 가격 자막의 입력값 추종. 카드 값과 텍스트 경계는 렌더 중 검사한다.

두 음성본은 저장소 `shortform-audio.mjs`로 믹스하고 `check-shortform-audio.mjs`로 참조 음성과 채널별 지연·상관관계를 검사한다. 1ms 이하 좌우 시차를 통과해야 한다. 전체본 검사와 독립컷 분할을 구분한다. 독립 청취 검수는 수행하지 않았으며 음성 자연스러움·발음에 대해 최종 승인했다고 보고하지 않는다. 영상 프레임을 추출해 카드·자막 줄바꿈·값 위치를 확인한다. LUFS 목표는 -14이며 AAC 최종 파일의 실측값은 평가서에 기록한다.

| 시안 | 강점 | 다음 개선 |
|---|---|---|
| 스택형 | 배경 대비가 강해 수치와 확인 필요 정보가 잘 분리됨 | 뒷장 움직임·행 등장에 의미 부여, 실사진과 교차 편집 |
| 전환형 | 밝고 정리된 문서형 정보 전달 | 카드 간 이동 거리를 줄여 숫자 추적 부담 완화 |
| 공통 | 같은 JSON·음성으로 비교 가능, 오류 유형을 코드로 검증 | 49.9초 상세본은 길다. 핵심 4장 18~22초 유성본을 다음 제작 목표로 제안 |

## 추가 콘텐츠 아이디어

18종 전체 정의는 card_rules.json과 시트에 동일하게 기록한다. 우선 개발 후보는 **성능점검 부위 지도**, **증빙 있는 최근 정비**, **보증·리콜 확인**, **실측 적재량**, **주차장 치수 비교**다. 딜러에게 유리한 정보만 나열하는 대신 구매 전 확인할 항목을 함께 보여주는 것이 차별점이다.

시세 순위는 동일 연식·트림·주행·사고 조건, 표본수, 조회일이 있을 때만 계산한다. 월 유지비는 월주행·유가·공인연비 가정을 먼저 공개한다. 사진·영상에서 옵션을 추정한 값은 원문 표시값과 다른 필드에 두고, 영상 확정 문구에 자동 합치지 않는다. 영화 장면·공식 신차 가격표·연비는 필요한 원본과 사용 범위가 확보된 뒤 별도 샘플로 제작한다.

## 기존 문서와 공존

v1 문서와 다른 에이전트의 시안은 덮어쓰지 않는다. 기존 `46_규칙_카드컷루틴`은 유지하고 새 `47_카드정보_v2`에 유형·입력·누락·자막·검수·산출물을 추가한다. 저장소에는 별도 브랜치/초안 PR로 기록하고 기존 서비스 배포·병합은 하지 않는다. 상위 노션 작업은 다른 시안·확장 기법이 남아 있으므로 진행 중을 유지한다.
