# 카드 정보 기법 v2 — 정본 매뉴얼

## 1. 목적
엔카는 성능점검·보험이력·옵션을 탭마다 눌러 본다. 보배드림은 15~30초 독립 컷 한 편에서 카드가 한 장씩 올라오며 요약한다. 어떤 에이전트가 만들어도 같은 결과가 나오도록 값은 파일 한 곳에만 둔다.

## 2. 파일 (단일 기준)
| 파일 | 역할 |
| --- | --- |
| `scripts/shortform/card_info/card_rules.json` | 카드 틀·줄·강조·시간·순서·유형·금지 낱말 값 (이 파일만 고친다) |
| `scripts/shortform/be_locked_rules.json` | 노랑·칩 자리·자막 자리·효과음·음량 (카드도 이 값을 그대로 따른다) |
| `scripts/shortform/card_info/samples/g400d_cards_input.json` | 샘플 입력 (차란차 G400d, 확인된 값만) |
| `scripts/shortform/card_info/render_card_stills.py` | 기준 정지 화면 렌더러 (시안 1·2 대조용) |

실행: `python3 scripts/shortform/card_info/render_card_stills.py <입력.json> <출력폴더> [배경사진]`
- 값 없는 줄은 빼고, 줄이 2개 미만이면 카드를 뺀다. 금지 낱말이 있으면 멈춘다. 카드가 자막 자리(1180px 아래)를 침범하면 멈춘다.

## 4. 카드 유형 (card_rules.json `types`)
차량 정보 · 가격 · 성능 점검 · 보험 이력 · 옵션(격자) · 추가 옵션 · 차량 특징 · 판매자 설명 · 보증 · 한 장 요약. 각 유형의 줄 이름·근거 칸·강조 줄은 json에 있다. 새 유형은 json `types`와 `order`에 추가만 하면 된다.

## 5. 움직임 (영상 단계, 시안 1·2)
- 카드 아래→위 0.35초(easeOutBack), 줄은 0.25초 간격 페이드, 숫자 카운트업 0.8초, 퇴장 위로 0.25초.
- 효과음: 카드 들어올 때 whoosh, 노랑 숫자 ding (카드당 최대 2개, 간격은 be_locked).
- 내레이션: 카드당 한 문장, 핵심 값 1~2개만. 자막 강조는 말한 숫자만 노랑. ElevenLabs KKC HQ 1회 생성.
- 시안 1 = 스택형(앞 카드 위로 겹쳐 쌓임), 시안 2 = 전환형(가득 채우며 좌→우). 둘 다 이 json·같은 입력으로 만들고, 마지막 프레임이 `render_card_stills.py` 결과와 같아야 한다.

## 6. 검수 (전달 전 모두 통과)
1. 카드 글자 = 입력 json 값 (100%)
2. 금지 낱말 0 · 차량번호·연락처 0
3. 카드당 줄 4 이하, 카드 아래 끝 ≤ 1180px
4. 노랑 외 강조색 0 (`check_be.py` 화면 실측)
5. 음량 −14 LUFS ±1, 피크 −1.5 dBTP 이하
6. 다른 에이전트가 같은 json으로 같은 정지 화면을 뽑는가
