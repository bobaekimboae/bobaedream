# 퀵필터 이미지 검수표 v01

## 자동 검수

- [ ] 파일이 매니페스트 경로에 존재한다.
- [ ] 파일명이 영문 소문자·숫자·밑줄·버전 규칙을 따른다.
- [ ] 캔버스가 512×320 RGBA다.
- [ ] 네 모서리가 완전 투명하다.
- [ ] 알파 12 이상인 가시 픽셀이 존재한다.
- [ ] 가시 박스가 목표 폭·높이를 초과하지 않는다.
- [ ] 가시 박스 중심 오차가 ±2px 이내다.
- [ ] 가시 박스 하단이 기준선 ±2px 이내다.
- [ ] 다른 항목과 파일 해시가 중복되지 않는다.

## 수동 검수

- [ ] 앞머리가 왼쪽이다.
- [ ] 정확한 정측면이며 3/4 전면이 강조되지 않는다.
- [ ] 실제 차량·장비로 가능한 구조다.
- [ ] 바퀴·트랙·붐·적재함·부착물 등 식별 부위가 잘리지 않았다.
- [ ] 같은 생산 묶음의 색온도·노출·채도·재질 표현이 같다.
- [ ] 배경·문자·로고·워터마크·번호판·사람·불필요한 소품이 없다.
- [ ] 접지 그림자가 과하지 않고 대상이 떠 보이지 않는다.
- [ ] 64×40 축소 화면에서도 다른 유형과 즉시 구분된다.
- [ ] 모바일 76×102 셀과 PC 84×102 셀에서 기준선과 여백이 같다.

## 판정

- 자동 검수 1개라도 실패: `FAIL`, 배포 금지
- 수동 검수 1개라도 실패: `REVISION`, 새 버전 제작
- 모두 통과: `PASS`, 제품 연결 가능
- 100개 양산 목표: `PASS 99개 이상 / 100개`
