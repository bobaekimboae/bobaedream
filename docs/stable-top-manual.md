# 매물 목록 상단 구조 안정성 매뉴얼 v1.5

> 원본: https://claude.ai/artifact/Cm7M9wDvk8mjvveKUSfe28 (2026-09-27, v1.3). 저장소 적용 현황: v1.2 경로 분리·모바일 첫 화면 유형 줄 82는 QF-106b, v1.4 모델 이미지 칸은 QF-109에서 적용, v1.3 로고 크기 3단계·이름 폭 고정·제조사 10개 + 전체 브랜드는 QF-108에서 적용. 점검 스크립트 `npm run check:stability`의 기준 값은 이 문서의 표와 같아야 한다.
>
> 측정 기준 갱신(2026-10-03): 초톳 앱·현재 모바일웹·보배드림 채택값의 분리 원칙과 신규 자산 규격은 `docs/quick-filter-image-slot-rules_v02.md`를 따른다. 아래 표는 현재 배포 구현값이며, 초톳 전 표면의 공통 실측값을 뜻하지 않는다.

보배드림 매물 목록(과쯔 모드 기준)의 상단 영역이 **초톳처럼 흔들리지 않게** 만드는 규칙이다. 기준 실측은 M-029~M-031(로고 칸), M-033~M-035(초톳 앱), M-039(초톳 휴대폰·고양이 페이지 단계 전환)이다. 모든 수치는 CSS px.

## 1. 원칙 7가지

1. **층은 고정한다.** 층의 순서와 개수는 어떤 조건을 골라도 바뀌지 않는다.
2. **④ 퀵필터 자리는 절대 닫지 않는다.** 계층이 끝나면 다음 속성 줄로 바뀐다.
3. **높이는 두 가지뿐이다.** ④가 이미지 줄일 때와 알약 줄일 때. 앞으로 고르며 나갈 때 높이 변화는 이미지 → 알약 1회뿐이다(칩 ×로 되돌아갈 때는 예외).
4. **내용이 칸을 바꾸지 않는다.** 이름이 길어도, 이미지가 늦게 떠도, 칩이 늘어도 칸 크기는 그대로다(말줄임·가로 스크롤로 처리).
5. **제목은 고정한다.** 상단 메뉴(중고차 · 수입차 등)에서 들어온 카테고리 이름만 쓴다: "중고차 / 국산 중고차 / 수입 중고차". 유형 줄에서 고른 유형은 그 이름("트럭 · 특장" · "바이크" · "캠핑카" · "올드카" · "건설기계" · "부품 · 용품", v1.5). 칩으로 고른 조건은 제목을 바꾸지 않고, 대수·날짜를 쓰지 않는다.
6. **PC와 모바일은 구조가 다르다.** 같은 규칙을 억지로 맞추지 않고, 각자의 층 표를 따른다.
7. **안내선으로 확인한다.** 모든 칸과 층은 &debug=1 안내선으로 눈으로 확인할 수 있어야 하고, 자동 점검이 수치로 확인한다.

## 4. 상태 전환 규칙(④ 자리)

| 순서 | ④ 줄 | 칩 줄 | 높이 |
|---|---|---|---|
| 1 | 제조사 이미지 줄 | 필터 · [중고차 ×] · 제조사 ▾ … | 이미지 |
| 2 | 모델 이미지 줄 | … [벤츠 ×] · 모델 ▾ | 이미지 |
| 3 | 세부모델 이미지 줄 | … [C클래스 ×] · 세부모델 ▾ | 이미지 |
| 4 | 트림 알약 줄(트림이 없으면 건너뜀) | … [W206 ×] · 트림 ▾ | 알약(유일한 높이 변화) |
| 5 | 연식 알약 줄(2026 … 2019 · 이전) | … [C200 ×] · 연식 ▾ | 알약 |
| 6 | 연식 줄 유지, 고른 알약만 검정 | … [2023년 ×] | 알약 |

- 칩의 ×는 그 단계부터 아래만 푼다. 풀린 단계의 ④ 줄로 돌아간다.
- "필터 초기화"는 1번 상태로 돌아간다.

## 5. 금지 사항

- 카드·줄에 **고정 최소 높이**를 걸어 빈 공간을 만드는 것
- ④ 줄을 **숨기거나 닫는** 것
- 제목에 **대수·날짜**를 넣는 것, 조건에 따라 **제목 문구가 바뀌는** 것
- **가로 스크롤바**가 보이는 것(스크롤은 동작)
- 칩·알약·이름이 **줄바꿈**되어 줄 높이가 늘어나는 것(한 줄 + 가로 스크롤 / 말줄임)
- 이미지에 **크기 없이** 넣어 로딩 뒤 줄이 밀리는 것
- 층 사이 간격을 **요소 여백의 합**으로 우연히 맞추는 것(층 상자 사이 간격을 한 곳에서 정의)

## 6. 슬롯 체크 박스(&debug=1)

주소 끝에 `&debug=1`을 붙이면 오른쪽 아래 버전 배지 옆에 체크 박스 3개가 보인다. 레이아웃에는 영향이 없다(outline만 사용).

| 체크 박스 | 켜면 보이는 것 | 색 |
|---|---|---|
| 로고·이미지 칸 | 로고 상자(40·36), 이미지 칸(56×28), 칸 세로 중심선 | 빨강 점선 #E5484D |
| 층 상자 | ①~⑤ 각 층의 상자 테두리와 층 번호 | 파랑 점선 #2F6FEB |
| 간격 숫자 | 층 사이 간격 숫자(예 36 · 18 · 16), 카드 높이 | 규칙과 같으면 초록, 다르면 빨강 |

- 규칙 위반이 있으면 해당 칸·층에 **빨간 점 8px**와 이유(예 "넘침 4", "간격 20 ≠ 18", "허용 높이 아님")를 작게 표시
- 켠 상태는 브라우저 저장소에 기억(못 쓰면 매번 꺼진 상태로 시작)

## 7. 자동 점검(check:stability)

- 흐름: 처음 → 벤츠 → C클래스 → W206 → C200 → 2023 → 연식 해제 → 필터 초기화
- 크기: PC 1440·1280 / 모바일 393·360
- 확인 항목
  1. 각 단계의 층 순서·개수가 표와 같다
  2. 층 사이 간격이 표와 같다(±0.5)
  3. PC 카드 높이가 허용 두 값 중 하나다, 앞으로 가는 흐름(처음 → 2023)에서 높이 변화 1회
  4. 칸 넘침 0, 가로 스크롤바 보임 0, 줄바꿈 0
  5. 제목 문구 "중고차" 고정, 숫자·"년"·"월" 글자 0
  6. 이미지 로딩 전후 층 위치 차이 0
- 결과: 단계 × 크기 표(통과/실패와 수치), 실패 시 캡처
