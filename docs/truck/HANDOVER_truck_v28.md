# 코덱스-특장 인수인계 v28

## 1) 담당 범위

- 트럭·특장 형식·세부형식 이미지 카드 추가 축소 및 로컬 검수

## 2) 현재 진행 상태

- 완료: 모바일 카드 80×88px 적용
- 완료: PC 카드 100×100px 적용
- 완료: 이미지 위·텍스트 아래, 2줄 명칭, 선택 상태 유지
- 완료: 모바일·PC 인앱 브라우저 시각 검수
- 완료: 긴 세부형식 2줄 높이·이미지 로딩 확인
- 미착수: GitHub Pages 배포

## 3) 결정된 사항과 그 이유

- 카드 폭을 줄여 모바일 한 화면에 약 4.5개 형식이 보이게 했다.
- 내부 이미지는 카드 폭의 약 90%를 유지해 차량 식별력을 보존했다.
- 16px 곡률로 축소된 카드 크기에 맞는 둥근 정도를 적용했다.

## 4) 미결 사항·막힌 점
