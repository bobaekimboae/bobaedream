# 코덱스-특장 인수인계 v08

## 1) 담당 범위

- 화물·특장차의 엔카 기준 필터를 우리 시안의 `트럭 전용 필터`로 그룹화
- PC 좌측·협폭 필터 서랍·모바일 전체 필터에 동일한 입력과 결과 동작 적용

## 2) 현재 진행 상태

- 완료: 엔카 화물·특장 실화면의 필터 순서와 선택값 재확인
- 완료: PC `형식/적재용량` 아래 `트럭 전용 필터` 그룹과 15개 필터 배치
- 완료: 모바일 전체 필터에 같은 그룹·순서·형식 드릴다운 배치
- 완료: 가상 트럭 30대에 트럭 전용 항목값 부여 및 실제 목록 필터링 연결
- 완료: PC·모바일 확인 버튼의 임시 선택 대수 실시간 갱신
- 진행 중: GitHub Pages 배포 및 공개 URL 재검수

## 3) 결정된 사항과 그 이유

- 원본 순서는 2026-10-02 엔카 화물·특장 PC 실화면을 직접 펼쳐 확인한 결과를 기준으로 했다.
- `엔카 진단`은 경쟁사 고유 명칭을 피하기 위해 `트럭 진단`으로 표시하고 `진단 완료` 선택값을 사용한다.
- 형식 계층과 전용 필터는 PC·모바일에서 같은 상태와 가상 매물 30대를 사용해 결과가 다르게 보이지 않도록 했다.
- 필터 항목값은 가상 검증 데이터이며 실제 판매 정보가 아니다.

## 4) 미결 사항·막힌 점
