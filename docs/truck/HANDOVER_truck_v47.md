# 코덱스-특장 인수인계 v47

## 1) 담당 범위

- 기본 필터와 동일하게 정리한 트럭 유형 모바일 바텀시트를 공개 배포하고 공개본을 검증한다.

## 2) 현재 진행 상태

- 완료: 모바일 트럭 유형 시트 외곽·헤더·하단 버튼 통일.
- 완료: 모바일·PC 로컬 검증.
- 완료: GitHub Pages 공개 배포.
- 완료: 공개 모바일 394×852와 와이드 모바일 모드 재검증.

## 3) 결정된 사항과 그 이유

- 모바일 트럭 유형 시트는 기본 필터의 520px 최대 폭, 780px 최대 높이, 60px 헤더, 80px 하단 액션 규칙을 공유한다.
- 모바일 `초기화`는 112×44px, `N대 보기`는 남은 폭×44px이며 확인색은 `#1B4C8C`이다.
- PC는 모바일 규격을 강제로 쓰지 않고 기존 PC 중앙 모달 규격을 유지한다.

## 4) 미결 사항·막힌 점

- 실제 운영 매물 API 대수 연동은 미확인이다.
- 코덱스-자료 상호 검수는 미검수다.
