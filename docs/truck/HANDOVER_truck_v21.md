# 코덱스-특장 인수인계 v21

## 1) 담당 범위

- 트럭·특장 카고 세부형식의 경형·1톤 분류 수정 및 가상 매물 교체

## 2) 현재 진행 상태

- 완료: `경형 트럭 (1톤 미만)`과 `1톤 트럭` 분리
- 완료: 경형 적재용량 `0.5톤`, 1톤 적재용량 `1톤` 분리
- 완료: 포터2를 `1톤 트럭`, 라보를 `경형 트럭 (1톤 미만)`으로 분리
- 완료: 경형 매물 이미지와 1톤 트럭 이미지 분리
- 완료: 이전 `경형 트럭 (1톤)` 공유 링크를 `1톤 트럭`으로 호환
- 완료: PC·모바일 로컬 자동 회귀검수
- 진행 중: GitHub Pages 배포 및 공개 화면 검수

## 3) 결정된 사항과 그 이유

- `경형 트럭 (1톤)`이라는 기존 명칭은 라보급과 포터급을 한 범위에 섞으므로 폐기했다.
- 경형은 `1톤 미만`, 포터·봉고급은 `1톤 트럭`으로 분리해 필터 결과가 서로 섞이지 않게 했다.
- 엔카 원문은 접속 제한으로 재확인하지 못했으므로 미확인 톤수는 추가하지 않고 검증 매물의 `0.5톤`과 `1톤`만 적용했다.

## 4) 미결 사항·막힌 점

- 엔카 현재 원문 필터의 경형 세부 톤수 전체 목록: 미확인(자동 접속 제한)
- 공개 GitHub Pages 배포 및 최종 URL 검수: 진행 중
- 전체 `npm run verify`의 관리자 헬스 엔드포인트 기존 404는 트럭 범위 밖의 알려진 실패다.
