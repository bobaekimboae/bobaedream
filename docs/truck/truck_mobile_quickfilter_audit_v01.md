# 트럭 모바일 퀵필터·차량 이미지 감사 v01

- 감사일: 2026-10-02
- 대상: 공개 GitHub Pages 트럭·특장 PC·모바일 화면
- 대상 버전: `0ec56e6`
- 범위: 차량 이미지 높이·너비, 모바일 퀵필터 레이아웃, 긴 명칭 표시, 형식 → 세부형식 → 적재·규격 동작
- 구현 변경: 없음

## 결론

- PC 형식 퀵필터는 카드 `84×102px`, 이미지 `76×40px`로 원본 `228×120px` 비율과 일치해 안정적이다.
- 모바일은 카드 `64×74px`, 이미지 영역 `56×36px`, 라벨 `12px/18px`다. `캠핑카/캠핑 트레일러`가 3줄 `54px`이 되어 이미지 `36px`와 합산 시 카드 높이를 최소 `18px` 초과한다.
- 모바일의 `캠핑트레일러`는 `캠핑트레일 / 러`로 끊겨 한 글자 고아줄이 생긴다.
- 모바일 화살표가 가장자리 카드 위에 겹쳐 이미지와 라벨을 가린다.
- 매물 이미지는 원본 `960×480px`(2:1)을 PC `160×160px`, 모바일 `136×136px` 정사각형에 `contain`으로 표시한다. 왜곡이나 잘림은 없지만 위아래 여백이 커서 차체가 작아 보인다.
- 형식 → 세부형식 → 적재·규격 전환은 정상 동작했다. `캠핑카/캠핑 트레일러` → `캠핑트레일러` → `3m·4m·5m·7m·9m`까지 확인했다.

## 단계별 상태

1. PC 초기 화면 — 정상
   - 형식 카드와 긴 명칭이 최대 2줄 안에 들어간다.
   - PC 퀵필터 이미지 비율은 원본과 일치한다.
2. 모바일 형식 퀵필터 — 수정 필요
   - 2줄 명칭은 카드 높이를 정확히 소진하고, 3줄 명칭은 카드 밖으로 넘친다.
   - 모바일 강제 미리보기에서는 넘친 라벨이 하단 내비게이션과 충돌해 더 심하게 보인다.
3. 모바일 긴 형식 선택 후 세부형식 — 수정 필요
   - 선택과 다음 뎁스 전환은 정상이다.
   - `캠핑트레일러`의 마지막 글자가 별도 줄로 떨어진다.
4. 모바일 적재·규격 뎁스 — 정상
   - `3m·4m·5m·7m·9m` 칩 노출과 필터 개수 증가는 정상이다.

## 권장안

### 1순위: 모바일 퀵필터 규격 통일

- 이미지 영역을 `56×30px`로 통일한다. 원본 1.9:1과 거의 같아 개별 이미지 높이 차이가 사라진다.
- 카드 폭은 `72px`, 높이는 `78px`를 권장한다.
- 라벨은 최대 2줄, 줄높이 `18px`, 고정 높이 `36px`로 둔다.
- 터치 화면에서는 좌우 화살표를 숨기고 스와이프와 끝부분 페이드로 이동 가능성을 알린다.

### 2순위: 표시명과 데이터값 분리

필터 값과 상세 화면의 정식 명칭은 유지하고, 좁은 퀵필터 카드에서만 짧은 표시명을 사용한다.

| 정식 명칭 | 모바일 표시명 |
|---|---|
| 캠핑카/캠핑 트레일러 | 캠핑카·트레일러 |
| 폐기/음식물수송 | 폐기물·음식물 |
| 차량견인/운송 | 견인·운송 |
| 덤프/건설/중기 | 덤프·건설 |
| 캠핑트레일러 | 캠핑 트레일러 |

- 접근성 이름과 선택 칩에는 정식 명칭을 유지한다.
- 줄바꿈이 필요한 명칭은 임의 글자 단위가 아니라 공백 또는 명시적 줄바꿈 지점에서만 나눈다.

### 3순위: 매물 이미지 프레임 조정

- 원본 2:1 이미지는 그대로 두고 `object-fit: contain`을 유지한다.
- PC 프레임은 `160×112px`, 모바일 프레임은 `136×96px`부터 비교 시안을 권장한다.
- 정사각형 프레임을 유지해야 하면 이미지 소스의 상하 여백을 줄인 전용 크롭본을 사용한다.
- `cover`는 트럭 앞뒤가 잘릴 수 있으므로 권장하지 않는다.

## 제한 사항

- 인앱 브라우저의 모바일 화면은 430px 레이아웃을 1280×720 창에 확대하는 강제 미리보기다. 하단 내비게이션 충돌의 체감 정도는 실제 세로형 기기에서 추가 확인이 필요하다.
