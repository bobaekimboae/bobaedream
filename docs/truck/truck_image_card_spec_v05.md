# 트럭 형식 이미지 카드 시안 v05

## 최종 축소 요청

- 모바일 카드: 72×80px
- PC 카드: 88×90px
- 이미지 위·텍스트 아래 배치 유지
- 카드 전체 클릭·터치 영역 유지

## 규격

| 환경 | 카드 | 이미지 | 하단 명칭 | 모서리 |
|---|---:|---:|---:|---:|
| 모바일 | 72×80px | 64×36px | 64×32px, 11/16px, 최대 2줄 | 14px |
| PC | 88×90px | 80×43px | 80×34px, 11/17px, 최대 2줄 | 14px |

## 상태

- 기본 FINN형 배경: `#F1F1F3`
- 호버: `#E8EBEF`
- 선택 Airbnb형: 흰 배경, `#222222` 2px 내부 외곽선
- 선택 그림자: `rgba(0, 0, 0, 0.12)`

## 유지 기준

- 차량 이미지 비율 왜곡 없음
- 모든 차량 이미지 하단 기준선 정렬
- 긴 형식·세부형식 최대 2줄 표시
- 모바일에서 약 5개 카드와 다음 항목 일부 노출
