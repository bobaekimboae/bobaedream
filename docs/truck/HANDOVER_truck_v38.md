# 코덱스-특장 인수인계 v38

## 1) 담당 범위

- 트럭·특장 초톳형 형식·세부형식·유형 퀵필터의 이미지–명칭 간격 및 명칭 크기 보정과 공개 배포.

## 2) 현재 진행 상태

- 완료: 드라이브 초톳 카테고리·브랜드 캡처 교차 검수.
- 완료: 초톳 실사이트 차량 홈과 트럭 목록 확인.
- 완료: 모바일·PC 유형 이미지–명칭 간격 및 명칭 크기 반영.
- 완료: GitHub Pages 공개 배포와 공개 화면 자동 재측정.

## 3) 결정된 사항과 그 이유

- 브랜드 로고 규격은 초톳 캡처·실사이트와 유사해 40×40px 및 명칭 간격 8px을 유지했다.
- 유형 이미지–명칭 간격은 모바일 7px·PC 9px로 보정했다.
- 유형 명칭은 모바일·PC 모두 14px, 최대 두 줄로 확정했다.
- 긴 트럭 형식명을 보존하면서도 카드 배경·테두리·곡률·그림자는 사용하지 않는다.

## 4) 미결 사항·막힌 점

- 정확한 초톳 DOM CSS 원본값은 미확인이다. 1080×2340 캡처 환산값과 실사이트 시각 대조를 사용했다.
- 코덱스-자료 상호 검수는 미검수다.
