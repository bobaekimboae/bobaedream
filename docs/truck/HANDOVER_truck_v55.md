# 코덱스-특장 인수인계 v55

## 1) 담당 범위

- 트럭 유형 루트 이미지의 각도를 정측면 기준으로 통일하고 공개 배포한다.

## 2) 현재 진행 상태

- 완료: 구형 3/4 계열 루트 이미지 9종을 정측면 v05로 교체.
- 완료: 신규 마스터 파일과 228×120 배포본 저장.
- 완료: `truck-format-catalog.ts` 루트 이미지 매핑 갱신.
- 완료: 자동검수, 빌드, 모바일·PC 로컬 브라우저 검수.
- 진행 중: 공개 배포.

## 3) 결정된 사항과 그 이유

- 바텀시트와 PC 모달의 트럭 유형 이미지는 56×40px로 작으므로 3/4 입체감보다 정측면 실루엣 통일을 우선한다.
- 카고·윙바디·크레인·탱크로리 v02는 유지하고, 나머지 루트 유형을 v05 정측면으로 맞췄다.
- `특수차`와 `기타`는 같은 파일을 재사용하지 않고 각각 특수 장비차와 섀시캡 이미지로 분리했다.

## 4) 미결 사항·막힌 점

- 코덱스-자료 상호 검수는 미검수다.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 사용자 지시: 트럭 유형 이미지를 정측면으로 통일하고 배포.
- 코덱스-자료 상호 검수는 대기 중이다.

## 7) 검수 상태

- 이미지 접촉시트 육안 검수: 완료.
- `npm run verify:qf`: 통과.
- `npm run build`: 통과.
- 모바일 로컬: v05 루트 이미지 경로, 바텀시트 표시, 콘솔 오류 0건 확인.
- PC 로컬: v05 루트 이미지 경로, 모달 표시, 콘솔 오류 0건 확인.
- 공개 배포: 진행 중.

1. 변경사항을 커밋하고 GitHub Pages 배포를 실행한다.
