# 코덱스-특장 인수인계 v31

## 1) 담당 범위

- 트럭·특장 형식·세부형식 이미지 카드의 모서리 곡률 축소

## 2) 현재 진행 상태

- 완료: 모바일·PC 카드 곡률 14px → 10px
- 완료: 모바일 72×80px, PC 88×90px 카드 크기 유지
- 완료: 이미지 위·텍스트 아래, 긴 명칭 최대 2줄 유지
- 완료: 로컬 모바일·PC 시각 검수
- 미착수: 공개 배포

## 3) 결정된 사항과 그 이유

- 사용자의 `곡을 줄이자` 요청을 카드 모서리 곡률 축소로 반영했다.
- 카드 밀도와 이미지 균형은 직전 승인 방향을 보존하기 위해 v05 크기를 유지했다.
- 10px은 작은 카드에서 과도한 캡슐 형태를 줄이면서 클릭 영역 경계를 명확히 하는 값으로 선택했다.

## 4) 미결 사항·막힌 점

- 공개 배포는 사용자 요청 후 진행한다.
