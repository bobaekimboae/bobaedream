# 코덱스-특장 인수인계 v50

## 1) 담당 범위

- 트럭 유형 모달·바텀시트의 측면 이미지 샘플을 제작해 실제 필터에 연결한다.
- 모바일과 PC에서 이미지 인지성, 줄간격, 탐색·선택·확정 동작을 검수한다.

## 2) 현재 진행 상태

- 완료: 카고·윙바디·탱크로리·카고크레인 측면 이미지 v02 제작.
- 완료: 1484×1060 투명 원본을 228×120, 바닥선 y=111로 정규화.
- 완료: 상위 유형과 대표 2뎁스 매핑 연결.
- 완료: 모바일 행 64px, PC 행 60px, 공통 이미지 표면 56×40px 적용.
- 완료: 로컬 모바일·PC 시각 검수와 선택·확정·URL 동작 검증.
- 진행 중: GitHub Pages 공개 배포와 공개본 재검수.

## 3) 결정된 사항과 그 이유

- 앞머리가 왼쪽인 측면형을 사용한다. 긴 트럭의 적재함·탱크·크레인 장비 차이를 작은 슬롯에서 직접 비교하기 쉽다.
- 원본 마스터와 배포본을 분리한다. 배포본은 기존 정규화 파이프라인과 같은 228×120 규격을 사용한다.
- 이미지는 56×40px의 연회색 표면에 아래 정렬한다. 흰색·은색 차체가 흰 바텀시트에서 사라지는 문제를 줄인다.
- 이번 시안은 네 유형만 교체해 기존 3/4 이미지와 직접 비교할 수 있게 했다.

## 4) 미결 사항·막힌 점

- 측면형은 차체 비율상 실제 표시 높이가 약 21~25px다. 확대하면 앞뒤가 잘리므로 사용자 비교 후 최종 방향을 정해야 한다.
- 나머지 상위 유형과 2뎁스 전용 측면 이미지는 미제작이다.
- 전체 `npm run verify`는 기존 관리자 `/category-admin/` 404 테스트 1건에서 중단된다. 트럭 변경 검증인 `verify:qf`, 별도 build, 순차 `test:sites`는 통과했다.
