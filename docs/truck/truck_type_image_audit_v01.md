## 결론

트럭 유형 필터의 탐색·선택 구조와 하단 확정 동작은 정상이다. 이미지 인지성이 약한 핵심 원인은 원본 해상도가 아니라 아래 세 가지다.

1. 모바일과 PC 모두 이미지 요소가 `32×28px`이고, 228×120 원본이 `contain`으로 들어가 실제 차량 도형은 약 `30×15px`만 그려진다.
2. 흰색·은색 차량을 흰 행 배경에 바로 놓아 차체 외곽 대비가 약하다.
3. 서로 다른 유형에 동일 파일 또는 범용 파일을 재사용해 이미지가 유형 구분자 역할을 하지 못한다.

상단 퀵필터는 같은 계열 이미지를 `64×64px` 영역에서 보여 상대적으로 인지가 쉽다. 따라서 바텀필터만의 원본 품질 문제가 아니라 표시 규격과 유형별 매핑 문제다.

## 우선순위별 문제

### P1 — 표시 크기가 차량 이미지 비율과 맞지 않음

- 32×28px는 아이콘에는 맞지만 2:1에 가까운 차량 실사 누끼에는 작다.
- 모바일과 PC가 동일 규격이어서 PC의 넓은 모달도 장점을 쓰지 못한다.
- 현재 상단 퀵필터 64px 이미지와 비교하면 바텀필터 실루엣 높이가 약 절반이다.

### P1 — 동일 이미지가 다른 의미에 배정됨

- 상위 13개 중 `윙바디·탑차/냉장·냉동차`, `특수차/기타` 두 쌍이 완전히 중복된다.
- 카고 하위에서 준중형·중형·준대형이 완전히 중복된다.
- 사용자는 텍스트를 읽기 전 이미지만 보고 구분할 수 없다.

### P2 — 밝은 차체와 흰 행 배경의 대비 부족

- 흰색·은색 통일 규칙 자체는 적절하지만 흰 행에 배경판 없이 놓으면 차체 경계와 장비 형상이 약해진다.
- 그림자만으로는 30px 수준의 도형을 충분히 분리하지 못한다.

### P2 — 대표 이미지가 분류 범위를 충분히 설명하지 못함

- `트랙터·트레일러`는 트레일러 단독보다 트랙터 헤드+세미트레일러 결합 실루엣이 적합하다.
- `특수차`는 일반 서비스 트럭보다 장비가 명확한 복합 대표형 또는 전용 픽토그램이 적합하다.

## 권장 규격

### 1차: 레이아웃 보정

| 항목 | 권장값 |
|---|---|
| 모바일·PC 행 높이 | 60px |
| 체크박스 | 20×20px 유지 |
| 이미지 표면 | 56×40px |
| 이미지 배경 | `#F7F7F7`, 반경 6px |
| 이미지 맞춤 | `contain`, `center bottom` |
| 체크박스→이미지 간격 | 12px |
| 이미지→명칭 간격 | 10px |
| 구분선 시작점 | 이미지 표면의 왼쪽, 현재 원칙 유지 |
| 긴 명칭 | 한 줄 말줄임 유지, 전체 명칭은 접근성 이름으로 보존 |

56×40px 요소에서는 228×120 원본이 약 56×29.5px로 그려져 차량 도형 높이가 약 26px까지 회복된다. 48px 폭은 약 23px 높이에 머물러 특장 장비 구분에는 여전히 빠듯하다.

### 2차: 유형 전용 이미지 교체

1. `냉장·냉동차`: 냉동탑 또는 냉동윙 전용 이미지. 냉동기 유닛이 분명하게 보이게 한다.
2. `특수차`: `기타`와 분리. 대표 장비가 큰 특수차 전용 이미지로 교체한다.
3. `트랙터·트레일러`: 트랙터 헤드와 세미트레일러가 함께 보이는 이미지로 교체한다.
4. `준중형/중형/준대형`: 캡 크기·축 수·적재함 길이가 단계별로 명확히 달라지는 전용 이미지 3종을 제작한다.
5. 이후 모든 2·3뎁스에서 동일 파일 재사용 목록을 자동 검사한다.

## 제작 규칙 보완

- 원본 캔버스 228×120px와 투명 PNG 규칙은 유지한다.
- 앞 3/4, 앞머리 왼쪽, 흰색·은색, 바닥 기준선 통일 규칙도 유지한다.
- 상위 유형은 실제 모델 정확도보다 `적재함·탑·냉동기·크레인·탱크·덤프·견인 장비`의 실루엣 구분을 우선한다.
- 카고 톤급은 색상 차이로 구분하지 않고 차축·캡·적재함 길이 차이로 구분한다.
- 밝은 차체 외곽이 사라지지 않도록 얕은 회색 표면과 1px 이내의 부드러운 바닥 그림자를 함께 사용한다.
- 파일 매핑 검수에서 서로 다른 형제 노드가 같은 파일을 쓰면 경고한다. 의도적 재사용은 매니페스트에 사유를 기록한다.
