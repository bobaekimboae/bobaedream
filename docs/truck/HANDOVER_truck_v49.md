# 코덱스-특장 인수인계 v49

## 1) 담당 범위

- 플랫폼별 로고·모델 캡처를 대조해 트럭 유형 바텀시트의 로고·차량 이미지 권장 규격을 정한다.

## 2) 현재 진행 상태

- 완료: Google Drive 폴더의 대표 플랫폼 캡처 확인.
- 완료: 모바일 밀도, 이미지 제작, 정보구조·접근성 관점의 독립 의견 수렴.
- 완료: 로고·차량 이미지의 공통 열과 광학 크기 합의.
- 미착수: 실제 UI 적용, 신규 에셋 제작, 공개 배포.

## 3) 결정된 사항과 그 이유

- 공통 미디어 열은 56×40px로 맞추되 로고와 차량의 실제 그림 크기는 다르게 사용한다. 플랫폼들이 로고는 정방형, 차량은 가로형으로 광학 보정하기 때문이다.
- 로고는 40×40px, 차량은 56×40px를 기본으로 한다.
- 모바일 행은 64px, PC 행은 60px로 한다. PC에서도 이미지를 줄이지 않고 세로 패딩만 줄여 인지성을 유지한다.
- 1뎁스는 전용 이미지, 2뎁스는 외형 차이가 있는 항목만 이미지, 3뎁스는 기본 텍스트로 한다.

## 4) 미결 사항·막힌 점

- 각 플랫폼의 원본 CSS 수치는 캡처만으로는 미확인이다.
- 사용자 승인 전이므로 UI와 에셋은 수정하지 않았다.
- 코덱스-자료의 신규 이미지 제작 및 상호 검수가 필요하다.

## 5) 산출물 목록

- `truck_bottomsheet_media_consensus_v01.md` / v01 / `docs/truck/`
- `HANDOVER_truck_v49.md` / v49 / `docs/truck/`

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- Google Drive의 당근·엔카·이처·동처띠·오토홈·과쯔 캡처를 읽기 전용으로 확인했다.
- 신규 유형 이미지 제작과 코덱스-자료 상호 검수는 대기 중이다.

## 7) 검수 상태

- Drive 대표 로고·모델 캡처: 검수완료.
- 세 관점 독립 의견: 수렴완료.
- 최종 권장값: 로고 40×40px, 차량 56×40px, 모바일 행 64px, PC 행 60px.
- 코드 변경·배포 없음.
- 코덱스-자료 상호 검수 미검수.

## 8) 다음에 할 일

1. 사용자 승인 시 합의 규격을 로컬 시안에 적용한다.
2. 모바일·PC 루트와 2·3뎁스를 시각 검수한다.
3. 상위 중복 이미지와 카고 톤급 중복 이미지를 전용 이미지로 교체한다.
4. 접근성 이름과 동일 이미지 중복 검사를 추가한다.
5. 코덱스-자료 상호 검수를 요청한다.
