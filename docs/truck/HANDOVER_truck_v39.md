# 코덱스-특장 인수인계 v39

## 1) 담당 범위

- 실제 보배드림 트럭·특장 필터에 최종 트럭 유형 트리와 PC 모달·모바일 바텀시트를 연결한다.

## 2) 현재 진행 상태

- 완료: 최종 13개 상위 유형과 하위 유형 트리 코드화.
- 완료: 트럭 가상 매물 30대의 형식·세부 유형을 새 분류에 맞게 교체.
- 완료: 모바일 바텀시트와 PC 중앙 모달 연결.
- 완료: 상단 필터칩·PC 좌측 필터·모바일 전체 필터 진입 연결.
- 완료: 선택값 URL 저장과 실제 목록·대수 연동.
- 진행 중: GitHub Pages 공개 배포.

## 3) 결정된 사항과 그 이유

- 화면 명칭은 `형식/적재용량` 대신 `트럭 유형`을 사용한다. 새 트리는 차체·용도 유형을 우선 탐색하고 적재량·장비는 별도 필터 축으로 유지하기 때문이다.
- PC는 중앙 모달, 모바일은 바텀시트를 사용하되 동일 컴포넌트와 상태를 공유한다.
- 행은 체크박스·32px 유형 이미지·명칭·대수·하위 화살표 순서다. 화살표는 실제 하위가 있는 행에만 표시한다.
- 중간 그룹 선택은 그 아래 실제 매물을 모두 포함한다. 예: `내장탑` 선택은 일반·하이탑·저상형·상승형을 포함한다.
- 0대 정의는 비활성으로 남겨 전체 분류 체계를 확인할 수 있게 한다.
