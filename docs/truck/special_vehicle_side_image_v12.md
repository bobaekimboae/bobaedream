- 제작 도구: Codex 내장 이미지 생성 도구, 투명 배경 편집 모드

## 목적

- 특수차 4개 그룹과 하위 유형을 글자만 읽지 않아도 장비·차체 실루엣으로 구분한다.
- 기존 사진의 해상도·각도 차이를 제거하고 모든 유형을 같은 슬롯 규칙으로 제공한다.
- 사용자의 각도 보정 요청에 따라 준측면을 허용하지 않고 90도 정측면만 사용한다.

## 슬롯·각도 규칙

- 마스터: 투명 PNG, 생성 원본 보존.
- 배포본: 228×120px 투명 PNG.
- 화면 표시: 바텀시트 56×40px, 상단 퀵필터는 기존 반응형 슬롯 규칙을 따른다.
- 방향: 차량 앞은 왼쪽, 운전석 측면이 보이는 90도 좌측 정투영.
- 금지: 전면 그릴 면, 후면 면, 상판 면, 원근 수렴, 3/4 구도.
- 검수 기준: 두 바퀴 중심 수평, 바퀴 원형 유지, 차체 바닥선 y=111, 좌우 잘림 없음.
- 색상: 흰색·밝은 회색 차체, 짙은 섀시, 용도 인식에 필요한 최소 안전색만 허용.
- 문·장비: 닫힘·접힘·수납 상태. 사람, 상표, 글자, 번호판, 배경은 제외.
