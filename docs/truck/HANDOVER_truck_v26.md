# 코덱스-특장 인수인계 v26

## 1) 담당 범위

- 트럭·특장 형식·세부형식 카드의 이미지·텍스트 배치와 비율 조정

## 2) 현재 진행 상태

- 완료: 차량 이미지 위·명칭 아래 순서 적용
- 완료: 모바일 이미지 영역 80×47px, PC 이미지 영역 104×54px 적용
- 완료: 카드 외곽 크기와 한 행 노출 수 유지
- 완료: 기본 FINN형 배경과 Airbnb형 선택 상태 유지
- 완료: 인앱 브라우저 모바일·PC 시각 검수
- 미착수: GitHub Pages 배포

## 3) 결정된 사항과 그 이유

- 카드를 키우지 않고 내부 이미지 영역을 확대해 목록 밀도와 차량 식별력을 함께 유지했다.
- 명칭은 사용자 요청대로 차량 이미지 아래에 두고 최대 2줄 영역을 고정했다.
- 차량 이미지는 같은 하단 기준선에 정렬해 차종별 높이 차이가 있어도 카드 행이 흔들리지 않게 했다.

## 4) 미결 사항·막힌 점

- 공개 배포는 사용자 지시 대기 중이다.

## 5) 산출물 목록

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 사용자 수정 요청: 텍스트를 이미지 밑으로 이동하고 카드·이미지 균형 조정
- 다른 코덱스 파일은 수정하지 않음

- PC 1280×900: 카드 112×108px, 이미지 104×54px, 간격 4px 확인
- 공개 배포: 미검수
