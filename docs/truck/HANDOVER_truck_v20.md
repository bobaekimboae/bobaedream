## 3) 결정된 사항과 그 이유

- 정식 형식·세부형식 데이터값과 PC 표기는 유지하고, 모바일 퀵필터만 짧은 표시명을 사용한다.
- 긴 명칭은 최대 2줄 고정으로 카드 밖 넘침을 방지한다.
- 트럭 이미지의 가로 비율을 살리고 앞뒤 잘림을 막기 위해 `contain`을 유지한다.

## 4) 미결 사항·막힌 점

- 전체 `npm run verify`의 관리자 헬스 엔드포인트 테스트는 기존 404로 17건 중 1건 실패한다. 트럭 범위와 GitHub Pages 검증은 통과했다.
- 인앱 브라우저 강제 모바일 미리보기의 화면 높이는 실제 세로형 기기와 다르다.
