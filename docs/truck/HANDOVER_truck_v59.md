# 코덱스-특장 인수인계 v59

## 1 담당 범위

- 카고(화물)트럭 하위 차급 6종의 차량 크기별 슬롯 밸런스 교정과 공개 배포.

## 2 현재 진행 상태

- 완료: v13 모바일·PC 화면과 투명 이미지 실차 영역 측정.
- 완료: 내장 이미지 생성 도구를 이용한 차급별 차체 비율 교정.
- 완료: 228×120 투명 PNG·WebP v14 정규화.
- 완료: 실제 퀵필터 데이터 경로를 v14로 교체.
- 진행 중: 모바일·PC 실제 화면 검수와 공개 배포.

## 3 결정된 사항과 이유

- 슬롯 캔버스와 바닥선은 v13 규칙을 유지한다.
- 차량 영역은 `164×65 → 176×72 → 187×76 → 196×80 → 207×81 → 217×83px`로 폭과 높이가 함께 증가한다.
- 자연 비율을 유지하기 위해 CSS 변형이나 비균등 확대 대신 차급별 마스터를 다시 생성한다.
- 방향·색상·정측면·축 수·평적재함은 기존 규칙을 유지한다.
