# 코덱스-특장 인수인계 v58

## 1 담당 범위

- 카고(화물)트럭 하위 차급 6종의 정측면 이미지 제작과 실제 퀵필터 연결.

## 2 현재 진행 상태

- 완료: 기존 가이드·매니페스트와 최신 트럭·특장 v02 이미지 규칙 확인.
- 완료: 경형·소형·준중형·중형·준대형·대형 생성 마스터 제작.
- 완료: 228×120 투명 PNG·WebP 정규화와 실제 데이터 연결.
- 완료: 모바일 실제 화면 로딩·잘림·콘솔 오류 검증.
- 미착수: 공개 배포. 별도 지시 전에는 배포하지 않는다.

## 3 결정된 사항과 이유

- 30도 준측면은 차폭과 범퍼가 강조되므로 90도 정측면으로 통일한다.
- 차급 차이는 캡 높이, 축거, 적재함 길이, 바퀴 크기와 축 수로 구분한다.
- 흰 배경을 합성하지 않고 알파가 유지되는 WebP를 실제 화면에 연결한다.

## 4 미결 사항과 막힌 점

- 공개 배포는 사용자 별도 지시 대기.

## 7 검수 상태

- 생성 이미지 접촉시트 육안 검수: 완료.
- 배포 이미지 6종: 228×120px, RGBA, 알파 범위 0~255 확인.
- 로컬 HTTP: 6개 WebP 모두 200 `image/webp` 확인.
- 모바일 390×844: 6개 라벨과 v13 이미지 경로, 72×45px 표시, 하단 정렬, 잘림 없음 확인.
- 브라우저 콘솔 오류: 0건.
- `npm run verify:qf`: 통과.
