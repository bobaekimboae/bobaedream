# 코덱스-특장 인수인계 v42

## 1) 담당 범위

- 실제 트럭 유형 필터의 모바일 바텀시트와 PC 모달을 기준 시안에 맞춰 보정하고 공개 배포한다.

## 2) 현재 진행 상태

- 완료: 구분선을 체크박스·이미지 영역에서 제외하고 명칭 열부터 시작하도록 수정.
- 완료: 모바일 바텀시트 제목 좌측 정렬 및 우측 닫기 버튼 배치.
- 완료: 트럭 화면의 중복 `카테고리` 칩 제거.
- 완료: 모바일·PC 로컬 검증 및 GitHub Pages 공개 배포.
- 미착수: 실제 운영 매물 API 대수 연동.

## 3) 결정된 사항과 그 이유

- 구분선은 행 좌측 96px에서 시작한다. 체크박스와 유형 이미지 영역을 비워 핀노 목록 구조를 따르고, 명칭 시작선과 맞춘다.
- 모바일 제목은 바텀시트 좌측 20px, 닫기 버튼은 우측 16px의 44px 터치 영역으로 배치한다.
- `트럭 · 특장`이 현재 카테고리를 이미 나타내므로 트럭 화면에서만 일반 `카테고리` 칩을 제외한다.
- 모바일 칩 순서는 `트럭 · 특장 → 트럭 유형 → 연식 → 가격 → 연료`로 확정한다.
