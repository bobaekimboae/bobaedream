# 코덱스-특장 인수인계 v54

## 1) 담당 범위

- 트레일러 이미지 12종을 10도 준측면에서 90도 완전 정측면으로 교정한다.

## 2) 현재 진행 상태

- 완료: 트레일러 12종 완전 정측면 마스터 v04 생성.
- 완료: 앞·뒤 면, 상판, 장축 수렴 여부 육안 검수.
- 완료: 228×120px, 차체 폭 224px, 바닥선 y=111 정규화.
- 완료: 실제 트랙터·트레일러 하위 유형 필터를 v04 경로로 변경.
- 완료: 모바일·PC 로컬 시안에서 v04 이미지 12종과 56×40px 슬롯 검증.
- 미착수: 공개 배포.

## 3) 결정된 사항과 그 이유

- 10도 준측면은 작은 슬롯에서도 앞·뒤 단면이 보여 사용자가 완전 측면으로 인식하지 못하므로 폐기한다.
- 각도 규칙을 90도 orthographic side elevation으로 고정한다.
- 통과 조건은 앞면 0px, 뒷면 0px, 상판 0px, 장축 수평·평행, 바퀴 원형이다.

## 4) 미결 사항·막힌 점

- 공개 배포 전 사용자 시안 확인이 필요하다.
- 매물 0대 항목은 비활성 투명도로 이미지가 흐리게 표시된다.

- 기존 v03 마스터를 유형·기계구조 참조 이미지로 사용했다.
- 코덱스-자료 상호 검수는 대기 중이다.

## 7) 검수 상태

- 마스터 12종 각도 육안 검수: 완료.
- `npm run verify:qf`: 통과.
- `npm run build`: 통과.
- 모바일 로컬: v04 이미지 12개, 56×40px, 콘솔 오류 0건.
- PC 로컬: v04 이미지 12개, 56×40px, 콘솔 오류 0건.
