# 트럭 유형 실사 이미지 매니페스트 v02

## 제작 기준

- 레이아웃: 좌향 완전 측면, 카메라는 차축 높이에서 차체와 수직
- 차량 체형: 한국·일본 상용차 기준
  - 소형: 기아 봉고, 현대 포터, 히노 듀트로, 이스즈 엘프 계열의 비례 참고
  - 중형: 현대 마이티·파비스, 히노 렌저, 이스즈 포워드 계열의 비례 참고
  - 대형: 현대 엑시언트, 히노 프로피아, 이스즈 기가 계열의 비례 참고
- 제외: 미국식 롱노즈, 유럽식 캡 디자인을 대표 형태로 사용하지 않음
- 마스터: 투명 PNG, 3:2 가로형, 기본 1536×1024
- UI 슬롯: 모바일 64×64px, PC 88×88px, `object-fit: contain`
- 색상: 흰색 차체와 중립 회색 장비를 기본으로 하며 식별에 필요한 기능색만 허용
- 그림자: 8~10% 중립 회색 접지 그림자
- 금지: 로고, 문자, 워터마크, 인물, 배경 풍경, 차체 절단, 과도한 원근

## 특수 형상 규칙

- 카캐리어: 상·하부 적재 데크 전체와 후면 램프를 노출한다. 앞범퍼를 크게 보이게 하는 3/4 각도는 금지한다.
- 크레인: 붐과 후크를 차체 폭 안으로 접은 작업 전 이동 상태를 기본으로 한다.
- 트랙터: 세미트레일러를 연결하지 않고 제5륜 커플러와 6×4 축 구성을 노출한다.
- 트레일러: 트랙터와 트레일러의 전체 길이를 한 화면에 표시하고 양 끝과 모든 차축을 자르지 않는다.
- 모터홈: 유럽 밴형보다 국내·일본 경상용 캡오버 기반의 박스형 모터홈을 우선한다.
- 긴 차량은 높이를 임의로 키우지 않고 전체 길이를 유지한 채 `contain`으로 축소한다.
