# 트럭·특장 모바일 이미지 퀵필터 검수 v02

## 변경 내용

- 모바일 메인 퀵필터의 `형식` 텍스트 알약줄을 차량 이미지 카드 13개로 교체
- 형식을 고른 뒤의 `세부 형식` 텍스트 알약줄을 차량 이미지 카드로 교체
- 전체 필터의 `형식/적재용량` 시트에도 56×36 이미지 영역 적용
- 적재량·규격 단계는 이미지가 아닌 알약칩 유지

## 기준

| 항목 | 모바일 규격 |
|---|---:|
| 카드 칸 | 64×74 px |
| 차량 이미지 영역 | 56×36 px |
| 카드 간격 | 8 px |
| 전체 필터 시트 이미지 래퍼 | 64×44 px |
| 전체 필터 시트 차량 이미지 | 56×36 px |

배포용 이미지 원본은 v01의 228×120 투명 PNG를 그대로 재사용한다. 별도 재생성이나 형상 변경은 하지 않았다.

## 검수 항목

- 모바일 393 px에서 형식 이미지 13/13 로드
- 형식 선택 후 카고 세부형식 이미지 3/3 로드
- 메인 퀵필터 카드 64×74 px, 이미지 영역 56×36 px 확인
- 전체 필터 시트 이미지 래퍼 64×44 px, 이미지 56×36 px 확인
- 적재·규격 단계 알약칩 유지
- PC의 76×40 이미지 규격 유지
- `npm run build` 통과
