# 트럭 형식 이미지 카드 시안 v01

## 적용 범위

- 트럭·특장 전용 형식 및 세부형식 퀵필터
- 모바일과 PC 공통
- 다른 카테고리에는 적용하지 않음

## 시각 방향

- 기본 상태: 노르웨이 FINN 참고 화면처럼 이미지와 명칭을 하나의 연회색 카드에 묶는다.
- 선택 상태: 에어비앤비처럼 흰 배경, 진한 외곽선, 약한 그림자로 선택을 표시한다.
- 카드의 텍스트, 이미지, 빈 영역을 포함한 전체 면적이 하나의 클릭·터치 대상이다.

## 색상 코드

| 항목 | 값 |
|---|---|
| 기본 배경 | `#F1F1F3` |
| 호버 배경 | `#E8EBEF` |
| 선택 배경 | `#FFFFFF` |
| 선택 외곽선·텍스트 | `#222222` |
| 기본 텍스트 | `#18181B` |
| 선택 그림자 | `rgba(0, 0, 0, 0.12)` |

## 카드 규격

| 환경 | 카드 | 모서리 | 명칭 영역 | 이미지 영역 |
|---|---:|---:|---:|---:|
| 모바일 | 88×96px | 18px | 76×34px, 12/17px, 최대 2줄 | 76×42px |
| PC | 112×108px | 18px | 96×36px, 13/18px, 최대 2줄 | 96×50px |

## 상태 규칙

- 기본: 연회색 배경, 외곽선 없음
- 호버: 기본보다 한 단계 진한 회색 배경
- 선택: 흰 배경, `#222222` 2px 내부 외곽선, 약한 그림자
- 키보드 포커스: 선택색 기반 3px 포커스 링
- 누름: 0.97배 축소 피드백
- 긴 명칭: 말줄임표 대신 단어 단위 최대 2줄 표시

## 검수 결과

- 390×844 모바일: 카드 88×96px, 이미지·명칭 순서, 하단 메뉴 비중첩 확인
- 1280×900 PC: 카드 112×108px, 세부형식 2줄 표시 확인
- 선택 상태: 흰 배경, `#222222` 테두리·텍스트, 그림자 확인
- 자동 회귀검수: 모바일·PC 포함 5건 통과
