# 코덱스-특장 인수인계 v11

## 1) 담당 범위

- 화물·특장차 가상 매물 30대에 형식별 대표 이미지를 추가하고 PC·모바일에 배포

## 2) 현재 진행 상태

- 완료: 트럭 형식별 무상표 대표 이미지 13종 생성
- 완료: 투명 배경 960×480 PNG 최적화
- 완료: 가상 매물 30대 이미지 v02 매핑
- 완료: PC·모바일 로컬 및 공개 화면 검수
- 완료: GitHub Pages 배포

## 3) 결정된 사항과 그 이유

- 실매물 사진 수신 여부가 미확인이므로 외부 사이트 사진을 복제하지 않고 무상표 생성 이미지를 사용한다.
- 같은 형식의 매물은 대표 이미지 1종을 공유한다. 형식 필터 UI 검증에 필요한 구분을 유지하면서 파일 용량과 중복을 줄이기 위함이다.
- 기존 `scenario-v01.ts`는 보존하고 이미지 매핑을 `scenario-images-v02.ts`로 분리해 버전 기록 규칙을 지킨다.

## 4) 미결 사항·막힌 점

- 제조사·모델별 실제 매물 사진 제공 여부: 미확인
- 실제 서비스 API 이미지 필드 연결: 미착수
- 전체 `npm run verify`의 관리자 헬스 엔드포인트 테스트는 기존 404로 17건 중 1건 실패한다. 트럭 범위 검증·배포 빌드·공개 화면은 통과했다.
