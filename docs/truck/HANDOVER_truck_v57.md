# 코덱스-특장 인수인계 v57

## 1) 담당 범위

- 트럭·특장 실제 필터의 `특수차` 그룹과 모든 하위 유형에 90도 정측면 이미지를 연결하고 공개 배포한다.

## 2) 현재 진행 상태

- 완료: 특수차 그룹 대표 4종과 하위 유형 25종 마스터 제작.
- 완료: 228×120 배포본 29종 정규화.
- 완료: 실제 모바일 바텀시트·PC 필터 모달 데이터 매핑.
- 완료: 자동검수, 로컬 브라우저 검수, GitHub Pages 공개 배포.

## 3) 결정된 사항과 그 이유

- 준측면은 사용하지 않고 앞·뒤·상판 면이 보이지 않는 90도 정측면만 허용한다.
- 그룹 대표와 하위 유형을 모두 별도 제작해 드릴다운 전후의 인지 차이를 유지한다.
- 실사 느낌은 유지하되 흰색·밝은 회색 차체와 최소 안전색으로 작은 슬롯의 형태 인식을 우선한다.

## 4) 미결 사항·막힌 점

- 코덱스-자료 상호 검수는 대기 중이다.
- 가상 매물은 현재 활어차 1대만 있어 나머지 하위 유형의 결과 수는 0대다.
