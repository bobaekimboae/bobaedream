## 2) 현재 진행 상태

- 완료: 모바일 트럭 형식·세부형식 카드 `72×78px` 적용
- 완료: 모바일 퀵필터 이미지 `56×30px` 통일
- 완료: 모바일 표시명 축약 및 정식 접근성 이름 유지
- 완료: 모바일 퀵필터 좌우 화살표 제거, 가로 스와이프 유지
- 완료: 트럭 매물 이미지 프레임 PC `160×112px`, 모바일 `136×96px` 적용
- 완료: 로컬 PC·모바일 실측 및 뎁스 동작 검수
- 진행 중: GitHub Pages 배포 및 공개 화면 검수

## 3) 결정된 사항과 그 이유

- 데이터값과 선택 칩의 정식 명칭은 바꾸지 않고 모바일 퀵필터 표시명만 줄였다.
- 원본 `228×120px` 퀵필터 이미지 비율에 맞춰 모바일 이미지 영역을 `56×30px`로 통일했다.
- 긴 명칭은 `64×36px` 안에서 최대 2줄로 제한해 카드 높이를 넘지 않게 했다.
- 모바일 화살표는 카드 위를 가리므로 숨기고 기본 가로 스와이프를 유지했다.
- 매물 이미지는 `contain`을 유지해 트럭 앞뒤가 잘리지 않도록 했다.

## 4) 미결 사항·막힌 점

- 전체 `npm run verify`는 기존 관리자 헬스 엔드포인트 404로 17건 중 1건 실패한다.
