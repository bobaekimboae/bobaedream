# 카고 차급 정측면 이미지 v14

- 작성일: 2026-10-04
- 적용 범위: 카고(화물)트럭 하위 차급 퀵필터

## 교정 목표

v13은 차량 폭은 차급 순서대로 증가했지만 경형이 가장 높고 준대형이 가장 낮아 보였다. v14는 이미지 생성 도구로 차체 비율을 다시 제작하고 동일한 228×120px 슬롯에 정규화하여 폭과 높이가 모두 단계적으로 증가하게 했다.

## 확정 슬롯

| 차급 | 대표 중량 | 차량 영역 | 축 구성 |
|---|---|---:|---|
| 경형 | 1톤 미만 | 164×65px | 2축 소형 |
| 소형 | 1톤급 | 176×72px | 2축 |
| 준중형 | 2.5~3.5톤 | 187×76px | 2축 |
| 중형 | 4~5톤 | 196×80px | 2축 |
| 준대형 | 7.5~8.5톤 | 207×81px | 3축 |
| 대형 | 11~25톤 | 217×83px | 4축 |

## 공통 규칙

- 캔버스: 228×120px 투명 알파.
- 방향: 차량 전면이 왼쪽인 90도 정측면.
- 중심: 캔버스 수평 중앙.
- 바닥선: 114px.
- 보디: 적재물이 없는 개방형 평적재함.
- 색상: 흰색 또는 밝은 회색.
- 금지: 제조사 로고, 글자, 워터마크, 원근 왜곡, 축 수 변경, 윙·탑·덤프 보디.

## 생성 방식

기존 v13을 참조 이미지로 사용하여 내장 이미지 생성 도구로 차급별 차체 비율을 교정했다. 생성 후 축 수, 정측면, 적재함, 투명 배경을 검사하고, 228×120px 슬롯으로 정규화했다.
