# 코덱스-특장 인수인계 v52

## 1) 담당 범위

- 트랙터·트레일러 하위 유형용 측면 이미지 시안을 제작하고 실제 바텀시트에 연결한다.

## 2) 현재 진행 상태

- 완료: 기타를 제외한 트레일러 하위 유형 12종 AI 측면 이미지 제작.
- 완료: 228×120px, 바닥선 y=111 배포본 정규화.
- 완료: 실제 모바일 트랙터·트레일러 하위 유형 바텀시트 연결과 로컬 확인.
- 진행 중: 사용자 시안 검토.
- 미착수: 트랙터·헤드와 기타 트레일러 신규 이미지 제작.

## 3) 결정된 사항과 그 이유

- 트랙터 헤드를 제외해 긴 트레일러 구조를 작은 슬롯에서 최대한 크게 보인다.
- 킹핀 방향을 왼쪽, 후축을 오른쪽으로 통일한다.
- 정측면에 가까운 10도 준측면을 사용해 형상 비교를 우선한다.

## 4) 미결 사항·막힌 점

- 평판 트레일러는 56×40px에서 데크가 얇아 명암 보완이 필요하다.
- 매물 0대 항목은 비활성 투명도로 이미지가 더 흐리게 보인다.
- 공개 배포는 아직 하지 않았다.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 기존 트럭 측면 이미지 v02를 스타일 기준으로 사용했다.
- 코덱스-자료 상호 검수는 대기 중이다.

## 7) 검수 상태

- `npm run verify:qf`: 통과.
- `npm run build`: 통과.
- 로컬 모바일 바텀시트: 12종 연결과 이미지 경로 확인.
- 공개 배포: 미검수.

## 8) 다음에 할 일

1. 사용자에게 12종 시안을 검토받는다.
2. 평판 데크 대비를 보완한다.
3. 전체 모바일·PC 검수 후 공개 배포한다.
