# 코덱스-특장 인수인계 v43

## 1) 담당 범위

- 트럭 유형 바텀시트·PC 모달의 행 구분선을 아이콘 영역까지 확장한다.

## 2) 현재 진행 상태

- 완료: 체크박스 영역은 유지하고 구분선 시작점을 명칭 열 96px에서 아이콘 열 52px로 이동.
- 진행 중: 모바일·PC 시각 검수 및 공개 배포.
- 미착수: 실제 운영 매물 API 대수 연동.

## 3) 결정된 사항과 그 이유

- 구분선은 행 좌측 52px에서 시작한다. 체크박스 터치 영역은 비우면서 아이콘 아래까지 행 경계를 명확하게 표시하기 위해서다.
- 제목·닫기 버튼·행 높이·체크박스·아이콘·명칭 열과 선택 동작은 v42 규격을 유지한다.

## 4) 미결 사항·막힌 점

- 실제 운영 매물 API 대수 연동은 미확인이다.
- 코덱스-자료 상호 검수는 미검수다.

## 5) 산출물 목록

- `truck-type-picker.css` / v43 / `src/prototype/filters/`
- `HANDOVER_truck_v43.md` / v43 / `docs/truck/`

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 사용자의 수정 요청 `아이콘까지 구분선 긋자`를 기준으로 반영했다.
- 코덱스-자료 검수 대기.

## 7) 검수 상태

- 로컬 코드 반영 완료.
- 모바일·PC 시각 검수 진행 중.
- 공개 배포 진행 중.
