# 트럭 2뎁스 칩 레일 곡률 보완 계획서 v03

## 보완 목표

- Car300 02-1 캡처의 연식 카드 레일처럼 첫 변경 카드부터 마지막 옵션까지 같은 곡률을 사용한다.
- 마지막 칩의 오른쪽 모서리가 화면 경계에 붙지 않도록 기존 레일 끝 여백을 유지한다.

## 적용 규격

- 공통 칩 곡률: 8px
- 첫 `형식 변경` 칩: 64×52px, 흰색, 1px 외곽선
- 일반 차급 칩: 최소 88×52px, `#F3F3F5`
- 칩 간격: 8px
- 레일 끝 여백: 모바일 16px, PC 20px
- 적용 범위: 트럭 2뎁스 텍스트 칩 전체와 마지막 칩

## 검수

- 첫 칩·중간 칩·마지막 칩의 `border-radius: 8px` 확인
- 모바일 390×844에서 마지막 칩까지 스크롤하고 오른쪽 16px 여백 확인
- PC 1280×900에서 오른쪽 20px 여백 확인
- 형식 변경 복귀와 차급 선택 흐름 회귀 확인
