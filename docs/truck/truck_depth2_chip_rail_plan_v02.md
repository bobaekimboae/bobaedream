# 트럭 2뎁스 칩 레일 보완 계획서 v02

## 보완 목표

- Car300 캡처처럼 하위 선택 레일의 첫 칸에 상위 단계를 바꾸는 외곽선 칩을 둔다.
- 일반 회색 옵션과 시각적으로 구분하면서 같은 높이와 세로 리듬을 유지한다.

## 적용 규격

- 문구: `형식 변경`
- 위치: 2뎁스 가로 레일의 첫 번째 항목
- 크기: 64×52px
- 배경: `#FFFFFF`
- 테두리: `1px solid #D9D9DD`
- 모서리: 12px
- 글자: 14/19px, 500, `#222`, 두 줄 중앙 정렬
- 동작: 선택 시 현재 트럭 형식·하위 차급·톤수를 해제하고 1뎁스 트럭 형식 레일로 복귀

## 검수

- 모바일·PC에서 첫 칸 위치와 8px 옵션 간격 확인
- 일반 차급 칩과 높이·곡률 일치 확인
- `형식 변경` 선택 후 1뎁스 복귀 확인
- 기존 차급 선택 → 정확한 톤수 흐름 회귀 확인
