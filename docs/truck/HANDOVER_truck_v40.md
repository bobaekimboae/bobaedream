# 코덱스-특장 인수인계 v40

## 1) 담당 범위

- 실제 보배드림 트럭·특장 필터의 최종 트럭 유형 트리를 PC 모달·모바일 바텀시트로 공개 배포하고 검증한다.

## 2) 현재 진행 상태

- 완료: 최종 13개 상위 유형과 하위 유형 트리 공개 배포.
- 완료: 트럭 가상 매물 30대의 유형·세부 유형 교체.
- 완료: 모바일 바텀시트, PC 중앙 모달, 상단 필터칩, PC 좌측 필터 연결.
- 완료: 선택값 URL 저장과 실제 목록·대수 연동.
- 완료: GitHub Pages 공개 모바일·PC 검증.

## 3) 결정된 사항과 그 이유

- 화면 명칭은 `트럭 유형`을 사용한다. 차체·용도 유형을 우선 탐색하고 적재량·장비는 별도 필터 축으로 유지하기 때문이다.
- 핀노 캡처 폴더의 체크박스·단일 열·행 구분·대수·하위 화살표 구조를 참고한다.
- 선택 색상은 핀노의 파란색이 아니라 에어비앤비식 블랙 `#111`과 흰 체크를 사용한다.
- 행 규격은 54px, 체크박스 20px, 이미지 슬롯 32px, 열 간격 12px다.
- PC는 중앙 모달, 모바일은 바텀시트를 사용하되 동일 컴포넌트와 상태를 공유한다.
- 중간 그룹 선택은 그 아래 실제 매물을 모두 포함한다.

## 4) 미결 사항·막힌 점

- 실제 운영 매물 API와 대수 연동은 미확인이다. 현재 대수는 UI 검증용 가상 매물 30대 기준이다.
