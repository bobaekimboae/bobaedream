# 코덱스-특장 인수인계 v48

## 1) 담당 범위

- 공개 트럭 유형 바텀필터의 이미지 인지성을 모바일·PC·뎁스별로 교차검수한다.

## 2) 현재 진행 상태

- 완료: 모바일 목록 상단 퀵필터와 트럭 유형 바텀시트의 이미지 크기 비교.
- 완료: 모바일 루트와 카고 하위 유형의 이미지 슬롯·파일 매핑 검수.
- 완료: PC 중앙 모달의 이미지 슬롯·파일 매핑 검수.
- 완료: 개선 규격과 전용 이미지 교체 우선순위 문서화.
- 미착수: UI 규격 수정, 신규 이미지 제작, 공개 배포.

## 3) 결정된 사항과 그 이유

- 인지성 저하의 주원인은 228×120 원본 품질이 아니라 32×28px 표시 요소, 흰 배경 대비, 형제 노드 간 이미지 중복이다.
- 1차 권장 규격은 행 60px, 이미지 표면 56×40px, `#F7F7F7`, 반경 6px이다. 2:1 차량 이미지가 실제 약 56×30px로 그려져야 특장 장비 실루엣이 남기 때문이다.
- 상위 유형 전용 이미지와 카고 톤급 전용 이미지를 별도 제작해야 한다. 단순 확대만으로는 동일 파일 재사용 문제가 해결되지 않기 때문이다.

## 4) 미결 사항·막힌 점

- 사용자 승인 전이므로 실제 UI와 에셋은 수정하지 않았다.
- 전용 이미지 제작은 코덱스-자료와 상호 검수가 필요하다.
- 실제 운영 매물 API 대수 연동은 미확인이다.

## 5) 산출물 목록

- `truck_type_image_audit_v01.md` / v01 / `docs/truck/`
- `HANDOVER_truck_v48.md` / v48 / `docs/truck/`

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 기존 코덱스-자료의 228×120 이미지 슬롯 규칙을 기준으로 원본과 표시값을 대조했다.
- 코덱스-자료 상호 검수와 상위·카고 하위 전용 이미지 제작은 대기 중이다.

## 7) 검수 상태

- 공개 모바일 394×852: 루트·카고 하위 검수완료.
- 공개 PC 1280×720: 중앙 모달 검수완료.
- 상단 퀵필터 64×64px와 바텀필터 32×28px 비교 완료.
- 중복 매핑 확인: 윙바디·탑차/냉장·냉동차, 특수차/기타, 카고 준중형/중형/준대형.
- 코드 변경·배포 없음.
- 코덱스-자료 상호 검수 미검수.

## 8) 다음에 할 일

1. 사용자 승인 시 행 60px·이미지 56×40px 표면을 모바일·PC에 적용한다.
2. 냉장·냉동차, 특수차, 트랙터·트레일러, 카고 준중형·중형·준대형 전용 이미지를 제작한다.
3. 동일 부모 아래 이미지 파일 중복 검사를 자동화한다.
4. 모바일·PC의 루트·2뎁스·3뎁스와 선택·초기화·확정 동작을 회귀검수한다.
5. 코덱스-자료 상호 검수를 요청한다.
