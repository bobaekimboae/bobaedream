- 트럭·특장 형식·세부형식 이미지 카드의 카드·차량 이미지 비율 보정

## 2) 현재 진행 상태

- 완료: 이미지 위·텍스트 아래 순서 적용
- 완료: 모바일 이미지 영역을 80×47px로 확대
- 완료: PC 이미지 영역을 104×54px로 확대
- 완료: 카드 외곽 크기와 Airbnb형 선택 상태 유지
- 진행 중: 모바일·PC 로컬 시각 검수
- 미착수: GitHub Pages 배포

## 3) 결정된 사항과 그 이유

- 한 행 노출 수를 유지하기 위해 카드 외곽 크기는 바꾸지 않았다.
- 차량 식별력을 높이기 위해 내부 좌우·상단 여백을 줄이고 이미지 면적만 확대했다.
- 차량 바닥선 정렬과 하단 2줄 명칭 영역은 유지했다.

## 4) 미결 사항·막힌 점
