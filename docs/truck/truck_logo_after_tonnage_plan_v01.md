# 트럭 톤수 다음 제조사 로고 뎁스 계획 v01

- 작성일: 2026-10-04
- 담당: 코덱스-중고차
- 적용 대상: 트럭 · 특장 퀵필터

## 목표

- 퀵필터 순서를 `형식 → 차급 → 톤수·규격 → 제조사 로고 → 모델`로 고정한다.
- 톤수·규격을 선택하기 전에는 제조사 로고를 노출하지 않는다.
- 제조사 로고는 트럭 전용 상위 10개를 초톳 브랜드 슬롯 규격으로 표시한다.

## 초톳 슬롯 규칙

| 항목 | 모바일 | PC |
|---|---:|---:|
| 셀 | 76×102px | 84×102px |
| 로고 상자 | 40×40px | 40×40px |
| 셀 간격 | 8px | 8px |
| 첫 셀 시작 | 16px | 20px |
| 이름 상자 | 68px, 최대 2줄 | 76px, 최대 2줄 |
| 이름 | 14px / 21px / 400 / `#595959` | 동일 |

- 로고는 투명 배경 원본을 `contain`으로 중앙 배치한다.
- 로고별 비율은 유지하고 임의 확대·변형하지 않는다.
- 별도 카드 배경·테두리·둥근 모서리는 사용하지 않는다.
- 로고 아래 이름은 긴 경우 2줄까지만 표시한다.
- 초톳 모바일웹의 64×56 압축형은 별도 화면 변형으로 기록만 유지한다. 현재 보배 매물 목록 퀵필터에는 기존에 확정한 초톳 앱·카테고리 레일형 76×102 규칙을 적용한다.

## 제조사 순서

1. 현대
2. 기아
3. 타타대우
4. KG모빌리티
5. 볼보
6. 스카니아

8. 벤츠
9. 이베코
10. 다프(DAF)
11. 전체 브랜드

## 동작 규칙

- 톤수·규격을 선택하면 같은 퀵필터 자리가 제조사 로고 레일로 바뀐다.
- 제조사 선택 시 모델 뎁스로 이동한다.
- 차급 또는 톤수를 다시 선택하면 제조사·모델 선택을 초기화한다.
- 톤수 단계가 없는 형식은 차급 선택 직후 제조사 로고를 노출한다.

## 완료 기준

- 모바일·PC에서 톤수 선택 전 제조사 레일이 보이지 않는다.
- 톤수 선택 후 제조사 레일이 보인다.
- 10개 제조사 이미지가 404 없이 표시된다.
- 모바일·PC 슬롯 수치가 위 표와 일치한다.
- 제조사 선택 후 모델 레일로 이동한다.
