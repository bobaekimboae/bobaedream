# 코덱스-특장 인수인계 v35

## 1) 담당 범위

- 트럭·특장 초톳형 브랜드·유형 퀵필터의 위아래 간격 조정.

## 2) 현재 진행 상태

- 완료: 모바일·PC 기존 간격 실측.
- 완료: 필터 줄과 이미지 행 사이를 8px로 통일.
- 완료: 브랜드 로고·명칭 및 유형 이미지·명칭 간격 축소.
- 완료: 모바일·PC 자동 실측과 로컬 시각 검수.
- 진행 중: 공개 배포.

## 3) 결정된 사항과 그 이유

- 카드 크기와 터치 영역은 유지하고 내부 콘텐츠만 재배치했다. 조밀도를 높이면서 터치 편의성을 보존하기 위해서다.
- 모바일·PC 이미지 행의 위쪽 외부 간격은 8px로 통일했다.
- 브랜드 로고와 명칭 사이는 8px, 유형 이미지와 명칭 사이는 모바일 2px·PC 4px로 정했다.

## 4) 미결 사항·막힌 점

- 공개 배포 후 실제 화면 재검수가 남아 있다.
- 코덱스-자료 상호 검수는 미검수다.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 다른 코덱스 자료는 수정하지 않았다.
- 코덱스-자료의 상호 검수를 기다린다.

## 7) 검수 상태

- `npm run verify:qf`: 통과.
- 모바일·PC 간격 자동 검사: 통과.
- 콘솔 오류: 0건.
- 공개 배포: 대기.
