# 견인·운송차 유형 이미지 v04

- 작성일: 2026-10-04
- 상태: 제작·정규화·64×40 검수 완료

## 변경 이유

v03의 2단 카캐리어는 작은 슬롯에서 일반 적재차처럼 보여 `견인·운송차` 식별이 약했다.

## v04 식별 규칙

- 좌향 90° 정측면을 유지한다.
- 흰색 캡과 차콜 견인차 본체를 사용한다.
- 주황색 언더리프트·휠 크래들을 큰 식별점으로 사용한다.
- 피견인 승용차의 앞바퀴가 들리고 뒷바퀴가 지면에 닿은 상태를 보여준다.
- 2단 카캐리어·일반 평판·크레인 카고 형태는 사용하지 않는다.
- 초톳 기준 모바일 64×40 슬롯에서도 견인 동작이 읽혀야 한다.
