# 코덱스-특장 인수인계 v18

## 1) 담당 범위

- 트럭·특장 PC·모바일 차량 이미지 규격 및 모바일 퀵필터 긴 명칭 감사

## 2) 현재 진행 상태

- 완료: 공개 PC·모바일 퀵필터 화면 캡처
- 완료: 차량 매물 및 퀵필터 이미지 렌더링 크기 실측
- 완료: 형식 → 세부형식 → 적재·규격 전환 교차검증
- 완료: 긴 명칭 표시 개선안 작성
- 미착수: 구현 변경 및 재배포

## 3) 결정된 사항과 그 이유

- 이번 요청은 진단과 개선 아이디어 범위로 해석해 소스 코드는 변경하지 않았다.
- 모바일 퀵필터의 핵심 원인은 `64×74px` 카드 안에서 3줄 라벨이 `54px`까지 늘어나는 높이 초과다.
- 이미지 왜곡보다 매물 원본 2:1과 정사각형 프레임의 비율 불일치가 차체를 작아 보이게 하는 원인이다.

## 4) 미결 사항·막힌 점

- 모바일 카드 `72×78px`, 이미지 `56×30px`, 2줄 라벨 및 짧은 표시명 적용 여부 결정 필요
- 매물 이미지 프레임 PC `160×112px`, 모바일 `136×96px` 비교 시안 적용 여부 결정 필요
- 실제 세로형 모바일 기기에서 하단 내비게이션과의 간격 재확인 필요
