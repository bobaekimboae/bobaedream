# 트럭 형식 이미지 카드 시안 v02

## 변경 요청 반영

- 카드 안의 순서를 `차량 이미지 → 텍스트`로 변경했다.
- 기본 FINN형 카드와 Airbnb형 선택 상태는 v01과 동일하게 유지한다.

## 적용 범위

- 트럭·특장 전용 형식 및 세부형식 퀵필터
- 모바일과 PC 공통
- 다른 카테고리에는 적용하지 않음

## 색상 코드

| 항목 | 값 |
|---|---|
| 기본 배경 | `#F1F1F3` |
| 호버 배경 | `#E8EBEF` |
| 선택 배경 | `#FFFFFF` |
| 선택 외곽선·텍스트 | `#222222` |
| 기본 텍스트 | `#18181B` |
| 선택 그림자 | `rgba(0, 0, 0, 0.12)` |

## 카드 규격

| 환경 | 카드 | 모서리 | 이미지 영역 | 하단 명칭 영역 |
|---|---:|---:|---:|---:|
| 모바일 | 88×96px | 18px | 76×42px | 76×34px, 12/17px, 최대 2줄 |
| PC | 112×108px | 18px | 96×50px | 96×36px, 13/18px, 최대 2줄 |

## 상태 규칙

- 기본: 연회색 배경, 외곽선 없음
- 호버: 기본보다 한 단계 진한 회색 배경
- 선택: 흰 배경, `#222222` 2px 내부 외곽선, 약한 그림자
- 키보드 포커스: 선택색 기반 3px 포커스 링
- 누름: 0.97배 축소 피드백
- 긴 명칭: 하단에서 단어 단위 최대 2줄 표시
