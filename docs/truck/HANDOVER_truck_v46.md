# 코덱스-특장 인수인계 v46

## 1) 담당 범위

- 제시된 기본 필터 주소와 트럭 유형 모바일 바텀시트의 외곽·헤더·하단 버튼을 교차검수하고 동일 규격으로 맞춘다.

## 2) 현재 진행 상태

- 완료: 기준 기본 필터의 모바일 시트·하단 버튼 실측.
- 완료: 트럭 유형 모바일 시트 외곽·헤더·하단 버튼 통일.
- 완료: 모바일 필터 적용 동작과 PC 회귀 검증.
- 진행 중: 공개 배포.

## 3) 결정된 사항과 그 이유

- 모바일 트럭 유형 시트는 기본 전체 필터와 같은 폭 최대 520px, 높이 `100dvh - 48px`, 최대 780px, 상단 라운드 20px을 사용한다.
- 모바일 헤더는 60px, 제목은 좌측 20px의 20/28px 700으로 통일한다.
- 모바일 하단 액션은 80px, 패딩 14px 20px, 버튼 간격 8px으로 통일한다.
- `초기화`는 112×44px, `N대 보기`는 남은 폭×44px과 파란색 `#1B4C8C`을 사용한다.
- PC는 모바일 전체 필터가 아니라 PC 공통 모달 규격을 유지한다.
