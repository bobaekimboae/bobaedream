# 트럭 2뎁스 칩 레일 작업 계획서 v01

## 목표

- 트럭 형식을 선택한 다음 나타나는 2뎁스에서 반복 이미지를 제거한다.
- 차급명 또는 세부 형식을 빠르게 훑을 수 있는 가로 카드형 칩 레일로 교체한다.
- 카고 차급은 `차급명 + 적재중량 범위`를 2줄로 보여주고, 선택 뒤 정확한 적재중량 칩으로 이어지게 한다.

## 디자인 결정

- 참고 구조: Car300의 계층형 2줄 카드 칩.
- 보배드림 적용: Pretendard, 중립 회색 배경, 검정 본문, 선택 후 상단 적용 칩으로 상태를 압축한다.
- 슬롯: 높이 52px, 최소 너비 88px, 최대 너비 148px, 모서리 12px, 칩 간격 8px.
- 모바일 좌우 여백 16px, PC 좌우 여백 20px.
- 카고: 1행 차급명 14/19px 600, 2행 대표 적재 범위 12/16px 500.
- 기타 트럭 형식: 명칭을 최대 2줄로 표시하고 이미지 영역은 만들지 않는다.

## 데이터 연결 교정

- 기존 적재중량 원본 값은 유지한다.
- 새 6개 차급과 구형 적재중량 키를 범위로 연결한다.
- 서비스 차급은 법정 차종 분류가 아닌 빠른 탐색용임을 전제로 한다.
- 선택 흐름: 트럭 형식 → 2뎁스 카드 칩 → 정확한 적재중량 칩 → 제조사.

## 검수 항목

- 390×844 모바일과 1280×900 PC에서 칩 높이·여백·가로 스크롤을 확인한다.
- 카고 6개 차급 모두 2줄이 잘리지 않는지 확인한다.
- 2뎁스 선택 후 정확한 적재중량 단계가 나타나는지 확인한다.
- 긴 세부 형식은 2줄 안에서 읽히고 다른 UI를 밀지 않는지 확인한다.
- 키보드 포커스, 터치 상태, 콘솔 오류, 이미지 404를 확인한다.
- 빌드와 관련 회귀 테스트를 통과한 뒤 GitHub Pages에 공개 배포한다.
