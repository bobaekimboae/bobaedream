# 코덱스-특장 인수인계 v37

## 1) 담당 범위

- 트럭·특장 초톳형 형식·세부형식·유형 퀵필터의 이미지–명칭 간격 및 명칭 크기 보정과 공개 배포.

## 2) 현재 진행 상태

- 완료: 드라이브 초톳 카테고리·브랜드 캡처와 현재 배포본 교차 검수.
- 완료: 모바일·PC 유형 이미지–명칭 간격 및 모바일 명칭 크기 코드 반영.
- 완료: 로컬 자동·시각 검수.
- 진행 중: GitHub Pages 공개 배포.

## 3) 결정된 사항과 그 이유

- 브랜드 로고 규격과 간격은 시각 측정 결과 초톳과 유사해 유지한다.
- 유형 이미지–명칭 간격은 모바일 7px·PC 9px로 늘린다.
- 모바일 유형 명칭은 초톳의 가독성에 맞춰 12px에서 14px로 올린다.
- 트럭의 긴 명칭을 위해 한 줄 강제 대신 최대 두 줄을 유지한다.

## 4) 미결 사항·막힌 점

- 정확한 초톳 DOM CSS 원본값은 미확인이다. 캡처 환산값을 사용했다.
- 코덱스-자료 상호 검수는 미검수다.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 드라이브의 초톳 캡처 2장을 읽기 전용 기준 자료로 사용했다.
- 다른 코덱스 구현 파일은 수정하지 않았다.

## 7) 검수 상태

- 자동 검수: 모바일·PC 슬롯 수치 통과, 콘솔 오류 0건.
- 모바일·PC 시각 검수: 초톳 캡처와 실사이트 대조 완료.
- `npm run verify:qf`, `npm run build`, `npm run test:sites`: 통과.

- 공개 배포: 진행 중.
