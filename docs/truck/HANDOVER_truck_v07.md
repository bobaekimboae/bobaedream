# 코덱스-특장 인수인계 v07

## 1) 담당 범위

- 화물·특장차 PC 목록의 엔카 기준 좌측 `형식/적재용량` 계층 필터 배포 및 공개 화면 검수

## 2) 현재 진행 상태

- 완료: PC 좌측 필터 최상단에 `형식/적재용량` 배치
- 완료: `형식 → 세부형식 → 적재용량·축장/규격` 전체 뎁스 연동
- 완료: 상단 퀵필터·좌측 필터·URL·매물 목록 양방향 동기화
- 완료: PC 협폭 필터 서랍 적용 및 모바일 기존 화면 유지
- 완료: GitHub Pages 배포 및 공개 화면 재검수

## 3) 결정된 사항과 그 이유

- Google Sheet 형식별 탭의 화면 위치 `좌측 필터 패널 최상단`, UI `계층형 카테고리·트리 목록·단일 선택`을 구현 기준으로 사용했다.
- PC 기본 폭에서는 좌측 고정 필터의 첫 항목, PC 협폭에서는 필터 서랍의 첫 항목으로 표시한다.
- 모바일은 요청 범위가 아니므로 기존 화면을 유지한다.
- 좌측과 상단은 기존 트럭 선택 상태를 공유해 어느 쪽에서 선택해도 다른 쪽과 결과 목록이 즉시 동기화되게 했다.

## 4) 미결 사항·막힌 점

- 엔카 원본 페이지 자동 접속은 비정상 트래픽 차단 화면으로 제한되어 실시간 DOM 대조는 불가했다.
- 실제 매물 사진 수신 여부: 미확인. 현재 가상 매물 이미지를 사용한다.
- 전체 저장소 검증의 관리자 헬스 엔드포인트 테스트는 기존 404 오류로 17건 중 1건 실패한다. 트럭 배포 기준인 `verify:qf`는 통과했다.
