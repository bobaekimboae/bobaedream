# 코덱스-특장 인수인계 v06

## 1) 담당 범위

- 화물·특장차 PC 목록의 엔카 기준 좌측 `형식/적재용량` 계층 필터

## 2) 현재 진행 상태

- 완료: PC 좌측 필터 최상단에 `형식/적재용량` 추가
- 완료: `형식 → 세부형식 → 적재용량·축장/규격` 드릴다운
- 완료: 상단 퀵필터·URL·매물 목록과 양방향 상태 동기화
- 완료: PC 협폭 필터 서랍 적용 및 모바일 미노출 확인
- 완료: 로컬 빌드·클릭·시각 검수
- 진행 중: 배포 대기

## 3) 결정된 사항과 그 이유

- Google Sheet 형식별 탭의 화면 위치 `좌측 필터 패널 최상단`, UI `계층형 카테고리·트리 목록·단일 선택`을 구현 기준으로 사용했다.
- PC 기본 폭에서는 좌측 고정 필터의 첫 항목, PC 협폭에서는 필터 서랍의 첫 항목으로 표시한다.
- 모바일은 요청 범위가 아니므로 기존 화면을 유지한다.
- 좌측 필터와 상단 퀵필터는 별도 상태를 만들지 않고 기존 트럭 선택 상태를 공유한다.

## 4) 미결 사항·막힌 점

- 엔카 원본 페이지 자동 접속은 비정상 트래픽 차단 화면으로 제한되어 실시간 DOM 대조는 불가했다.
- 실제 매물 사진 수신 여부: 미확인. 기존 임시 아이콘을 유지한다.
