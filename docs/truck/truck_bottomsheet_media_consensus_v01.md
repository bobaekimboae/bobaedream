## 검토자별 독립 의견

### 의견 A — 모바일·PC 행 밀도

- 공통 미디어 열 `56×40px`.
- 로고 외곽 `40×40px`, 실제 심볼 최대 `32×32px`, 가로 워드마크 최대 `36×20px`.
- 차량 유형 `56×40px`, 실제 실루엣 최소 `52×28px`.
- 모바일 행 `64px`, PC 행 `60px`.
- 당근 모델의 가독성과 이처의 밀도를 절충하는 안이 적합.

### 의견 B — 이미지 제작·광학 크기

- 텍스트 시작선을 맞추기 위한 공통 미디어 열은 필요하지만 로고와 차량의 실제 크기를 같게 만들면 안 됨.
- 로고는 `40×40px` 타일 안에서 실제 심볼 최대 `32×32px`, 워드마크 최대 `40×18px`.
- 차량은 `56×40px`, 실루엣 폭 `50px 이상`.
- 흰색·은색 차량은 `#F7F7F7` 표면과 약한 그림자 또는 `#ECECEC` 경계가 필요.
- 트럭은 차체보다 적재함·탱크·크레인 등 기능 장비가 슬롯 폭의 60% 이상 보이게 제작.

### 의견 C — 정보구조·접근성

- 브랜드 필터 행에는 로고만, 트럭 유형 행에는 차량 이미지 만 배치. 한 행에 둘을 함께 넣지 않음.
- 공통 열 `56px`, 로고 `40×40px`, 트럭 유형 `56×36px`.
- 모바일 행 `64px`, PC 행 `60px`. 긴 명칭이 2줄이면 모바일 `72px`, PC `68px`까지 확장.
- 이미지는 보조정보이며 체크박스·텍스트·매물 수만으로도 의미가 전달되어야 함.
- 3뎁스 사진은 오인 위험이 있으므로 기본 미사용, 필요한 경우 단색 도식 아이콘 사용.

## 최종 합의 규격

### 행과 정렬

| 항목 | 모바일 | PC |
|---|---:|---:|
| 기본 행 높이 | 64px | 60px |
| 2줄 명칭 행 | 72px | 68px |
| 체크박스 | 20×20px | 20×20px |
| 공통 미디어 열 | 56×40px | 56×40px |
| 체크박스→미디어 | 12px | 12px |
| 미디어→명칭 | 12px | 12px |
| 명칭 | 15~16px | 15px |

PC 모달은 폭이 넓어도 이미지를 축소하지 않는다. 추가 폭은 긴 명칭과 대수 영역에 사용한다.

### 브랜드 로고

| 유형 | 외곽 슬롯 | 실제 로고 상한 |
|---|---:|---:|
| 심볼형·원형 | 40×40px | 32×32px, 복잡한 엠블럼은 최대 34×34px |
| 가로 워드마크 | 40×40px | 40×18px |
| 세로형 | 40×40px | 24×34px |

- `contain`, 중앙 정렬, 투명 배경.
- 원형 테두리는 기본적으로 사용하지 않는다. 선택 표면 또는 브랜드 원본에 원이 포함된 경우만 유지한다.
- 같은 56px 미디어 열의 중앙에 40px 로고 슬롯을 놓아 차량 이미지 행과 명칭 시작선을 맞춘다.

### 트럭 유형·모델 이미지

- 표시 슬롯 `56×40px`.
- 권장 실제 실루엣 폭 `50~54px`, 높이 `28~38px`.
- `object-fit: contain`, `object-position: center bottom`.
- 표면 `#F7F7F7`, 반경 `6px`. 경계가 필요하면 `1px #ECECEC`.
- 밝은 차량은 바닥 아래 약한 그림자를 사용하되 큰 카드 그림자는 금지.
- 앞 3/4 또는 10~15도 약측면. 트럭 유형에서는 후방 장비가 슬롯 폭의 60% 이상 보이도록 한다.
- 기존 228×120 마스터를 유지할 경우 투명 여백을 제거하고 차체 폭을 90% 이상 채운다.

## 접근성·예외

- 장식 이미지는 `alt=""`, `aria-hidden="true"`.
- 체크박스 접근성 이름은 `항목명 + 매물 수`를 포함한다.
- 하위 화살표는 `○○ 하위 유형 보기`라는 별도 접근성 이름을 갖는다.
- 선택 상태는 이미지·색상만으로 표현하지 않고 체크박스와 `aria-checked`를 함께 사용한다.
- 로고나 이미지가 없을 때도 56px 열을 유지하고 중립 플레이스홀더를 사용한다.
- 같은 부모 아래 서로 다른 항목에 동일 차량 이미지를 배정하지 않는다.

## 1차 시안 권장값

`모바일 64px 행 / PC 60px 행 / 공통 56px 미디어 열 / 로고 40×40px / 차량 56×40px`

현재의 `32×28px` 차량 요소는 로고에는 최소 수준이지만 트럭 실루엣과 특장 장비를 구분하기에는 부족하다. 1차 시안에서는 위 규격 하나만 적용해 루트·2뎁스·3뎁스를 비교한 뒤, 필요할 경우 차량 폭만 60~64px로 올리는 순서가 안전하다.
