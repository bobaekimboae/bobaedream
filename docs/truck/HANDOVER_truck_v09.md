# 코덱스-특장 인수인계 v09

## 1) 담당 범위

- 화물·특장차의 엔카 기준 필터를 `트럭 전용 필터`로 그룹화하고 PC·모바일에 배포

## 2) 현재 진행 상태

- 완료: 엔카 화물·특장 실화면 필터 순서·선택값 확인
- 완료: PC 좌측·협폭 필터 서랍의 트럭 전용 필터와 입력 동작
- 완료: 모바일 전체 필터의 같은 그룹·순서·형식 드릴다운
- 완료: 가상 트럭 30대 결과 연동, 확인 버튼 대수 갱신, 차량번호·판매자 검색
- 완료: GitHub Pages 배포 및 공개 화면 재검수

## 3) 결정된 사항과 그 이유

- `엔카 진단`은 경쟁사 고유 명칭을 피하려고 `트럭 진단`으로 표시하며 `진단 완료` 값으로 동작한다.
- 모든 트럭 전용 입력은 같은 가상 매물 필드를 사용해 PC·모바일 결과가 일치한다.
- 가상 매물의 필터값은 UI 검증용이며 실제 판매 정보가 아니다.

## 4) 미결 사항·막힌 점

- 실제 매물 사진·자료팀 슬롯 수신 여부: 미확인
- 실제 서비스 API의 필터 코드값 매핑: 미착수
- 전체 `npm run verify`의 관리자 헬스 엔드포인트 테스트는 기존 404로 17건 중 1건 실패한다. 트럭 범위 `verify:qf`와 배포 빌드는 통과했다.
