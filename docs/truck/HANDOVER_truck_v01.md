# 코덱스-특장 인수인계 v01

## 1) 담당 범위

- 화물·특장차 시안의 엔카 기준 형식·세부 형식 퀵필터

## 2) 현재 진행 상태

- 완료: 엔카 형식 13개 및 세부 형식 88개 데이터 정의
- 완료: 트럭·특장 선택 흐름 `형식 → 세부 형식 → 제조사` 연결
- 완료: 선택 칩, 단계별 해제, 초기화, URL 상태 연결
- 진행 중: 자동 검수
- 미착수: 공개 배포

## 3) 결정된 사항과 그 이유

- 엔카 매핑 자료의 명칭을 그대로 사용한다. 원본 자료와 화면 값의 일치가 우선이기 때문이다.
- 트럭 형식 선택은 기존 퀵필터 알약 레일을 재사용한다. 모바일·PC 동작과 접근성 구조를 함께 유지하기 위해서다.

## 4) 미결 사항·막힌 점

- `트렉터`, `로우베드/릴리리` 표기 교정 여부: 미확인
- 트럭 가상 매물과 형식·세부 형식별 결과 수 연결: 미확인
