## 촬영 키트 연결(보배드림 추가)

- 사진 추가 칸을 누르면 초톳 앱은 바로 자체 앨범이 열린다. 웹은 휴대폰 앨범을 그릴 수 없어 같은 자리에 `사진 · 영상 추가` 시트를 둔다: ① `촬영 키트로 찍기(추천)` + `딜러 간편 / 촬영팀 전문` ② `앨범에서 고르기`(여러 장, 사진 10MB 초과 제외, 최대 30) ③ `카메라로 바로 찍기`.
- ①을 누르면 지금 입력을 IndexedDB `bbm-register`에 보관하고 `nuxt-shootkit/?from=register&cat=…&role=dealer|crew&back=…`로 간다. 촬영 키트는 이때 소재지 칸을 숨기고 등록 버튼을 `등록 화면으로 보내기`로 바꾼다. 누르면 사진 · 영상을 같은 사이트 IndexedDB `bbm-shootkit/drafts`의 `handoff` 한 건으로 두고 돌아온다. 등록 화면은 그 한 건을 읽어 맨 앞에 넣고 지운다(두 번 들어오지 않음).

## 등록 시간 측정

- 시작 = 등록 화면 진입. 지점 = 첫 사진 · 설명 · 가격 · 상세 정보 · 촬영 키트 완료 · 미리보기 · 등록하기 누름 · 등록 완료. 시작 시각은 이 탭(sessionStorage)에 두어 촬영 키트에 다녀와도 이어서 잰다.
- 등록 완료 화면에 걸린 시간과 지점별 시각을 보여 주고, 최근 50건을 이 브라우저(localStorage `bbm-register-runs`)에 쌓는다. `&debug=1`이면 오른쪽 아래에 흐르는 시간이 보인다.
- 서버가 없어 업로드 · 영상 처리 대기는 들어 있지 않다. 사람이 손으로 한 시간만 잰다.
