# 보배드림 퀵필터 에셋 지침 v1.6 — 차량 이미지 · 브랜드 로고
적용 범위: 매물리스트 뎁스 퀵필터(DepthCard 80×72), 차종 시트, 메인 유형·브랜드 칩
추가 기준: 초톳 1080×2340 캡처 8장, 384 CSS px·2.8125배율 실측(2026-10-03)

> 공용 측정·표면 분리·아이콘·장축 차량 규칙은 `docs/quick-filter-image-slot-rules_v03.md`와 `docs/image/quickfilter_image_production_manual_v01.md`가 최신 기준이다. 이 문서의 72×102/64×40 값은 현재 QF-109 구현값으로 유지하되, 분류형 이미지 방향은 좌향 90° 정측면 규칙이 우선한다.

## A. 차량 이미지
| 항목 | 기준 |

| 방향 | 분류형 퀵필터는 앞머리 왼쪽 90° 정측면. 메인 홍보형만 앞 3/4 허용 |
| 색상 | 흰색 또는 은색. 없으면 밝은 회색·밝은 파랑까지. 검정·빨강·진남색 등 진한 색 금지 |

## B. 브랜드 로고
| 항목 | 기준 |
|---|---|
| 형식 | SVG 우선, 없으면 투명 PNG(표시 크기의 3배 이상) |
| 배경 | 투명. 흰 사각형·원형 배경이 들어간 파일 금지 |
| 여백 | 로고 윤곽 기준 여백 0으로 trim |
| 엠블럼(원형·방패·심볼) | 40×40 상자에서 긴 변 33(82.5%), r ≤ 1.25 |
| 중간 가로형 | 40×40 상자에서 폭 36.4(91%), 1.25 < r < 1.6 |
| 워드마크(넓은 가로형) | 40×40 상자에서 폭 40(100%), r ≥ 1.6 |
| 칸 | PC 84×102, 모바일 76×102. 로고 상자 40×40, 상단 6, 이름까지 14 |
| 색 | 브랜드 원색. 흰색 로고는 사용 금지(연회색 카드에서 안 보임) |

### 트럭·특장 모바일 제목 없는 슬롯 정렬

- 1080×2340 초톳 캡처는 384 CSS px·2.8125배율로 환산한다.
- 좌측 제목과 제목 칸을 제거하고 첫 슬롯을 모바일 x=16px, PC x=20px에서 시작한다.
- 트럭 유형 이미지·제조사 로고·모델 이미지는 같은 슬롯 시작선을 사용한다.
- 제조사 로고 반복 피치는 초톳과 같은 84px이다. 트럭 이미지는 76×48px 표시 볼륨을 보존하고 카드 겹침을 막기 위해 88px 카드·8px 간격·96px 피치를 사용한다.

## C. 검수 체크리스트 (배포 전)
1. 384px 기준 캡처에서 모델·세대 레일의 모든 차량 앞머리가 왼쪽인가
2. 흰색·은색인가, 진한 색이 섞이지 않았는가
3. 배경 흰 사각형·잘린 경계·반투명 얼룩이 보이지 않는가
4. 모바일 모델 슬롯이 72×102, 이미지 캔버스가 64×40, 카드 피치가 80인가
5. 로고: 40×40 상자 안에서 비율 단계(33·36.4·40)를 따르고 흰 배경 상자가 없는가
6. 세대마다 다른 이미지인가(같은 이미지 반복 시 목록 기록)

### 엔카 모델·세대 크로스체크 게이트 (2026-10-07 확정)

- 분류 정본은 엔카 DB 스냅숏의 `제조사 → 모델그룹 → 세대` 경로다. 공식 제조사 카탈로그·카이즈유·다나와는 외관과 출시 색을 판정하는 자료이며 엔카의 모델·세대 경로를 임의로 바꾸는 근거로 쓰지 않는다.
- 이미지 제작 전 `세대 key`, `displayName`, 상위 모델그룹명, `releaseYm`, `endYm`, 노출 상태를 확인한다. 하나라도 다르면 제작·연결·배포를 멈추고 데이터 담당에게 보고한다.
- 모델 목록은 엔카의 `sortOrder`를 기준으로 전체 위치를 대조한다. 매물 0대 모델을 제품 정책상 숨기면 남은 모델의 상대 순서뿐 아니라 엔카 원래 위치가 압축된다는 사실도 검수 보고서에 명시한다.
- 세대가 올바른 상위 모델그룹 아래에 있는지 확인한다. 엔카처럼 같은 목록에서 인라인으로 펼칠지, 별도 세대 화면으로 이동할지는 UX 정책으로 분리하여 기록하며 데이터 위치 일치와 화면 배치 일치를 혼용하지 않는다.
- 엔카가 전기형·후기형을 한 세대로 합친 경우 대표 외관을 임의로 별도 세대로 만들지 않는다. 선택한 대표 외관(예: 후기형·LCI·EVO)과 선택 이유를 매니페스트의 `전후기형`·`비고`에 기록한다.
- 제작 후 세대 key와 `generation-images/{manufacturer}.json`의 키가 1:1이어야 하며, 연결 파일명도 매니페스트와 정확히 같아야 한다. 동일 key 중복, 누락 파일, 다른 세대 이미지 재사용은 불합격이다.
- 완료 제조사는 아래 명령으로 엔카의 모든 노출 세대가 빠짐없이 들어왔는지 검사한다. 부분 제작 중에는 `--require-complete`를 빼고 연결된 행만 검사한다.

```powershell
python scripts/check-encar-generation-assets.py --brand lamborghini --require-complete
```

## F. 차량군별 색상·재질 제작 기준 (v1.6)

- 단일 기준 문서: `docs/image/autoscout24_chotot_vehicle_image_manual_v01.md`.
- 개발·검수용 수치 파일: `docs/image/vehicle_category_color_manifest_v01.csv`.
- 슬롯 크기·간격·기준선은 초톳, 사진 품질·조명·누끼는 AutoScout24, 구조 정확도는 공식 제조사 자료를 따른다.
- 승용차·전기차·슈퍼카·클래식카·바이크·트럭·버스·캠핑카·건설기계·자재운반장비·농기계·보트·부품의 팔레트를 분리한다.
- 실루엣이 1순위다. 색만 바꿔 다른 유형으로 만드는 방식은 금지한다.
- 색상 면적은 매니페스트 비율의 ±5%, 배경은 완전 투명, 출력 프로필은 sRGB로 고정한다.
- 접지 그림자는 `#12181C`, 접지선 아래 2px, 카테고리별 불투명도·폭·높이·블러를 매니페스트대로 이미지에 포함하며 CSS 그림자를 중복 적용하지 않는다.
- 분류형은 좌향 90도 정측면, 메인 홍보형만 3/4를 허용한다. 두 표면은 구도가 달라도 팔레트·재질·광원 규칙을 공유한다.
