적용 범위: 매물리스트 뎁스 퀵필터(DepthCard 80×72), 차종 시트, 메인 유형·브랜드 칩
추가 기준: 초톳 1080×2340 캡처 8장, 384 CSS px·2.8125배율 실측(2026-10-03)

> 공용 측정·표면 분리·아이콘·장축 차량 규칙은 `docs/quick-filter-image-slot-rules_v02.md`가 최신 기준이다. 이 문서의 72×102/64×40 값은 현재 QF-109 구현값으로 유지한다.

## A. 차량 이미지

|---|---|
| 방향 | 앞 3/4, 앞머리 왼쪽(운전석 쪽 측면이 보이는 컷) — 모든 모델·세대 동일 |
| 색상 | 흰색 또는 은색. 없으면 밝은 회색·밝은 파랑까지. 검정·빨강·진남색 등 진한 색 금지 |
| 촬영 | 스튜디오 컷(균일 조명). 길거리·전시장 배경 사진에서 오려낸 컷은 금지 |
| 배경 | 투명(PNG 알파 또는 WebP 알파). 흰 배경 이미지 금지 |
| 그림자 | 옅은 바닥 그림자 허용(투명도 20% 이하, 차 바닥 아래 4px 이내) |
| 여백 | 차 윤곽(바퀴·미러 포함) 기준 여백 0으로 trim 후 캔버스에 배치 |

## B. 브랜드 로고
| 항목 | 기준 |
|---|---|
| 형식 | SVG 우선, 없으면 투명 PNG(표시 크기의 3배 이상) |
| 배경 | 투명. 흰 사각형·원형 배경이 들어간 파일 금지 |
| 여백 | 로고 윤곽 기준 여백 0으로 trim |
| 엠블럼(원형·방패·심볼) | 40×40 상자에서 긴 변 33(82.5%), r ≤ 1.25 |
| 중간 가로형 | 40×40 상자에서 폭 36.4(91%), 1.25 < r < 1.6 |
| 워드마크(넓은 가로형) | 40×40 상자에서 폭 40(100%), r ≥ 1.6 |
| 칸 | PC 84×102, 모바일 76×102. 로고 상자 40×40, 상단 6, 이름까지 14 |
| 색 | 브랜드 원색. 흰색 로고는 사용 금지(연회색 카드에서 안 보임) |

## C. 검수 체크리스트 (배포 전)
1. 384px 기준 캡처에서 모델·세대 레일의 모든 차량 앞머리가 왼쪽인가
2. 흰색·은색인가, 진한 색이 섞이지 않았는가
3. 배경 흰 사각형·잘린 경계·반투명 얼룩이 보이지 않는가
4. 모바일 모델 슬롯이 72×102, 이미지 캔버스가 64×40, 카드 피치가 80인가
5. 로고: 40×40 상자 안에서 비율 단계(33·36.4·40)를 따르고 흰 배경 상자가 없는가
6. 세대마다 다른 이미지인가(같은 이미지 반복 시 목록 기록)
