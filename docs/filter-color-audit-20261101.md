# 차량 검색 필터 색상 전수 점검 / 2026-11-01

## 판단 및 적용 범위

슬라이더를 포함한 선택·활성 상태를 보배드림 블루로 통일한다. 텍스트 전체를 블루로 바꾸지 않고 동작 상태만 강조한다. 현재 Guazi PC 사이드바/모달, 모바일 바텀시트/전체 필터가 범위이며 기존 형상·간격·동작은 바꾸지 않는다.

공용 CSS를 읽는 기존 Nuxt 소비자에도 같은 규칙을 제공한다. 신규 React 화면이나 API를 만들지 않는다. 기존 사용자 시안 root는 React 19.2.7/TS 7.0.2/Vite 8.1.3, Nuxt 소비자는 Nuxt 3.21.11/Vue 3.5.43/TS 5.9 계열로 확정 리뉴얼 스택과 차이가 있다. 의존성 변경·Nuxt 4 전체 이관·Laravel API 연결은 이번 CSS 수정의 범위가 아니다.

## 팔레트 계약

| 역할 | 색상 | 적용 |
| --- | --- | --- |
| Primary | `#306BD9` | 버튼, 선택 구간, 손잡이, 체크, 탭, 활성 스위치, 포커스 |
| Soft | `#EDF3FF` | 선택한 행·외곽선 프리셋의 보조 배경 |
| Ink / Hover | `#2456B3` | 옅은 배경의 선택 글자 / 하단 버튼 hover |
| Secondary line | `#C2D3F5` | 그룹 배경의 보조 구분선 |
| Neutral | 기존값 유지 | 본문·닫기·초기화·미선택·비활성·비선택 트랙 |
| Semantic / actual | 기존값 유지 | 오류 빨강, 색상 견본, 브랜드 로고, 체크/스위치 손잡이 흰색 |

흰 글자/Primary와 Ink/Soft 대비를 코드로 계산해 각각 4.5:1 이상을 검사한다. 선택 여부는 체크·테두리·밑줄·위치 변화도 남겨 색상에만 의존하지 않는다. 전체 WCAG 적합 판정을 의미하지 않는다.

## 실제 화면 점검 순서와 결과

1. 기존 가격 화면: 하단 버튼과 탭/선택 구간의 색상이 달랐다. 공통 Primary로 수정했다.
2. PC 주행거리: 막대·양쪽 손잡이·풍선·포커스 Primary, 비선택 트랙 회색을 computed style로 확인했다. 키보드 ArrowRight로 최소값이 1,000km로 이동하는 동작을 확인했다.
3. PC 가격: 선택 탭/밑줄/구간 Primary를 확인했다. 최저 3,000/최고 1,000 입력 시 오류 `#E5484D`와 비활성 버튼 `#D9D9D9`가 유지되는 것을 확인했다.
4. PC 연료/연식: 체크 Primary·미선택/비활성 흰 바탕, 연식 프리셋 Soft/Ink/Primary 테두리를 확인했다.
5. 모바일 전체 필터: 거래 가능 스위치 켜짐 및 하단 버튼 Primary를 확인했다. 기본 꺼짐은 기존 회색이다.
6. 모바일 가격: 3천만원 선택 시 구간·탭·하단 버튼 Primary와 선택 상태를 확인했다. PC/모바일 검색 상태·버튼 이벤트는 기존 동작을 유지한다.

대표 화면의 실측과 전체 선택자 인벤토리/회귀 테스트를 병행한다. 카테고리·제조사 등 데이터에 따라 나타나지 않은 모든 말단 조합을 실제 기기에서 전수 조작한 것은 아니다. Firefox pseudo-element는 소스 규칙 검사이며 Firefox 실제 구동 결과는 아니다. 부분 체크·흰 체크의 구조와 상태 이벤트는 변경하지 않았다.

## 보존/제외

- GNB·목록 상단의 검정 카테고리/적용 알약과 일반 본문은 변경하지 않는다.
- 독립 `/bike/`, `/truck/` 사이트 테마 및 ChoTot/Dongchedi 동결 비교 모드는 제외한다.
- 차량 색상 견본·브랜드 이미지·오류색·비활성 스타일은 변경하지 않는다.
- 보호 런타임 파일과 의존성/lockfile은 수정하지 않는다.

캡처 원본은 로컬 검수 폴더에 보관하고 공개 배포 산출물에는 넣지 않는다. PC 초기 캡처 중 흐린/불완전 이미지는 증거로 채택하지 않는다. 완료 보고의 실제 배포 링크와 최종 캡처를 우선한다.
