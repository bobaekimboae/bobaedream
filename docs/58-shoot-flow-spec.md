## 2. 화면별 요소와 상태 변화

### 2-1. 등록 화면
- 머리줄: 뒤로 · 제목 · `완성도 N%`(주황 11px) · `임시저장함`(주황 숫자 배지) · 아래 주황 진행 막대.
- 완성도: 들어오면 0% → 소재지가 채워지며 20% → 사진 1장 이상 28%(영상을 더해도 28% 그대로 확인).
- `차량 소재지 (필수)` 값 한 줄.
- 사진 구역 제목 3단계: `사진·영상 올리기` → (올리는 중) `차량 사진 인식 중…` → `차량 사진 인식 완료`.
- 오른쪽 `? 촬영 규칙 보기` → 화면 12.
- 빨간 안내: 「첫 사진은 좌측 전면 45° 차량 사진을 써 주세요.」 + 회색 「더 잘 보여요!」.
- 비어 있을 때: 그림자 카드 하나에 `사진 추가 | 영상 추가` 두 칸.
- 올리는 중(약 3초): 토스트 「사진을 처리하고 있어요. 앱을 나가지 마세요」, 안내 카드 「사진 규정까지 1장 부족해요」 + 주황 `사진 추가` 알약, 사진 칸은 회색 로고 칸 + `업로드 중`.
- 인식 완료: `등록 팁` 카드(말풍선 아이콘 · 펼침 꺾쇠). 「아직 N개 각도가 부족해요」(N = 9 − 채운 규칙 각도). 펼치면 「더 올려 주세요: 측면 | 후면 | …」.
- 사진 칸 78×78: 오른쪽 위 휴지통, 오른쪽 아래 워터마크, 아래 각도 이름(카메라로 찍은 칸 이름, 앨범 사진은 `기타`). 누르면 화면 4.
- 사진 추가 칸: 카메라 + `N/30`. 영상이 있으면 `영상 추가` 칸이 사라진다(영상 1개).
- 영상 칸: 표지 + 파란 점 3개(올리는 중) → 재생 표시 + 휴지통.
- 휴지통 → 팝업 「사진을 삭제할까요?」(취소 · 주황 확인).
- 차량 인증: 라디오 3개(자동차등록증 · 등록원부 · 차대번호 명판). 고르면 아래 사진 상자 이름이 바뀐다.
- 아래: `임시저장`(배지 +1, 토스트) · 주황 그라데이션 `등록하기`(시안이라 안내만, 58 `发布信息`은 누르지 않음).

### 2-2. 사진 촬영
- 위: X(누르면 확인 없이 닫히고 이번에 찍은 사진은 버린다) · 제목. 사진 촬영 화면에는 플래시가 없다(영상 촬영 화면에만 있음).
- 카메라 화면 위 회색 알약 `{각도} 촬영`.
- 칸 레일(80×70, 간격 8, 아래 검은 이름 띠 20): `좌측 전면 45° · 정면 · 우측 전면 45° · 우측면 · 후면 · 좌측면 · 계기판 · 실내 · 엔진룸 · 트렁크 · 기타 · 기타`. 등록 화면에 이미 있는 각도는 빠진다(다시 열면 `정면`부터).
- 고른 칸 흰 테두리. 칸을 누르면 그 칸을 고르고 알약 글자가 바뀐다.
- 셔터(바깥 64 회색 · 안 52 흰색): 찍으면 찰칵 소리, 고른 칸에 사진 + 오른쪽 위 ×, 다음 빈 칸으로 넘어가고, `N/30`이 1 오른다. 칸이 다 차면 `기타` 칸이 하나 더 생긴다. 30장이면 토스트.
- 칸의 × → 그 사진만 빠지고 칸이 다시 빈 칸이 된다.
- `번호판 가리기` 켜기·끄기: 아이콘만 밝아진다(58에서도 화면 변화 없음 확인).
- `N/30` + 주황 `완료`(늘 보임) → 등록 화면에 추가.
- 아래 `촬영 · 앨범` 탭(흰 밑줄). 좌우로 밀어도 바뀐다.

### 2-3. 앨범
- 제목 `내 앨범 ▾`, 주황 띠 「우선 업로드 각도: 좌측 전면 45° | 정면 | 우측 전면 45° | 우측면 | 후면 | 좌측면」.
- 3열 격자. 방금 찍은 사진이 맨 앞, 주황 체크로 선택돼 있다. 칸 오른쪽 아래 원을 누르면 선택·해제, 개수 `N/30`이 바뀐다.
- 새로 고른 사진이 있을 때만 `완료`가 보인다(0장이면 숨김 확인).
- 보배드림은 휴대폰 사진첩을 직접 읽을 수 없어 첫 칸 `휴대폰 사진 불러오기`(파일 고르기)를 둔다.

### 2-4. 사진 미리보기·편집
- 위: X(편집 내용을 버리고 닫기, 확인 없음) · `사진 미리보기(N)`.
- 아래 줄: 회색 `+`(사진 더 추가) · 사진 칸(×로 빼면 그 자리가 `다시 올리기` 칸이 된다).
- 도구: `번호판 가리기`(주황) · `모자이크` · `회전` · `자르기` · 주황 `완료`(편집을 저장하고 등록 화면으로).
- 번호판 가리기: 사진 가운데 흰 스티커 + 흰 선택 상자. 손잡이 4개 = 왼쪽 위 ×(숨기기) · 오른쪽 위 회전(손가락 방향을 따라 돈다) · 아래 두 개 크기(가운데 기준으로 사방이 같이 커진다).
  - 스티커는 사진당 1개. ×로 숨긴 뒤 다시 누르면 마지막 위치·크기·각도로 돌아온다.
  - 스티커를 짧게 누르면 선택 상자가 사라지고 다시 누르면 나온다.
  - 끌어서 옮기기: adb 합성 터치로는 58에서 움직이지 않아 확인하지 못했다. 일반 동작대로 끌어서 옮기게 만들었다.

### 2-5. 모자이크
- 흰 화면 · 회색 머리줄 `모자이크`.
- 붓 3개(주황 테두리 원, 고르면 주황으로 채움) + `붓 설정`. 기본은 가운데.
- 손가락으로 그은 곳이 픽셀 블록으로 바뀐다(블록 = 사진 폭의 1/48).
- `실행 취소`는 마지막 획 하나 지우기, `다시 실행`은 되살리기(58: 되살리면 획이 그대로 돌아옴 확인).
- 아래 `취소`(버림) | 주황 `저장`.

### 2-6. 회전
- 가운데 주황 원형 화살표 안에 `90` + `회전`. 누를 때마다 시계 방향 90°.
- `취소` | `저장`.
- 58은 회전 후 취소해도 자르기 화면에 회전된 사진이 보였다(58 버그). 보배드림은 취소하면 되돌린다.

### 2-7. 자르기
- 주황 모서리 틀 + 3분할 선, 틀 밖은 흰색으로 흐리게.
- `4:3 가로`(기본) · `3:4 세로` 상자 버튼. 틀을 끌어 옮긴다.
- 58에서 `3:4`를 누르자 앱이 다른 화면(仅需三步 판매 화면)으로 튕겼다. 보배드림은 정상 동작으로 만들었다.

### 2-8. 영상 촬영 (촬영 부위 템플릿)
- 위: X · `차량 영상` · 플래시(켜면 주황 + 손전등).
- 회색 알약 `{단계} 촬영`. 흰 사각 틀(모서리 굵은 선) + 아래 「촬영 항목이 맞는지 확인해 주세요」.
- 단계 칩 4개: `차량 외관 · 실내 · 엔진룸 · 트렁크`. 고른 칩은 커져서 `예시` 표시가 붙은 템플릿이 나온다.
  - 템플릿: 촬영 대상 그림 + 카메라를 움직일 방향을 그리는 주황 화살표(2.4초 반복). 58은 실사 예시 영상이라 같은 구성을 그림으로 만들었다. 움직임 줄이기 설정이면 멈춘다.
- 녹화(빨간 버튼): 틀 가운데 큰 `3 → 2 → 1` → 녹화. 틀 오른쪽 위에 `00:01` 시간, 버튼 글자 `일시정지`, 칩이 작아지고 진행 막대·빨간 점, `앨범` 탭이 사라진다.
  - 10초보다 짧게 멈추면 토스트 「녹화 시간이 부족해요」, 녹화는 계속. 58에서 4초는 거절, 11초는 허용을 확인해 10초로 정했다.
  - 22초가 되면 자동으로 멈춘다(4단계 모두 00:22 확인).
- 멈춘 뒤: 끝난 칩에 `00:22` + 이름, 다음 단계로 넘어가 예시가 나오고, 버튼 `계속`, 오른쪽 주황 `다음`, `앨범` 탭이 다시 보인다.
- 마지막 단계를 멈추거나 `다음`을 누르면 → 어두운 화면 + 돌아가는 표시(합치는 중) → 영상 미리보기.
- 한 파일로 이어서 녹화한다(MediaRecorder 일시정지·이어하기).
- 보배드림만: 녹화한 것이 있을 때 X를 누르면 「촬영한 영상을 지우고 나갈까요?」. 58은 확인하지 못했다.

### 2-9. 영상 미리보기 · 2-10. 표지 선택
- 미리보기: 가운데 재생, 칩에 단계별 길이, `00:00/01:20`(현재/전체), 주황 `다음`.
- 표지 선택: 알약 `영상 표지 선택`, 아래 장면 8개 줄(고른 칸 흰 테두리 + 주황 체크), 「영상에서 한 장면을 골라 표지로 정해 주세요」 + `완료` → 등록 화면 영상 칸(올리는 중 파란 점 → 재생 표시).

### 2-11. 촬영 규칙
- 분홍 띠 「사진은 1장 이상 올려 주세요」.
- 차량 외관(4장): 좌측 전면 45° | 측면 | 후면 | 정면 · 실내(4장): 앞좌석 | 뒷좌석 | 센터페시아 전체 | 계기판 · 기타(1장): 엔진룸. 4열 그림 + 이름.
