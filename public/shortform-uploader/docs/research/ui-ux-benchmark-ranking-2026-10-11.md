# 보배드림 딜러 숏폼 제작 UI·UX 벤치마크 순위

작성일: 2026-10-11

## 결론

한 제품을 그대로 복제하지 않고 다음 조합으로 자체 구축한다.

- 제작 흐름: CARVID
- 한 화면 선택 UX: OnlyCars
- 선택 피로 최소화와 플랫폼 내 노출: VCAT.AI × 번개장터
- 재고·가격·판매완료 동기화: Phyron
- 촬영 품질과 번호판 보호: Spyne·CarCutter
- 원본 영상 자동 편집: OpusClip

## 실제 UI·UX 참고 순위

| 순위 | 서비스 | 참고할 화면·흐름 | 보배드림 적용 |
|---:|---|---|---|
| 1 | [CARVID](https://www.carvidapp.com/) | 재고 선택부터 세로 영상 생성, 다채널 게시, 판매완료 처리까지 연결된 딜러 작업 흐름 | 전체 정보 구조와 운영 상태 모델의 기준 |
| 2 | [OnlyCars](https://www.onlycars.de/) | 차량 등록 → 사진 정렬·표지 선택 → 템플릿·음악·비율 → 생성의 짧은 제작 흐름 | 새 영상 만들기 화면의 직접 기준 |
| 3 | [Pippit AI](https://www.pippit.ai/) | 상품 URL·사진에서 콘텐츠를 만드는 커머스형 생성 UX와 게시 캘린더 | URL/매물 기반 자동 입력과 생성 후 배포 흐름 |
| 4 | [VCAT.AI](https://vcat.ai/) × 번개장터 | 판매자는 복잡한 편집 없이 상품 데이터만 확인하고 플랫폼이 영상 스타일을 자동 결정 | 템플릿 3개 이하, 기본값 우선, 선택 피로 최소화 |
| 5 | [Phyron](https://www.phyron.com/inventory-videos) | 신규 재고 생성, 가격 변경, 판매완료 제거가 자동으로 이어지는 운영 구조 | 보배드림 재고 이벤트와 영상 상태 동기화 |
| 6 | [autofox](https://www.autofox.ai/video-ads) | 한 번 구성해 1:1·9:16 규격을 함께 출력하는 UX | 채널별 비율 자동 생성과 브랜드 프리셋 |
| 7 | [Spyne](https://www.spyne.ai/ai-car-video-generator) / [CarCutter](https://www.carcutter.com/) | 촬영 순서, 구도, 흔들림, 배경, 번호판 보호를 촬영 단계에서 해결 | 모바일 촬영 가이드와 품질 검사 |
| 8 | [OpusClip](https://www.opus.pro/) | 긴 원본 영상에서 하이라이트, 세로 리프레임, 자막을 자동 생성 | 딜러 워크어라운드 영상의 선택 입력 |

## 현재 프로토타입에 반영한 원칙

1. 보배드림 재고를 첫 진입점으로 사용한다.
2. 내 매물, 차량번호 조회, 직접 선택이 같은 차량 확인 화면으로 합류한다.
3. 사진은 순서와 표지만 직접 정하고 나머지는 자동 추천한다.
4. 원본 영상은 선택 사항으로 두어 사진만으로도 제작할 수 있다.
5. 템플릿은 클린·다이내믹·프리미엄 3개만 제공한다.
6. 길이는 15·30·45초, 비율은 9:16·1:1·16:9로 제한한다.
7. 보배드림·Instagram·YouTube·TikTok·MP4를 채널별 출력 대상으로 분리한다.
8. 게시 전 가격·주행거리·권리 확인을 명시한다.
9. 임시저장, 렌더 진행률, 실패·재시도 상태를 제품 구조에 포함한다.
10. 실제 서비스에서는 가격 변경과 판매완료 이벤트를 게시물 상태와 동기화한다.
