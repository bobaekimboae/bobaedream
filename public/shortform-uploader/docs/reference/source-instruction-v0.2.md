## 1. 제작 목적

보배드림 숏폼 촬영팀과 중고차 딜러가 매물 등록 과정에서 휴대폰으로 사진과 영상을 직접 촬영하고, 촬영한 미디어를 등록·수정·삭제할 수 있는 업로더와 촬영 템플릿을 만든다.

매물 등록 화면에서 사용자가 `영상 등록` 또는 `사진/영상 등록` 영역을 누르면 휴대폰 촬영 도구가 열려야 한다. 촬영 도구 안에서는 자유형 영상 업로드와 템플릿형 촬영을 모두 지원한다.

최종 산출물은 GitHub Pages에서 실제 동작 가능한 모바일 우선 웹 데모로 제작한다.

## 3. 촬영 모드

### 모드 A. 자유형 숏폼

틱톡처럼 정해진 섹션 없이 딜러 또는 촬영팀이 자유롭게 촬영하는 방식이다.

- 세로 9:16 영상 1개 업로드
- 촬영 또는 앨범 선택 지원
- 권장 길이: 15초, 30초, 60초
- 최대 길이: 90초 권장
- 사용처: 딜러 멘트, 매장 분위기, 이벤트 매물, 튜닝카·슈퍼카 소개, 자유 홍보 영상

### 모드 B. 템플릿형 촬영

보배드림 표준 매물 등록용 기본값이다.

- 정해진 촬영 부위를 순서대로 안내
- 사진과 영상을 각각 체크리스트 방식으로 관리
- 촬영 완료 여부를 섹션별로 표시
- Cars24처럼 시청자가 섹션별로 골라 볼 수 있는 뷰어 제공
- 사용처: 촬영팀 표준 촬영, 딜러 직접 촬영, 검수 가능한 정규 매물 등록

## 5. 핵심 기능 요구사항

### 5-1. 등록폼 진입

- 매물 등록폼 안에 `사진/영상 업로드` 영역을 배치한다.
- 최초 상태에서는 `사진 추가`, `영상 추가` 버튼을 58닷컴처럼 나란히 보여준다.
- 대표 이미지 안내 문구를 표시한다.
- 촬영 규칙 보기 링크를 제공한다.
- 현재 업로드 수와 부족한 촬영 각도를 안내한다.

### 5-2. 카메라 촬영 화면

공통 구조:

- 전체 화면 카메라 프리뷰

## 6. GitHub Pages 데모 구현 범위

GitHub Pages는 정적 호스팅이므로 실제 서버 저장소 업로드는 구현하지 않는다. 대신 사용자가 휴대폰 브라우저에서 촬영하고, 브라우저 내부 저장소에 미디어 상태가 유지되는 실동작 데모를 만든다.

필수 구현:

- 모바일 우선 반응형 화면
- 등록폼 화면
- 사진/영상 업로드 영역
- 자유형/템플릿형 모드 선택
- 휴대폰 카메라 호출
- 사진 촬영 또는 파일 선택
- 영상 촬영 또는 파일 선택
- 섹션별 등록 상태 표시
- 썸네일 미리보기
- 등록, 수정, 삭제, 대표 이미지 변경
- 업로드 진행률 시뮬레이션
- 임시저장
- Cars24식 섹션 뷰어

기술 권장:

- HTML, CSS, JavaScript 또는 Nuxt/Vue 기반 정적 배포
- 카메라 호출: `input type="file" capture` 우선
- 가능한 브라우저에서는 `getUserMedia`와 `MediaRecorder` 사용
- iOS Safari 호환을 위해 파일 선택 fallback 필수
- 미디어 저장: IndexedDB 권장
- 미디어 URL: Blob URL 사용
- 배포: GitHub Pages

데모 한계 명시:

- 서버 업로드, 계정 로그인, 실제 매물 DB 연동은 제외
- 실제 서비스에서는 S3, Cloudflare R2, GCS 같은 오브젝트 스토리지와 서버 API 필요
- 데모에서는 브라우저를 닫거나 저장소를 삭제하면 미디어가 사라질 수 있음

## 12. 제작 담당 AI에게 전달할 최종 지시문

아래 지시문을 그대로 전달한다.

> 보배드림 중고차 매물 등록용 숏폼 촬영 업로더와 촬영 템플릿 데모 사이트를 제작하라.
>
> 목표는 보배드림 촬영팀과 중고차 딜러가 휴대폰으로 매물 사진과 영상을 직접 촬영하고, 등록·수정·삭제·임시저장까지 할 수 있게 만드는 것이다.
>
> 원본 기준은 58닷컴 중국 중고차 등록/촬영 시스템과 Cars24 호주 차량 영상 투어다.
>
> 58닷컴에서는 등록폼 안의 사진·영상 업로드, 전체화면 카메라, 촬영 대상 pill, 샘플 카드, 촬영/앨범 전환, 사진 30장 카운터, 영상 1개 선택 UI, 썸네일 삭제, 번호판 가림 버튼, 완료 버튼 구조를 가져온다.
>
> Cars24에서는 Walkaround, Features, Dashboard, Seats, Driver POV, Boot, Tyres, Engine 8개 섹션과 하단 아이콘 챕터 탭, 선택 섹션 주황색 강조, 세로형 영상 플레이어 구조를 가져온다.
>
> 보배드림 데모는 자유형 숏폼 모드와 템플릿형 촬영 모드를 모두 제공해야 한다.
>
> 자유형은 틱톡처럼 섹션 없이 세로 영상 1개를 촬영하거나 업로드하는 방식이다.
>
> 템플릿형은 사진 체크리스트와 영상 챕터를 분리한다. 사진은 좌측 전방 45도, 차량 전면, 우측 전방 45도, 우측면, 차량 후면, 좌측면, 실내, 계기판, 앞좌석, 뒷좌석, 트렁크, 엔진룸, 타이어·휠, 흠집·하자, 등록증·차대번호를 지원한다. 영상은 Walkaround, Features, Dashboard, Seats, Driver POV, Boot, Tyres, Engine 8개 챕터를 지원한다.
>
> GitHub Pages에서 실제 동작 가능한 모바일 웹 데모로 제작한다. 정적 사이트이므로 실제 서버 업로드는 제외하되, 브라우저 내부 저장소를 사용해 촬영한 사진과 영상의 등록, 수정, 삭제, 대표 이미지 변경, 임시저장이 실제로 동작해야 한다.
>
> 휴대폰 카메라 호출은 `input type="file" capture`를 기본으로 구현하고, 가능한 브라우저에서는 `getUserMedia`와 `MediaRecorder`를 사용할 수 있게 한다. iOS Safari에서는 파일 선택 fallback이 반드시 동작해야 한다.
>
> 디자인은 첨부된 아이콘 원본을 우선 사용하고, 58닷컴의 주황색 촬영 버튼·완료 버튼·검은색 카메라 하단 바·샘플 카드 구조와 Cars24의 하단 챕터 아이콘 탭 구조를 모바일 기준으로 정교하게 재현한다.
>
> 최종 산출물은 GitHub Pages 배포 URL, 소스 코드, 화면 캡처, 샘플 영상, 샘플 이미지, 해외 유사 솔루션 조사표, 제작 지시문 최종본이다.
