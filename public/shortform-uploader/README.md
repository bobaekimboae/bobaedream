# 보배드림 딜러 영상 스튜디오

보배드림 중고차 딜러가 등록된 매물 사진으로 판매용 영상을 구성하는 반응형 프런트엔드 프로토타입입니다.

## 주요 흐름

1. 보배드림 재고, 차량번호 조회, 직접 선택으로 차량 불러오기
2. 사진 추가, 순서 변경, 표지 지정
3. 선택 원본 영상 추가와 품질 확인
4. 영상 템플릿, 화면 비율, 15·30·45초 길이, 배경 음악 선택
5. 게시 채널과 소개 문구 확인
6. 영상 생성 진행 상태와 결과 확인

## 동작 범위

- 딜러 재고 검색 및 매물 전환
- 매물 정보 자동 반영
- 차량번호 조회·직접 선택 대체 경로
- 로컬 이미지 추가
- 원본 영상 선택 입력
- 사진 순서 변경, 표지 지정, 삭제
- 9:16, 1:1, 16:9 실시간 미리보기
- 템플릿과 음악 선택
- 채널 선택과 게시 문구 작성
- 브라우저 임시저장
- 영상 생성 진행 상태 시뮬레이션
- 프로젝트 설정 JSON 다운로드

벤치마크 우선순위와 설계 근거는 `docs/research/ui-ux-benchmark-ranking-2026-10-11.md`에 정리했습니다.

## 로컬 실행

`bike-filter-app/public` 디렉터리에서 정적 서버를 실행합니다.

```bash
python -m http.server 5180
```

브라우저에서 `http://127.0.0.1:5180/shortform-uploader/` 경로를 엽니다.

## 프로토타입 한계

- 실제 MP4 합성, 인코딩, 음원 믹싱은 포함하지 않습니다.
- 보배드림 실재 매물 API와 게시 채널 API는 연결하지 않았습니다.
- 업로드한 로컬 이미지는 새로고침 후 복원되지 않습니다.
- 실제 서비스에서는 매물 API, 미디어 스토리지, 렌더 큐, 게시 채널 인증이 필요합니다.
