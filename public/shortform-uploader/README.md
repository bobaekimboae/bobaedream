# 보배드림 숏폼 촬영 업로더 데모

보배드림 촬영팀과 중고차 딜러가 휴대폰으로 매물 사진/영상을 촬영하고 등록하는 흐름을 검증하기 위한 정적 웹 데모입니다.

## 포함 기능

- 58닷컴식 사진/영상 등록폼
- 사진 추가, 영상 추가 2분할 진입 카드
- 자유형 숏폼 모드와 템플릿형 촬영 모드
- 사진 30장 슬롯 구조
- Cars24식 8개 영상 챕터
- 휴대폰 카메라/앨범 호출
- 사진/영상 등록, 교체, 삭제
- 대표 이미지 지정
- 번호판 가림 토글
- IndexedDB 임시저장과 새로고침 복원
- Cars24식 세로 영상 뷰어

## 로컬 실행

```bash
python3 -m http.server 4173
```

브라우저에서 아래 주소를 엽니다.

```txt
http://localhost:4173/
```

## GitHub Pages 배포

이 저장소를 GitHub에 올린 뒤 Pages source를 GitHub Actions로 설정하면 `.github/workflows/deploy-pages.yml`이 정적 파일을 배포합니다.

## 데모 한계

- 서버 업로드는 포함하지 않습니다.
- 실제 매물 DB 연동은 포함하지 않습니다.
- 로그인/권한은 포함하지 않습니다.
- 미디어는 브라우저 IndexedDB에 저장됩니다.
- 브라우저 저장소를 삭제하면 임시저장 데이터도 사라집니다.
- 실제 서비스 전환 시 S3, Cloudflare R2, GCS 같은 오브젝트 스토리지와 서버 API가 필요합니다.
