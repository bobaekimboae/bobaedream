# AS24 테마 붓칠 원본

- 출처: 노션 DB 「스카우트24 테마별」 (https://app.notion.com/p/316f27da357c439cb522c9d87f7b0a0d) 테마 바탕색 SVG 7개. 2026-11-10 받음.
- 파일은 한 글자도 고치지 않았다. 렌더러(`scripts/shortform/brushfill.py` `theme_mask`)가 rsvg-convert로 칠 모양(알파)만 읽고 색은 칩 종류별로 칠한다.
- 칩 종류: 포인트(숫자) = 노랑 `#F5F200` · 옵션/기능 = 민트 `#00FFD0`. 파일 이름의 숫자는 원본 가로_세로 크기.
- 내부 편집 재현용. 원본 영상·소리는 쓰지 않는다.
