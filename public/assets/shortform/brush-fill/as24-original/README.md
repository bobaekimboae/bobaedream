# 오토스카우트24 칠 원본 (노션 아이콘 DB)

노션 「보배드림 독일 아우토 스카우트 24」 아이콘 DB에 저장된 원본 SVG를 **한 글자도 고치지 않고** 그대로 둔다(다른 아이콘 원본과 같은 규칙). 색은 쓰는 쪽에서 마스크로 바꾼다.

| 파일 | 노션 이름 | 출처 사이트 | 원본 비율(가로:세로) | 우리 용도 |
|---|---|---|---|---|
| `yellow_mark.svg` | 형광 마커 | AutoScout24.de 검색 스프라이트 | 72:38 (1.9) | 짧은 낱말·숫자 칠 |
| `highlighter.svg` | 형광펜 밑줄 | autotrader.ca 내차팔기 | 116:33 (3.5) | 중간 길이 낱말 칠 |
| `disruptor.svg` | 형광 강조선 | AutoScout24.de 검색 스프라이트 | 214:23 (9.3) | 긴 낱말 칠(벨기에 리본 칠과 같은 모양) |

쓰는 법: 파이썬 `scripts/shortform/brushfill.py`의 `original_mask(w, h, text)`가 글자 칸 비율에 가장 가까운 원본을 골라 늘려 그린다. 웹은 CSS `mask-image`로 쓰고 `mask-size: 100% 100%`로 늘린다.
