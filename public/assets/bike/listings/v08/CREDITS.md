# 바이크 매물 사진 v08

- 출처: 라이트바겐(reitwagen.co.kr) 매물 대표 사진. 사용자가 구글 시트 「가상 매물 시나리오 › 바이크」(2026-10-08 수집)에 정리한 이미지 URL을 그대로 내려받았다.
- 용도: 보배드림 시안의 UI 검증용 목록 썸네일. 실서비스 게시용이 아니다.
- 가공: 가로 900px 이하로 줄여 webp로 저장. 47번(베스파 GTS 300)은 광고 이미지라 전화번호·문구를 빼고 바이크 부분만 잘랐다.
- 원본 상세 URL·매물 ID·실제 판매자명은 저장소에 두지 않는다(판매자 이름은 가상 값).
