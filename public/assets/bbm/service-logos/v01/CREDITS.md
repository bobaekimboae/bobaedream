# 보배드림 서비스 로고 v01

- 원본 링크:

- 제작 방식: OpenAI 이미지 생성으로 투명 배경 PNG를 신규 제작
- 공통 규칙: 보배드림 얼굴형, 크림색 눈, 빨간 코를 유지하고 서비스별 소품만 교체
- 팔레트: 네이비·크림·레드. 건설기계만 안전모 식별을 위해 노랑을 보조색으로 사용
- 생성 프롬프트 요약:
  - 바이크: 얼굴을 풀페이스 헬멧에 결합
  - 커뮤니티: 얼굴과 말풍선을 결합
  - 트럭: 얼굴을 트럭 전면부에 결합
  - 건설기계: 안전모와 굴착기 버킷을 결합
  - 올드카: 클래식 스티어링휠과 윙 모티프에 결합
- 용도: 보배드림 프로토타입의 헤더·차량 유형·커뮤니티 서비스 식별 마크

이 파일들은 외부 로고를 복제하지 않고, 제공된 보배드림 응용 원칙을 기준으로 새로 만든 시안입니다.
