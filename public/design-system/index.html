Overview

eBay Playbook형 디자인 시스템 사이트

보배드림 중고차 리스트, 필터, 상세, 등록 화면의 UI 규칙을 문서화하고 실제 항목 등록과 수정까지 할 수 있는 운영 화면입니다. Cars.com Fuse 전체 목차를 포함하고, Seed Design처럼 영문명과 한국어명을 함께 표시합니다.

운영 기준

Notion은 의사결정과 가이드, Google Sheet는 측정값 DB, 이 사이트는 디자인 시스템을 검색하고 등록·수정하는 공개 카탈로그로 사용합니다.

등록 데이터

토큰, 컴포넌트, 아이콘, 버튼, 상태값을 동일한 스키마로 관리합니다. 등록된 데이터는 브라우저에 저장되며 JSON 또는 CSV로 백업할 수 있습니다.

Cars.com Fuse 전체 목차 + eBay Playbook 대응

Cars.com Fuse 공개 사이드바의 모든 항목을 누락 없이 넣고, Accordion (아코디언)처럼 영문 기능명과 한국어명을 같이 표기합니다. 설명은 Seed Design 방식에 맞춰 정의, 구성, 상태, 사용 기준을 바로 읽을 수 있게 작성했습니다.

Workflow

Codex 자동 운영 흐름

하루 1회 또는 2회 화면을 점검해 측정값을 누적하고, 확정된 항목만 Figma 라이브러리로 승격합니다.

01

페이지 확인

PC 1440px, 모바일 390px 기준으로 리스트·상세·등록 페이지를 엽니다.

02

CSS 측정

Computed 기준으로 폰트, 간격, radius, shadow, z-index, safe area를 측정합니다.

03

마스터 저장

측정값은 Google Sheet, 확정 기준은 이 사이트와 Notion에 기록합니다.

04

Figma 승격

검토필요 상태가 닫힌 항목만 Variables와 Components로 반영합니다.
