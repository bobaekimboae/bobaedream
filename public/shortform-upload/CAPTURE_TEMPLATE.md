# 보배드림 매물 숏폼 촬영 템플릿

## 공통 원칙

| 구분 | 기준 |
| --- | --- |
| 대표 이미지 | 좌전 45도 차량 전체 컷을 1순위로 사용 |
| 사진 수량 | 기본 10장 필수, 최대 30장 |
| 영상 수량 | 자유 숏폼 1개 필수, 분류별 검수 영상 추가 |
| 자유 숏폼 | 15-60초, 딜러 말투와 차량 장점을 자연스럽게 촬영 |
| 부위별 영상 | 외관, 실내, 엔진/시동음, 트렁크/적재/특장 작동을 분리 |
| 하자 고지 | 흠집, 문콕, 전도, 누수, 부식은 별도 그룹으로 촬영 |
| 번호판 | 공개 여부를 선택하고 필요 시 후처리 블러 플래그 전달 |
