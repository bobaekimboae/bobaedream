# 보배드림 숏폼 촬영 업로더

58닷컴 중고차 등록폼의 `완성도`, `필수 촬영`, `차량 인증` 구조를 바탕으로 만든 모바일 우선 정적 웹 프로토타입입니다. GitHub Pages에 그대로 올릴 수 있고, 휴대폰 브라우저에서 카메라 촬영과 앨범 업로드를 테스트할 수 있습니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 휴대폰 카메라는 보안 정책 때문에 `localhost` 또는 HTTPS 배포 주소에서 가장 안정적으로 작동합니다.

## 들어간 기능

- 매물 분류: 승용/SUV, 수입/슈퍼카, 화물/특장, 캠핑카/RV, 바이크
- 사진 템플릿: 좌전 45도, 정면, 우전 45도, 측면, 후면, 계기판, 실내, 엔진룸, 트렁크/적재, 흠집/하자 등
- 영상 템플릿: 자유 숏폼, 외관 워크어라운드, 실내 소개, 시동/엔진음, 특장/RV 전용 영상
- 58닷컴형 등록폼: 완성도 %, 필수 항목, 누락 촬영 안내, 초안 저장, 게시 검수 요청
- 휴대폰 촬영 도구: 카메라 프레임, 촬영 부위 슬롯, 사진 촬영, 영상 녹화, 앨범 선택
- 미디어 관리: 등록, 수정, 부위 변경, 메모 입력, 대표 지정, 교체, 삭제
- 저장: 브라우저 IndexedDB에 사진/영상 Blob 저장, localStorage에 매물 메타데이터 저장
- 내보내기: 서버 연동용 JSON 메타데이터 다운로드

## 운영 적용 메모

실서비스에서는 정적 저장 대신 API 서버와 오브젝트 스토리지가 필요합니다. 이 프로토타입의 IndexedDB 구조는 프런트엔드 동작 검증용이며, 서버 연동 시 `listing.assets[]`의 `slotId`, `kind`, `mime`, `size`, `note`, `cover` 값을 업로드 메타데이터로 보내면 됩니다.

## 권장 서버 API

| 메서드 | 경로 | 용도 |
| --- | --- | --- |
| `POST` | `/api/listings` | 매물 초안 생성 |
| `PATCH` | `/api/listings/:id` | 기본 정보, 촬영 상태, 검수 메모 수정 |
| `POST` | `/api/listings/:id/assets` | 사진/영상 원본 업로드 |
| `PATCH` | `/api/assets/:id` | 촬영 부위, 메모, 대표 여부 수정 |
| `DELETE` | `/api/assets/:id` | 촬영 파일 삭제 |
| `POST` | `/api/listings/:id/review` | 게시 검수 요청 |
