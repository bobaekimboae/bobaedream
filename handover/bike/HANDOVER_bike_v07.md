# 코덱스-바이크 인수인계 v07

## 1) 담당 범위

- 바이크 필터·가변필터·퀵필터·매물 목록·상세·등록 화면
- 이번 버전: FINN형 1뎁스 이미지 카드와 텍스트 2뎁스 모델 목록 적용

## 2) 현재 진행 상태

- 완료: 혼다 전체 카탈로그 245개를 모델 선택 원본으로 연결
- 완료: 현재 가상 매물 7개 모델과 카탈로그 명칭 정규화 연결
- 완료: 빠른 선택은 매물 있는 모델만, 전체 시트는 245개 모두 표시
- 완료: 전체 모델 검색과 0대 비활성 상태 적용
- 완료: 장르 1뎁스 FINN형 가로 이미지 카드 적용
- 완료: 모바일 72×80px·이미지 64×36px 실측 검수
- 진행 중: GitHub Pages 공개 배포 확인
- 미착수: 장르 나머지 9종 이미지 제작

## 3) 결정된 사항과 그 이유

- 30대 테스트 매물에 등장한 모델을 제조사 전체 모델 체계로 오인하지 않는다.
- 빠른 선택은 현재 결과가 있는 모델만 노출해 0건 진입을 막는다.
- 전체 모델 체계는 `전체 N개`에서 모두 제공하고, 0대 항목은 비활성화한다.
- 2뎁스 모델은 사용자 요청에 따라 우선 텍스트로 제공한다.
- 장르 이미지는 모바일·PC에서 같은 비율과 선택 상태를 유지한다.
