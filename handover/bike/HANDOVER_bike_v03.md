# HANDOVER_bike_v03

## 1) 담당 범위

- 바이크 카테고리의 필터·가변필터·퀵필터·매물 목록·상세 연결.
- 이번 작업은 코덱스-자료가 만든 바이크 가상 매물 v07과 이미지 30장을 실제 시안에 적용했다.

## 2) 현재 진행 상태

- 완료: 바이크 가상 매물 30대 실제 목록 연결.
- 완료: 목록 이미지 30장과 시나리오 1:1 연결.
- 완료: v02 교체 이미지 3장 적용.
- 완료: 제조사에서 실제 보유 모델로 내려가는 모델 이미지 레일 연결.
- 완료: PC 좌측 필터·모바일 전체 필터의 실제 결과 수 연동.
- 완료: 선택 매물의 바이크 상세·가상 판매자 정보 연결.
- 진행 중: C등급 이미지 2장 대체본 확보.
- 미착수: 코덱스-중고차 상호 검수.

## 3) 결정된 사항과 그 이유

- `category=바이크`일 때 승용 샘플 대신 `bikeCars`만 사용한다. 다른 카테고리와 데이터가 섞이지 않게 하기 위함이다.
- 모델 레일은 전체 카탈로그 1,835개가 아니라 v07의 30대에 실제 존재하는 모델을 사용한다. 0대 모델로 이동해 빈 목록이 되는 문제를 막는다.
- 바이크 사진은 목록 카드에서는 `cover`, 모델 레일에서는 높이 맞춤으로 사용한다.
- 동일 매물임이 확인된 001·009·019만 v02 사진으로 연결하고 기존 v01도 보존한다.

## 4) 미결 사항·막힌 점

- `bike-008`: 원문 매물 종료로 동일 매물 전체 사진 미확인.
- `bike-027`: 원문 갤러리에 전체 차량 사진이 없어 대체본 미확인.
- 이미지 상업 이용 및 재배포 권리는 미확인.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

- 코덱스-자료의 v07 CSV·가상 판매자 정보·이미지 v01/v02를 수신해 적용했다.
- 코덱스-중고차에 요청 범위·누락·명칭·수치·파일 버전 상호 검수가 필요하다.

## 7) 검수 상태

- 생성 검증: 30행·30 ID·30 이미지·누락 0 확인 완료.
- 빌드 검증: `npm run verify:qf` 통과.
- 브라우저 검증: 모바일 20장 로드·깨진 이미지 0·스포츠 10대·상세 `bike-030` 연결 통과.
- PC·모바일 캡처 육안 확인 완료.
- 상호 검수: 미검수.

## 8) 다음에 할 일

1. 배포 주소에서 바이크 30대와 이미지 응답을 재검증한다.
2. 코덱스-중고차 상호 검수를 받는다.
3. `bike-008`, `bike-027` 대체 사진이 확정되면 새 이미지 버전과 시나리오 버전을 추가한다.
