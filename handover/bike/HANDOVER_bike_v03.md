# HANDOVER_bike_v03

## 1) 담당 범위

바이크 카테고리의 필터·가변필터·퀵필터·매물 목록/상세/등록 연동.

## 2) 현재 진행 상태

- 완료: 제조사 79개·모델 1,835개 카탈로그 및 브랜드 상위 10개
- 완료: 제조사→모델 종속 선택, PC·모바일 바이크 전용 필터 순서
- 완료: v04 가상 매물 30대와 이미지 30장 1:1 연결
- 완료: 장르·배기량·면허·매물출처를 실제 매물 결과에 연동
- 완료: 선택 매물의 v04 정보와 가상 판매자 정보를 상세 화면에 연동
- 완료: 모바일 필터 결과 버튼 직접 클릭 검증
- 미착수: 매물 등록 화면의 v04 값 자동 입력

## 3) 결정된 사항과 그 이유

- 최신 시나리오는 v04만 구현 기준으로 사용했다. 전달 지시에서 v02는 참고 기록으로 명시되었기 때문이다.
- 연결 기준은 `scenario_id`와 `image_file`로 고정했다. 매물과 이미지의 1:1 대응을 보장하기 위해서다.
- 면허와 매물출처 선택값은 기존 임시값 대신 v04의 실제 값으로 교체했다. 선택값과 결과 데이터가 서로 어긋나지 않게 하기 위해서다.
- 상세 연락 방식은 `앱 채팅만 사용 (가상)`을 그대로 표시하고 실제 전화번호를 만들지 않았다.

## 4) 미결 사항·막힌 점

- 매물 등록 화면에서 v04 필드 전체를 자동 입력하는 흐름은 미착수.
- 코덱스-자료의 별도 로고·모델 슬롯 매니페스트 적용 여부는 미확인.
- 공개 배포는 이번 자료 전달 요청만으로 승인된 것으로 간주하지 않아 미배포.
