# 코덱스-중고차 작업 인수인계서

- 코덱스 이름: 코덱스-중고차
- 파일용 코드: `car`
- 문서 버전: `v52`
- 작성일: 2026-10-03 (KST)
- 이전 문서: `HANDOVER_car_v51.md`

## 1) 담당 범위

- 보배드림 중고차 퀵필터의 승용 브랜드 상위 10종 로고 선정과 실제 슬롯 테스트.

## 2) 현재 진행 상태

- 완료: 기존 확정 상위 10 순서(현대·제네시스·기아·쉐보레·르노코리아·KGM·BMW·벤츠·아우디·포르쉐)를 유지.
- 완료: Drive 후보 폴더의 K카·과쯔 원본을 40×40 슬롯과 24×24 목록 슬롯에서 비교.
- 완료: PNG 투명 여백을 알파 16 기준으로 제거하고 SVG는 원본 벡터를 유지한 테스트 자산 10종 생성.
- 완료: `brandlogo=drive10` 파라미터에서만 테스트 자산을 쓰도록 구현하여 기존 기본 로고를 보존.
- 완료: 모바일 실제 퀵필터에서 국내 브랜드 5개와 제조사 목록을 육안 검수하고 전체 빌드 검증.
- 완료: Google Sheet `승용브랜드10` 탭에 원본·크기·비율·선정 이유·원본 링크 기록.
- 미착수: 테스트 세트를 기본 로고로 확정 적용하고 공개 배포.

## 3) 결정된 사항과 그 이유

- 과쯔 원본: 현대, 제네시스, BMW, 벤츠, 포르쉐. 작은 슬롯에서 대비가 좋고 제네시스·포르쉐는 256px 원본을 확보했다.
- K카 원본: 기아, 쉐보레, 르노코리아, KGM, 아우디. 워드마크·외곽선이 선명하며 르노·KGM은 SVG다.
- KGM은 구형 쌍용 심볼 후보를 제외하고 현행 KGM 워드마크를 채택했다.
- 광학 크기는 기존 v02 규칙을 유지한다: 40×40 슬롯 안 정사각·세로형 긴 변 33px, 중간 가로형 36.4px, 넓은 워드마크 40px.

## 4) 미결 사항·막힌 점

- 각 로고의 공식 브랜드 사용 가이드·상표 사용 허용 범위는 `미확인`이다.
- Google Sheets 브라우저는 로그아웃 상태라 화면 렌더 육안 검수는 못 했고 API 재조회로 값·서식·링크를 검수했다.
- 공개 배포는 이번 요청 범위에 포함되지 않았다.
