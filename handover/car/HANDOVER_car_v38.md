## 1) 담당 범위

- 보배드림 커뮤니티 PC 기본형 탑메뉴의 선택 칩·비선택 텍스트 혼합형 교정.

## 2) 현재 진행 상태

- 완료: 선택된 메뉴만 검정 알약 칩으로 표시.
- 완료: 비선택 메뉴의 배경·외곽선을 제거하고 텍스트 메뉴로 표시.
- 완료: `view`·`board` URL 상태에 따른 탑메뉴 자동 선택.
- 완료: 선택 항목 `aria-current="page"` 적용.
- 완료: 기본형·Reddit형 영향 및 전체 빌드 검수.
- 미착수: GitHub Pages 공개 배포.

## 3) 결정된 사항과 그 이유

- 모든 메뉴를 칩으로 표시할 때 생기는 버튼 덩어리 느낌을 줄이기 위해 현재 위치만 칩으로 강조한다.
- 메뉴 전체 터치 영역은 40px로 유지하고, 상하 3px 투명 테두리를 사용해 선택 칩의 실제 가시 높이는 34px로 만든다.
- 비선택 메뉴는 14px/600, 선택 메뉴는 14px/700과 `#222` 배경을 사용한다.
- `board=시승기`에서는 `게시판`이 아니라 `시승기`가 선택되도록 URL 상태와 메뉴 상태를 연결한다.
- 세부 게시판처럼 탑메뉴에 직접 없는 항목은 `게시판`을 선택 상태로 유지한다.
- Reddit형은 탑메뉴 자체를 숨기므로 이번 교정의 영향을 받지 않는다.

## 7) 검수 상태

- `board=시승기`: `시승기` 단독 칩과 `aria-current="page"` 확인.
- `view=home`: `홈` 단독 칩 확인.
- `board=국산차 오너톡`: `게시판` 단독 칩 확인.
- 비선택 메뉴: 투명 배경·투명 테두리·14px/600 확인.
- 선택 메뉴: 검정 배경·흰색·14px/700·40px 터치 영역 확인.
- 브라우저 콘솔 오류 없음.
- `npm run verify:qf`: 통과.
