# 코덱스-중고차 작업 인수인계서

- 코덱스 이름: 코덱스-중고차
- 파일용 코드: `car`
- 문서 버전: `v04`
- 작성일: 2026-10-02 (KST)
- 이전 문서: `HANDOVER_car_v03.md`

## 1) 담당 범위

- 중고차 실제 메인, 중고차 목록 진입, 중고차 메인용 공통 UI 아이콘 적용을 담당한다.
- 트럭·특장, 바이크, 건설기계 등 다른 카테고리는 메인 메뉴의 임시 상태만 제공하고 실제 화면은 구현하지 않는다.

## 2) 현재 진행 상태

- 완료: 노션 `베트남 초톳` 아이콘 DB에서 검색·메뉴·셰브론 아래·화살표 우·위치 SVG 원본 선별.
- 완료: AutoScout24 모바일 원본을 384px 기준으로 확인하고 메뉴 칩 높이·외곽선·활성 대비를 교정.
- 완료: 일반 루트 진입 시 새 중고차 메인을 표시하고 `?qf=guazi` 등 기존 목록 주소는 기존 목록을 유지하도록 경로 분리.
- 완료: 메인 서비스 칩 선택 시 히어로 문구·배경·버튼 문구 변경 및 선택 칩 중앙 이동.
- 완료: 중고차 CTA를 `?qf=guazi&filtericon=notion` 목록으로 연결.
- 미착수: 다른 카테고리 실제 화면 연결.

## 3) 결정된 사항과 그 이유

- 일반 루트에만 메인을 표시한다. 기존 검수·공유 링크의 쿼리 파라미터가 있으면 목록 화면을 유지해 기존 시안 주소의 회귀를 막는다.
- 서비스 칩은 40px 높이, 1px 회색 외곽선, 999px 곡률로 통일하고 활성 칩만 AutoScout 계열 짙은 네이비 `#16212E`와 흰 글자를 사용한다.
- 아이콘은 노션 DB의 SVG 원본을 영문 소문자 파일명으로 저장해 검색·메뉴·위치·선택 셰브론·섹션 이동에 사용한다.
- 메인에서 중고차 외 카테고리는 담당 범위 보호를 위해 준비 중 상태만 보여 준다.

## 4) 미결 사항·막힌 점

- 다른 카테고리의 실제 목적지 주소와 콘텐츠는 각 담당 코덱스 결과 대기.
- 코덱스-자료의 상호 검수는 미진행.
