## 1) 담당 범위

코덱스-중고차는 보배드림 중고차 메인 영역을 담당한다.

- 중고차 모바일·PC 매물 목록과 보기 방식
- 중고차 퀵필터, 전체 필터, 필터칩, 바텀시트와 PC 사이드바
- 중고차 매물 카드의 차량명·스펙·가격·지역·판매자·배지 표시
- 중고차 상세·매물 등록 화면의 중고차 범위 작업
- 중고차 가상 매물과 공통 자료를 화면에 연결하고 동작 검수
- 코덱스-자료가 만든 중고차용 이미지·슬롯·가상 시나리오·퀵필터 시나리오의 상호 검수

담당하지 않는 범위:

- 공통 원본 이미지의 직접 수정·배포, 슬롯 매뉴얼·통합 매니페스트 제작: 코덱스-자료 담당
- 바이크 화면과 로직: 코덱스-바이크 담당
- 화물·특장차 화면과 로직: 코덱스-특장 담당
- 건설기계 화면과 로직: 코덱스-건설 담당

## 3) 결정된 사항과 그 이유

1. 기본 작업 기준은 `?qf=guazi`로 유지한다. 기존 개발 시안과 검수 자료가 이 경로에 집중되어 있어 비교가 가능하다.
2. PC는 `&pc=1` 개발 시안형만 수정한다. 초톳형과 동처띠형은 비교 기준이므로 별도 요청 없이 변경하지 않는다.
3. 모바일 차량명은 제조사·모델과 세부모델·트림을 각각 한 줄로 분리한다. 긴 차명을 의미 단위로 유지하면서 카드 높이 변동을 제한하기 위해서다.
4. 목록형 썸네일은 136×136px, 8px 곡률을 사용한다. 동일 폭의 초톳 화면 실측 결과와 맞추기 위해서다.
5. 개인 판매자는 지역만, 개인 외 판매자는 실제 매매단지명을 함께 표시한다. 임의의 `지역 + 매매단지` 문구를 만들지 않고 실제 위치 의미를 유지하기 위해서다.
6. 판매자 유형과 주행거리 바텀시트는 내부 임시 선택과 외부 적용 상태를 분리한다. 확정 버튼을 누르기 전 필터칩과 매물 목록이 바뀌지 않도록 하기 위해서다.
7. 필터 아이콘 기본 방향은 3개 조절선 형태다. 비교용 Notion·깔대기 등은 직접 주소로만 확인한다.
8. 매물 특징 제목의 최신 직접 확인안은 카드 전체 위 한 줄 `titlepos=top`이다. 사진 열 안에만 두는 `photo-top`은 폭이 좁아 현재 요구와 달라 비교 경로로 남겼다.
9. 모바일 하단 홈과 매물등록은 `#222` 계열을 사용하고 안전영역을 확보한다. 보배드림 공통 블랙 액션과 푸터 가림 방지를 동시에 맞추기 위해서다.
10. 새 분담 체계 이후 공통 이미지·슬롯·시나리오 원본은 코덱스-자료가 관리하고, 코덱스-중고차는 중고차 화면 연결과 상호 검수만 수행한다. 중복 수정과 버전 충돌을 막기 위해서다.

## 4) 미결 사항·막힌 점

1. `titlepos=top`을 중고차 목록의 기본값으로 바꿀지, 검수용 직접 주소로만 유지할지는 미확인이다. 현재 기본값은 `after-model`이다.
2. 바디타입 최종안은 AutoScout24 원본의 4열 수치와 아이콘 중심선을 다시 실측해야 한다.
3. 실제 운영 검색 결과 수와 중복 제거 수를 제공하는 백엔드 연결은 미확인이다. 현재 프로토타입 결과 수는 보유 데이터 기준이다.
4. `public/assets/cars/luxury-ui-test/`의 기존 파일명에는 한글이 포함되어 새 파일명 규칙과 맞지 않는다. 코덱스-자료 담당 범위이므로 코덱스-중고차가 임의로 이름을 바꾸지 않았다.
5. 럭셔리 이미지 30개와 외부 드라이브 원본 번호의 1:1 대응은 기존 구현에 반영되어 있으나 이번 인수인계 작성 시 외부 원본을 다시 열어 재검수하지 않아 미확인이다.
6. 제공된 Notion·Google Drive·Google Sheets 원본 링크의 현재 접근 가능 여부는 이번 문서 작성 시 재확인하지 않아 미확인이다.
7. 작업 트리에 기존 수정·미추적 보고서 파일이 남아 있다. 사용자 또는 선행 작업 소유물일 수 있어 삭제·이동·커밋하지 않았다.
8. `npm run verify`의 중고차 런타임 검사는 통과했지만 담당 밖인 카테고리 관리자 테스트 `admin UI and health endpoint are executable`에서 `/health`가 기대값 200 대신 404를 반환해 전체 검증이 중단됐다. 코덱스-중고차가 관리자 영역을 수정하지 않았으며 원인은 미확인이다.

## 6) 다른 코덱스와 주고받은 자료, 대기 중인 요청

### 현재까지 확인된 수신 자료

- 판매자 유형 SVG, 바디타입 SVG, 초톳 판매자 프사 50개, 럭셔리 차량 이미지 30개가 현재 저장소에 들어 있다.

### 코덱스-자료에 전달할 요청
