# 코덱스-중고차 작업 인수인계서

- 코덱스 이름: 코덱스-중고차

- 문서 버전: `v41`
- 작성일: 2026-10-02 (KST)
- 이전 문서: `HANDOVER_car_v40.md`

## 1) 담당 범위

- 보배드림 커뮤니티 PC 상단 1뎁스·하위 게시판 탭 정보 구조.

## 2) 현재 진행 상태

- 완료: 상단 메뉴를 `홈 · 피드 · 자동차 · 유머 · 정치/시사`로 단순화.
- 완료: 1뎁스를 직접 선택했을 때만 2뎁스 탭을 노출.
- 완료: 섹션별 하위 탭과 게시글 필터 연동.
- 완료: 브라우저·콘솔·전체 빌드 검수.
- 미착수: GitHub Pages 공개 배포.

## 3) 결정된 사항과 그 이유

- 기본 화면과 기존 게시글 상세에서는 2뎁스를 숨겨 상단 밀도를 낮춘다.
- `자동차` 선택 시 `전체 · 국산차 · 수입차 · 전기차`만 우선 노출한다.
- `유머` 선택 시 `전체글 · 유머 · 짤방`을 노출한다.
- `정치/시사` 선택 시 `전체글 · 국민의힘 · 민주당`을 노출한다.
- 2뎁스는 URL의 `section`과 `topic`으로 상태를 보존하고 선택 탭에 `aria-current`를 제공한다.
- 사용자가 제시한 많은 자동차 주제는 첫 시안에 모두 노출하지 않고 핵심 게시판 4개로 축약했다.

## 4) 미결 사항·막힌 점

- 실제 운영 분류 확정 후 자동차·유머·정치/시사 탭을 추가할 수 있다.
- 유머·정치/시사 게시글은 UI 동작 확인용 가상 데이터다.

## 7) 검수 상태

- 기본 상세 URL: 2뎁스 숨김 및 탭 0개 확인.
- `section=car`: 자동차 탭 4개와 전체 게시글 45개 확인.
- `section=politics`: 정치/시사 탭 3개와 가상 게시글 확인.
- `section=politics&topic=민주당`: 선택 탭과 결과 1건 일치 확인.
- 브라우저 콘솔 오류 0건.
- `npm run verify:qf` 통과.
