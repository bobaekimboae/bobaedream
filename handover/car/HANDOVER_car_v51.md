## 1) 담당 범위

## 2) 현재 진행 상태

- 완료: 실사형·브랜드 로고·아이콘형 Drive 원본 12장을 384 CSS px, 2.8125배율로 재측정.
- 완료: 카테고리 메인 실사, 리스트 상단 실사 퀵필터, 실제 매물 사진을 서로 다른 용도로 분리.
- 완료: `xe.chotot.com` 384px에서 긴 카테고리명·모델 선택창·자연폭 모델 알약 동작을 직접 확인.
- 완료: 코덱스-자료와 코덱스-특장의 독립 검토를 반영해 충돌값을 해결.
- 완료: Google Sheet `보배드림 퀵필터 이미지·로고 슬롯 규칙 v02` 작성 및 재조회 검수.
- 완료: 저장소 공용 규칙 문서 `docs/quick-filter-image-slot-rules_v02.md` 작성.
- 미착수: 확정 규칙을 실제 퀵필터 UI 코드로 마이그레이션하고 공개 배포하는 작업.

## 3) 결정된 사항과 그 이유

- 기준 화면은 360px가 아니라 384px다. 1080÷2.8125가 384이며 40·48·72·84px 토큰에 수렴한다.
- 카테고리 메인은 64×48, 리스트 상단 퀵필터는 64×40으로 래퍼를 분리한다.
- 실제 매물 사진은 `cover`, 탐색용 투명 컷아웃은 `contain`을 사용한다.
- 브랜드는 40×40 박스와 84px 피치, 원형/단독 아이콘은 각각 40px 박스와 72px 피치를 사용한다.
- 이미지 카드 라벨은 14/20 최대 2줄, 고정폭 선택창은 1줄 말줄임, 자연폭 모델 알약은 전체명을 노출한다.
- 장축 트럭·버스·트레일러는 목록 템플릿 전체에 4:3을 적용하며 같은 목록에서 1:1과 혼용하지 않는다.
- Class A/B/C는 버스형·밴형·캡오버형 설명과 실루엣 이미지를 함께 쓴다.

## 4) 미결 사항·막힌 점
