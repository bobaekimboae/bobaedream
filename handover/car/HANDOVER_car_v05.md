# 코덱스-중고차 작업 인수인계서

- 코덱스 이름: 코덱스-중고차

- 문서 버전: `v05`
- 작성일: 2026-10-02 (KST)
- 이전 문서: `HANDOVER_car_v04.md`

## 1) 담당 범위

- 중고차 실제 메인, 중고차 목록 진입, 중고차 메인용 공통 UI 아이콘 적용을 담당한다.
- 다른 카테고리는 메인 메뉴의 임시 상태만 제공하고 실제 화면은 구현하지 않는다.

## 2) 현재 진행 상태

- 완료: 노션 원본 UI 아이콘 5종과 AutoScout형 서비스 칩을 실제 루트 메인에 적용.
- 완료: 일반 루트는 새 메인, 기존 쿼리형 주소는 중고차 목록으로 분리.
- 완료: 1차 Pages 배포 후 발견한 이중 `bobaedream/assets` 경로를 배포 안전 상대 경로 조합으로 교정.
- 진행 중: 교정본 재배포와 공개본 이미지 404 최종 확인.
- 미착수: 다른 카테고리 실제 화면 연결.

## 3) 결정된 사항과 그 이유

- Pages 작업의 문자열 치환 대상인 `/assets/`를 React 소스에 완성 문자열로 두지 않고 경로 조각을 `join`해 만든다. 로컬에서는 `assets/...`, Pages에서는 프로젝트 루트 기준 `assets/...`로 동일하게 해석되며 이중 치환을 피한다.
- 독립 프로토타입은 기존 `data-img` 구분자 방식, 실제 React 메인은 경로 조각 결합 방식을 각각 유지한다.

## 4) 미결 사항·막힌 점

- 다른 카테고리 실제 목적지 주소는 각 담당 코덱스 결과 대기.
- 코덱스-자료 상호 검수 대기.
