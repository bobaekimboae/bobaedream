- 코덱스 이름: 코덱스-중고차
- 파일용 코드: `car`
- 문서 버전: `v02`
- 작성일: 2026-10-02 (KST)
- 기준 브랜치: `codex/seller-font-weight`
- 이전 문서: `HANDOVER_car_v01.md`

## 1) 담당 범위

- 중고차 메인, 목록, 상세, 등록, 중고차 필터와 퀵필터를 담당한다.
- 바이크·화물/특장·건설기계 화면은 담당하지 않는다.
- 이번 임시 메인에서는 다른 카테고리를 메뉴에만 표시하고 해당 화면이나 데이터는 구현하지 않았다.

## 2) 현재 진행 상태

### 완료

- AutoScout형 임시 모바일 메인 1차 시안을 기존 AutoTrader형 골격을 재사용해 구성했다.
- 서비스 메뉴를 `전체 / 중고차 / 커뮤니티 / 트럭/특장 / 바이크 / 건설기계 / 캠핑카 / 부품/용품` 순서의 가로 스크롤 알약칩으로 구성했다.
- 선택 칩은 블랙, 미선택 칩은 흰색과 회색 테두리로 구분했다.
- 보배드림 공통 헤더 SVG, 이미지 히어로, 검색 카드, 바디 타입, 인기 제조사, 내 차 팔기, 추천 매물 구조를 유지했다.
- 중고차 CTA를 기존 `?qf=guazi&filtericon=notion` 목록에 연결했다.
- 384×900px에서 칩 스크롤·선택 상태·중고차 이동·콘솔 오류를 검수했고 `npm run verify:qf`를 통과했다.

### 진행 중

- 노션 원본 이미지와의 픽셀 단위 2차 비교는 원본 접근 문제로 대기 중이다.

### 미착수

- 다른 카테고리의 실제 메인·검색·목록 화면 연결은 각 담당 코덱스 범위이므로 미착수다.
- GitHub Pages 배포는 사용자가 이번 단계에서 요청하지 않아 미착수다.

## 3) 결정된 사항과 그 이유

1. 기존 `public/prototypes/autotrader-bobaedream-main/index.html`을 1차 임시 메인으로 재사용한다. 이미 검색 중심 모바일 메인과 필요한 이미지 자산이 있어 빠르게 구조를 검증할 수 있기 때문이다.
2. 전체 메뉴는 화면 상단의 독립 가로 스크롤 알약칩으로 둔다. 8개 항목을 모바일 한 줄에 유지하고 탐색 계층을 먼저 보여 주기 위해서다.
3. 선택색은 현재 보배드림 공통 액션과 같은 `#222`를 사용한다.
4. 중고차만 실제 목록으로 연결한다. 다른 카테고리의 구현 권한과 작업 범위를 침범하지 않기 위해서다.

## 4) 미결 사항·막힌 점

- 노션 페이지 본문은 이미지 2장으로 확인되지만 브라우저에서 로그인 화면이 뜨고 첨부 주소가 만료되어 원본 픽셀 실측은 미확인이다.
- 메뉴 칩의 최종 높이·간격·선택색은 노션 원본을 다시 열 수 있을 때 2차 교정이 필요하다.
- 다른 카테고리 선택 후 연결할 최종 주소는 각 담당 코덱스 산출물 대기다.
