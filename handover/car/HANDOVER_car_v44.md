# 코덱스-중고차 작업 인수인계서

- 코덱스 이름: 코덱스-중고차
- 파일용 코드: `car`
- 문서 버전: `v44`
- 작성일: 2026-10-02 (KST)
- 이전 문서: `HANDOVER_car_v43.md`

## 1) 담당 범위

- 보배드림 커뮤니티 PC 레딧형의 영상·텍스트·이미지 혼합 피드 시안.

## 2) 현재 진행 상태

- 완료: 텍스트 전용·사진 1장·사진 갤러리·영상 썸네일 카드 혼합.
- 완료: 기존 차량 이미지와 영상 아이콘 자산 재사용.
- 완료: 카드 상세 이동과 레딧 레이아웃 상태 유지.
- 완료: 1440px 브라우저·이미지·콘솔·전체 빌드 검수.
- 미착수: GitHub Pages 공개 배포.

## 3) 결정된 사항과 그 이유

- 24개 피드 중 텍스트 전용 15개, 사진 1장 3개, 갤러리 3개, 영상 3개로 구성해 텍스트 중심 커뮤니티 성격을 유지한다.
- 사진·영상은 제목과 본문 미리보기 아래에 배치해 글의 맥락을 먼저 읽게 한다.
- 단일 사진과 영상은 16:9, 갤러리는 큰 대표 이미지와 작은 보조 이미지의 2열 구조를 사용한다.
- 영상에는 중앙 재생 아이콘과 우측 하단 재생 시간을 표시한다.
- 갤러리에는 우측 상단 사진 수를 표시한다.
- 모든 미디어는 `object-fit: cover`로 표시하며 기존 레딧형 카드 폭 안에서만 확장한다.

## 4) 미결 사항·막힌 점

- 영상은 시안용 썸네일이며 실제 재생은 연결하지 않았다.
