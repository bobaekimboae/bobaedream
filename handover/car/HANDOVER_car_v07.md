## 1) 담당 범위

- 중고차 실제 메인, 중고차 목록 진입, 메인용 공통 UI 아이콘을 담당한다.
- 다른 카테고리는 임시 선택 상태만 제공한다.

## 2) 현재 진행 상태

- 완료: 노션 원본 검색·메뉴·위치·셰브론·화살표 SVG 5종 적용.
- 완료: AutoScout형 40px 서비스 알약칩 교정.
- 완료: 일반 루트에 실제 메인을 노출하고 기존 쿼리형 매물 목록 경로 보존.
- 완료: Pages 이중 자산 경로와 히어로 CSS 상대경로 문제 교정·재배포.
- 미착수: 다른 카테고리 실제 화면 연결.

## 3) 결정된 사항과 그 이유

- 일반 루트는 메인, `qf` 등 기존 검수 쿼리가 있으면 목록을 표시한다.
- 일반 이미지 경로는 영문 경로 조각 결합, 히어로는 문서 기준 인라인 배경으로 구성해 Pages 자동 치환과 외부 CSS 상대경로 영향을 피한다.
- 중고차 외 서비스 칩은 담당 범위를 넘지 않도록 준비 중 상태만 제공한다.

## 4) 미결 사항·막힌 점
