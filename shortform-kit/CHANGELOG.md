# 변경 기록

형식: 버전 · 날짜 · 무엇을 · 왜 · 정한 사람

## v0.2.0 · 2026-11-22

**AS24 관찰 기법 23개에 표준 이름 + 보배드림 사례 예제** — 정한 사람: 사용자(「재미와 정보 두 개를 제공」)
- 이름이 없던 23개를 모두 등록(상태 「관찰」): 퀴즈 첫 화면, 덮개 공개, 둘 중 하나, 시리즈 타이틀, 설명용 그림 컷,
  단색 배경 진행자, 세로 3분할, 비교 차 카드, 폰 앱 화면, 매물 카드, 웹 창, 감탄 큰 낱말, 인용 문장 카드, 순번 숫자,
  가격 예고, 통계 화살표 칩, 칩 교체, 국기, 놀람 선, 버튼 누름, 붓 원 와이프, 댓글 유도, 팔로우 유도
- 항목마다 「보배드림 사례」(한국 중고차 매물에서 쓰는 예)와 AS24 원본 장면 링크·크기·길이를 붙임
- 새 칸 **목적(재미 / 정보 / 둘 다)** — 모든 항목에 표시, 한 영상에 재미·정보 기법이 둘 다 들어가야 함
- AS24 관찰 스킬 53개 모두 우리 코드에 대응(빈칸 0) → 사전 107개(구성 19 · 기법 60 · 옵션 표시 19 · 자산 9)
- 사실 원칙 유지: 비교·통계·국기 값은 원장·공식 출처 있는 값만, 감탄·인용은 사람이 실제 말한 것만

## v0.1.0 · 2026-11-22

**새로 만듦 — 편집 기법 사전**
- 편집 유형 4가지 확정(사진 / 실촬영 심플 / 실촬영 3D / ASMR) — 정한 사람: 사용자
- 카드 설명형은 유형이 아니라 **편집 구성(스킬)**으로 둠 — 사용자
- 편집 구성: 카드 정보(기본 정보·성능점검·보험이력·제원), 카탈로그 컷, 딜러 설명 컷, 배기음 컷, 첫 컷 임팩트 — 사용자
- 그동안 쓴 기법 전수조사: 코드 3곳(사진판 `photo_listing`, 실촬영 `video_listing`, 공용 `sag_reel_v1.py`)과
  AS24 관찰 스킬 53개(`edit_skills/library_v2.json`), 실촬영 기법 T01~T07, 옵션 표시 17개를 한 사전으로 합침
  → 84개 항목(구성 12 · 기법 44 · 옵션 표시 19 · 자산 9)
- 영상별 사용 기법 기록 도구 `identify.py`(사진판)
