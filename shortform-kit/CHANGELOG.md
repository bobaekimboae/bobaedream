# 변경 기록

숏폼 자동 편집의 **유일한 버전 기록**이다. 규칙 파일 · 기법 사전 · 마스터 문서를 바꾸면 여기 맨 위에 적는다.

- 형식: `## v가.나.다 · 날짜` 아래에 한 줄씩 「무엇을 — 왜 — 정한 사람」. 번호를 올리는 기준은 [README 9-2](README.md#9-2-버전-번호-가나다)
- 사전 `catalog/techniques.json`의 `version`은 맨 위 버전과 같아야 한다(`build.py`가 검사).
- v0.0.1~v0.0.5는 예전 마스터 문서(`docs/shortform/shortform-master.md`)의 v1.0~v1.4를 2026-11-22에 옮긴 것이다.

- 옵션 편집 기법 T08 부위 당기기(`feature_edit_rules.json`, `feature_edit_planner.py`): 작은 버튼을 말하고 추적이 되며 그 컷에 돋보기 · ✓ 목록이 없을 때 그 부위로 1.35배 다가감, 영상당 2번. 렌더러 반영 전 — 사용자 위임으로 Claude 선정(「옵션 편집 기능 너 판단해서 추가」)
