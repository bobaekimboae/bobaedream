# 보배드림 숏폼 카드정보 제작·검수 제안 v0.2

작성자: 서울오토갤러리 자동 영상 제작 코덱스 마스터
작성일: 2026-11-26 (KST)
상태: 클로드 시안 1·2 제작을 위한 컨설팅. 실제 영상 제작·평가 완료를 의미하지 않는다.

## 2차 제안 적용

사용자 2차 지시에 따라 카드 라이브러리는 기존 7종 + 차량이력 타임라인 = 8종이며 매물별 선택 삽입이다. 선택한 기본 카드들의 상대 순서는 차량 기본정보 → 성능점검 → 보험이력 → 차량이력 타임라인이다. 중간에 생략된 카드를 채우지 않는다. 카드 끄기·빈 선택·근거 미확보이면 0종도 가능하며 생략 사유를 남긴다. 8종 모두를 한 편에 넣도록 강제하지 않는다.

[2차 제작·출처·선택 매뉴얼](card-selection-v2.md), [기계 판독 선택 계약](card-selection-v2.json), [참조 계획 검사](check_v2_policy.mjs)를 우선 적용한다. 이전 16종 표의 C08~C16은 1차 확장 후보로 보존한다. 새 타임라인은 기존 소유 이력 요약과 구분하고 국토부·TS의 실제 차량 단위 근거를 확보한 뒤 사용한다. 이번 G400d 자료에는 해당 응답을 검증하지 못했으므로 타임라인 생략 계획을 제시한다. 참조 계획 검사는 운영 선택기·API·MP4 시험 완료를 뜻하지 않는다.

기존 shortform-kit 사전 v0.2.4의 SG-CARD-BASIC·INSPECT·INSURE·SPEC·SG-CATALOG를 재사용한다. 새 별칭은 제안 상태이며 사전 등록·사용자 선택 전 운영 렌더에 넣지 않는다. v2 선택 모드에서 기본정보 두 번째 컷 강제는 적용하지 않는다. 기존 v1 프리셋 자체와 최대 6줄·확정 색상은 변경하지 않는다.

## 카드별 입력·대사·검수

### C01 성능점검

- 입력: inspection_date, inspection_accident, simple_repair, repair_note
- 근거: 성능점검 원문 + 선택된 체크박스
- 자막 예시: 기록상 사고이력 없음 / 단순수리 있음
- 대사 초안: 성능점검기록부에는 사고이력 없음, 단순수리 있음으로 표시되어 있습니다.
- 검수: 문서 날짜 표시. A등급 생성 금지. 보험 이력과 합치지 않음.
- 상태: 기존 코드 확장 제안

### C02 보험 이력

- 입력: own_damage_count, other_damage_count, insurance_as_of
- 근거: 보험 이력 원문 또는 출처 표시 요약
- 자막 예시: 내차 피해 1회 / 상대차 피해 없음
- 대사 초안: 공개된 보험 이력에는 내차 피해 한 번, 상대차 피해는 없음으로 표시됩니다.
- 검수: 보험 처리와 사고 판정을 구분. 수리비 미확인은 0원으로 표시하지 않음.
- 상태: 기존 코드 확장 제안

### C03 차량 정보

- 입력: model, first_registered, mileage_km
- 근거: 매물 원장 + 등록·점검 자료

- 대사 초안: 2021년 5월 최초 등록된 G400d입니다. 매물 표시 주행거리는 3만 3천 475킬로미터입니다.
- 검수: v2에서는 선택된 기본 카드 중 상대순서 1이며 필수·두 번째 컷 강제가 아니다. v1 프리셋과 최대 6줄 규칙은 보존한다.
- 상태: 기존 코드 확장 제안

### C04 옵션 정보

- 입력: option_name, option_selected, option_source

## 카드 디자인과 모션

AutoScout24 NL 웹 검색 결과에서 모델·가격·등록월·주행·연료·출력·판매자 정보를 묶어 보여주는 구조를 확인했다. 이 웹 정보 위계를 카드로 옮기는 제안이다. 이번 작업에서 릴스의 모션·색상·노출 시간을 새로 실측하지 않았다. 가격의 세금 조건처럼 수치에 붙는 조건을 함께 보존한다.

A안은 기존 카드와 양립하는 밝은 배경, B안은 차콜 배경 비교안이다. 기존 확정 강조색·칠 디자인을 덮어쓰지 않는다. 한 제목과 2~3개 보조 사실을 순서대로 보여준다. 사진형 기존 기본 카드의 나머지 정보는 보조 행으로 유지 가능하다. 숫자 카운트업은 중간 가짜 가격이 보일 수 있으므로 쓰지 않는다. 본문은 고정하고 입장 0.18초·행 순차 0.12초·퇴장 0.12초를 초기 시안값으로 비교한다. 권리 확보된 짧은 효과음을 카드 시작에 한 번만 사용하며 사실마다 효과음을 겹치지 않는다.

1080×1920 작업용 배치 시작값: 카드 x=80..900, y=250..1000. 기존 자막 y=1050..1220 부근과 충돌하지 않게 시작한다. 이는 실제 앱 안전영역 보장이 아니므로 Instagram·TikTok·YouTube UI에서 다시 검수한다. 포인터가 필요 없는 독립 정보 카드에는 손가락을 넣지 않는다. 원문 링크·기준일은 읽을 수 있는 크기로 두며 많은 원문을 작은 글씨로 축소하지 않는다.

## 자동화 계약과 제작 순서

원장 revision 고정 → fact_id와 문서 날짜·선택 상태 확인 → 카드 종류 선택 → 승인 대본 → ElevenLabs 타임스탬프 → 카드 시간 결정 → 타임라인 조립 → MP4 → 개인정보·권리·사실·앱 UI 검사 → 딜러 완성본 승인 → 게시.

색·시트·손상·차체를 생성형 AI로 바꾸지 않는다. 모든 카드에 fact_ids를 붙이고 자막·대사·그래픽이 같은 값을 읽게 한다. 원장 수정 시 해당 대본·TTS 캐시·MP4 승인 무효화. 모델 생성 결과는 저장·해시 고정한 뒤 렌더에 사용한다. 입력 단위는 정수 ms, 출력은 기존 1080×1920/30fps/H.264/AAC 프리셋을 재사용한다. 원문 PDF·이미지·영상이나 고객 개인정보는 공개 GitHub에 넣지 않는다.

기존 렌더러를 새로 만들지 않고 shortform-kit에 사실 바인딩·카드 타임라인을 연결하는 어댑터를 제안한다. 이 패킷은 생산 코드가 아니며 새 카드 기법은 사전 등록 PR과 함께 검토한다.
