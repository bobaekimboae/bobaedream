# 사진 매물 → 벨기에판 쇼츠 (파이프라인 v1.3, 2026-11-17)

작업 전 프로젝트 문서 `claude/매물-릴스-제작-파이프라인-에이전트공용-v1.md`(v1.3)를 먼저 읽는다. 렌더러 `common.py`의 `PIPELINE_VERSION`과 매뉴얼 버전을 함께 올린다.

코드: `scripts/shortform/photo_listing/` (common.py 렌더 · mkcfg.py 차량별 설정 생성 · tr.py 받아쓰기 · still.py 확인용 정지컷 · icons3d/ 3D 아이콘 · cfg_example_g63.py 예시). 공용 그리기 함수는 `scripts/shortform/sag_reel_v1.py`(`SAG_EDIT=bobae_be`).

## 지킬 원칙
- 차 사진은 실사진 그대로. AI 이미지→영상 금지, 배경 제거·보정 없음. 움직임은 확대·이동·자르기만.
- 대본·칩의 사실은 매물 정보와 사진에 보이는 것만. 없는 숫자 금지. 할부·월납 금액 금지.
- 번호판은 가리지 않고, 개인 연락처만 가린다. 코드네임은 BMW·벤츠·포르쉐만.
- 음악·효과음은 자체 자산만(`public/assets/shortform/bgm/bobae_showroom_v1.mp3`, `sfx/ding.wav`·`whoosh.wav`).
- 크레딧 드는 생성(음성)은 한 번 만들고 확인. 커밋·배포는 사용자가 말할 때만. 파일명은 영문.

## 순서
1. **사진 받기**: 딜러 매물 페이지(조이모터스 상세)의 사진 주소 목록 → 차량별 폴더 `src/`에 받고, `src2/p01.png…`로 번호 매김(1번 = 정면/대표).
2. **부위 이름표**: 사진마다 정면·옆·뒤·휠·계기판·대시보드·센터콘솔·시트·적재공간 등 부위를 적는다. 흔들림·중복은 뺀다.
3. **대본**: 30초 안팎, 11~13컷. 훅(제조사·모델) → 제작/등록·주행 → 정식출고·무사고 → 외관색 → 엔진·마력·제로백 → 옵션 2~4개 → 적재공간 → 특이사항(리스·보증 등) → CTA 「보배드림 앱에서 자세한 정보를 보시거나 구글·애플 스토어에서 다운받으세요!」.
4. **음성**: 일레븐랩스 `creative_generate_speech`, Hwan(`GFsKFsadyjMQ7MPv89Tw`), 모델 eleven_v4, 대본 앞 `[excited]`·마지막 안내 `[warmly]`, 합니다체 → 무음만 줄여 `voice_a.mp3`. 숫자·영문은 대본에 소리 나는 대로(일인 신조 · 영껀 · 씩스바이투), 화면 자막은 원래 표기. 속도는 `BBM_SPEED=1.0` 기본(목표 55~60초에서 벗어날 때만 1.1~1.2), 속도를 바꾸면 `voice.wav`를 지운다.
5. **어절 시각**: `python3 tr.py <차폴더>` (faster-whisper large-v3-turbo, word_timestamps) → `voice_a_words.json`, 어절 번호 목록 출력.
6. **설정(cfg.py)**: mkcfg.py에 차량별 dict 작성 — `OUT`, `HOOK=(제조사, 모델, '등록월 · 주행')`, `FIT`(차 전체를 맞춤 표시할 가로 사진 번호), `WHOOSH_AT`(휙 효과음 컷 2개), `MARKS`(칩별 이모지), `EXTRA_CHIPS`, `CUTS` 튜플 = (사진번호, 부위, 첫 어절번호, 자막어절[(글자,번호)…, '|'로 줄 나눔], 칩(글자,어절번호) 또는 None, 넘김, 켄번스(가로시작, 가로끝, 확대시작, 확대끝, 세로중심)).
7. **확인**: `python3 common.py <차폴더> --plan` → plan.json(컷 시작·끝·칩). `python3 still.py <차폴더> 시각들…` → 정지컷 시트로 칩·자막 겹침·차 잘림 확인.
8. **렌더**: `python3 common.py <차폴더>` (1080×1920·30fps). 영상 옆에 `영상.mp4.plan.json`(판 ED-PHOTO·쓴 기법)이 남는다.
9. **검사**: `python3 scripts/shortform/check_be.py <영상>` — `통과` 전에는 전달하지 않는다. 부위 이름표는 공용 `scripts/shortform/auto/photo_tagger.py`(SigLIP 2, 2026-11-22 CLIP에서 교체), 계기판 숫자는 `odometer.py`(RapidOCR 3.x · PP-OCRv6).

## 렌더 규칙 (common.py)
- 컷 시작 = 첫 어절의 실제 소리 시작(받아쓰기 시작에서 -32dB 넘는 첫 지점으로 당김) − 0.12초. 끝에 0.5초 여유 + 끝 화면 2초.
- 사진: 세로 꽉 채움 기본, `FIT` 사진은 차 전체 + 같은 사진 흐리게 채움. 켄번스는 부드러운 가속(ease).
- 넘김: whip_l·whip_r(가로 밀기+모션블러), push_up(위로), zoom(확대+흐림+섬광), flash(흰 섬광), blur(흐림 교차) — 컷 경계 앞뒤 절반씩.
- 첫 화면: 제조사 노랑 붓띠 칩 + 같은 줄 흰 큰 모델명 + 아래 등록월·주행 한 줄.
- 칩: 노랑 붓띠(오토스카우트 BE), 숫자 칩은 화면 28% 높이에 크게 띄우고 그동안 말 자막 숨김, 글자 칩은 자막 위. 칩은 기울이지 않는다(0°, 2026-11-22 사용자 확정 · 첫 컷 브랜드 칩만 판 자체 기울기). 색·크기·자리 값은 `be_locked_rules.json`에서만 읽는다.
- 말 자막: 2~5어절 덩어리, 말하는 낱말 따라 색 바뀜(`phrase_img_be3`).
- 딜러 칩(딜러 이름·상사가 있을 때): 왼쪽 위(36,96) 독일식 두 줄 둥근 상자 — cfg `DEALER_CHIP_STYLE='de'`, `DEALER_CHIP_LINES=['○○○ 딜러','○○센터']`, `DEALER_CHIP_SIZE=38`. 위 노랑 `#E4E25C` −2°, 아래 흰 `#F8F8F6`가 0.14배 덮음, 상자 높이 = 글자 1.85배, 여백 0.24배, 모서리 0.17배. 대안 붓칠(노션 원본 430_239)은 칠 높이 2.8배·여백 0.2배, 글자가 칠 밖으로 나가지 않을 때까지 폭 자동 확장. 딜러 개인 연락처는 넣지 않는다.
- 딜러 로고 이미지만 있을 때: 왼쪽 위(40,96) 흰 알약 안. 끝 화면: 마지막 장면 어둡게 + 보배드림 엔드카드 커짐 + 딜러 로고.
- 소리: 목소리(highpass 70·약한 압축) + 배경음(목소리 나오면 줄임) + 효과음(첫 딩 0.05초, 휙은 WHOOSH_AT 컷 0.16초 전) → 2단 loudnorm. 목표값은 `be_locked_rules.json`의 audio(−14 LUFS ±1, TP −1.5)에서 읽고 코드에 숫자를 쓰지 않는다.

## 변형 (환경변수, 파일명 꼬리)
- 기본: 동적 넘김 → `_.mp4`
- `BBM_FADE=1`: 모든 넘김을 0.5초 페이드, 휙 효과음 없음, 사진은 상자 맞춤 → `_fade`
- `BBM_ICON3D=1`: 칩 오른쪽 끝에 큰 3D 아이콘(icons3d, Fluent 3D 이모지 등, 칩 글자 키워드로 자동 선택) → `_3d`
- 둘 다 → `_fade_3d`. 네 가지를 함께 만들어 비교하게 한다.

## 독립 컷 — 성능지 요약 · 가격 인하 카드 (v1.4)
- 딜러가 성능·상태 점검기록부를 주면 카탈로그형 독립 컷으로 "핵심만 읽어 주기" 구간을 넣는다. 차 폴더에 `cards.json`(bg 사진 번호, report: doc·diagram_box·car·stamp·rows·foot, price: old_label·old·new_label·new·note·photo)을 쓰고 `python3 report_cut.py <차폴더>` → `src2/p20~p25`(머리만 → 체크 5줄), `p30~p31`(신차가 → X줄 + 할인 판매가).
- 성능지 원본에서는 차체 그림 칸만 잘라 쓴다. 차량번호·차대번호·제시번호·검사자 칸은 쓰지 않는다. 체크 줄은 성능지에 있는 칸만(사고·단순수리 / 침수·화재 / 렌트·리스·영업용 / 튜닝·리콜 / 엔진·변속기 누유·주요 장치). "있음"은 숨기지 않는다.
- 성능지 주행거리(점검 당시)와 딜러 글(현재)이 다르면 딜러 글 숫자를 말한다.
- 대본: "자, 성능점검 기록부. 핵심만 읽어 드립니다" → 한 문장 = 한 줄 = 한 컷.
- cfg: 카드 컷 켄번스 정지 `(.5,.5,1.0,1.0,.5)`, 첫 카드 `dip_white`(가격 `dip_black`), 다음 단계는 넘김 `'reveal'`(0.18초, 단계마다 팝), `CAP_CY_PHOTOS={20:1660,…,30:1600,31:1600}`로 자막을 카드 아래에. 카드 컷엔 노랑 칩을 띄우지 않는다. 사진 컷 복귀는 `fade_long`.
- 앱 안내 문구를 빼라는 지시가 있으면 마지막 문장은 딜러 문의로 끝내고, 끝 화면은 보배드림 로고만.

## 검수
- 길이 28~35초, 첫 말 0.2초 안, −14±1 LUFS.
- 정지컷 시트로 칩-자막 겹침·차 잘림·사실 오류 0 확인, 사진이 원본 그대로인지 확인.
- 결과는 영문 파일명 mp4로 전달(`bobae_be_joy_<차>.mp4`). 의견·변경은 노션에도 기록.
