# 벨기에판 규칙 고정

## 단일 기준
- `scripts/shortform/be_locked_rules.json` 한 파일이 벨기에판 색·자막 높이·칩 글자 크기·칩 자리·기울기·등장 시각·유지 시간·컷 뒤 자막 비움·효과음 개수·음량의 유일한 기준이다.
- 렌더 코드(sag_reel_v1.py, photo_listing, 브이로그 렌더러 등)는 이 파일을 읽기만 하고 숫자를 코드에 직접 쓰지 않는다.
- 매뉴얼 v4·교본 v3·자막 규칙 v2·효과음 규칙 v1의 숫자와 다르면 이 파일이 맞다. 옛 값(#EEEF05·#F7EC38·파랑 칩·67%·2.7°)을 다시 쓰지 않는다.
- 규칙은 사용자가 말할 때만, 이 파일만 고친다.

## 사용자 확정(user_locked) — 묻지 않고 바꾸지 않는다
- 칩 옆 Fluent 3D 아이콘은 좋음 · 따로 툭 뜨는 이모지 스티커 금지
- 노랑 한 색만 · 주황 획·원·민트 화살표·반짝임 금지
- 자막에는 붓칠·마커를 칠하지 않는다
- 포인트 칩은 장소 칩과 같은 위쪽 고정 자리, 같은 순간이면 같은 자리에서 글자만 바뀜
- 모든 칩은 글자 크기·모양이 같다
- 영상 매물은 벨기에 효과음 기준(음악 있으면 1번), 사진 매물은 효과음 많게(예외)

## 순서
1. 렌더 전: `python3 scripts/shortform/check_be.py --code` — 렌더 코드 값이 규칙 파일과 같은지.
2. 렌더: 렌더러가 영상 옆에 `영상.mp4.plan.json`(칩 시각·글자 크기·자리·효과음·컷)을 남긴다.
3. 렌더 후: `python3 scripts/shortform/check_be.py 영상.mp4` — 음량, 효과음 개수·간격, 칩 글자 크기·자리 하나, 칩이 컷을 넘지 않음, 칩 유지 시간, 화면 실측(칩 윗선·높이 일정, 칩 노랑 색, 자막 띠에 칠 없음).
4. `실패`가 하나라도 있으면 고치고 다시 렌더한다. `통과` 전에는 사용자에게 영상을 주지 않는다.
5. 결정·변경은 노션 에이전트 의견 DB에 남긴다. 커밋·배포는 사용자가 말할 때만.
