# 컷별 차량 기능 설명 숏폼 (나세르형)

차란차식 "사진 넘기기 + 사양 나열"이 아니다. 영상의 컷 하나 = 기능 하나. 화면에 보이는 그 기능을 내레이션이 설명하고, 자막과 포인트 표시가 그 기능 위치를 따라간다.

## 꼭 지킬 원칙
- 반사기 원칙: 영상은 자르기·속도·확대·이동만. AI 배경 교체·지우기·보정 금지. 번호판은 가리지 않는다.
- 대사는 매물원장 값 + 화면에 실제 보이는 것만. 지어내지 않는다. 화면만 가리키는 추상 대사("트렁크는 이렇게 열리고") 금지 — 구체적 사실·제원을 말한다.
- 판매가격은 원장에 있으면 말한다(기본 켬). 연락처·차량번호는 자막·대사에 넣지 않는다.
- 모델 코드네임은 BMW·벤츠·포르쉐만.
- 크레딧 쓰는 생성(TTS·받아쓰기)은 재시도로 반복 호출하지 않는다. 한 번 만들고 확인.
- 파일 이름은 영문(ASCII).
- 새 코드는 리뉴얼 스택(Nuxt 4·Vue 3·TS / Laravel 12). 시안 단계 렌더는 Python·FFmpeg 워커 허용.

## 입력
1. 원본 영상: 구글 드라이브 `숏폼샘플/영상/` (제미나이가 다운로드, 파일명 = 릴스 코드.mp4)
2. 매물원장: 드라이브 `숏폼샘플/매물원장` 시트 한 행
   - 필드: 영상코드 · 원본링크 · 계정 · 게시일 · 제조사 · 모델 · 세대/트림 · 연식(최초등록 연월) · 주행거리 · 연료 · 변속기 · 배기량/마력 · 색상 · 가격 · 주요 옵션(쉼표) · 사고/보험 · 지역/단지 · 드라이브 영상 링크 · 비고
   - 원장에 없는 값은 비워 두고 대사에 쓰지 않는다.

## 확정 음성
- ElevenLabs `KKC HQ` (voice_id `PDoCXqBQFGsvfO0hNkEs`, 20대 남성·서울 말투), 모델 `eleven_v3`, 맨 앞 `[calm]` 한 개만. 긴 영어 태그 금지(앞에 잡음 생김).
- 대사는 하오체 금지, 「입니다」와 「요」를 섞어 실제 중고차 판매 숏폼처럼. 화면에 나온 장치는 원리를 한 문장으로 설명(예: 디퍼렌셜 락). 숫자는 한글로 풀어 쓴다(12.3 → 십이 쩜 삼).
- 한 문장만 고칠 때는 그 문장만 같은 목소리로 한 번 생성해 무음 구간에 끼우고 낱말 시각을 다시 받는다.
- 제원은 매물원장 + 사용자가 준 제원 출처(ADAC·다나와 등)만. 계기판이 안 읽히면 주행거리·가격은 말하지 않는다. 확정 발음 표: XC90 엑스씨구공, GV70 지브이칠공, G80 지팔공, T8 티팔.
- '…'는 꼬리 울림을 키우므로 쉼표 위주.

## 절차

### 1. 컷 나누기
- `ffmpeg -vf "select='gt(scene,0.3)',showinfo"` 또는 PySceneDetect로 컷 경계 추출 → `cuts.json` [{i, start, end}].
- 0.6초 미만 컷은 앞 컷에 합친다.

### 2. 컷별 기능 판정
- 부위 이름 초안은 `scripts/shortform/auto/shot_tagger.py`(SigLIP 2 base, 공용 `vlm.py`, 2026-11-22 CLIP에서 교체 · cha13 27장면 22 대 18)로 붙이고, 사람이 정지컷 시트로 한 번 확인한다.
- 컷마다 가운데 프레임 1장 + 시작·끝 프레임으로 접촉 시트(contact sheet)를 만든다.
- 각 컷에 기능 1개를 붙인다: 부위(외관 앞/옆/뒤·휠·실내·계기판·센터 화면·시트·썬루프·트렁크·엔진룸 등) + 기능명 + 원장 근거 필드.
- 원장에 근거가 없는 기능은 이름만("파노라마 썬루프") 말하고 수치를 붙이지 않는다. 확신이 없으면 그 컷은 일반 대사(차명·연식)로 둔다.
- 결과: `feature_map.json` [{cut, part, feature, fact, source_field, anchor_xy}] — anchor_xy는 기능이 화면에서 있는 점(정규화 0~1).

### 3. 대본
- 컷 길이 × 한국어 말속도 약 6.5음절/초 이하로 컷당 한 문장. 첫 컷은 훅(차명 + 가장 센 사실), 끝 컷은 가격·지역.
- `script.json` [{cut, line_tts(발음 표기), line_sub(표준 맞춤법)}]. 자막은 표준 맞춤법, TTS만 발음 표기.

### 4. 음성 생성 (한 번)
- 전체 대본을 한 번에 생성해 톤을 맞춘다(컷마다 따로 만들면 톤이 튄다). `generations_count: 1`.

### 5. 씽크 매핑
- ElevenLabs Scribe로 단어별 시간 추출 → 각 컷 문장의 첫·끝 단어 시간을 찾아 `sync_map.json` [{cut, a_start, a_end, words:[{t,s,e}]}].
- 영상 컷을 음성 구간에 맞춘다: 컷이 짧으면 0.8~1.0배 감속 또는 마지막 프레임 정지(최대 0.5초), 길면 앞뒤 트림. 속도 변화는 0.8~1.25배 안.
- 컷 전환은 문장 시작 0.1초 전.

### 6. 트래킹
- anchor_xy가 있는 컷은 OpenCV VitTrack(OpenCV 5.1, `scripts/shortform/models/vittrack_2023sep.onnx`, Apache-2.0 · 모델이 없으면 CSRT로 자동 대체)으로 기능 점을 프레임마다 추적 → `track_<cut>.json`. 추적 점수 0.2 미만 프레임은 직전 위치 유지.
- 포인트 칩(기능명)·화살표·3D 아이콘이 이 점을 따라간다. 추적 실패(신뢰도 낮음) 프레임은 직전 위치 고정 후 0.2초 페이드아웃.

### 7. 그래픽·자막
- 말 자막: 바탕 칠 없음, 흰 글자 + 검은 테두리, 한 낱말씩 강조(현재 낱말 노랑 `#F5F200`(be_locked_rules.json color.yellow)). 화면 하단 1/3.
- 기능 칩: 노랑 붓칠 칩 + 화살표가 트래킹 점을 따라감. 화살표는 부위가 보이는 원본 구간에서만, 칩 위·아래 자리는 컷 안에서 고정(뒤집힘 방지), 아래 칩은 화면 58% 높이까지. 부위가 금방 사라지는 짧은 컷은 0.55배로 늦춰 끝에서 멈춤.
- 보조 정보(토크·변속기·제로백 등)는 직접 그린 흰 알약 금지 → **AS24 테마 붓칠 원본(`brush-fill/as24-theme/126_40.svg`, 칠 폭 520px 넘으면 `265_42.svg`)을 흰색으로 칠한 칩** + 오토스카우트 선 아이콘 또는 Fluent 3D + 진한 글자. 노랑 = 핵심, 흰 붓 = 보조.
- 칩 여백은 노랑·흰 같은 공식: 높이 = 글자 높이 × 1.9, 좌우 여백 = 높이 × 0.31, 칠의 가운데 줄에서 실제 칠해진 구간을 재서 그 가운데에 내용 배치(`scripts/shortform/video_listing/chip_margin_check.py`로 확인).
- 큰 숫자는 3D 글자(180, 마력 210). 숫자·기호가 섞인 값(265/60 R18)은 한 크기로. 시트 열선·통풍은 Fluent 3D 🔥❄️, 메모리 시트는 💺 + 노랑 원 ①②③(디스켓 금지). 아이콘은 Fluent 3D만(없으면 microsoft/fluentui-emoji 공식에서 받음).
- 효과음: 칩·숫자 딩, 시트 아이콘(열선·통풍·메모리·마사지)이 톡 나올 때 pop 0.30(딩과 0.45초 안이면 생략, 아이콘끼리 0.45초 안이면 앞의 것만). 마력은 딩 대신 말 울음 효과음(1회 생성). BGM은 음성 대비 낮게, 자체 음원.

### 8. 렌더·검수
- 1080×1920, 30fps, H.264, AAC, −14 LUFS ±1 · TP −1.5(be_locked_rules.json audio).
- 검수표: ① 모든 컷에 기능 1개 ② 대사 수치가 원장과 일치 ③ 음성 시작과 컷 전환 차이 0.15초 이하 ④ 칩이 기능 위치에서 벗어나지 않음 ⑤ 연락처·차량번호 노출 없음 ⑥ 바닥 소음·울림 확인.
- 산출물(영문 파일명): `<code>_feature_short.mp4`, `cuts.json`, `feature_map.json`, `script.json`, `sync_map.json`, `track_*.json`. 드라이브 `숏폼샘플/결과/<code>/`.
