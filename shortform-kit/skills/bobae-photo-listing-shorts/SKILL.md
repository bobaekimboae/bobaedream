# 사진 매물 → 숏폼 변환 (규격 v1.2)

딜러 영상이 없고 매물 사진만 있을 때 쓴다. 영상 매물은 `scripts/shortform/sag_reel_v1.py` 기본 흐름을 그대로 쓴다.

## 0. 지켜야 할 원칙 (어기면 출고 금지)
- **차 픽셀은 실사진 그대로.** AI 이미지→영상(Kling·Veo·Runway 등)으로 차를 움직이게 하지 않는다. 휠·로고·흠집·실내가 바뀔 수 있다(aicarvideo도 경고, Bring a Trailer AI 사진 사고). 움직임은 확대·이동·자르기만.
- 배경 제거·광택·흠집 지우기 없음. 번호판은 가리지 않는다(국내 딜러 매물 원칙). 개인 연락처·서류만 가린다.
- 대본·자막·라벨의 사실은 매물 정보(연식·주행·연료·가격·옵션)와 사진에 보이는 것만. 없는 숫자는 쓰지 않는다. 할부·월납 금액은 넣지 않는다.
- 음악·효과음은 자체 생성분만(`public/assets/shortform/sfx`, 코드 생성 BGM, 일레븐랩스). 캡컷·다른 앱 소리 금지.

## 1. 입력
- 매물 정보 1건(차명·연식/등록월·주행·연료·가격·옵션·딜러·단지)
- 사진 5~12장(6~8장 권장). 4장 미만이면 숏폼 대신 사진 카드만 만들고 사용자에게 알린다.

## 2. 사진 고르기·순서
1. 부위 분류: 촬영키트 자동 분류(`public/data/shoot-autosort-v1.json`, open_clip) 또는 눈으로 확인해 `앞 3/4 · 옆 · 뒤 3/4 · 정면 · 휠 · 계기판(주행거리) · 대시보드 · 앞좌석 · 뒷좌석 · 트렁크 · 옵션 화면` 이름표를 붙인다.
2. 같은 각도 중복·흔들림·어두운 사진은 뺀다.
3. 순서(오토스카우트 BE 투어 리듬): **앞 3/4(첫 장, 훅) → 옆 → 뒤 3/4 → 휠 → 계기판 → 대시보드 → 시트 → 트렁크 → 앞 3/4 다시(끝 화면 바탕)**. 대사에서 설명하는 옵션 사진은 그 구절 자리로 당긴다.

## 3. 사진 → 원본 영상 만들기
- 1080×1920 세로. 가로 사진(4:3·16:9)은 **차 전체가 보이게 가운데 맞춤 + 같은 사진을 흐리게 키워 위아래 채움**. 차 일부를 잘라내는 9:16 강제 자르기 금지(실내·디테일 사진만 꽉 채워도 됨).
- 사진 한 장 = 1.6~2.2초(투어형) 또는 2~3.5초(설명형). 움직임은 한 장에 하나: 천천히 확대(1.00→1.06), 좌우 이동(폭 4% 이내), 휠·디테일은 확대에서 시작. 같은 움직임 연속 2번 금지.
- 만든 슬라이드 영상을 `sag_reel_v1.py`의 원본으로 넣고, 설정 파일 `shots`의 시각을 사진 구간에 맞춘다.

## 4. 대본·음성·자막 (규격 v1.2)
- 30~35초, 5~7구절: 훅(차명·핵심 숫자) → 사양 → 옵션 1~3개 → 가격 → 「보배드림 앱에서 확인하세요」. 말은 0.2초 안에 시작.
- 음성: 일레븐랩스 v4(MCP `creative_generate_speech`), 낱말 시각은 Scribe(`creative_transcribe_audio`) → 대괄호 태그 낱말을 빼고 `SAG_VOICE_WORDS`로.
- 설정 파일 `STYLE`: `cap_style='v12'`(Pretendard ExtraBold 60, 흰 글자+검정 외곽선, y 1050~1220, 2~4어절·최대 2줄, 강조어 1개 #FFD56A), 라벨 칠 #306BD9 `stk_shape='as24'`, `feat_y≈780 · big_y≈760 · price_y=470`(라벨이 자막과 겹치지 않게), `sfx_pack=True · sfx_bus≈0.55`. 마력 라벨만 그림 스티커(`horse.png`), 옵션은 ✓.
- 참고 설정: `scripts/shortform/reels/gle_s4.py`.

## 5. 검수 (모두 통과해야 전달)
- 길이 28~40초, 끝 화면 약 2.4초, 첫 말 ≤0.2초
- 음량 −14±1 LUFS · 피크 −1 dBTP 이하(loudnorm 2단계 측정 보정, 영상은 copy)
- 6장면 접촉 시트로 확인: 라벨-자막 겹침 없음, 차 잘림 없음, 사실 오류 0, 번호판 외 개인정보 노출 없음
- 사진이 AI로 바뀌지 않았는지 원본과 한 장씩 비교

## 6. 전달·기록
- mp4는 영문 파일명(`brand-model-v12.mp4`)으로 사용자에게 보내고, 샘플 페이지는 `public/shortform-samples/` 에 넣되 배포는 사용자가 「배포해」라고 할 때만.
- 바뀐 규칙·결과는 `docs/shortform/shortform-master.md` 버전 기록과 노션 「영상 분석 스킬 조합」에 남긴다. 도구 번호는 P01–P17 · M001–M037 정본을 쓴다.
