# 보배드림 숏폼 자동 편집 키트 (shortform-kit)

매물 사진·촬영 영상으로 숏폼을 **자동으로, 누가 만들어도 똑같이** 편집하기 위한 매뉴얼·규칙·도구 모음입니다.
고치는 곳은 이 깃허브 하나뿐입니다. 구글 시트·노션은 보기용 사본입니다.

## 지금 들어 있는 것 (v0.1)

| 파일 | 하는 일 |
|---|---|
| `catalog/techniques.json` | **편집 기법 사전** — 모든 편집 요소의 표준 이름·코드(단일 기준) |
| `catalog/CATALOG.md` | 사람이 읽는 사전(자동 생성, 직접 고치지 않음) |
| `catalog/build.py` | 사전 검사 + CATALOG.md 만들기 |
| `catalog/identify.py` | 만든 영상에 어떤 기법을 썼는지 코드로 기록 |
| `CHANGELOG.md` | 버전별 변경 기록(무엇을 / 왜 / 누가 정했나) |

## 이름 체계 (5단계)

1. **편집 유형** `ED-*` — 소재와 성격. 4가지
   - `ED-PHOTO` 사진 매물 숏폼 변환
   - `ED-SIMPLE` 실촬영 · 오토스카우트24 벨기에 심플
   - `ED-3D` 실촬영 · 나세르 3D 효과
   - `ED-ASMR` 내레이션 없이 녹음된 소리만
2. **편집 구성** `SG-*` — 독립 컷 단위로 끼우는 덩어리(카드 정보 컷, 카탈로그 컷, 딜러 설명 컷, 배기음 컷, 첫 컷 임팩트 등)
3. **편집 기법** `CAP-* CHIP-* LIST-* MARK-* FX-* MOVE-* TR-* INS-* SFX-* BGM-* VO-* AUD-*` — 화면·소리에 거는 효과 하나
4. **옵션 표시** `FM-*` — 열선·통풍·마사지·메모리 등 차량 기능을 말할 때 부위에 붙는 이모지·3D 글자
5. **자산** `AS-*` — 칠 판 SVG, 3D 이모지, 효과음, 배경음악

## 쓰는 법

```bash
# 사전 검사 + 사람용 문서 다시 만들기 (규칙을 바꾼 뒤 꼭 실행)
python3 shortform-kit/catalog/build.py

# 만든 영상이 무슨 기법을 썼는지 기록 (차폴더에 used_techniques.json)
python3 shortform-kit/catalog/identify.py 차폴더 [--fade]
```

## 규칙

- 사전에 없는 기법은 쓰지 않습니다. 새 기법은 사전에 먼저 등록하고 `CHANGELOG.md`에 적습니다.
- 상태가 `금지`인 기법은 쓰지 않습니다(예: 따로 뜨는 이모지 스티커, 반짝이, 기울어진 붓띠).
- 규칙 값은 사용자가 정할 때만 바꿉니다.
- 대본·칩의 사실은 매물 원장에만 있는 값으로 씁니다. 사진·영상은 보정하지 않습니다(자르기·이동·확대·흐린 채움만).
- 남의 영상(AS24·나세르 원본)은 저장소에 넣지 않습니다. 분석해서 얻은 규칙만 넣습니다.
