# 샤오홍수 에디터 템플릿 UX 분석

## 범위

- 근거: 사용자가 제공한 편집 화면 스크린샷 1장과 17.12초 화면 녹화
- 확인한 흐름: 템플릿 탐색 → 템플릿 적용 → 장면 선택 → 장면 메뉴 → 마무리 도구
- 제한: 게시, 저장, 오류, 빈 상태, 키보드 접근성은 제공 자료만으로 확인하지 못함

## 전체 판단

샤오홍수 편집기의 강점은 기능의 수가 아니라 선택 순서다. 먼저 템플릿으로 영상 전체의 분위기를 결정하고, 이후 장면별 길이·TTS·텍스트를 문맥 메뉴에서 수정한다. 화면 하단에는 현재 단계에서 필요한 도구만 남겨 초보자도 다음 행동을 쉽게 찾게 한다.

## 단계별 상태

1. 템플릿 탐색 — 양호
   - 추천·신규·레트로·여행·게임처럼 분위기 기준으로 분류한다.
   - 실제 사진이 들어간 세로 썸네일로 적용 결과를 고르기 전에 예측할 수 있다.
   - 가로 스크롤의 뒤쪽 템플릿은 존재를 놓칠 수 있다.

2. 템플릿 적용과 즉시 재생 — 매우 양호
   - 템플릿 선택 후 미리보기에서 사진 크롭, 전환, 텍스트 배치가 바로 보인다.
   - 사용자는 설정값이 아니라 완성될 영상의 인상을 기준으로 선택한다.

3. 장면 타임라인 — 양호
   - 장면 썸네일과 초 단위 길이를 한 줄에서 확인하고 선택 장면을 흰 테두리로 표시한다.
   - 선택 상태가 색과 테두리에 의존하므로 스크린리더용 선택 정보가 별도로 필요하다.

4. 장면 문맥 메뉴 — 매우 양호
   - Clip time, TTS, Edit, Delete를 선택한 장면 가까이에 띄워 이동 거리를 줄인다.
   - 삭제가 다른 작업과 같은 시각적 비중이어서 실수 방지 확인이나 위험 색상 구분이 필요하다.

5. 마무리 도구와 다음 단계 — 양호
   - Crop, Text, Stickers 세 가지로 선택지를 제한하고 Next를 강하게 강조한다.
   - 회색 보조문구와 작은 시간 표시는 대비와 글자 크기 검증이 필요하다.

## CARVID 적용 원칙

- 템플릿은 스타일 하나가 아니라 자막 위치·자막 모양·강조색·음악 분위기를 묶은 프리셋으로 동작한다.
- 차량 사진을 카드 배경으로 사용해 실제 결과를 선택 전에 확인한다.
- 추천·신규·레트로·드라이브·판매 분류로 자동차 업무에 맞게 재구성한다.
- 기존 한 화면 데스크톱 편집 구조를 유지하되, 모바일에서는 템플릿 카드가 가로 스크롤로 바뀐다.
- 선택 상태를 화면 표시와 `aria-pressed`에 함께 제공한다.
