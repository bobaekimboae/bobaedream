# 기여 규칙

1. Issue에 변경 목적과 영향을 기록합니다.
2. 작은 브랜치와 Pull Request로 작업합니다.
3. OpenAPI·migration·rollback 문서를 코드와 함께 수정합니다.
4. `make test`와 `make analyse` 결과를 PR에 첨부합니다.
5. 실데이터·시크릿·내부 URL을 fixture, 로그, 화면 캡처에 넣지 않습니다.
6. Published 데이터를 직접 수정하는 변경은 받지 않습니다.

커밋은 Conventional Commits 형식(`feat:`, `fix:`, `docs:`, `test:`, `chore:`)을 사용합니다.
