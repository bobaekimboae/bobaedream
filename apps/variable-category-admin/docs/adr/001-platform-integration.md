# ADR-001 기존 플랫폼 통합

- 상태: 제안
- 기준일: 2026-09-22

## 결정

신규 관리자는 Laravel 13·Filament 5 기반 독립 모듈형 서비스로 개발한다. 기존 매물 시스템은 Source of Truth로 유지하고 읽기 전용 Listing Contract와 Outbox Event로 연결한다.

## 이유

- 기존 관리자 배포와 신규 정책 배포의 장애 범위를 분리한다.
- 레거시 컬럼과 도메인 용어의 결합을 어댑터 한 곳으로 제한한다.
- Shadow Read와 단계적 전환이 가능하다.
- 정책만 즉시 롤백할 수 있다.

## 실서버 통합 전 필수 확인

다음 값은 실제 저장소와 인프라를 조사한 뒤 본 ADR에 추가 승인해야 한다.

- 기존 Laravel/PHP 버전
- 기존 매물 PK와 상태 코드
- 동일 DB 또는 별도 DB 여부
- 검색엔진과 인덱싱 방식
- 인증·SSO 방식
- 배포 플랫폼과 Secret Manager

조사 전에는 신규 시스템이 기존 플랫폼과 같은 Laravel 버전이라고 가정하지 않는다.
