## 이번 실기기 재확인

1. 동처띠 리뷰 작성 초안을 직접 불러와 차량·오너·평점 화면을 다시 확인했다.
2. 별 한 개의 실제 터치 영역은 두 구간으로 나뉘며 0.5점 단위로 입력된다.
3. 기본 필수 평가는 외관·실내·공간·사양·주행감·주행거리/에너지 6개다.
4. 오너를 켜면 출고 시기·구매 도시·차량 가격·연료별 실사용 수치가 추가되고, 끄면 해당 묶음이 사라진다.
5. 목록 카드는 작성자/인증 → 별·점수·총평·연식·보유기간 → 본문 → 3분할 사진 → 날짜·공유·댓글·추천 순이다.
6. 상세는 어두운 헤더/작성자 → 어두운 점수 카드 → 구매 정보 → 본문/사진 → 반응/댓글 순이다.
