# 차량 리뷰 게시판 오류 수정·전수조사 보고서

- 조사일: 2026-10-16
- 기준 화면: 동처띠 안드로이드 차량 평가 등록 화면 실기기 캡처
- 구현 범위: 커뮤니티 진입, 리뷰 목록, 등록, 별점, 오너/비오너, 동력원별 항목, 상세
- 검증 뷰포트: 모바일 390×844, PC 1440×900
- 자동 검증 원본: `results.json`

## 결론

평점 선택 뒤 한국어 코멘트가 보이지 않거나 잘리던 P1 오류를 수정했다. 차량리뷰는 별도 목록 앱이 아니라 기존 보배드림 커뮤니티 안의 `차량리뷰` 독립 데이터 테이블로 이식했다. 전기계열 8개 항목과 내연기관 전용 2개 항목의 0.5~5.0점 100개 상태를 실제 클릭해 문구 노출·색상·잘림을 검사했으며, 등록·상세·삭제까지 포함한 자동 검사 결과는 **PASS 225 / FAIL 0**이다.

## 최종 구조와 디자인 결정

- 커뮤니티의 `자동차뉴스`와 같은 방식으로 `data/boards/vehicle-review.csv`와 `board-vehicle-review.js`를 분리했다. 일반 시나리오 게시글과 리뷰 데이터는 섞이지 않는다.
- 목록은 기존 커뮤니티 탑 메뉴·게시판 프로필 구조 안에서 렌더링하고, 등록·상세 화면은 동일한 리뷰 저장소를 사용한다.
- 동처띠의 노란 CTA·선택색은 그대로 복제하지 않고 에어비앤비식 `#222` 블랙과 흰색 대비로 커스텀했다.
- 별점은 CSS 별이나 문자 `★`를 그리지 않고 초톳 실제 SVG를 사용한다. 도움돼요·댓글·작성은 레딧/치지직, 공유는 오토스카우트, 브랜드 엠블럼은 프로젝트의 오토홈 계열 브랜드 자산을 사용한다.
- 폰 재연결 확인: serial `ed5f279e`, package `com.ss.android.auto`, activity `.drivers.publish.NewPublisherActivityV2`. 재연결 화면은 `../dongchedi-review-audit-1016/60-reconnect-current.png`에 저장했다.

## 반성 및 재발 방지

이전 검사는 “문구가 DOM에 존재한다”는 사실을 통과 기준으로 삼았고, 실제로 사람이 읽을 수 있는지와 한국어 번역 뒤의 폭 변화를 검사하지 않았다. 이것이 가장 큰 잘못이었다. 이번부터는 다음을 고정한다.

1. 선택형 문구는 모든 상태를 실제 클릭한다.
2. `visibility`, `opacity`, 실제 사각형, `scrollWidth/clientWidth`를 함께 검사한다.
3. 중국어·영어 원문 번역은 의미뿐 아니라 목표 폭에서의 한국어 길이를 검증한다.
4. 목록·등록·상세를 별도 화면이 아니라 하나의 진입 흐름으로 검사한다.
5. 모바일 검사 뒤 PC 1440 화면과 깨진 이미지·콘솔 오류를 함께 확인한다.
