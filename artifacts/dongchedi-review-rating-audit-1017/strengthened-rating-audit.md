1. 별 아이콘 중앙만 누르지 않고 별 하나의 좌·우 터치 영역을 각각 눌러 `0.5` 단위 10개 상태를 직접 확인했다.
2. 한두 대표 항목이 아니라 10개 평가 항목의 `0.5~5.0` 전체 조합 100개를 원문 사전과 화면에 각각 대조했다.
3. 화면 문구만 보지 않고 선택 라디오의 `aria-checked`, 숫자 표시, 즉시 피드백 팝오버를 별도로 검사했다.
4. 균일 점수가 아닌 `0.5·1.5·2.5·3.5·4.5·5.0` 조합으로 평균 반올림을 검증했다.
5. 전기차·플러그인 하이브리드·주행거리 연장형·하이브리드·내연기관·출시 예정 전기차를 각각 열어 필수/선택 평가 항목과 실사용 입력 항목을 검사했다.
6. 오너/비오너 전환, 제목·필수 평점·오너 정보·본문 길이의 오류 우선순위를 검사했다.
7. React 작성 화면뿐 아니라 커뮤니티 독립 상세 페이지에 저장된 평가 키·한국어 항목명·문구·숫자가 그대로 이어지는지 검사했다.

## 원본 재확인으로 발견한 오류

이전 기록은 코멘트 구간을 `0.5·1.0·1.5 / 2.0·2.5 / 3.0·3.5 / 4.0·4.5 / 5.0`으로 잘못 묶었다. 원본 앱에서 별의 양쪽 반을 모두 조작한 실제 경계는 다음과 같다.

- 1단계: `0.5`, `1.0`
- 2단계: `1.5`, `2.0`
- 3단계: `2.5`, `3.0`
- 4단계: `3.5`, `4.0`
- 5단계: `4.5`, `5.0`

이 오류 때문에 이전 구현에서는 모든 항목의 `1.5`, `2.5`, `3.5`, `4.5` 문구가 한 단계 낮게 노출됐다. 공용 평점 함수와 커뮤니티 상세 함수를 모두 같은 경계로 수정했다.

추가로 커뮤니티 상세 페이지가 로컬 저장 리뷰의 `exterior`, `fuel` 같은 내부 키를 한국어 평가명으로 변환하지 못하고 일반 상태 문구로 대체할 수 있는 문제를 발견했다. 10개 평가 키를 한국어 이름과 점수별 문구에 연결하고, 종합 점수는 동력방식별 필수 6개 항목만으로 계산하도록 통일했다.
