# 동처띠 차량 리뷰 시스템 전수조사

- 조사일: 2026-10-16
- 조사 기기: POCO 24117RK2CG / Android 16 / 1080×2400
- 대상 앱: 동처띠(懂车帝, `com.ss.android.auto`)
- 수집 방식: USB ADB 화면 캡처 + Android UI 계층(XML) 동시 저장
- 한국형 구현 대상: 보배드림 차량 리뷰 등록·목록·상세

## 1. 핵심 원칙

1. 중국어 원문은 검증 근거로 그대로 보존한다.
2. 서비스 노출 문구는 직역하지 않고 국내 자동차 사용자에게 자연스럽게 다듬는다.
3. 차량의 동력원과 오너 여부를 독립된 가변 축으로 처리한다.
4. 확인하지 못한 상태는 추정으로 구현하지 않는다.
5. 외부 동처띠 서비스에는 테스트 글을 등록하지 않는다. 보배드림 로컬 테스트 글만 생성·삭제한다.

## 3. 동력원별 평가항목

| 동력원 | 표본 | 필수 6개 | 선택 2개 | 오너 실사용 입력 |
|---|---|---|---|---|
| 순수 전기(EV) | 长安启源A06 | 외관, 실내, 공간, 사양, 주행감, 주행거리·전비 | 주행보조, 스마트 콕핏 | 실주행거리(km) |
| 플러그인 하이브리드(PHEV) | 秦PLUS DM-i | 외관, 실내, 공간, 사양, 주행감, 주행거리·전비 | 주행보조, 스마트 콕핏 | 순수 전기 주행거리(km) |
| 주행거리 연장형(EREV) | 问界M7 增程 | 외관, 실내, 공간, 사양, 주행감, 주행거리·전비 | 주행보조, 스마트 콕핏 | 실주행거리(km) |
| 일반 하이브리드(HEV) | 凯美瑞 双擎 | 외관, 실내, 공간, 사양, 동력·핸들링, 연비 | 없음 | 차량 연비(L/100km 원본, 국내판 km/L) |
| 내연기관(ICE) | 迈腾 280TSI | 외관, 실내, 공간, 사양, 동력·핸들링, 연비 | 없음 | 차량 연비(L/100km 원본, 국내판 km/L) |

### 확인된 중요 차이

- PHEV는 일반 HEV와 같은 “하이브리드”로 합치면 안 된다. 평가항목은 EV 계열이고 오너 입력은 “순수 전기 주행거리”다.
- 일반 HEV는 ICE 계열과 같은 평가항목을 사용하며 오너 입력은 연비다.
- EREV는 EV/PHEV 계열 평가항목을 사용하지만 오너 입력 라벨은 “순수 전기 주행거리”가 아닌 “실주행거리”다.
- EV·PHEV·EREV의 주행보조·스마트 콕핏은 선택 평가라서 종합점수의 필수 검증과 분리한다.
- 동일 차급 비교 점수는 차종에 따라 조건부 노출된다.

## 4. 오너·비오너 가변 요소

| 상태 | 노출 요소 | 필수값 | 등록 결과 표식 |
|---|---|---|---|
| 비오너 | 차량·별점·서술·사진 | 필수 별점 6개, 서술 30자 | 일반 리뷰 |
| 오너 | 비오너 항목 + 출고시기·구매지역·차량가격·연료별 실사용 수치 | 오너 추가 필드 필수, 착지가격은 원본에서 선택 | 실소유자 리뷰 |
| 미출시 모델 | 오너 선택 숨김 | 시승/평가 근거 사진 요구 | 시승·평가 리뷰 |

오너 ON/OFF 자체는 같은 동력원 안에서 평가항목을 바꾸지 않는다. 평가항목의 변화는 동력원 축에서 발생하고, 오너 축은 구매정보와 실사용 수치, 인증 표식을 바꾼다.

## 5. 별점 코멘트 체계

- 점수: 0.5~5.0, 0.5점 간격
- 평가항목 유형: 10개
- 점수 매핑: 100개
- 항목별 코멘트 상태: 50개(0.5/1.0, 1.5/2.0, 2.5/3.0, 3.5/4.0, 4.5/5.0이 같은 문구 그룹)
- 중국어 고유 문구: 47개
- 전체 원문·직역·한국형 표현은 Google Sheet `동처띠 차량 리뷰 별점 사전`에 저장

한국형 표현 예시:

| 항목 | 중국어 원문 | 직역 | 실제 노출 문구 |
|---|---|---|---|
| 외관 0.5~1.0 | 奇丑无比 | 매우 못생김 | 디자인이 너무 아쉬워요 |
| 연비 0.5~1.0 | 吞油黑洞 | 기름을 삼키는 블랙홀 | 연료비 부담이 매우 커요 |
| 동력 4.5~5.0 | 人车合一 | 사람과 차가 하나 | 차와 하나가 되는 주행감이에요 |
| 주행거리 1.5~2.0 | 有些焦虑 | 약간 불안함 | 충전과 주행거리 부담이 있어요 |

## 7. 보배드림 구현 매핑

- 차량 엠블럼: 기존 오토홈 기반 브랜드 에셋 재사용
- 별점: 0.5점 터치 영역 10개, 시각적으로 5개 별
- 코멘트: 별점 변경 즉시 한국형 표현 노출, 원문은 검수용 보조 텍스트
- 모델 프로필: EV/PHEV/EREV/HEV/ICE 5종
- 오너 필드: 동력원별 단위와 라벨을 별도 데이터로 관리
- 저장: 데모에서는 브라우저 로컬 저장소 사용
- 목록: 동력원 필터, 실소유자 표식, 종합점수, 본문 미리보기
- 목록 탐색: 전체·최신·낮은 평가·도움순, 실소유자만 보기, 평가항목 태그, 결과 없음 상태
- 상세: 동처띠의 어두운 점수 카드 구조, 항목별 점수·코멘트·막대, 오너 정보, 도움돼요·댓글·공유
- 첨부: JPG·PNG·WebP 대표 사진 1장, 4MB 제한, 미리보기와 삭제
- 상세 상호작용: 구독 토글, 도움됨 토글, 댓글 열기·로컬 작성, 현재 상세 주소 복사
- 직접 진입: `tab=reviews`, `review=write`, `review={리뷰 ID}` 쿼리로 목록·등록·상세 상태 복원
- 테스트 삭제: 로컬에서 작성한 리뷰에만 삭제 버튼 노출
