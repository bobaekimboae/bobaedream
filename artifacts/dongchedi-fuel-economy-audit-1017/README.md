# 동처띠(懂车帝) 연비·전비 등록 화면 조사

조사일: 2026-10-17

기기: POCO / Android 16 / USB 개발자 모드

앱: `com.ss.android.auto`

## 정확한 진입 경로

홈 우측 상단 `+` → `发动态`(게시물 작성) → 작성 유형 가로 목록을 끝까지 이동 → `能耗`(에너지 소비).

초기 화면에는 `完成车型选择后，下方自动展示油耗/续航填写框`(차량을 선택하면 아래에 연비/주행거리 입력란이 자동 표시됩니다)라는 안내가 나오며, `绑定车型*`(차량 연결)이 필수다. 이미지 영역은 `添加能耗图片`(에너지 사용 사진 추가), 제목은 `添加标题更容易被推荐（选填）`(제목을 넣으면 더 추천되기 쉬움, 선택)로 표시된다.

## 검증된 가변 항목

| 조건 | 실차로 확인한 모델 | 표시 항목 |
|---|---|---|
| 내연기관 | BMW 2시리즈 2026 M235L | 지역*, 현재 총주행거리(km), 평균 연비(L/100km) |
| 전기차 | BMW i3 2026 eDrive40L | 지역*, 현재 총주행거리(km), 평균 전비(kWh/100km), 완충 실주행거리(km) |
| 플러그인 하이브리드 | BYD Qin PLUS DM 2026 DM-i 210KM | 지역*, 현재 총주행거리(km), 평균 전비(kWh/100km), 평균 연비(L/100km) |
| 일반 하이브리드 | 국내 서비스 규칙 | 지역*, 현재 총주행거리(km), 평균 연비(L/100km) |

수치 형식은 주행거리와 완충 주행거리는 정수, 평균 연비·전비는 소수점 한 자리로 구현했다. 게시물은 차량 리뷰와 다른 `bobae-fuel-economy-posts-v1` 저장소와 `fuel-economy` 독립 테이블을 사용한다.

## 원본 캡처 대응표

- `12-energy-writer.png`: 차량 선택 전 등록 화면
- `29-ice-form-loaded.png`: 내연기관 가변 입력란
- `49-ev-form-top.png`: 전기차 가변 입력란
- `60-phev-form-loaded.png`: 플러그인 하이브리드 가변 입력란

그 외 `09`~`60` 캡처는 진입, 차량 검색, 트림 선택, 뒤로 가기와 재선택 흐름을 시간순으로 보존한다. 조사 과정에서는 외부 게시물을 등록하지 않았다.

## 한국어 적용 원칙

- `能耗`는 사용자가 즉시 이해하도록 `연비·전비`로 표기한다.
- 중국식 `百公里油耗/电耗` 단위는 원본과 같은 `L/100km`, `kWh/100km`를 유지한다.
- 본문 안내는 도시/고속도로 비율, 날씨, 공조, 충전 주기·비용을 적도록 한국 운전 문화에 맞게 정리한다.
- 동처띠 노란색은 보배드림의 에어비앤비형 검정 활성 상태로 바꾸고, 아이콘은 기존 Reddit·Chợ Tốt·AutoScout24 자산만 사용한다.

## 구현·검수 시나리오

1. 독립 게시판 선택과 20개 테스트 기록 노출.
2. 전기차/플러그인/하이브리드/내연기관 필터.
3. 글쓰기 진입 후 차량 선택 전 필드 비노출.
4. 동력 방식 변경 때 입력 필드 재구성 및 기존 수치 초기화 경고.
5. 필수값 누락, 본문 20자 미만, 사진 4MB 초과 오류.
6. 정상 등록 → 독립 저장소 저장 → 상세 페이지 이동.
7. 상세 수치, 사진, 댓글 입력, 저장·도움·공유 동작.
8. 390×844 모바일과 1440×900 PC에서 레이아웃, 이미지, 콘솔 오류 검사.
